Open Source · Selbst gehostet · Docker-ready

Alle Ihre Backups. Ein Dashboard.

Schluss mit dem einzelnen Anmelden an jeder Duplicati-Weboberfläche. duplistatus überwacht jeden Server und Auftrag auf einem einzigen Bildschirm – damit Sie wissen, dass Ihre Sicherungen in Ordnung sind, bevor Sie ein Datenverlust unvorbereitet trifft.

duplistatus verwendet das integrierte HTTP-Reporting von Duplicati, sodass auf Ihren Backup-Rechnern nichts installiert werden muss.

duplistatus installieren Dashboard ansehen
Multi-Server-Überwachung ntfy- & E-Mail-Benachrichtigungen Standardmäßig sicher, zusätzlicher Schutz bei Bedarf

Die einzige Frage, auf die es ankommt

Sind alle meine Sicherungen in Ordnung? Ein einziger Bildschirm liefert die Antwort – über jeden Server, jeden Job und jede Ausführung hinweg.

localhost:9666

Entwickelt für alle, die Duplicati auf mehreren Rechnern ausführen

Ganz gleich, ob Sie ein NAS, einen Laptop, einen VPS oder zwei Heimserver betreiben: duplistatus zeigt sie alle auf einem Bildschirm.

01

Jede Sicherung auf einen Blick

Eine Karte pro Server zeigt die letzten 10 Ausführungen jedes Jobs. Wechseln Sie zu einer sortierbaren Tabelle, wenn Sie viele Server haben, und öffnen Sie eine beliebige Ausführung, um das vollständige Protokoll einschließlich Warnungen und Fehlern zu lesen.

  • Gesamtsummen für Server, Jobs, Ausführungen, Größe und Speicher
  • Automatisch aktualisierendes Dashboard für eine Videowand-Erfahrung
  • Versionsprüfung des Duplicati-Servers anhand des neuesten GitHub-Releases

02

Probleme erkennen, bevor es zu Datenverlust kommt

duplistatus erkennt überfällige, warnende und fehlgeschlagene Sicherungen automatisch und benachrichtigt Sie per ntfy-Push oder SMTP-E-Mail.

  • Prüfungen auf Überfälligkeit laufen standardmäßig regelmäßig
  • Erhalten Sie Benachrichtigungen für jeden Job mit Filtern pro Job: Aus, Alle, Warnungen oder Fehler
  • Reduzieren Sie die Benachrichtigungsflut mit der E-Mail zur täglichen Zusammenfassung.

03

Probleme zuverlässig beheben

Öffnen Sie eine beliebige Ausführung, um deren Protokoll mit Warnungen und Fehlern zu lesen und zu sehen, welche Wiederherstellungspunkte verfügbar sind. Diagramme für Dauer, Größe und Speicher stehen zur Verfügung, wenn Sie mehr Details wünschen.

  • Automatische Protokollerfassung von Ihren Duplicati-Servern
  • Verfügbare Versionen für jede Ausführung angezeigt
  • Diagramme für Dauer, Größe und Speicher

In vier Schritten von null zur Überwachung

Dank containerisierter Bereitstellung sind Sie in wenigen Minuten startklar – nicht erst nach Stunden.

Schritt 1

Den Container bereitstellen

Laden Sie das Image von Docker Hub oder GitHub herunter, stellen Sie Ihre Zeitzone ein und binden Sie ein Daten-Volume ein. Die Web-UI lauscht auf Port 9666. Schema-Migrationen werden beim Start automatisch angewendet.

Erste Schritte
Installationsanleitung
Schritt 2

Duplicati auf duplistatus ausrichten

Konfigurieren Sie jeden Duplicati-Server so, dass JSON-Berichte per POST an /api/upload gesendet werden. Sammeln Sie anschließend historische Protokolle, damit Überwachungsintervalle automatisch ausgefüllt werden. 

--send-http-json-urls=http://host:9666/api/upload
--send-http-log-level=Information
--send-http-max-log-lines=500

Benachrichtigungen konfigurieren

Konfigurieren Sie die E-Mail-Server-Einstellungen, um E-Mails von duplistatus zu erhalten.

Benachrichtigungseinstellungen
Schritt 4

Lassen Sie duplistatus Ihre Backups überwachen

duplistatus übernimmt die Überwachung. Wenn eine Sicherung überfällig ist oder mit Warnungen oder Fehlern abschließt, erhalten Sie eine Benachrichtigung oder E-Mail.
Für zusätzliche Sicherheit aktivieren Sie die optionale Tägliche Zusammenfassung: Sie erhalten sie täglich, selbst wenn alles in Ordnung ist.

Benutzerhandbuch

Standardmäßig sicher. Fügen Sie mehr Schutz hinzu, wenn Sie ihn benötigen.

Die Anmeldung ist ab dem ersten Start an, sodass ein privates Homelab direkt nach der Installation geschützt ist. Fügen Sie API-Schlüssel und IP-Zulassungslisten hinzu, wenn Sie es für das Internet freigeben.

Anmeldung mit Rollen

Melden Sie sich als Admin oder Benutzer an. Schränken Sie ein, welche Server die einzelnen Benutzer sehen können.

API-Schlüssel

Separate Schlüssel für Duplicati-Uploads und für schreibgeschützte Dashboards oder Widgets mit Begrenzungen für Upload-Größe und Rate Limits.

IP-Zulassungslisten

Zwei unabhängige Zulassungslisten: eine für das Administrationsinterface, eine für externe APIs. Sie schützen vor gefälschten Client-IPs, wenn duplistatus hinter einem Reverse Proxy läuft.

CSRF-Schutz

Sitzungsbasierte Routen sind vor Cross-Site-Request-Forgery geschützt.

Audit-Protokollierung

Jede Konfigurationsänderung und Benutzeraktion wird protokolliert. Filtern, exportieren und festlegen, wie lange Einträge aufbewahrt werden.

Anwendungsprotokolle

Ein Nur-Admin-Viewer ermöglicht das Suchen, Filtern und Exportieren von Anwendungsprotokollen mit Live-Aktualisierungen.

Für das Internet freigeben? Betreiben Sie es hinter einem Reverse Proxy mit HTTPS. Lesen Sie die Anleitung

In wenigen Minuten loslegen

Pullen Sie das Image, binden Sie ein Datenvolume ein und öffnen Sie Port 9666. 

# download the compose file
wget https://github.com/wsj-br/duplistatus/raw/refs/heads/master/production.yml -O duplistatus.yml
# start the container
docker compose -f duplistatus.yml up -d
# duplistatus production compose.yml
services:
  duplistatus:
    image: ghcr.io/wsj-br/duplistatus:latest
    container_name: duplistatus
    restart: unless-stopped
    environment:
      - TZ=Europe/London
      - PWD_ENFORCE=true
      - PWD_MIN_LEN=8
    ports:
      - "9666:9666"
    volumes:
      - duplistatus_data:/app/data
    networks:
      - duplistatus_network

networks:
  duplistatus_network:
    driver: bridge

volumes:
  duplistatus_data:
    name: duplistatus_data
# Create the volume
docker volume create duplistatus_data

# Start the container
docker run -d \
  --name duplistatus \
  -p 9666:9666 \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -v duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest
mkdir -p ~/duplistatus_data
# Start the container (standalone)
podman run -d \
  --name duplistatus \
  --userns=keep-id \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -p 9666:9666 \
  -v ~/duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest

Nachdem der Container gestartet wurde:

  1. 1 Öffnen Sie http://localhost:9666 in Ihrem Browser
  2. 2 Melden Sie sich mit dem Standard-Admin-Konto an. Sie werden beim ersten Anmelden aufgefordert, das Standard-Admin-Passwort zu ändern.
  3. 3 Verbinden Sie Ihre Duplicati-Server gemäß diesen Anweisungen und verwenden Sie dann Backup-Protokolle sammeln, um den Verlauf zu importieren
  4. 4 Im Internet freigeben? Fügen Sie mehr Schutz hinzu, indem Sie API-Schlüssel und IP-Zulassungslisten aktivieren und die Anwendung hinter einen Reverse-Proxy mit HTTPS schalten.
