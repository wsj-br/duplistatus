版本 1.4.1

概述​

版本 1.4.1 对仪表板体验进行了重大改进，包括内联图表控件、增强的过滤功能、系统主题支持和区域格式化选项。此版本还解决了影响图表渲染、备份详细信息加载和服务器连接检测的多个错误。此外，依赖项中的安全漏洞也已解决。

新功能​

内联图表控件​

  • 图表时间范围选择器：图表面板标题中的股票图表式胶囊按钮 (1W | 2W | 1M | 3M)，可快速切换时间范围，无需导航到显示设置。与显示设置共享状态。
  • 图表样式切换（问题 #54）：切换按钮，可直接从图表面板标题在折线图和柱状图之间切换。在所有面板间保持并同步。
  • 简化的时间范围：从 7 个选项减少到 4 个专注范围（1 周、2 周、1 个月、3 个月），其中 1 个月为新默认值。

显示和格式化选项​

  • 系统主题支持：显示设置现在包含"系统 (跟随操作系统)"选项，以自动匹配您的操作系统的浅色/深色偏好。
  • 格式区域覆盖（问题 #59）：用户可以在设置 > 显示设置中独立于界面语言选择格式化区域（支持 416 个区域）。日期、时间和数字格式遵循所选的格式区域，并提供实时预览。

服务器过滤​

  • 仪表板服务器过滤器：搜索字段移至应用标题栏，具有自动刷新和工具栏操作。空时仅显示搜索图标；悬停/单击展开文本字段。
  • 改进的过滤匹配（问题 #53）：过滤器现在匹配服务器 ID、URL 和任何备份作业名称。修复了过滤器更改时概览卡片网格不更新的问题。
  • 设置过滤：在设置 > 备份监控和设置 > 服务器中的服务器列表添加了过滤输入。

改进​

图表数据处理​

  • 滚动时间窗口：时间范围现在使用滚动天数窗口：1W = 最近 7 天，2W = 最近 14 天，1M = 最近 30 天，3M = 最近 90 天（以前基于日历）。
  • 数据整合：所有图表数据点在分桶之前按日历日整合。同一天的多个备份被适当地聚合。
  • 限制数据点：图表现在强制执行最多 30 个数据点，以获得更好的性能和可读性。
  • 工具提示简化：工具提示现在只显示日期（例如"5/12/26"），而不是日期和时间。

备份调度​

  • 基于 UTC 的计算：下次预期备份和超期检测现在在 UTC 中推进间隔和工作日检查，而不是本地时间，避免主机时区跨越夏令时时的一小时 UTC 偏移。
  • 增加超期容忍度：新安装和默认值现在使用 2 小时而不是 1 小时作为超期容忍度。

连接性和可靠性​

  • 连接丢失检测：添加了 /api/ping 端点和 30 秒基于标题的连接探测。刷新和自动刷新失败现在会打开连接丢失模态框，而不显示原始错误文本。
  • UI 偏好持久化：修复了导致用户 UI 偏好（概览侧边面板、图表时间范围、图表样式）在页面刷新时不持久化的竞争条件。

文档​

  • Duplicati 远程访问说明（问题 #40）：文档现在明确说明 Duplicati 远程访问是可选的，只有在需要直接链接到 Duplicati UI 时才必要。

错误修复​

  • 概览图表面板忽略时间范围过滤器：修复了面板显示所有数据点而不考虑所选时间范围的问题。面板现在使用正确的时间范围参数从 API 获取自己的数据。
  • 备份详情的 OOM 崩溃（问题 #62）：通过优化查询和 UI 渲染防止了 JavaScript heap out of memory。备份日志现在按需获取而不是一次性全部加载，最多 1000 行。
  • 备份版本解析（问题 #65）：convertTimestampToISO() 现在处理 Duplicati 在不同系统区域设置中使用的所有常见特定于区域的时间戳格式。

安全性​

依赖项漏洞修复​

  • npm audit 漏洞：解决了 7 个漏洞（1 个高危，6 个中等）：

    • 更新 next 到 16.3.0-canary.19 以修复 postcss@8.4.31（XSS）
    • 添加 .pnpmfile.cjs 以强制 serialize-javascript@^7.0.5（RCE、DoS）
    • 更新 mermaid 覆盖到 >=11.14.1（4 个中等漏洞）
    • 添加明确的 postcss@^8.5.14 和 serialize-javascript@^7.0.5 依赖项

  • pnpm 覆盖：为传递依赖 uuid >=14.0.0 和 postcss >=8.5.10 添加根 pnpm.overrides。

  • 高危漏洞：通过 pnpm 覆盖修复了 minimatch >=3.1.4 和 serialize-javascript >=7.0.3 的 4 个高危漏洞。

迁移说明​

从版本 1.3.2​

升级到版本 1.4.1 时：

  1. 无需数据库迁移：此版本不需要任何数据库架构更改。
  2. 新的默认逾期容差：新安装将默认使用 2 小时逾期容差而不是 1 小时。现有设置保持不变。
  3. 图表首选项：图表时间范围和样式首选项现在存储方式不同，升级后将重置为默认值（1 个月，线图）。
  4. 依赖项：运行 pnpm install 以应用更新的锁定文件和覆盖。

更新日志​

版本 1.4.1 更改​

  • 新增：在图表面板标题中添加内联图表时间范围选择器，带有药丸按钮（1W、2W、1M、3M）。
  • 新增：内联图表样式切换，可在图表面板标题中在线图和条形图之间切换（问题 #54）。
  • 新增：在显示设置中添加图表样式设置（平滑线/条形图切换）。
  • 新增：主题“系统（跟随操作系统）”选项，可自动匹配操作系统偏好。
  • 新增：格式区域覆盖（问题 #59）——独立于界面语言选择格式化区域（支持 416 个区域）。
  • 新增：服务器过滤（问题 #53），在设置 > 备份监控、设置 > 服务器和主仪表板中。
  • 新增：连接丢失检测，使用 /api/ping 和 30 秒基于头部的探测。
  • 更改：图表时间范围选项从 7 个减少到 4 个（1W、2W、1M、3M），默认现在是 1 个月。
  • 更改：时间范围计算现在使用滚动天窗口（1W = 最近 7 天等）。
  • 更改：图表数据在分桶之前按日历日合并；强制执行最大 30 个数据点。
  • 更改：图表工具提示现在只显示日期而不是日期和时间。
  • 更改：新安装的默认逾期容差从 1 小时更改为 2 小时。
  • 更改：下次预期备份计算现在使用 UTC 以避免夏令时漂移问题。
  • 更改：仪表板服务器过滤器移动到应用程序头部并启用自动刷新。
  • 修复：用户界面首选项在页面刷新时不持久化。
  • 修复：概览图表面板忽略时间范围过滤器。
  • 已修复：备份详情中的内存溢出崩溃（问题 #62）——日志现在按需获取，限制为 1000 行。
  • 已修复：针对特定区域设置的时间戳格式的备份版本解析（问题 #65）。
  • 安全性：通过依赖项更新和 pnpm 覆盖解决了 7 个 npm 审计漏洞。
  • 安全性：修复了 minimatch 和 serialize-javascript 中的高严重性漏洞。
