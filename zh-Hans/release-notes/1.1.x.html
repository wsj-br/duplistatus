版本 1.1.x

概述​

版本 1.1.x 是一个次要发布版本，解决了过期备份检测的关键问题，改进了 Podman 容器兼容性，并引入了容器架构改进。此版本专注于修复过期备份检测准确性并解决 Podman 环境中的网络问题。

新功能​

用户界面增强​

  • 自动刷新按钮右键上下文菜单 - 在应用程序工具栏中右键单击自动刷新按钮会打开显示设置页面，以便快速访问显示首选项
  • 改进的收集备份模态框 - 当选择服务器时，密码字段标签现在清楚地指示"（仅当密码更改时填写）"，使用户更清楚何时需要该字段

文档改进​

  • 文档托管迁移 - 文档已从 Docker 容器镜像迁移到 GitHub Pages，地址为 https://wsj-br.github.io/duplistatus/user-guide/overview，以提高可访问性和更轻松的更新
  • 应用程序标题中的用户指南链接现在指向外部文档站点

🐛 错误修复​

关键：过期备份检测 - 完全重新实现​

  • 修复过期备份检测 - 使用新算法完全重新实现了过期备份检测系统，该算法正确跟踪预期备份日期：
    • 算法确保手动备份不会改变计划备份时间（例如，晚上 10 点的手动备份不会改变下午 2 点的计划）
    • 修复备份监控设置中的"下次运行"列显示不正确日期的问题
    • 通过 /api/upload 或 /api/backups/collect 接收备份后，备份设置现在立即更新
    • 对于没有 Duplicati 同步的新服务器，使用第一个备份的时间作为计划参考
    • 有关更多详细信息，请参阅过期检测算法文档

Podman 容器修复​

  • 修复 Podman pod 网络 - 解决了在 Podman pods 中运行时阻止外部访问应用程序的问题。服务器现在在 Podman pod 和独立容器模式下都正确绑定到所有接口 (0.0.0.0:9666)
  • 修复 Tailscale 主机名的 DNS 解析 - 解决了 Podman 容器中的 DNS 解析问题，该问题阻止连接到 Tailscale 主机名或自定义 DNS 服务器。已在安装文档中添加说明。

邮件配置修复​

  • 修复 SMTP 空用户名/密码处理 - 解决了在邮件配置中清除用户名或密码字段仍会在数据库中存储加密值的问题。空字段现在正确存储为空字符串，可以正确清除

系统改进​

  • 减少控制台日志记录 - AuditLogger 现在只将失败的登录尝试记录到控制台；所有其他审计条目仅写入数据库

🚀 迁移说明​

从版本 1.0.x 升级​

升级到版本 1.1.0 时：

  1. 文档位置变更 - 文档现在托管在 GitHub Pages 上，而不是包含在 Docker 容器中。应用程序标题中的用户指南链接现在指向外部文档站点

  2. Podman 容器配置 - 如果使用 Podman pods，请确保使用 --dns 和 --dns-search 标志在 pod 级别设置 DNS 配置。应用程序现在在 Podman pods 和独立容器中都能正常工作

  3. 过期备份检测 - 过期备份检测系统已使用保留计划时间的新算法完全重新实现。现有的备份监控配置将继续工作，但您可能会注意到备份监控设置中更准确的"下次运行"日期。新算法确保手动备份不会移动计划的备份时间

  4. 无需数据库迁移 - 此版本不需要任何数据库架构更改

API 端点​

此版本中未添加新的 API 端点。所有现有端点保持不变。

报告错误​

报告错误时，请包含以下信息：

  • 版本：1.1.x（指定确切版本，例如 1.1.0）
  • 操作系统及版本
  • Docker/podman 版本
  • 容器类型（Docker 或 podman/Pod）
  • 错误消息和日志
  • 复现步骤
  • Podman 配置详情（如果在 podman/Pod 中运行）

更新日志​

版本 1.1.0 变更​

  • 新增：在自动刷新按钮上右键单击上下文菜单以打开显示设置
  • 新增：改进收集备份模态框中的密码字段标签
  • 变更：从 Docker 容器镜像中移除文档（现在托管在 GitHub Pages 上）
  • 变更：更新应用头部的用户指南链接指向 GitHub Pages 文档
  • 变更：减少 AuditLogger 的控制台日志记录（仅将失败的登录尝试记录到控制台）
  • 修复：通过正确实现预期备份日期跟踪来修复关键过期备份检测（详见 过期检测算法）
  • 修复：Podman pod 网络问题导致无法外部访问
  • 修复：Podman 容器中 Tailscale 主机名的 DNS 解析
  • 修复：SMTP 配置为用户名和密码字段为空时存储加密值
  • 修复：备份监控设置中的"下次运行"列显示不正确的日期
