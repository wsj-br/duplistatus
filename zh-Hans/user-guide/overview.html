概述

欢迎使用 duplistatus 用户指南。本综合文档提供了使用 duplistatus 监控和管理跨多个服务器的 Duplicati 备份操作的详细说明。

什么是 duplistatus？​

duplistatus 是一个专为 Duplicati 备份系统设计的强大监控仪表板。它提供：

  • 从单个界面集中监控多个 Duplicati 服务器
  • 实时跟踪所有备份操作的状态
  • 具有可配置警报的自动过期备份检测
  • 备份性能的综合指标和可视化
  • 通过 NTFY 和电子邮件提供灵活的通知系统
  • 可选的安全配置功能
  • 多语言支持（英语、法语、德语、西班牙语、巴西葡萄牙语、印地语和简体中文）。

安装​

有关先决条件和详细安装说明，请参阅安装指南。

访问仪表板​

成功安装后，按照以下步骤访问 duplistatus Web 界面：

  1. 打开您首选的网页浏览器
  2. 导航到 http://your-server-ip:9666
    • 将 your-server-ip 替换为您的 duplistatus 服务器的实际 IP 地址或主机名
    • 默认端口为 9666
  3. 您将看到登录页面。

首次使用时（或从预 0.9.x 版本升级后）使用这些凭据：

  • 用户名：admin
  • 密码：Duplistatus09

在右上角选择用户界面语言 ，或在登录后在 中选择（见下文）。

  1. 登录后，主仪表板将自动显示（首次使用时无数据）

用户界面概述​

duplistatus 提供了一个直观的仪表板，用于监控整个基础架构中的 Duplicati 备份操作。

用户界面组织为几个关键部分，以提供清晰全面的监控体验：

  1. 应用程序工具栏：快速访问基本功能和配置
  2. 仪表板摘要：所有受监控服务器的概览统计信息
  3. 服务器概述：卡片布局或表格布局，显示所有备份的最新状态，包括从上次收到的备份日志中获取的Duplicati 服务器版本
  4. 过期详情：鼠标悬停时显示过期备份的视觉警告和详细信息
  5. 可用备份版本：点击蓝色图标查看目标位置可用的备份版本
  6. 备份指标：交互式图表显示随时间变化的备份性能
  7. 服务器详情：特定服务器记录备份的全面列表，包括详细统计数据
  8. 备份详情：单个备份的深入信息，包括执行日志、警告和错误

应用程序工具栏​

应用程序工具栏提供了对关键功能和设置的便捷访问，组织有序，便于高效工作流程。

按钮描述
  筛选按 ID、URL 或备份作业名称搜索和筛选服务器。
  刷新屏幕立即手动刷新所有数据
启用或禁用自动刷新功能。在显示设置中配置
右键单击 打开显示设置页面
  打开 NTFY访问 ntfy.sh 网站以查看您配置的通知主题。
右键单击 显示二维码，以配置您的设备接收来自 duplistatus 的通知。
  Duplicati 配置打开所选 Duplicati 服务器的 Web 界面
右键单击 在新标签页中打开 Duplicati 旧版 UI (/ngax)
  收集日志连接到 Duplicati 服务器并检索备份日志
右键单击 收集所有已配置服务器的日志
  投递失败当电子邮件或 ntfy 投递失败时向管理员显示。如果没有记录任何失败，该按钮将被隐藏。请参阅投递失败。
  设置配置通知、监控、SMTP 服务器和通知模板
显示已连接的用户、用户类型（Admin、User），单击可打开用户菜单（包含语言选择）。在用户管理中查看更多信息
  用户指南打开用户指南并跳转到与您当前查看的页面相关的部分。工具提示会显示"[页面名称]的帮助"，以指示将打开哪篇文档。

用户菜单​

点击用户按钮会打开一个下拉菜单，其中包含特定于用户的选项。菜单选项根据您是以管理员还是普通用户身份登录而有所不同。两个角色都可以通过 语言 子菜单更改界面语言。所选语言在此浏览器上按用户保存（不是系统范围设置），因此不同账户可以保持不同的语言。支持的语言：英语、法语、德语、西班牙语、巴西葡萄牙语、印地语和简体中文。

基本配置​

  1. 配置您的 Duplicati 服务器 向 duplistatus 发送备份日志消息（必需）。
  2. 收集初始备份日志 - 使用 收集备份日志 功能从所有 Duplicati 服务器中填充历史备份数据到数据库。这也会根据每个服务器的配置自动更新备份监控间隔。
  3. 配置服务器设置 - 在 设置 → 服务器 中设置服务器别名和注释，使您的仪表板更具信息性。
  4. 配置 NTFY 设置 - 在 设置 → NTFY 中通过 NTFY 设置通知。
  5. 配置电子邮件设置 - 在 设置 → 电子邮件 中设置电子邮件通知。
  6. 配置备份通知 - 在 设置 → 备份通知 中设置每个备份或每个服务器的通知。
  7. 可选地限制访问 - 如果您想保护 /api/upload 和管理界面，请创建 API 密钥 和/或 IP 白名单。默认情况下两者都处于关闭状态。

重要

请记住按照 Duplicati 配置 部分中的说明配置 Duplicati 服务器向 duplistatus 发送备份日志。
