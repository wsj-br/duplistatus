आपके सभी बैकअप। एक डैशबोर्ड।

प्रत्येक Duplicati वेब इंटरफ़ेस में एक-एक करके लॉग इन करना बंद करें। duplistatus एक ही स्क्रीन से प्रत्येक सर्वर और जॉब की निगरानी करता है — ताकि डेटा हानि से पहले ही आपको पता चल सके कि आपके बैकअप ठीक हैं।

duplistatus, Duplicati की इन-बिल्ट HTTP रिपोर्टिंग का उपयोग करता है, इसलिए आपकी बैकअप मशीनों पर कुछ भी इंस्टॉल करने की आवश्यकता नहीं है।

duplistatus इंस्टॉल करें डैशबोर्ड देखें
मल्टी-सर्वर निगरानी ntfy और ईमेल अलर्ट डिफ़ॉल्ट रूप से सुरक्षित, आवश्यकता होने पर अतिरिक्त सुरक्षा

एकमात्र सवाल जो मायने रखता है

क्या मेरे सभी बैकअप ठीक हैं? एक ही स्क्रीन हर सर्वर, हर जॉब और हर रन में इसका उत्तर देती है।

localhost:9666

उन लोगों के लिए निर्मित जो एक से अधिक मशीनों पर Duplicati चलाते हैं

चाहे आप NAS, लैपटॉप, VPS या दो होम सर्वर चलाते हों, duplistatus उन सभी को एक स्क्रीन पर दिखाता है।

01

एक नज़र में प्रत्येक बैकअप देखें

प्रति सर्वर एक कार्ड प्रत्येक जॉब के पिछले 10 रन दिखाता है। जब आपके पास कई सर्वर हों, तो सॉर्ट करने योग्य तालिका पर स्विच करें, और चेतावनियों और त्रुटियों सहित इसका पूरा लॉग पढ़ने के लिए किसी भी रन को खोलें।

  • सर्वर, जॉब्स, रन, आकार और संग्रहण के लिए कुल योग
  • वीडियो वॉल अनुभव के लिए ऑटो-रिफ्रेशिंग डैशबोर्ड
  • नवीनतम GitHub रिलीज़ के विरुद्ध Duplicati सर्वर संस्करण जांचें
डैशबोर्ड गाइड पढ़ें
02

डेटा हानि बनने से पहले ही समस्याओं का पता लगाएं

duplistatus अतिदेय, चेतावनी और विफल बैकअप का स्वचालित रूप से पता लगाता है और ntfy पुश या SMTP ईमेल द्वारा आपको सचेत करता है।

  • अतिदेय जांचें डिफ़ॉल्ट रूप से समय-समय पर चलती हैं
  • प्रति-जॉब फ़िल्टर के साथ प्रत्येक जॉब के लिए सूचनाएं प्राप्त करें: बंद, सभी, चेतावनियाँ या त्रुटियाँ
  • दैनिक सारांश ईमेल के साथ सूचनाओं के शोर को कम करें।
बैकअप निगरानी के बारे में पढ़ें
03

आत्मविश्वास के साथ समस्या निवारण करें

चेतावनियों और त्रुटियों के साथ इसका लॉग पढ़ने के लिए किसी भी रन को खोलें, और देखें कि कौन से रिकवरी पॉइंट उपलब्ध हैं। जब आप अधिक विवरण चाहते हैं तो अवधि, आकार और संग्रहण के लिए चार्ट मौजूद हैं।

  • आपके Duplicati सर्वर से स्वचालित लॉग संग्रह
  • प्रत्येक रन के लिए उपलब्ध संस्करण दिखाए गए हैं
  • अवधि, आकार और संग्रहण के लिए चार्ट
बैकअप विवरण के बारे में पढ़ें

शून्य से निगरानी तक चार चरणों में

कंटेनरीकृत परिनियोजन का मतलब है कि आप मिनटों में तैयार और चालू हो जाते हैं — घंटों में नहीं।

चरण 1

कंटेनर परिनियोजित करें

Docker Hub या GitHub से इमेज पुल करें, अपना टाइमज़ोन सेट करें, और डेटा वॉल्यूम माउंट करें। वेब UI पोर्ट 9666 पर सुनता है। स्कीमा माइग्रेशन स्टार्टअप पर स्वचालित रूप से लागू होते हैं।

शुरू करें
इंस्टॉलेशन गाइड
चरण 2

Duplicati को duplistatus पर इंगित करें

प्रत्येक Duplicati सर्वर को /api/upload पर JSON रिपोर्ट POST करने के लिए कॉन्फ़िगर करें। फिर ऐतिहासिक लॉग एकत्र करें ताकि निगरानी अंतराल स्वचालित रूप से भर जाएं। 

--send-http-json-urls=http://host:9666/api/upload
--send-http-log-level=Information
--send-http-max-log-lines=500
Duplicati कॉन्फ़िगरेशन
चरण 3

अलर्ट कॉन्फ़िगर करें

ntfy पहले से ही कॉन्फ़िगर है। टॉपिक को अपने टॉपिक में बदलें, फिर इसे अपने फ़ोन पर सेट करने के लिए duplistatus द्वारा जनरेट किए गए QR कोड को स्कैन करें।
duplistatus से ईमेल प्राप्त करना शुरू करने के लिए ईमेल सर्वर सेटिंग्स कॉन्फ़िगर करें।

सूचना सेटिंग्स
चरण 4

duplistatus को अपने बैकअप पर नज़र रखने दें

duplistatus निगरानी रखता है। यदि कोई बैकअप अतिदेय है, या चेतावनियों या त्रुटियों के साथ समाप्त होता है, तो आपको एक नोटिफ़िकेशन या ईमेल मिलता है।
अतिरिक्त निश्चिंतता के लिए, वैकल्पिक दैनिक सारांश चालू करें: आप इसे हर दिन प्राप्त करते हैं, भले ही सब कुछ ठीक हो।

उपयोगकर्ता गाइड

डिफ़ॉल्ट रूप से सुरक्षित। ज़रूरत पड़ने पर अधिक सुरक्षा जोड़ें।

पहली शुरुआत से ही लॉगिन चालू रहता है, इसलिए एक निजी होमलैब शुरुआत से ही सुरक्षित रहता है। जब आप इसे इंटरनेट पर एक्सपोज़ करते हैं तो API कुंजियाँ और IP allowlists जोड़ें।

भूमिकाओं के साथ लॉगिन

एडमिन या उपयोगकर्ता के रूप में साइन इन करें। सीमित करें कि प्रत्येक उपयोगकर्ता कौन से सर्वर देख सकता है।

API कुंजियाँ

Duplicati अपलोड और केवल-पढ़ने योग्य डैशबोर्ड या विजेट के लिए अलग-अलग कुंजियाँ, अपलोड आकार और दर सीमाओं के साथ।

IP allowlists

दो स्वतंत्र अनुमति सूचियाँ: एक एडमिन इंटरफ़ेस के लिए, एक बाहरी API के लिए। जब duplistatus रिवर्स प्रॉक्सी के पीछे चलता है, तो वे स्पूफ़ किए गए क्लाइंट IP से सुरक्षा प्रदान करती हैं।

CSRF सुरक्षा

सत्र-आधारित (Session-based) रूट्स क्रॉस-साइट रिक्वेस्ट फोर्जरी (CSRF) से सुरक्षित हैं।

ऑडिट लॉगिंग

प्रत्येक कॉन्फ़िगरेशन परिवर्तन और उपयोगकर्ता कार्रवाई रिकॉर्ड की जाती है। फ़िल्टर करें, निर्यात करें और सेट करें कि रिकॉर्ड कितने समय तक रखे जाने हैं।

एप्लिकेशन लॉग

केवल-एडमिन व्यूअर आपको लाइव अपडेट के साथ एप्लिकेशन लॉग खोजने, फ़िल्टर करने और निर्यात करने की सुविधा देता है।

इसे इंटरनेट पर एक्सपोज़ कर रहे हैं? इसे HTTPS के साथ रिवर्स प्रॉक्सी के पीछे चलाएं। गाइड पढ़ें

सेल्फ़-होस्टिंग समुदाय के लिए निर्मित

duplistatus ओपन सोर्स, सेल्फ़-होस्टेड है, और इसे होमलैब स्वामियों और छोटी टीम के सिस्टम एडमिनिस्ट्रेटर के वास्तविक काम करने के तरीके के अनुसार डिज़ाइन किया गया है।

GitHub पर ओपन सोर्स

पूर्ण स्रोत कोड, समस्याएँ (issues) और रिलीज़। बिना किसी वेंडर लॉक-इन के योगदान दें, फ़ॉर्क करें या सेल्फ़-होस्ट करें।

GitHub पर देखें

विस्तृत दस्तावेज़

सेटअप गाइड, कॉन्फ़िगरेशन संदर्भ और सुरक्षा सेटिंग्स, सात भाषाओं में उपलब्ध हैं।

दस्तावेज़ पढ़ें

Docker, Portainer, और Podman

इमेज Docker Hub और GitHub पर प्रकाशित हैं। अपने पसंदीदा कंटेनर रनटाइम के साथ डिप्लॉय करें — एकल डेटा वॉल्यूम के अलावा कोई निर्भरता नहीं।

इंस्टॉलेशन विकल्प देखें

duplistatus एक स्वतंत्र प्रोजेक्ट है और Duplicati टीम से संबद्ध नहीं है।

कुछ ही मिनटों में शुरू करें

इमेज पुल करें, एक डेटा वॉल्यूम माउंट करें, और पोर्ट 9666 खोलें। 

# download the compose file
wget https://github.com/wsj-br/duplistatus/raw/refs/heads/master/production.yml -O duplistatus.yml
# start the container
docker compose -f duplistatus.yml up -d
# duplistatus production compose.yml
services:
  duplistatus:
    image: ghcr.io/wsj-br/duplistatus:latest
    container_name: duplistatus
    restart: unless-stopped
    environment:
      - TZ=Europe/London
      - PWD_ENFORCE=true
      - PWD_MIN_LEN=8
    ports:
      - "9666:9666"
    volumes:
      - duplistatus_data:/app/data
    networks:
      - duplistatus_network

networks:
  duplistatus_network:
    driver: bridge

volumes:
  duplistatus_data:
    name: duplistatus_data
# Create the volume
docker volume create duplistatus_data

# Start the container
docker run -d \
  --name duplistatus \
  -p 9666:9666 \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -v duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest
mkdir -p ~/duplistatus_data
# Start the container (standalone)
podman run -d \
  --name duplistatus \
  --userns=keep-id \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -p 9666:9666 \
  -v ~/duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest

कंटेनर शुरू होने के बाद:

  1. 1 अपने ब्राउज़र में http://localhost:9666 खोलें
  2. 2 डिफ़ॉल्ट एडमिन खाते से लॉग इन करें। पहले लॉगिन पर आपसे डिफ़ॉल्ट एडमिन पासवर्ड बदलने के लिए कहा जाता है।
  3. 3 इन निर्देशों का पालन करते हुए अपने Duplicati सर्वर कनेक्ट करें, फिर इतिहास आयात करने के लिए बैकअप लॉग एकत्र करें का उपयोग करें
  4. 4 क्या इसे इंटरनेट पर एक्सपोज़ कर रहे हैं? API कुंजियाँ और IP अनुमति सूचियाँ सक्षम करके अधिक सुरक्षा जोड़ें, और इसे HTTPS युक्त रिवर्स प्रॉक्सी के पीछे रखें।
