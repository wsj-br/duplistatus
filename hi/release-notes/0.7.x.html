संस्करण 0.7.x

अवलोकन​

संस्करण 0.7.x एक प्रमुख रिलीज है जो डेटाबेस स्कीमा, एपीआई संरचना और उपयोगकर्ता इंटरफेस में महत्वपूर्ण सुधार प्रस्तुत करता है। इस संस्करण में ऐसे परिवर्तन शामिल हैं जिनके कारण बाहरी एकीकरण को अपडेट करने की आवश्यकता होती है।

ब्रेकिंग परिवर्तन​

डेटाबेस स्कीमा परिवर्तन​

  • टेबल का नाम बदलना: machines टेबल का नाम बदलकर servers कर दिया गया
  • नए फ़ील्ड: alias, notes, created_at, और updated_at फ़ील्ड जोड़े गए
  • एपीआई प्रतिक्रिया परिवर्तन: सुसंगतता के लिए फ़ील्ड नाम अपडेट किए गए

पिछड़े असंगत एपीआई परिवर्तन​

  • फ़ील्ड का नाम बदलना: totalMachines → totalServers
  • ऑब्जेक्ट का नाम बदलना: एपीआई प्रतिक्रियाओं में machine → server
  • फ़ील्ड का नाम बदलना: backup_types_count → backupJobsCount
चेतावनी

एपीआई का उपयोग करने वाले बाहरी एकीकरण को अपडेट करना आवश्यक है ताकि संस्करण 0.7.x के साथ काम किया जा सके। विवरण के लिए पिछड़े असंगत एपीआई परिवर्तन गाइड देखें।

नई सुविधाएं​

बढ़ाया गया सर्वर प्रबंधन​

  • सर्वर उपनाम: सर्वर को दोस्ताना, यादगार नाम दें
  • सर्वर नोट्स: विवरण और अतिरिक्त जानकारी जोड़ें
  • सुधारित स्थिति ट्रैकिंग: बेहतर सर्वर स्थिति निगरानी
  • बढ़ाए गए सर्वर विवरण: अधिक व्यापक सर्वर जानकारी

सुधारित एपीआई संरचना​

  • सुसंगत प्रतिक्रिया प्रारूप: मानकीकृत एपीआई प्रतिक्रिया संरचना
  • बेहतर त्रुटि संभालना: सुधारित त्रुटि संदेश और कोड
  • बढ़ाई गई दस्तावेज़ीकरण: बेहतर एपीआई दस्तावेज़ीकरण
  • नए एंडपॉइंट्स: बेहतर एकीकरण के लिए अतिरिक्त एपीआई एंडपॉइंट्स

डेटाबेस सुधार​

  • बेहतर प्रदर्शन: ऑप्टिमाइज़ किए गए डेटाबेस क्वेरी और इंडेक्सिंग
  • डेटा अखंडता: बढ़ाई गई डेटा सत्यापन और बाधाएं
  • माइग्रेशन सिस्टम: स्वचालित डेटाबेस माइग्रेशन सिस्टम
  • बैकअप सिस्टम: सुधारित डेटाबेस बैकअप और पुनर्स्थापना

सुधार​

उपयोगकर्ता इंटरफ़ेस​

  • आधुनिक डिज़ाइन: बेहतर दृश्य डिज़ाइन के साथ अपडेट किया गया यूआई
  • प्रतिक्रियाशील लेआउट: बेहतर मोबाइल और टैबलेट समर्थन
  • सुधारित नेविगेशन: बढ़ाई गई नेविगेशन और उपयोगकर्ता अनुभव
  • बेहतर चार्ट: सुधारित चार्ट विज़ुअलाइज़ेशन और इंटरैक्टिविटी

सूचना प्रणाली​

  • बढ़ाए गए टेम्पलेट: बेहतर सूचना संदेश टेम्पलेट
  • सुधारित वितरण: अधिक विश्वसनीय सूचना वितरण
  • बेहतर त्रुटि संभालना: सूचनाओं के लिए सुधारित त्रुटि संभालना
  • बढ़ाई गई लॉगिंग: सूचना डीबगिंग के लिए बेहतर लॉगिंग

प्रदर्शन​

  • तेज़ क्वेरी: ऑप्टिमाइज़ किए गए डेटाबेस क्वेरी
  • बेहतर कैशिंग: सुधारित कैशिंग तंत्र
  • कम मेमोरी उपयोग: बेहतर मेमोरी प्रबंधन
  • तेज़ एपीआई प्रतिक्रिया: सुधारित एपीआई प्रतिक्रिया समय

बग सुधार​

डेटाबेस समस्याएँ​

  • दुर्लभ मामलों में डेटाबेस दूषण समस्याओं को ठीक किया गया
  • अपग्रेड के दौरान माइग्रेशन समस्याओं को हल किया गया
  • विशिष्ट परिदृश्यों में डेटा हानि समस्याओं को ठीक किया गया
  • डेटाबेस बैकअप और पुनर्स्थापना प्रक्रियाओं में सुधार किया गया

एपीआई समस्याएँ​

  • एपीआई प्रतिक्रिया असंगतताओं को ठीक किया गया
  • प्रमाणीकरण समस्याओं को हल किया गया
  • डेटा सत्यापन समस्याओं को ठीक किया गया
  • त्रुटि संभालना और संदेशों में सुधार किया गया

उपयोगकर्ता इंटरफेस​

  • डैशबोर्ड लोडिंग समस्याओं को ठीक किया गया
  • चार्ट रेंडरिंग समस्याओं को हल किया गया
  • मोबाइल लेआउट समस्याओं को ठीक किया गया
  • त्रुटि संदेश प्रदर्शन में सुधार किया गया

सूचना प्रणाली​

  • सूचना वितरण विफलताओं को ठीक किया गया
  • ईमेल कॉन्फ़िगरेशन समस्याओं को हल किया गया
  • एनटीएफवाई एकीकरण समस्याओं को ठीक किया गया
  • सूचना टेम्पलेट रेंडरिंग में सुधार किया गया

माइग्रेशन गाइड​

स्वचालित माइग्रेशन​

0.6.x से 0.7.x तक का माइग्रेशन स्वचालित रूप से होता है:

  1. बैकअप निर्माण: स्वचालित डेटाबेस बैकअप बनाया जाता है
  2. स्कीमा अपडेट: डेटाबेस स्कीमा को स्वचालित रूप से अपडेट किया जाता है
  3. डेटा माइग्रेशन: मौजूदा डेटा को संरक्षित और माइग्रेट किया जाता है
  4. सत्यापन: माइग्रेशन की जाँच की जाती है और लॉग किया जाता है

आवश्यक मैनुअल कदम​

  • बाहरी एकीकरण अपडेट करें: एपीआई का उपयोग करने वाले किसी भी बाहरी टूल को अपडेट करें
  • कार्यक्षमता का परीक्षण करें: सभी सुविधाओं के सही ढंग से काम करने की पुष्टि करें
  • दस्तावेज़ अपडेट करें: कोई भी कस्टम दस्तावेज़ अपडेट करें

कॉन्फ़िगरेशन परिवर्तन​

नए कॉन्फ़िगरेशन विकल्प​

# Server management
servers:
  defaultAlias: true
  showNotes: true
  sortBy: "name" # name, status, lastBackup

# API settings
api:
  version: "1.0"
  rateLimit: 100
  timeout: 30000

# Database settings
database:
  backupRetention: 7
  autoVacuum: true
  optimizeInterval: 24

अप्रचलित विकल्प​

  • machines कॉन्फ़िगरेशन (इसके बजाय servers का उपयोग करें)
  • पुराने एपीआई फ़ील्ड नाम (नए फ़ील्ड नामों का उपयोग करें)

अपग्रेड निर्देश​

संस्करण 0.6.x से​

  1. अपना डेटा बैकअप लें (अपग्रेड के दौरान स्वचालित बैकअप बनाया गया)
  2. डॉकर इमेज अपडेट करें: docker pull wsjbr/duplistatus:0.7.x
  3. कंटेनर पुनरारंभ करें: docker-compose down && docker-compose up -d
  4. लॉग की निगरानी करें: docker logs -f duplistatus
  5. एकीकरण अपडेट करें: एपीआई का उपयोग करने वाले किसी भी बाहरी उपकरण को अपडेट करें
  6. अपग्रेड की पुष्टि करें: जांचें कि सभी सुविधाएं सही ढंग से काम कर रही हैं

संस्करण 0.5.x या उससे पहले के संस्करण से​

  1. सबसे पहले 0.6.x पर अपग्रेड करें (यदि उपलब्ध हो)
  2. फिर ऊपर दिए गए चरणों का उपयोग करके 0.7.x पर अपग्रेड करें

ज्ञात समस्याएं​

माइग्रेशन समस्याएं​

  • बड़े डेटाबेस: बड़े डेटाबेस के लिए माइग्रेशन अधिक समय ले सकता है
  • डिस्क स्पेस: माइग्रेशन बैकअप के लिए पर्याप्त डिस्क स्थान सुनिश्चित करें
  • अनुमतियां: डेटाबेस एक्सेस के लिए फ़ाइल अनुमतियां जांचें

एपीआई संगतता​

  • बाहरी उपकरण: एपीआई का उपयोग करने वाले बाहरी उपकरणों को अपडेट की आवश्यकता है
  • फ़ील्ड नाम: कुछ फ़ील्ड नाम बदल दिए गए हैं
  • प्रतिक्रिया प्रारूप: कुछ प्रतिक्रिया प्रारूप बदल दिए गए हैं

कार्यान्वयन​

  • माइग्रेशन: माइग्रेशन के लिए पर्याप्त डिस्क स्थान और समय सुनिश्चित करें
  • एपीआई: नए एपीआई प्रारूप का उपयोग करने के लिए बाहरी एकीकरण अपडेट करें
  • परीक्षण: अपग्रेड के बाद सभी कार्यक्षमता का परीक्षण करें

समर्थन​

सहायता प्राप्त करना​

  • एपीआई संदर्भ: एपीआई दस्तावेज़ीकरण
  • माइग्रेशन गाइड: संस्करण अपग्रेड माइग्रेशन
  • समुदाय: गिटहब चर्चा
