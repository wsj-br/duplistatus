Versión 0.9.x

Vista general​

La versión 0.9.x es una versión importante que introduce un sistema integral de Control de Acceso y Seguridad de Usuarios. Esta versión transforma duplistatus de una aplicación de acceso abierto a un sistema seguro multiusuario con control de acceso basado en roles, registro de auditoría completo y características de seguridad de nivel empresarial. Toda la funcionalidad existente ahora está protegida detrás de la autenticación, asegurando que solo los usuarios autorizados puedan acceder y gestionar el monitoreo de copias de seguridad.

Cambios importantes​

Autenticación requerida​

  • Todas las páginas ahora requieren autenticación - Los usuarios deben iniciar sesión para acceder a la aplicación
  • Cuenta de administrador predeterminada se crea automáticamente:
    • Nombre de usuario: admin
    • Contraseña: Duplistatus09 (debe cambiarse en el primer inicio de sesión)
  • Las sesiones existentes se invalidan - Todos los usuarios deben iniciar sesión después de la actualización
  • Los puntos finales de la API ahora requieren autenticación - Las integraciones externas deben incluir cookies de sesión o usar solicitudes autenticadas
advertencia

Todos los usuarios deben iniciar sesión después de actualizar a la versión 0.9.x. Las credenciales de administrador predeterminadas son admin/Duplistatus09. Cambie la contraseña inmediatamente después del primer inicio de sesión.

Migración del esquema de base de datos​

  • Migración automática de v3.1 a v4.0 para instalaciones existentes
  • Nuevas tablas añadidas: users, sessions, audit_log
  • Copia de seguridad de base de datos creada automáticamente antes de la migración
  • Instalaciones nuevas comienzan directamente con el esquema v4.0 (no se necesita migración)

Nuevas características​

Sistema de Control de Acceso y Seguridad de Usuarios​

Sistema de autenticación​

  • Funcionalidad de inicio/cierre de sesión de usuario con gestión segura de sesiones
  • Autenticación basada en contraseña con hash bcrypt (factor de costo 12)
  • Mecanismo de bloqueo de cuenta (5 intentos fallidos, bloqueo de 15 minutos)
  • Cambio de contraseña forzado en el primer inicio de sesión
  • Aplicación de política de contraseñas:
    • Mínimo 8 caracteres
    • Al menos una letra mayúscula
    • Al menos una letra minúscula
    • Al menos un número
    • Caracteres especiales opcionales
  • Funcionalidad "Recordarme" con persistencia de nombre de usuario en localStorage
  • Autenticación basada en sesión con sesiones respaldadas por base de datos (reemplaza la memoria interna)
  • Protección CSRF integrada con autenticación
  • Cookies HTTP-only para seguridad de sesión
  • Seguimiento de dirección IP y agente de usuario para monitoreo de seguridad

Gestión de usuarios (Solo Administrador)​

  • Creación de usuarios con generación automática de contraseña temporal
  • Lista de usuarios con búsqueda, paginación y filtrado
  • Edición de usuarios (nombre de usuario, estado de administrador, cambio de contraseña requerido)
  • Funcionalidad de restablecimiento de contraseña con visualización de contraseña temporal
  • Eliminación de usuarios con salvaguardas (impide eliminación del último administrador)
  • Control de acceso basado en roles (roles Administrador/Usuario)
  • Indicadores de estado (Activo, Bloqueado, Debe cambiar la contraseña)
  • Seguimiento y visualización del último inicio de sesión

Sistema de registro de auditoría​

  • Registro de auditoría integral para todos los cambios del sistema y acciones de usuario
  • Visor de registro de auditoría con filtrado avanzado:
    • Filtrado por rango de fechas
    • Filtrado por usuario
    • Filtrado por acción
    • Filtrado por categoría
    • Filtrado por estado
  • Funcionalidad de exportación (formatos CSV y JSON)
  • Estadísticas y análisis de registro de auditoría
  • Periodo de retención configurable (30-365 días, predeterminado: 90 días)
  • Trabajo automático de limpieza cron (se ejecuta diariamente a las 2 AM UTC)
  • API de limpieza manual con soporte de simulacro
  • Registro de auditoría para:
    • Eventos de autenticación (inicio de sesión, cierre de sesión, cambios de contraseña, bloqueos de cuenta)
    • Operaciones de gestión de usuarios (crear, actualizar, eliminar, restablecimientos de contraseña)
    • Cambios de configuración (correo electrónico, NTFY, plantillas, tolerancia de vencimiento, configuraciones de copia de seguridad)
    • Operaciones de copia de seguridad (recopilación, eliminación, limpieza)
    • Gestión de servidores (añadir, actualizar, eliminar)
    • Operaciones del sistema (migraciones, limpieza, notificaciones)

Rediseño de la Página de Configuración​

  • Navegación lateral moderna con barra lateral plegable
  • Persistencia del estado de la barra lateral específica por usuario (preferencia de colapsado/expandido guardada por usuario)
  • Secciones de configuración agrupadas:
    • Notificaciones: Notificaciones de Copia de Seguridad, Monitoreo de copias de seguridad, Plantillas
    • Integraciones: NTFY, Correo electrónico
    • Sistema: Servidores, Usuarios (solo administrador), Registro de auditoría
  • Barra lateral fija que permanece visible al desplazarse
  • Diseño adaptable con espaciado optimizado
  • Icono de configuración y título "Configuración del Sistema" en el encabezado de la barra lateral
  • Botón Atrás integrado en el encabezado de la aplicación

Mejoras en la interfaz de usuario​

  • Página de inicio de sesión independiente con diseño moderno
  • Casilla "Recordarme" en el formulario de inicio de sesión para persistencia del nombre de usuario
  • Botones Mostrar/Ocultar contraseña en formularios de inicio de sesión y cambio de contraseña
  • Modal de cambio de contraseña con lista de verificación de validación en tiempo real
  • Indicador de usuario y botón de cierre de sesión en el encabezado de la aplicación
  • Visibilidad de IU basada en roles (características solo para administradores ocultas a usuarios regulares)
  • Insignias e indicadores de estado en toda la interfaz
  • Preferencias específicas del usuario almacenadas en localStorage (por ejemplo, estado colapsado de la barra lateral)

Características de Seguridad​

  • Hash de contraseñas con bcrypt (estándar de la industria)
  • Sanitización de datos sensibles en registros de auditoría (contraseñas, tokens, secretos nunca registrados)
  • Limitación de intentos para accesos
  • Expiración de sesión (24 horas)
  • Validación de token CSRF para todas las operaciones que cambian el estado
  • Herramienta CLI de recuperación de administrador para restablecer contraseña si se queda bloqueado

Herramientas para Desarrolladores​

  • Script CLI de recuperación de administrador (admin-recovery) para ejecución fácil en contenedores Docker
  • Funciona tanto localmente como en Docker con detección automática de rutas
  • Interfaces TypeScript completas (sin tipos any)
  • Middleware de autenticación para protección de rutas
  • Clase de utilidad de registro de auditoría con métodos de conveniencia

🚀 Notas de migración​

Desde la Versión 0.8.x​

Esta versión introduce autenticación y requiere que todos los usuarios inicien sesión. Al actualizar desde la versión 0.8.x:

  1. Migración Automática de Base de Datos: La aplicación migrará automáticamente su esquema de base de datos de v3.1 a v4.0
  2. Copia de Seguridad de Base de Datos: Se crea una copia de seguridad automática antes de la migración
  3. Cuenta de Administrador Predeterminada: Se crea una cuenta de administrador predeterminada:
    • Nombre de usuario: admin
    • Contraseña: Duplistatus09
    • Debe cambiar esta contraseña en el primer inicio de sesión
  4. Invalidación de Sesiones: Todas las sesiones existentes son invalidadas
  5. Inicio de Sesión Requerido: Todos los usuarios deben iniciar sesión después de la actualización
  6. Autenticación API: Las integraciones externas deben actualizarse para incluir autenticación

Consideraciones de Seguridad​

  • Cambiar Contraseña Predeterminada: Cambie inmediatamente la contraseña de administrador predeterminada después del primer inicio de sesión
  • Crear Cuentas de Usuario: Cree cuentas de usuario individuales para cada persona que necesite acceso
  • Revisar Registros de Auditoría: Verifique regularmente los registros de auditoría para monitoreo de seguridad
  • Configurar Retención: Establezca un período de retención adecuado para registros de auditoría según sus requisitos de cumplimiento
  • Copia de Seguridad de Clave Maestra: Si está actualizando desde 0.8.x, asegúrese de que el archivo .duplistatus.key esté respaldado

Pasos para el primer inicio de sesión​

  1. Iniciar sesión con credenciales predeterminadas (admin / Duplistatus09)
  2. Cambiar contraseña cuando se solicite (obligatorio en el primer inicio de sesión)
  3. Crear cuentas de usuario para otros usuarios (Configuración → Usuarios)
  4. Configurar retención de registro de auditoría si es necesario (Configuración → Registro de auditoría)
  5. Revisar registros de auditoría para verificar que el sistema funcione correctamente

🐛 Correcciones de errores​

  • Corregidos problemas de persistencia de sesiones tras reinicios del servidor
  • Mejorada la gestión de errores para fallos de autenticación
  • Mejorado el comentario de validación de contraseñas
  • Corregidas inconsistencias de interfaz en la página de configuración
  • Mejorado el rendimiento del filtrado de registros de auditoría

Puntos finales de la API​

Puntos finales de autenticación​

  • POST /api/auth/login - Autenticación de usuario
  • POST /api/auth/logout - Finalización de sesión
  • GET /api/auth/me - Información del usuario actual
  • POST /api/auth/change-password - Cambio de contraseña

Puntos finales de Gestión de usuarios (Solo Administrador)​

  • GET /api/users - Lista de usuarios
  • POST /api/users - Crear usuario
  • PATCH /api/users/{id} - Actualizar usuario
  • DELETE /api/users/{id} - Eliminar usuario

Puntos finales de Registro de auditoría​

  • GET /api/audit-log - Consultar registros de auditoría
  • GET /api/audit-log/download - Exportar registros de auditoría
  • GET /api/audit-log/stats - Estadísticas de auditoría
  • POST /api/audit-log/cleanup - Limpieza manual (solo administrador)
  • GET /api/audit-log/retention - Obtener configuración de retención
  • PATCH /api/audit-log/retention - Actualizar retención (solo administrador)
nota

Ahora todos los puntos finales de la API requieren autenticación. Consulte la Referencia de API para obtener detalles sobre la autenticación.
