Versión 1.0.x

Vista general​

La versión 1.0.x es una versión con nuevas funciones que introduce mejoras significativas en la configuración de correo electrónico, capacidades de gestión de servidores y herramientas de mantenimiento de bases de datos. Esta versión se centra en mejorar la fiabilidad de las notificaciones por correo electrónico, ampliar las opciones de conexión SMTP y proporcionar mejores herramientas para gestionar servidores e integridad de bases de datos.

Nuevas características​

Mejoras en la gestión de servidores​

  • Funcionalidad de cambio de contraseña de servidor - Los usuarios ahora pueden cambiar las contraseñas de servidor directamente desde la página de detalles del servidor haciendo clic en el icono de llave
  • Detección y combinación de servidores duplicados - Nueva función en el formulario de mantenimiento de base de datos para detectar servidores duplicados y combinarlos en una única entrada de servidor

Mejoras en Registro de Auditoría​

  • Registro de auditoría de carga de copias de seguridad - Todas las cargas de registros de copias de seguridad mediante el punto final /api/upload ahora se registran automáticamente en el registro de auditoría. Cada entrada incluye detalles de la copia de seguridad (ID del servidor, nombre del servidor, nombre de la copia de seguridad, estado, fecha, duración, recuentos de archivos, tamaños, advertencias y errores) junto con la dirección IP del cliente y la información del agente de usuario para fines de seguimiento y seguridad

Mejoras en la configuración de correo electrónico​

  • Aviso de configuración incompleta - Alerta visual mostrada cuando la configuración de correo electrónico no está correctamente configurada
  • Indicadores de estado del servicio - Etiquetas "(desactivado)" mostradas en casillas de verificación de notificaciones cuando los servicios de correo electrónico no están configurados
  • Información de remitente personalizable:
    • Campo Sender Name para personalizar el nombre mostrado como remitente en las notificaciones por correo electrónico
    • Campo From Address para especificar la dirección de correo electrónico mostrada como remitente
    • Nota: Algunos proveedores de correo electrónico anularán el From Address con el SMTP Server Username
  • Conmutador de autenticación SMTP - Opción para activar o desactivar la autenticación SMTP, compatible con servidores que no requieren autenticación
  • Validación de formato de correo electrónico - Validación para campos de destinatario y dirección de origen para garantizar el formato correcto de direcciones de correo electrónico
  • Correo electrónico de prueba mejorado - El correo electrónico de prueba ahora muestra detalles completos de conexión incluyendo nombre de host del servidor SMTP, puerto, tipo de conexión, estado de autenticación, nombre de usuario (si corresponde), correo electrónico del destinatario, dirección de origen, nombre del remitente y marca de tiempo de la prueba

Soporte de tipos de conexión SMTP​

  • Múltiples tipos de conexión - Soporte para tres tipos de conexión:
    • Plain SMTP (sin cifrado) en el puerto 25
    • STARTTLS (actualización a TLS) en el puerto 587
    • Direct SSL/TLS (cifrado desde el inicio) en el puerto 465
  • Tipo de conexión predeterminado - Cambiado a Direct SSL/TLS para nuevas configuraciones
  • Requisitos específicos de conexión - El campo From Address es obligatorio para conexiones Plain SMTP para garantizar la identificación adecuada del remitente de correo electrónico y el cumplimiento de RFC 5322

🐛 Correcciones de errores​

Correcciones del sistema de correo electrónico​

  • Corregida cabecera From faltante - Resueltos errores de cumplimiento de RFC 5322 asegurando que todos los mensajes de correo electrónico incluyan cabeceras From adecuadas
  • Corregido cifrado de correo electrónico para STARTTLS - Corregido manejo de cifrado para conexiones STARTTLS (puerto 587)
  • Corregidas conexiones SMTP simples - Resueltos errores de negociación TLS que estaban causando fallos en conexiones Plain SMTP
  • Corregida pérdida de configuración no guardada - Prevenido que la configuración de correo electrónico no guardada se borre al cambiar la contraseña
  • Corregida configuración SMTP obsoleta - Resuelto problema donde el punto final de correo electrónico de prueba estaba usando configuración SMTP obsoleta

Correcciones de interfaz de usuario​

  • Corregido conmutador de visibilidad de contraseña - Corregido comportamiento de la función de ver contraseña en el formulario de cambio de contraseña; hacer clic en el icono del ojo ahora muestra la contraseña para ambos campos de contraseña simultáneamente

Correcciones del sistema​

  • Corregido registro del punto de entrada de Docker - Resuelto problema donde el script del punto de entrada de Docker estaba descartando mensajes de registro
  • Corregido cálculo de fecha de próxima ejecución - Añadido recálculo automático de la fecha Next Run después de recopilar registros de copia de seguridad, asegurando que la fecha se actualice correctamente después de la recopilación de registros

🚀 Notas de migración​

De la versión 0.9.x​

Esta versión incluye mejoras en la configuración de correo electrónico y la gestión de servidores. Al actualizar desde la versión 0.9.x:

  1. No se requiere migración de base de datos - Esta versión no requiere cambios en el esquema de base de datos
  2. Actualizaciones de configuración de correo electrónico - Las configuraciones de correo electrónico existentes continuarán funcionando, pero puede que desee revisar y actualizar su configuración para aprovechar las nuevas funciones:
    • Considere establecer un Sender Name personalizado para una mejor identificación del correo electrónico
    • Verifique que su From Address esté configurado correctamente, especialmente si utiliza conexiones Plain SMTP
    • Pruebe su configuración de correo electrónico utilizando la función mejorada de correo electrónico de prueba
  3. Valor predeterminado del tipo de conexión - Las nuevas configuraciones de correo electrónico usarán por defecto el tipo de conexión Direct SSL/TLS
  4. Gestión de contraseñas de servidor - Ahora puede cambiar las contraseñas de servidor directamente desde la página de detalles del servidor sin necesidad de recopilar copias de seguridad nuevamente

Recomendaciones de configuración de correo electrónico​

  • Para uso en producción: Utilice conexiones STARTTLS o Direct SSL/TLS para entrega segura de correo electrónico
  • Para pruebas locales: Las conexiones Plain SMTP están disponibles para redes locales confiables
  • Requisito de dirección de origen: Cuando utilice Plain SMTP o cuando la autenticación esté desactivada, asegúrese de que el campo From Address esté configurado correctamente
  • Pruebe su configuración: Utilice siempre el botón "Enviar correo de prueba" para verificar que su configuración de correo electrónico funcione correctamente

Puntos finales de la API​

Puntos finales de configuración de correo electrónico​

  • GET /api/email/config - Obtener configuración de correo electrónico
  • POST /api/email/config - Actualizar configuración de correo electrónico
  • POST /api/email/test - Enviar correo electrónico de prueba
  • DELETE /api/email/config - Eliminar configuración de correo electrónico

Puntos finales de gestión de servidor​

  • PATCH /api/servers/{id}/password - Actualizar contraseña de servidor
  • POST /api/database/maintenance/merge-duplicate-servers - Combinar servidores duplicados
