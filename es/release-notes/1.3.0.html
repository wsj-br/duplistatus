Versión 1.3.0

Vista general​

La versión 1.3.0 introduce políticas de contraseña configurables, un nuevo visor de registros de aplicación para administradores, visualización de días laborables según la configuración regional y varias mejoras en la experiencia de usuario. Esta versión se centra en herramientas administrativas mejoradas y soporte internacionalizado mejorado.

Nuevas características​

Política de Contraseña Configurable​

  • Variables de entorno de política de contraseña: Configure los requisitos de validación de contraseña mediante variables de entorno:
    • PWD_ENFORCE: Establezca en false para desactivar los requisitos de complejidad de contraseña (mayúsculas, minúsculas, números). Por defecto aplica todas las reglas. Cuando está desactivado, solo se aplica la longitud mínima.
    • PWD_MIN_LEN: Establece la longitud mínima de contraseña en caracteres. Por defecto son 8 caracteres.
    • La verificación de contraseña predeterminada (prevención del uso de la contraseña de administrador predeterminada) siempre se aplica independientemente del ajuste PWD_ENFORCE.

Visor de Registros de Aplicación​

  • Nuevo visor de registros exclusivo para administradores: Vea y descargue registros de aplicación directamente desde la página de Configuración:
    • Acceda al archivo consolidado application.log y versiones de registro rotadas
    • Selector de cantidad de líneas configurable (100, 500, 1000, 5000, 10000 líneas)
    • Filtro de búsqueda en tiempo real con coincidencia de texto sin distinción entre mayúsculas y minúsculas
    • Alternancia de desplazamiento automático para monitoreo de registros en tiempo real con sondeo automático
    • Copiar al portapapeles y exportar registros filtrados como archivo de texto
    • Visualización de metadatos del archivo mostrando recuento de líneas, tamaño de archivo y marca de tiempo de última modificación
    • Rotación de registros en el inicio del contenedor (configurable mediante LOG_ROTATION_VERSIONS, por defecto: 5)

Guía de Usuario Consciente del Contexto​

  • Botón de ayuda dinámico: El botón de Guía de Usuario en el encabezado de la aplicación ahora abre documentación relevante para la página actual. La información sobre herramientas se actualiza para mostrar "Ayuda para Page Name" para indicar qué documentación se abrirá.

Mejora de Configuración del Servidor​

  • Acceso rápido a la interfaz de usuario de Duplicati: Al hacer clic derecho en el botón de configuración del servidor o en cualquier elemento de servidor en el menú emergente de selección de servidor se abre la interfaz de usuario heredada de Duplicati (/ngax) en una nueva pestaña.

🔧 Mejoras​

Visualización de Días Laborables Consciente de la Configuración Regional​

  • Ordenación internacionalizada de días laborables: La visualización de días laborables en el formulario de monitoreo de copias de seguridad ahora respeta la configuración regional de su navegador. Los días laborables se muestran en el orden correcto según la configuración regional (lunes-domingo para Reino Unido/Europa, domingo-sábado para Estados Unidos/Brasil).

Manejo Mejorado de Errores SMTP​

  • Mensajes de error mejorados: Los mensajes de error SMTP ahora proporcionan orientación más precisa:
    • Los errores de autenticación indican claramente problemas de nombre de usuario/contraseña
    • Los errores de versión SSL/TLS se identifican correctamente
    • Las sugerencias de tipo de conexión solo aparecen cuando realmente son relevantes

Comportamiento de Notificaciones Emergentes​

  • Notificaciones de error persistentes: Las notificaciones emergentes de error ahora permanecen hasta que se cierren manualmente, asegurando que no se pierdan mensajes de error importantes. Las notificaciones de éxito e informativas se cierran automáticamente después de 3 segundos.

Tabla de Configuración de Notificaciones​

  • Diseño simplificado: La tabla de configuración de notificaciones se ha optimizado con una columna combinada "Servidor / Copia de seguridad" e iconos contextuales que indican el estado de configuración de destino adicional.

🚀 Notas de migración​

Desde la Versión 1.2.x​

Al actualizar a la versión 1.3.0:

  1. Política de Contraseña: La nueva política de contraseña predeterminada aplica todos los requisitos de complejidad. Si necesita una política de contraseña más simple, configure las variables de entorno PWD_ENFORCE y PWD_MIN_LEN.

  2. Registros de la Aplicación: Toda la salida del contenedor (servidor y servicio cron) ahora se consolida en un único archivo data/logs/application.log.

  3. Rotación de Registros: La rotación de registros es configurable mediante la variable de entorno LOG_ROTATION_VERSIONS (predeterminada: 5 versiones).

  4. No se requiere migración de base de datos: Esta versión no requiere ningún cambio en el esquema de base de datos.

Puntos finales de la API​

El siguiente punto final de API ha sido introducido en esta versión:

Punto Final de Política de Contraseña​

  • GET /api/auth/password-policy - Devuelve la configuración actual de la política de contraseña

Puntos Finales de Registros de Aplicación​

  • GET /api/application-logs - Ver registros con selección de archivo y funcionalidad de cola
  • GET /api/application-logs/export - Exportar registros filtrados como archivo de texto

Puntos Finales Eliminados​

Los siguientes puntos finales de API no utilizados han sido eliminados en esta versión:

  • DELETE /api/backups/[backupId] - Punto final solo para desarrollo que nunca se usó
  • GET /api/audit-log/stats - El punto final no era llamado por el visor de registro de auditoría

  • Añadido: Rotación de registros con recuento de versiones configurable (LOG_ROTATION_VERSIONS)
  • Añadido: Botón de Guía de Usuario contextual que abre documentación relevante
  • Añadido: Clic derecho en la configuración del servidor para abrir la interfaz heredada de Duplicati
  • Añadido: Punto final de API GET /api/auth/password-policy para configuración de política de contraseña
  • Añadido: Puntos finales de API para visualización y exportación de registros de aplicación
  • Cambiado: La visualización de días de la semana ahora respeta la configuración regional del navegador
  • Cambiado: Las notificaciones de error persisten hasta que se cierren manualmente
  • Cambiado: Las notificaciones de éxito se cierran automáticamente después de 3 segundos (anteriormente 5 segundos)
  • Cambiado: Tabla de configuración de notificaciones simplificada con columna combinada "Servidor / Copia de seguridad"
  • Cambiado: Se consolidaron todos los registros del contenedor en un único archivo application.log
  • Mejorado: Los mensajes de error SMTP proporcionan una orientación más precisa
