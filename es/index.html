Código abierto · Autoalojado · Listo para Docker

Todos sus backups. Un panel de control.

Deje de iniciar sesión en cada interfaz web de Duplicati una a una. duplistatus supervisa cada servidor y tarea desde una sola pantalla, para que sepa que sus copias de seguridad están en buen estado antes de que una pérdida de datos le tome por sorpresa.

duplistatus utiliza el sistema integrado de informes HTTP de Duplicati, por lo que no es necesario instalar nada en sus equipos de copia de seguridad.

La única pregunta que importa

¿Están bien todas mis copias de seguridad? Una sola pantalla le da la respuesta, en cada servidor, cada trabajo y cada ejecución.

localhost:9666

Diseñado para quienes ejecutan Duplicati en más de una máquina

Tanto si utiliza un NAS, un portátil, un VPS o dos servidores domésticos, duplistatus los reúne todos en una sola pantalla.

01

Consulte cada copia de seguridad de un vistazo

Una tarjeta por servidor muestra las últimas 10 ejecuciones de cada trabajo. Cambie a una tabla clasificable cuando tenga muchos servidores y abra cualquier ejecución para leer su registro completo, incluidas advertencias y errores.

  • Totales de servidores, trabajos, ejecuciones, tamaño y almacenamiento
  • Panel con actualización automática para una experiencia de mural de vídeo
  • Comprobación de la versión del servidor Duplicati respecto a la última versión publicada en GitHub
Leer la guía del panel de control
02

Detecte problemas antes de que se conviertan en pérdida de datos

duplistatus detecta automáticamente copias de seguridad vencidas, con advertencias o fallidas y le avisa mediante notificaciones push de ntfy o correo electrónico SMTP.

  • Las comprobaciones de copias vencidas se ejecutan periódicamente de forma predeterminada
  • Reciba notificaciones para cada trabajo con filtros individuales: desactivado, todos, advertencias o errores
  • Reduzca el exceso de notificaciones con el correo electrónico de Resumen Diario.
Leer sobre el monitoreo de copias de seguridad
03

Solucione problemas con confianza

Abra cualquier ejecución para leer su registro, con advertencias y errores, y ver qué puntos de recuperación están disponibles. Dispone de gráficos de duración, tamaño y almacenamiento cuando necesite más detalles.

  • Recopilación automática de registros de sus servidores Duplicati
  • Versiones disponibles mostradas para cada ejecución
  • Gráficos de duración, tamaño y almacenamiento
Leer sobre los detalles de las copias de seguridad

De cero a monitorizado en cuatro pasos

El despliegue en contenedores significa que estará en funcionamiento en minutos, no en horas.

Paso 1

Desplegar el contenedor

Descargue la imagen de Docker Hub o GitHub, configure su zona horaria y monte un volumen de datos. La interfaz web escucha en el puerto 9666. Las migraciones de esquema se aplican automáticamente al inicio.

Primeros pasos
Guía de instalación
Paso 2

Apuntar Duplicati a duplistatus

Configure cada servidor Duplicati para enviar informes JSON mediante POST a /api/upload. A continuación, recopile los registros históricos para que los intervalos de monitorización se completen automáticamente. 

--send-http-json-urls=http://host:9666/api/upload
--send-http-log-level=Information
--send-http-max-log-lines=500

Configure los ajustes del servidor de correo electrónico para comenzar a recibir correos electrónicos de duplistatus.

Configuración de notificaciones
Paso 4

Deje que duplistatus supervise sus copias de seguridad

duplistatus se encarga de la supervisión. Si una copia de seguridad está vencida o finaliza con advertencias o errores, recibirá una notificación o un correo electrónico.
Para mayor tranquilidad, active el Resumen Diario opcional: lo recibirá todos los días, incluso cuando todo esté bien.

Guía del usuario

Seguro por defecto. Añada más protección cuando la necesite.

El inicio de sesión está activado desde el primer arranque, por lo que un homelab privado está protegido desde el primer momento. Añada claves de API y listas de IP permitidas cuando lo exponga a Internet.

Inicio de sesión con roles

Inicie sesión como Administrador o Usuario. Limite qué servidores puede ver cada usuario.

Claves de API

Claves independientes para las cargas de Duplicati y para paneles o widgets de solo lectura, con límites de velocidad y tamaño de carga.

Listas de IP permitidas

Dos listas de permitidos independientes: una para la interfaz de administración y otra para APIs externas. Protegen contra la suplantación de IP de cliente cuando duplistatus se ejecuta detrás de un proxy inverso.

Protección CSRF

Las rutas basadas en sesiones están protegidas contra la falsificación de solicitudes en sitios cruzados (CSRF).

Registro de auditoría

Se registra cada cambio de configuración y acción de usuario. Filtre, exporte y configure durante cuánto tiempo se conservan los registros.

Registros de la Aplicación

Un visor exclusivo para administradores le permite buscar, filtrar y exportar registros de la aplicación, con actualizaciones en directo.

¿Lo va a exponer a Internet? Ejecútelo detrás de un proxy inverso con HTTPS. Leer la guía

duplistatus es un proyecto independiente y no está afiliado con el equipo de Duplicati.

Empieza en cuestión de minutos

Descargue la imagen, monte un volumen de datos y abra el puerto 9666. 

# download the compose file
wget https://github.com/wsj-br/duplistatus/raw/refs/heads/master/production.yml -O duplistatus.yml
# start the container
docker compose -f duplistatus.yml up -d
# duplistatus production compose.yml
services:
  duplistatus:
    image: ghcr.io/wsj-br/duplistatus:latest
    container_name: duplistatus
    restart: unless-stopped
    environment:
      - TZ=Europe/London
      - PWD_ENFORCE=true
      - PWD_MIN_LEN=8
    ports:
      - "9666:9666"
    volumes:
      - duplistatus_data:/app/data
    networks:
      - duplistatus_network

networks:
  duplistatus_network:
    driver: bridge

volumes:
  duplistatus_data:
    name: duplistatus_data
# Create the volume
docker volume create duplistatus_data

# Start the container
docker run -d \
  --name duplistatus \
  -p 9666:9666 \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -v duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest
mkdir -p ~/duplistatus_data
# Start the container (standalone)
podman run -d \
  --name duplistatus \
  --userns=keep-id \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -p 9666:9666 \
  -v ~/duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest

Después de que se inicie el contenedor:

  1. 1 Abra http://localhost:9666 en su navegador
  2. 2 Inicie sesión con la cuenta de administrador predeterminada. Se le solicitará que cambie la contraseña de administrador predeterminada en el primer inicio de sesión.
  3. 3 Conecte sus servidores Duplicati siguiendo estas instrucciones y, a continuación, utilice Recopilar registros de copias de seguridad para importar el historial
  4. 4 ¿Va a exponerlo a Internet? Añada más protección habilitando claves de API y listas de IP permitidas, y colóquelo detrás de un proxy inverso con HTTPS.
