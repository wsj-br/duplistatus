# Version 0.8.x {/* #version-08x */}

## Übersicht {/* #overview */}

Version 0.8.x ist ein großes Update, das signifikante Sicherheitsverbesserungen, verbesserte Server-Management-Funktionen und ein umfassendes Benachrichtigungssystem mit SMTP-E-Mail-Unterstützung einführt. Diese Version konzentriert sich auf die Verstärkung der Sicherheit, die Verbesserung der Benutzerfreundlichkeit und die Bereitstellung flexiblerer Backup-Überwachungsoptionen.

## Neue Funktionen {/* #new-features */}

### Server-Management-Erweiterungen {/* #server-management-enhancements */}

- **Automatische Speicherung der Server-URL und des Passworts** beim Sammeln von Backups
  - Benutzer können die URL und das Passwort auf zwei Arten aktualisieren:
     - erneutes Sammeln von Backups mit aktualisierten Werten
     - Ändern der Einstellungen unter [Einstellungen → Server-Einstellungen](../user-guide/settings/server-settings.md)

### Erweiterte Backup-Überwachung {/* #enhanced-backup-monitoring */}

- **Neuer `Backup monitoring`-Konfigurationstab** mit Duplicati-serverkompatiblen Intervall-Einstellungen
    - Unterstützung für benutzerdefinierte Intervalle (z. B. "1D12h")
    - Automatische Aktualisierung überfälliger Intervalle aus der Duplicati-Konfiguration während der Backup-Protokoll-Sammlung
    - **Empfohlen:** Führen Sie die Sammlung nach der Änderung der Backup-Auftragsintervalle auf dem Duplicati-Server aus, um die duplistatus-Konfiguration zu synchronisieren
    - Benachrichtigungsvorlagen verwenden jetzt `{backup_interval}` anstelle von `{backup_interval_value}` und `{backup_interval_type}`.

### NTFY-Gerätekonfiguration {/* #ntfy-device-configuration */}

- **QR-Code-Generierung** für die automatische Gerätekonfiguration zum Empfang von Benachrichtigungen von **duplistatus**
   - Rechtsklick auf die `View NTFY Messages`-Schaltfläche in der Anwendungsleiste
   - "Gerät konfigurieren"-Schaltfläche unter [Einstellungen → NTFY-Einstellungen](../user-guide/settings/ntfy-settings.md)

### Verbesserte Backup-Sammlung {/* #improved-backup-collection */}

- **Automatische HTTP/HTTPS-Erkennung**, Verbindungen werden in dieser Reihenfolge versucht: HTTPS → HTTPS mit selbstsigniertem Zertifikat → HTTP-Fallback
- **Server-Auswahl-Dropdown** in der `Collect Backup Logs`-Schnittstelle für die direkte server-spezifische Sammlung
- **Mehrere Adressen** im Hostnamen (kommagetrennt) werden jetzt akzeptiert (müssen dasselbe Passwort und denselben Port verwenden)
- **Einzel-Server-Backup-Sammlung-Schaltflächen** wurden zu `Dashboard (table)`, [Einstellungen → Backup-Überwachung](../user-guide/settings/backup-monitoring-settings.md) und [Einstellungen → Server](../user-guide/settings/server-settings.md) hinzugefügt
- **Massen-Sammlung-Funktionalität** für alle Server mit gültiger Konfiguration (URL und Passwort)
   - `Collect All`-Schaltflächen unter [Einstellungen → Backup-Überwachung](../user-guide/settings/backup-monitoring-settings.md) und [Einstellungen → Server](../user-guide/settings/server-settings.md)
   - Rechtsklick-Kontextmenü auf die `Collect Backup Logs`-Schaltfläche in der Anwendungsleiste

### Erweiterte Benachrichtigungssystem {/* #enhanced-notification-system */}

- **SMTP-E-Mail-Benachrichtigungsunterstützung:**
    - SMTP-Server-Konfiguration unter [Einstellungen → E-Mail-Einstellungen](../user-guide/settings/email-settings.md)
    - Pro-Backup-Auftrag-Konfiguration für NTFY- und/oder E-Mail-Benachrichtigungen
    - HTML-formatierte Vorlagen unter Verwendung der bestehenden [Einstellungen → Benachrichtigungsvorlagen](../user-guide/settings/notification-templates.md)
- **Pro-Backup-Auftrag-Benachrichtigungskonfiguration:**
    - Individuelle Benachrichtigungseinstellungen unter [Einstellungen → Backup-Benachrichtigungen](../user-guide/settings/backup-notifications-settings.md)
    - Visuelle Indikatoren (graue Symbole) wenn NTFY oder E-Mail nicht richtig konfiguriert ist

- **Lokalisierung:**
    - neue Umgebungsvariable `LANG` zum Festlegen der Sprache in der Anwendung erstellt
    - jetzt ist das Format von Daten und Zahlen in den Benachrichtigungen und Protokollen vorhersehbar

## 🔒 Sicherheitsverbesserungen {/* #-security-enhancements */}

### CSRF-Schutz {/* #csrf-protection */}

- **Sitzungsbasierte Authentifizierung** mit robustem Sitzungsmanagement
- **CSRF-Token-Validierung** für alle API-Anfragen, die den Zustand ändern
- **Sitzungen laufen automatisch nach 24 Stunden ab**; CSRF-Tokens werden alle 30 Minuten aktualisiert
- Sicherung gegen Cross-Site Request Forgery, während die Kompatibilität mit externen APIs erhalten bleibt

### Minimierung von Klartext-Passwörtern {/* #plaintext-password-minimization */}

- **Passwörter können nur über die Benutzeroberfläche festgelegt werden**; kein API-Endpunkt gibt gespeicherte Passwörter preis
- **Manipulation von Klartext-Passwörtern ist im gesamten System minimiert**

### Erweiterte Kryptografie für sensible Daten {/* #advanced-cryptography-for-sensitive-data */}

- **Verschlüsselung sensibler Daten** (z. B. Passwörter, SMTP-Anmeldeinformationen) mit AES-256-GCM
- **Master-Schlüssel wird automatisch generiert** und sicher in `.duplistatus.key` gespeichert
- **PBKDF2 mit 100.000 Iterationen** zur Schlüsselerzeugung zur Verstärkung der Sicherheit
- **Authentifizierungstags werden überprüft** und der Speicher wird nach der Verwendung sicher gelöscht
- **Berechtigungen der Master-Schlüsseldatei** werden strikt auf 0400 gesetzt, um den maximalen Schutz zu gewährleisten

## 🚀 Migrationshinweise {/* #-migration-notes */}

### Von Version 0.7.x {/* #from-version-07x */}

Diese Version enthält signifikante Sicherheitsverbesserungen und neue Funktionen. Beim Upgrade von Version 0.7.x:

1. **Automatische Datenbankmigration:** Die Anwendung migriert automatisch das Datenbankschema, um neue Funktionen zu unterstützen
2. **Master-Schlüsselgenerierung:** Ein neuer Master-Schlüssel wird für die Verschlüsselung sensibler Daten generiert
3. **Sitzungsverwaltung:** Bestehende Sitzungen werden ungültig gemacht und neue CSRF-geschützte Sitzungen werden eingerichtet
4. **Konfigurationsupdates:** Einige Konfigurationsschlüssel wurden aktualisiert, um neue Funktionen zu unterstützen
5. **Vorlagenänderungen:** Die Variablen `{backup_interval_value}` und `{backup_interval_type}` wurden durch `{backup_interval}` ersetzt. Standardvorlagen werden automatisch angepasst, aber angepasste Vorlagen werden nicht migriert. Bitte überprüfen Sie Ihre Vorlagen.

### Sicherheitsaspekte {/* #security-considerations */}

- **Master-Schlüsseldatei:** Stellen Sie sicher, dass die `.duplistatus.key`-Datei richtig gesichert und gesichert ist
- **Dateiberechtigungen:** Die Master-Schlüsseldatei wird eingeschränkte Berechtigungen (0400) haben, um die Sicherheit zu gewährleisten
- **Passwortverschlüsselung:** Bestehende Passwörter werden mit dem neuen kryptografischen System verschlüsselt
