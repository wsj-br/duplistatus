# Version 0.8.x {/* #version-08x */}

## Übersicht {/* #overview */}

Version 0.8.x ist ein umfangreiches Update, das bedeutende Sicherheitsverbesserungen, verbesserte Serververwaltungsfunktionen und ein umfassendes Benachrichtigungssystem mit SMTP-E-Mail-Unterstützung einführt. Diese Veröffentlichung konzentriert sich auf die Stärkung der Sicherheit, Verbesserung der Benutzerfreundlichkeit und Bereitstellung flexiblerer Optionen zur Backup-Überwachung.

## Neue Funktionen {/* #new-features */}

### Verbesserungen bei der Serververwaltung {/* #server-management-enhancements */}

- **Automatische Speicherung von Server-URL und Passwort** beim Sammeln von Backups
  - Benutzer können URL und Passwort auf zwei Arten aktualisieren:
     - Neues Sammeln von Backups mit aktualisierten Werten
     - Ändern der Einstellungen unter [Einstellungen → Servereinstellungen](../user-guide/settings/server-settings.md)

### Erweiterte Backup-Überwachung {/* #enhanced-backup-monitoring */}

- **Neuer `Backup monitoring` Konfigurationsbereich** mit Duplicati-Server-kompatiblen Intervalleinstellungen
    - Unterstützung für benutzerdefinierte Intervalle (z.B. "1D12h")
    - Automatische Aktualisierung überfälliger Intervalle aus der Duplicati-Konfiguration während des Backup-Protokollsammlungsprozesses
    - **Empfohlen:** Führen Sie die Sammlung nach Änderung der Backup-Jobintervalle im Duplicati-Server durch, um die duplistatus-Konfiguration zu synchronisieren
    - Benachrichtigungsvorlagen verwenden jetzt `{backup_interval}` anstelle von `{backup_interval_value}` und `{backup_interval_type}`.

### NTFY-Gerätekonfiguration {/* #ntfy-device-configuration */}

- **QR-Code-Generierung** für automatische Gerätekonfiguration zum Empfangen von Benachrichtigungen von **duplistatus**
   - Rechtsklick auf die `View NTFY Messages` Schaltfläche in der Anwendungssymbolleiste
   - "Gerät konfigurieren"-Schaltfläche unter [Einstellungen → NTFY-Einstellungen](../user-guide/settings/ntfy-settings.md)

### Verbesserte Backup-Sammlung {/* #improved-backup-collection */}

- **Automatische HTTP/HTTPS-Erkennung**, Verbindungen werden in dieser Reihenfolge versucht: HTTPS → HTTPS mit selbstsigniertem Zertifikat → HTTP-Fallback
- **Serverauswahl-Dropdown** in der `Collect Backup Logs` Oberfläche für direkte serverspezifische Sammlung
- **Mehrere Adressen** im Hostnamen (durch Komma getrennt) werden nun akzeptiert (müssen dasselbe Passwort und Port teilen)
- **Einzelserver-Backup-Sammelfunktionen** hinzugefügt zu `Dashboard (table)`, [Einstellungen → Backup-Überwachung](../user-guide/settings/backup-monitoring-settings.md) und [Einstellungen → Server](../user-guide/settings/server-settings.md)
- **Massensammlungsfunktion** für alle Server mit gültiger Konfiguration (URL und Passwort)
   - `Collect All` Schaltflächen unter [Einstellungen → Backup-Überwachung](../user-guide/settings/backup-monitoring-settings.md) und [Einstellungen → Server](../user-guide/settings/server-settings.md)
   - Kontextmenü per Rechtsklick auf `Collect Backup Logs` Schaltfläche in der Anwendungssymbolleiste

### Erweitertes Benachrichtigungssystem {/* #enhanced-notification-system */}

- **SMTP-E-Mail-Benachrichtigungsunterstützung:**
    - SMTP-Server-Konfiguration unter [Einstellungen → E-Mail-Einstellungen](../user-guide/settings/email-settings.md)
    - Einzelne Konfiguration pro Backup-Job für NTFY und/oder E-Mail-Benachrichtigungen
    - HTML-formatierte Vorlagen unter Verwendung vorhandener [Einstellungen → Benachrichtigungsvorlagen](../user-guide/settings/notification-templates.md)
- **Einzelne Benachrichtigungskonfiguration pro Backup-Job:**
    - Individuelle Benachrichtigungseinstellungen unter [Einstellungen → Backup-Benachrichtigungen](../user-guide/settings/backup-notifications-settings.md)
    - Visuelle Indikatoren (ausgegraute Symbole), wenn NTFY oder E-Mail nicht ordnungsgemäß konfiguriert sind

- **Lokalisierungsunterstützung:**
    - Neue Umgebungsvariable `LANG` erstellt, um die Lokalisierung in der Anwendung festzulegen
    - Jetzt ist das Format von Datumsangaben und Zahlen in den Benachrichtigungen und Protokollen vorhersehbar

## 🔒 Sicherheitsverbesserungen {/* #-security-enhancements */}

### CSRF-Schutz {/* #csrf-protection */}

- **Sitzungsbasierte Authentifizierung** mit robuster Sitzungsverwaltung
- **CSRF-Token-Validierung** erzwungen für alle API-Anfragen, die den Zustand ändern
- **Sitzungen laufen automatisch** nach 24 Stunden ab; CSRF-Tokens werden alle 30 Minuten aktualisiert
- Gewährleistet Schutz vor Cross-Site Request Forgery, während die Kompatibilität mit externen APIs erhalten bleibt

### Minimierung von Klartext-Passwörtern {/* #plaintext-password-minimization */}

- **Passwörter können nur über die Benutzeroberfläche festgelegt werden**; kein API-Endpunkt zeigt gespeicherte Passwörter an
- **Die Manipulation von Klartext-Passwörtern wird im gesamten System minimiert**

### Fortgeschrittene Kryptografie für sensible Daten {/* #advanced-cryptography-for-sensitive-data */}

- **Verschlüsselung sensibler Daten** (z.B. Passwörter, SMTP-Zugangsdaten) unter Verwendung von AES-256-GCM
- **Hauptschlüssel wird automatisch generiert** und sicher in `.duplistatus.key` gespeichert
- **PBKDF2 mit 100.000 Iterationen** zur Schlüsselableitung verwendet, um die Sicherheit zu stärken
- **Authentifizierungstags werden überprüft** und der Speicher nach der Verwendung sicher geleert
- **Dateiberechtigungen für den Hauptschlüssel** sind strikt auf 0400 gesetzt, um maximalen Schutz zu gewährleisten

## 🚀 Migrationshinweise {/* #-migration-notes */}

### Von Version 0.7.x {/* #from-version-07x */}

Diese Version enthält erhebliche Sicherheitsverbesserungen und neue Funktionen. Beim Upgrade von Version 0.7.x:

1. **Automatische Datenbankmigration:** Die Anwendung wird Ihr Datenbankschema automatisch migrieren, um neue Funktionen zu unterstützen
2. **Generierung des Hauptschlüssels:** Ein neuer Hauptschlüssel wird für die Verschlüsselung sensibler Daten generiert
3. **Session-Verwaltung:** Bestehende Sitzungen werden ungültig gemacht und neue CSRF-geschützte Sitzungen werden eingerichtet
4. **Konfigurationsaktualisierungen:** Einige Konfigurationsschlüssel wurden aktualisiert, um neue Funktionen zu unterstützen
5. **Vorlagenänderungen:** Die Variablen `{backup_interval_value}` und `{backup_interval_type}` wurden durch `{backup_interval}` ersetzt. Standardvorlagen werden automatisch angepasst, aber individuelle Vorlagen werden nicht migriert. Bitte prüfen Sie Ihre Vorlagen.

### Sicherheitsaspekte {/* #security-considerations */}

- **Hauptschlüsseldatei:** Stellen Sie sicher, dass die Datei `.duplistatus.key` ordnungsgemäß gesichert und geschützt ist
- **Dateiberechtigungen:** Die Hauptschlüsseldatei erhält eingeschränkte Berechtigungen (0400) aus Sicherheitsgründen
- **Passwortverschlüsselung:** Bestehende Passwörter werden mit dem neuen kryptografischen System verschlüsselt
