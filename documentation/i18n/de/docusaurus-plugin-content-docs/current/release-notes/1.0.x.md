# Version 1.0.x {/* #version-10x */}

## Übersicht {/* #overview */}

Version 1.0.x ist eine Funktionsversion, die signifikante Verbesserungen bei der E-Mail-Konfiguration, den Serververwaltungsfunktionen und den Datenbankwartungstools einführt. Diese Version konzentriert sich auf die Verbesserung der Zuverlässigkeit von E-Mail-Benachrichtigungen, die Erweiterung der SMTP-Verbindungsoptionen und die Bereitstellung besserer Werkzeuge zur Verwaltung von Servern und Datenbankintegrität.

## Neue Funktionen {/* #new-features */}

### Serververwaltungserweiterungen {/* #server-management-enhancements */}

- **Funktion zum Ändern des Serverpassworts** - Benutzer können jetzt Serverpasswörter direkt über die Serverdetailseite ändern, indem sie auf das Schlüsselsymbol klicken
- **Erkennung und Zusammenführen doppelter Server** - Neue Funktion im Formular für Datenbankwartung zur Erkennung doppelter Server und Zusammenführen zu einem einzigen Servereintrag

### Verbesserungen der Audit-Protokollierung {/* #audit-logging-enhancements */}

- **Audit-Protokollierung für Sicherungsuploads** - Alle Sicherungsprotokoll-Uploads über den `/api/upload`-Endpunkt werden jetzt automatisch im Audit-Protokoll erfasst. Jeder Eintrag enthält Sicherheitsdetails (Server-ID, Servername, Backup-Name, Status, Datum, Dauer, Dateianzahl, Größen, Warnungen und Fehler) zusammen mit Client-IP-Adresse und Benutzer-Agent-Informationen zu Tracking- und Sicherheitszwecken

### E-Mail-Konfigurationserweiterungen {/* #email-configuration-enhancements */}

- **Hinweis auf unvollständige Konfiguration** - Visueller Hinweis wird angezeigt, wenn E-Mail-Einstellungen nicht ordnungsgemäß konfiguriert sind
- **Indikatoren für Service-Status** - "(deaktiviert)"-Beschriftungen werden auf Benachrichtigungs-Checkboxes angezeigt, wenn E-Mail-Dienste nicht konfiguriert sind
- **Anpassbare Absenderinformationen**:
  - `Sender Name`-Feld zur Anpassung des Anzeigenamens, der als Absender in E-Mail-Benachrichtigungen gezeigt wird
  - `From Address`-Feld zur Angabe der E-Mail-Adresse, die als Absender gezeigt wird
  - Hinweis: Einige E-Mail-Anbieter überschreiben den `From Address` mit dem `SMTP Server Username`
- **SMTP-Authentifizierungsschalter** - Option zum Aktivieren oder Deaktivieren der SMTP-Authentifizierung, unterstützt Server, die keine Authentifizierung benötigen
- **E-Mail-Formatvalidierung** - Validierung für Empfänger- und Absenderadressfelder zur Sicherstellung des richtigen E-Mail-Adressformats
- **Verbesserter Test-E-Mail** - Test-E-Mail zeigt jetzt umfassende Verbindungsdetails an, einschließlich SMTP-Server-Hostname, Port, Verbindungstyp, Authentifizierungsstatus, Benutzername (falls zutreffend), Empfänger-E-Mail, Absenderadresse, Absendername und Test-Zeitstempel

### Unterstützung für SMTP-Verbindungstypen {/* #smtp-connection-type-support */}

- **Mehrere Verbindungstypen** - Unterstützung für drei Verbindungstypen:
  - `Plain SMTP` (keine Verschlüsselung) auf Port 25
  - `STARTTLS` (Upgrade auf TLS) auf Port 587
  - `Direct SSL/TLS` (verschlüsselt ab Start) auf Port 465
- **Standard-Verbindungstyp** - Geändert zu `Direct SSL/TLS` für neue Konfigurationen
- **Verbindungsspezifische Anforderungen** - `From Address`-Feld ist für `Plain SMTP`-Verbindungen erforderlich, um ordnungsgemäße Identifizierung des E-Mail-Absenders und RFC 5322-Konformität sicherzustellen

## 🐛 Fehlerbehebungen {/* #-bug-fixes */}

### E-Mail-Systemkorrekturen {/* #email-system-fixes */}

- **Behobener fehlender `From`-Header** - RFC 5322-Konformitätsfehler behoben, indem sichergestellt wurde, dass alle E-Mail-Nachrichten ordnungsgemäße `From`-Header enthalten
- **Behobene E-Mail-Verschlüsselung für STARTTLS** - Korrigierte Verschlüsselungsbehandlung für `STARTTLS`-Verbindungen (Port 587)
- **Behobene Plain SMTP-Verbindungen** - TLS-Verhandlungsfehler behoben, die `Plain SMTP`-Verbindungen zum Scheitern brachten
- **Behobener Verlust ungespeicherter Konfiguration** - Verhindert, dass ungespeicherte E-Mail-Konfiguration beim Ändern des Passworts gelöscht wird
- **Behobene veraltete SMTP-Konfiguration** - Problem behoben, bei dem der Test-E-Mail-Endpunkt eine veraltete SMTP-Konfiguration verwendete

### Benutzeroberflächenkorrekturen {/* #user-interface-fixes */}

- **Behobener Passwort-Sichtbarkeitsschalter** - Verhalten der Passwortanzeige-Funktion im Passwortänderungsformular korrigiert; Klicken auf das Augensymbol zeigt jetzt das Passwort für beide Passwortfelder gleichzeitig an

### Systemkorrekturen {/* #system-fixes */}

- **Behobenes Docker-Entrypoint-Logging** - Problem behoben, bei dem das Docker-Entrypoint-Skript Protokollmeldungen verworfen hat
- **Behobene Berechnung des nächsten Ausführungsdatums** - Automatische Neuberechnung des `Next Run`-Datums nach Sammeln der Sicherungsprotokolle hinzugefügt, um sicherzustellen, dass das Datum nach Protokollsammlung korrekt aktualisiert wird

## 🚀 Migrationshinweise {/* #-migration-notes */}

### Von Version 0.9.x {/* #from-version-09x */}

Diese Version enthält Verbesserungen bei der E-Mail-Konfiguration und Serververwaltung. Beim Upgrade von Version 0.9.x:

1. **Keine Datenbankmigration erforderlich** - Diese Version erfordert keine Änderungen am Datenbankschema
2. **Aktualisierungen der E-Mail-Konfiguration** - Bestehende E-Mail-Konfigurationen funktionieren weiterhin, Sie sollten Ihre Einstellungen jedoch überprüfen und aktualisieren, um die neuen Funktionen zu nutzen:
   - Erwägen Sie die Festlegung einer benutzerdefinierten `Sender Name` für eine bessere E-Mail-Identifikation
   - Überprüfen Sie, ob Ihr `From Address` korrekt eingestellt ist, insbesondere wenn Sie `Plain SMTP`-Verbindungen verwenden
   - Testen Sie Ihre E-Mail-Konfiguration mit der verbesserten Test-E-Mail-Funktion
3. **Standard-Verbindungstyp** - Neue E-Mail-Konfigurationen verwenden standardmäßig den `Direct SSL/TLS`-Verbindungstyp
4. **Server-Passwortverwaltung** - Sie können Server-Passwörter jetzt direkt auf der Server-Detailseite ändern, ohne Backups neu sammeln zu müssen

### Empfehlungen zur E-Mail-Konfiguration {/* #email-configuration-recommendations */}

- **Für Produktiveinsatz**: Verwenden Sie `STARTTLS`- oder `Direct SSL/TLS`-Verbindungen für sichere E-Mail-Zustellung
- **Für lokale Tests**: `Plain SMTP`-Verbindungen sind für vertrauenswürdige lokale Netzwerke verfügbar
- **Absenderadresse erforderlich**: Wenn Sie `Plain SMTP` verwenden oder wenn Authentifizierung deaktiviert ist, stellen Sie sicher, dass das Feld `From Address` ordnungsgemäß konfiguriert ist
- **Testen Sie Ihre Konfiguration**: Verwenden Sie immer die Schaltfläche "Test-E-Mail senden", um zu überprüfen, ob Ihre E-Mail-Einrichtung korrekt funktioniert

## API-Endpunkte {/* #api-endpoints */}

### E-Mail-Konfigurationsendpunkte {/* #email-configuration-endpoints */}

- `GET /api/email/config` - E-Mail-Konfiguration abrufen
- `POST /api/email/config` - E-Mail-Konfiguration aktualisieren
- `POST /api/email/test` - Test-E-Mail senden
- `DELETE /api/email/config` - E-Mail-Konfiguration löschen

### Serververwaltungsendpunkte {/* #server-management-endpoints */}

- `PATCH /api/servers/{id}/password` - Server-Passwort aktualisieren
- `POST /api/database/maintenance/merge-duplicate-servers` - Doppelte Server zusammenführen
