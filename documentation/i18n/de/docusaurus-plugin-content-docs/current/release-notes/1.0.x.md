# Version 1.0.x {/* #version-10x */}

## Übersicht {/* #overview */}

Version 1.0.x ist ein Funktionsrelease, das bedeutende Verbesserungen bei der E-Mail-Konfiguration, den Serververwaltungsfunktionen und den Werkzeugen zur Datenbankverwaltung einführt. Dieses Release konzentriert sich auf die Verbesserung der Zuverlässigkeit von E-Mail-Benachrichtigungen, die Erweiterung der SMTP-Verbindungsoptionen und die Bereitstellung besserer Werkzeuge zur Verwaltung von Servern und der Integrität von Datenbanken.

## Neue Funktionen {/* #new-features */}

### Server-Management-Erweiterungen {/* #server-management-enhancements */}

- **Funktion zur Änderung des Serverpassworts** - Benutzer können jetzt Serverpasswörter direkt von der Serverdetailseite aus ändern, indem sie auf das Schlüsselsymbol klicken
- **Erkennung und Zusammenführung doppelter Server** - Neue Funktion im Formular zur Datenbankverwaltung zur Erkennung doppelter Server und deren Zusammenführung in einen einzelnen Servereintrag

### Verbesserungen beim Audit-Logging {/* #audit-logging-enhancements */}

- **Audit-Logging für Backup-Uploads** - Alle Backup-Protokoll-Uploads über den `/api/upload`-Endpunkt werden jetzt automatisch im Audit-Protokoll erfasst. Jeder Eintrag enthält Backup-Details (Server-ID, Servername, Backup-Name, Status, Datum, Dauer, Dateizahlen, Größen, Warnungen und Fehler) sowie die IP-Adresse des Clients und Informationen zum Benutzer-Agenten zur Nachverfolgung und Sicherheitszwecken.

### Verbesserungen der E-Mail-Konfiguration {/* #email-configuration-enhancements */}

- **Hinweis auf unvollständige Konfiguration** - Visuelle Warnung wird angezeigt, wenn die E-Mail-Einstellungen nicht ordnungsgemäß konfiguriert sind
- **Statusanzeigen für Dienste** - "(deaktiviert)"-Labels werden auf den Kontrollkästchen für Benachrichtigungen angezeigt, wenn die E-Mail-Dienste nicht konfiguriert sind
- **Anpassbare Absenderinformationen**:
  - `Sender Name`-Feld zur Anpassung des angezeigten Namens, der als Absender in E-Mail-Benachrichtigungen angezeigt wird
  - `From Address`-Feld zur Angabe der E-Mail-Adresse, die als Absender angezeigt wird
  - Hinweis: Einige E-Mail-Anbieter überschreiben die `From Address` mit der `SMTP Server Username`
- **Umschalter für SMTP-Authentifizierung** - Option zum Aktivieren oder Deaktivieren der SMTP-Authentifizierung, die Server unterstützt, die keine Authentifizierung erfordern
- **Validierung des E-Mail-Formats** - Validierung der Felder für Empfänger- und Absenderadresse, um das richtige E-Mail-Adressformat sicherzustellen.
- **Erweiterte Test-E-Mail** - Die Test-E-Mail zeigt jetzt umfassende Verbindungsdetails an, einschließlich SMTP-Server-Hostname, Port, Verbindungstyp, Authentifizierungsstatus, Benutzername (falls zutreffend), Empfänger-E-Mail, Absenderadresse, Absendername und Test-Zeitstempel.

### Unterstützung für SMTP-Verbindungstypen {/* #smtp-connection-type-support */}

- **Mehrere Verbindungstypen** - Unterstützung für drei Verbindungstypen:
  - `Plain SMTP` (keine Verschlüsselung) auf Port 25
  - `STARTTLS` (Upgrade auf TLS) auf Port 587
  - `Direct SSL/TLS` (verschlüsselt von Anfang an) auf Port 465
- **Standardverbindungstyp** - Geändert auf `Direct SSL/TLS` für neue Konfigurationen
- **Verbindungsspezifische Anforderungen** - `From Address`-Feld ist erforderlich für `Plain SMTP`-Verbindungen, um eine ordnungsgemäße Identifizierung des E-Mail-Absenders und die Einhaltung von RFC 5322 sicherzustellen.

## 🐛 Fehlerbehebungen {/* #-bug-fixes */}

### Fehlerbehebungen im E-Mail-System {/* #email-system-fixes */}

- **Fehler im fehlenden `From`-Header behoben** - RFC 5322-Konformitätsfehler behoben, indem sichergestellt wurde, dass alle E-Mail-Nachrichten ordnungsgemäße `From`-Header enthalten
- **Fehler bei der E-Mail-Verschlüsselung für STARTTLS behoben** - Korrektur der Verschlüsselungsbehandlung für `STARTTLS`-Verbindungen (Port 587)
- **Fehler bei einfachen SMTP-Verbindungen behoben** - TLS-Verhandlungsfehler behoben, die dazu führten, dass `Plain SMTP`-Verbindungen fehlschlugen
- **Fehler beim Verlust nicht gespeicherter Konfiguration behoben** - Verhindert, dass nicht gespeicherte E-Mail-Konfigurationen beim Ändern des Passworts gelöscht werden.
- **Fehler bei veralteter SMTP-Konfiguration behoben** - Problem behoben, bei dem der Test-E-Mail-Endpunkt eine veraltete SMTP-Konfiguration verwendete.

### Fehlerbehebungen in der Benutzeroberfläche {/* #user-interface-fixes */}

- **Fehler beim Umschalter für die Passwortsichtbarkeit behoben** - Verhalten der Funktion zum Anzeigen des Passworts im Passwortänderungsformular korrigiert; Ein Klick auf das Augensymbol zeigt jetzt das Passwort für beide Passwortfelder gleichzeitig an.

### Fehlerbehebungen im System {/* #system-fixes */}

- **Fehler beim Docker-Entrypoint-Logging behoben** - Problem behoben, bei dem das Docker-Entrypoint-Skript Protokollnachrichten verlor
- **Fehler bei der Berechnung des nächsten Ausführungsdatums behoben** - Automatische Neuberechnung des `Next Run`-Datums nach dem Sammeln von Backup-Protokollen hinzugefügt, um sicherzustellen, dass das Datum nach der Protokollsammlung korrekt aktualisiert wird.

## 🚀 Migrationshinweise {/* #-migration-notes */}

### Von Version 0.9.x {/* #from-version-09x */}

Diese Version enthält Verbesserungen bei der E-Mail-Konfiguration und Serververwaltung. Beim Upgrade von Version 0.9.x:

1. **Keine Datenbankmigration erforderlich** - Diese Version erfordert keine Änderungen am Datenbankschema
2. **E-Mail-Konfiguration Updates** - Bestehende E-Mail-Konfigurationen funktionieren weiterhin, Sie sollten jedoch Ihre Einstellungen überprüfen und aktualisieren, um neue Funktionen zu nutzen:
   - Überlegen Sie, eine benutzerdefinierte `Sender Name` festzulegen, um die E-Mail-Identifikation zu verbessern
   - Stellen Sie sicher, dass Ihr `From Address` korrekt eingestellt ist, insbesondere wenn Sie `Plain SMTP` Verbindungen verwenden
   - Testen Sie Ihre E-Mail-Konfiguration mit der erweiterten Test-E-Mail-Funktion
3. **Standardverbindungstyp** - Neue E-Mail-Konfigurationen verwenden standardmäßig den `Direct SSL/TLS` Verbindungstyp
4. **Server-Passwortverwaltung** - Sie können nun Server-Passwörter direkt von der Server-Detailseite aus ändern, ohne Backups neu sammeln zu müssen

### E-Mail-Konfiguration Empfehlungen {/* #email-configuration-recommendations */}

- **Für den Produktionsbetrieb**: Verwenden Sie `STARTTLS` oder `Direct SSL/TLS` Verbindungen für sichere E-Mail-Übertragung
- **Für lokale Tests**: `Plain SMTP` Verbindungen sind für vertrauenswürdige lokale Netzwerke verfügbar
- **Absenderadresse erforderlich**: Wenn Sie `Plain SMTP` verwenden oder die Authentifizierung deaktiviert ist, stellen Sie sicher, dass das `From Address` Feld korrekt konfiguriert ist
- **Testen Sie Ihre Konfiguration**: Verwenden Sie immer die Schaltfläche "Test-E-Mail senden", um zu überprüfen, ob Ihre E-Mail-Einrichtung korrekt funktioniert

## API-Endpunkte {/* #api-endpoints */}

### E-Mail-Konfiguration Endpunkte {/* #email-configuration-endpoints */}

- `GET /api/email/config` - E-Mail-Konfiguration abrufen
- `POST /api/email/config` - E-Mail-Konfiguration aktualisieren
- `POST /api/email/test` - Test-E-Mail senden
- `DELETE /api/email/config` - E-Mail-Konfiguration löschen

### Server-Management Endpunkte {/* #server-management-endpoints */}

- `PATCH /api/servers/{id}/password` - Server-Passwort aktualisieren
- `POST /api/database/maintenance/merge-duplicate-servers` - Doppelte Server zusammenführen
