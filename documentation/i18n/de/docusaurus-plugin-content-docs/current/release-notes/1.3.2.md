# Version 1.3.2 {/* #version-132 */}

## Übersicht {/* #overview */}

Version 1.3.2 ist eine Wartungsversion, die Sicherheitslücken in Abhängigkeiten behebt, Warnungen bei der Installation von pnpm (peer webpack und veraltete Unterabhängigkeiten) behebt, Lint- und Build-Warnungen in der App und Dokumentation löst und die Dokumentation auf die aktuellen Docker-Skriptnamen und Paketversionen aktualisiert.

## Sicherheit {/* #security */}

### Abhängigkeitsvulnerabilitätsbehebungen {/* #dependency-vulnerability-fixes */}

- **Dependabot-Abhängigkeitsupdates (Dokumentation)**: Zwei Dependabot-PRs wurden zusammengeführt, um Sicherheitslücken im Dokumentationsarbeitsbereich zu beheben:
  - **ajv** in `/documentation`: aktualisiert von 8.17.1 auf 8.18.0 und von 6.12.6 auf 6.14.0.
  - **fast-xml-parser** in `/documentation`: aktualisiert von 5.3.5 auf 5.3.8.
  Beide wurden über den dependabot multi-update für /documentation zusammengeführt.

- **pnpm-Overrides für hochgradige Sicherheitslücken**: pnpm-Overrides wurden hinzugefügt, um vier hochgradige Sicherheitsprobleme zu beheben:
  - **minimatch** (>=3.1.4): Behebt GHSA-3ppc-4f35-3m26 (ReDoS durch wiederholte Wildcards), GHSA-7r86-cg39-jmmj (kombinatorische Rückwärtsverfolgung) und GHSA-23c5-xmqv-rm74 (nested extglobs backtracking) in documentation > @docusaurus/core > serve-handler > minimatch.
  - **serialize-javascript** (>=7.0.3): Behebt GHSA-5c6j-r48x-rmvq (RCE über RegExp.flags und Date.prototype.toISOString()) in webpack > terser-webpack-plugin > serialize-javascript.

## Fehlerbehebungen {/* #bug-fixes */}

- **pnpm-Installationswarnungen**: Drei Installationswarnungen wurden behoben: (1) Unmet peer `webpack@5.104.1` von `next-intlayer` > `@intlayer/webpack` (Projekt hat webpack 5.105.3) durch Hinzufügen von `pnpm.peerDependencyRules.allowedVersions.webpack: "5"` in root `package.json`. (2) Veraltete Unterabhängigkeiten `prebuild-install@7.1.3` (von better-sqlite3) und `whatwg-encoding@3.1.1` (von documentation > docusaurus-search-local > cheerio) durch Hinzufügen von `pnpm.allowedDeprecatedVersions` für beide, damit die Installation ohne Warnungen läuft.
- **Anwendungsprotokolle-Viewer (exhaustive-deps)**: Die react-hooks/exhaustive-deps-Warnung für den Auto-scroll-Effekt wurde behoben. `logData` wird absichtlich aus dem Abhängigkeitsarray ausgeschlossen, damit das Scrollen nur bei Änderungen von Auto-scroll oder der ausgewählten Datei erfolgt, nicht bei jedem Poll; das neue Zeilen-Scrollen wird in `loadLogs` behandelt. Eine eslint-disable-next-line mit einem kurzen Kommentar wurde hinzugefügt.
- **Build-Warnung vscode-languageserver-types (Dokumentation)**: Die Webpack "Critical dependency: require function is used in a way in which dependencies cannot be statically extracted"-Warnung für die transitive Abhängigkeit `vscode-languageserver-types` (von intlayer-editor) im Dokumentationsbuild (Docusaurus) wurde über ein Inline-Plugin in `documentation/docusaurus.config.ts` unterdrückt, das `ignoreWarnings` hinzufügt. Die Warnung tritt nur beim Dokumentationsbuild, nicht beim Hauptprogramm auf.

## Migrationshinweise {/* #migration-notes */}

### Von Version 1.3.1 {/* #from-version-131 */}

Wann Sie auf Version 1.3.2 aktualisieren:

1. **Keine Datenbankmigration erforderlich**: Diese Version erfordert keine Änderungen am Datenbankschema.
2. **Docker-Befehle**: Wenn Sie die dokumentierten pnpm-Skripte verwenden, verwenden Sie `pnpm docker:up`, `pnpm docker:down`, `pnpm docker:clean` und `pnpm docker:devel` anstelle der vorherigen `docker-up`, `docker-down`, etc.
3. **Abhängigkeiten**: Führen Sie `pnpm install` aus, um die aktualisierte Sperrdatei und die Overrides anzuwenden; für typische Installationen sind keine manuellen Änderungen an den Abhängigkeiten erforderlich.
