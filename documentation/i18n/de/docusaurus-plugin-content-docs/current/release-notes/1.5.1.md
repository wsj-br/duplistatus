# Version 1.5.1 {/* #version-151 */}

## Übersicht {/* #overview */}

Version 1.5.1 ist ein Wartungs- und Sicherheits-Release. Es aktualisiert Next.js, um SSRF bei der Bildoptimierung, Cache Poisoning und verwandte Probleme zu beheben, stärkt die Verschlüsselung gespeicherter Geheimnisse und öffnet benutzerdefinierte NTFY-Server-Links auf dem von Ihnen konfigurierten Server. Veröffentlichte Container-Images für amd64 und arm64 teilen sich wieder einen Digest.

---

## Verbesserungen {/* #improvements */}

### Dokumentation {/* #documentation */}

- **Dokumentations-Startseite**: Die Wurzel der Dokumentationsseite ist jetzt eine Produktseite, die den Sicherungs-Status, Screenshots, Sicherheit und Installation abdeckt, anstatt auf die Einführung weiterzuleiten. **Docs** und `/intro` öffnen weiterhin den Leitfaden.

---

## Fehlerbehebungen {/* #bug-fixes */}

- **Benutzerdefinierte NTFY Server-Links (Problem #85)**: Der Link zum Thema Einstellungen und das NTFY-Symbol in der Symbolleiste öffnen den von Ihnen konfigurierten Server. Sie führen nicht mehr immer zu `https://ntfy.sh`.
- **Multi-Architektur-Images**: Release-Builds fügen keine Provenance-Attestierungen mehr hinzu, sodass die GitHub Container Registry und Docker Hub sich einen Digest teilen und `linux/amd64` sowie `linux/arm64` gemeinsam getaggt werden.

---

## Sicherheit {/* #security */}

### Framework und gespeicherte Geheimnisse {/* #framework-and-stored-secrets */}

- **Next.js 16.4.3**: `package.json` deklariert 16.3.8 (Dependabot #84). Die Abhängigkeitsüberschreibung installiert 16.4.3, das die Fixes dieser Version für SSRF bei der Bildoptimierung, Probleme mit Metadaten-Routen und Cache-Poisoning, Draft Mode-Leckagen durch `use cache` und eine Informationspreisgabe im Entwicklungsserver enthält.
- **Stärkere Geheimnisverschlüsselung**: Neue und erneut gespeicherte Geheimnisse verwenden PBKDF2-SHA256 mit 600.000 Iterationen, gegenüber 100.000. Bereits mit der vorherigen Anzahl gespeicherte Geheimnisse werden weiterhin entschlüsselt. Das erneute Speichern eines Geheimnisses schreibt es mit der höheren Anzahl neu.

## Migrationshinweise {/* #migration-notes */}

### Ab Version 1.5.0 {/* #from-version-150 */}

Wann Sie auf Version 1.5.1 aktualisieren:

1. **Keine Datenbankmigration erforderlich**: Diese Version ändert das Datenbankschema nicht. Bestehende verschlüsselte Geheimnisse funktionieren weiterhin.
2. **Abhängigkeiten**: Führen Sie `pnpm install` aus, um die aktualisierte Lockfile und die Overrides anzuwenden.
3. **Keine Konfigurationsänderungen erforderlich**: API-Schlüssel, Zulassungslisten, Benachrichtigungseinstellungen und NTFY Server-URLs bleiben unverändert.
