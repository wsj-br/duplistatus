# Version 1.3.0 {/* #version-130 */}

## Übersicht {/* #overview */}

Version 1.3.0 führt konfigurierbare Passwortrichtlinien, einen neuen Anwendungsprotokolle-Viewer für Administratoren, eine gebietsschema-aware Wochentagsanzeige und mehrere Verbesserungen der Benutzerfreundlichkeit ein. Diese Version konzentriert sich auf verbesserte administrative Tools und erweiterte Internationalisierungsunterstützung.

## Neue Funktionen {/* #new-features */}

### Konfigurierbare Passwortrichtlinie {/* #configurable-password-policy */}

- **Passwortrichtlinien-Umgebungsvariablen**: Konfigurieren Sie Passwortvalidierungsanforderungen über Umgebungsvariablen:
  - `PWD_ENFORCE`: Legen Sie dies auf `false` fest, um Komplexitätsanforderungen für Passwörter (Großbuchstaben, Kleinbuchstaben, Zahlen) zu deaktivieren. Standardmäßig werden alle Regeln erzwungen. Bei Deaktivierung wird nur die Mindestlänge erzwungen.
  - `PWD_MIN_LEN`: Legt die Mindestlänge des Passworts in Zeichen fest. Standardmäßig sind dies 8 Zeichen.
  - Die Standard-Passwortprüfung (Verhinderung der Verwendung des Standard-Admin-Passworts) wird immer erzwungen, unabhängig von der `PWD_ENFORCE`-Einstellung.

### Anwendungsprotokolle-Viewer {/* #application-logs-viewer */}

- **Neuer admin-only Protokolle-Viewer**: Zeigen und laden Sie Anwendungsprotokolle direkt von der Einstellungsseite herunter:
  - Zugriff auf die konsolidierte `application.log`-Datei und rotierte Protokollversionen
  - Konfigurierbarer Zeilenanzahl-Selektor (100, 500, 1000, 5000, 10000 Zeilen)
  - Echtzeit-Suchfilter mit großschreibungsunempfindlicher Textübereinstimmung
  - Umschaltmöglichkeit für automatisches Scrollen zur Echtzeit-Protokollüberwachung mit automatischer Abfrage
  - Kopieren in die Zwischenablage und Exportieren gefilterter Protokolle als Textdatei
  - Anzeige von Dateimetadaten, die die Zeilenanzahl, die Dateigröße und den letzten Änderungszeitstempel anzeigen
  - Protokollrotation beim Container-Start (konfigurierbar über `LOG_ROTATION_VERSIONS`, Standard: 5)

### Kontextbezogene Benutzeranleitung {/* #context-aware-user-guide */}

- **Dynamischer Hilfe-Button**: Die Benutzeranleitung im App-Header öffnet nun Dokumentation, die für die aktuelle Seite relevant ist. Der Tooltip wird aktualisiert, um "Hilfe für `Page Name`" anzuzeigen, um anzuzeigen, welche Dokumentation geöffnet wird.

### Serverkonfigurationserweiterung {/* #server-configuration-enhancement */}

- **Schneller Zugriff auf die Duplicati-Benutzeroberfläche**: Durch Rechtsklicken auf die Serverkonfigurationsschaltfläche oder auf einen beliebigen Server im Serverauswahl-Popover wird die Duplicati-Legacy-Benutzeroberfläche (`/ngax`) in einem neuen Tab geöffnet.

## 🔧 Verbesserungen {/* #-improvements */}

### Gebietsschema-aware Wochentagsanzeige {/* #locale-aware-weekday-display */}

- **Internationalisierte Wochentagsreihenfolge**: Die Wochentagsanzeige im Backup-Überwachungsformular berücksichtigt nun die Gebietsschema-Einstellungen Ihres Browsers. Die Wochentage werden in der richtigen Reihenfolge basierend auf dem Gebietsschema angezeigt (Montag-Sonntag für UK/Europa, Sonntag-Samstag für US/Brasilien).

### Erweitertes SMTP-Fehlerhandling {/* #enhanced-smtp-error-handling */}

- **Verbesserte Fehlermeldungen**: SMTP-Fehlermeldungen bieten nun genauere Anleitungen:
  - Authentifizierungsfehler zeigen klar Benutzernamen/Passwort-Probleme an
  - SSL/TLS-Versionsfehler werden korrekt identifiziert
  - Vorschläge für Verbindungstypen erscheinen nur dann, wenn sie tatsächlich relevant sind

### Verhalten der Toast-Benachrichtigungen {/* #toast-notification-behaviour */}

- **Persistente Fehlerbenachrichtigungen**: Fehler-Toasts bleiben nun bis zum manuellen Schließen erhalten, um sicherzustellen, dass Sie wichtige Fehlermeldungen nicht verpassen. Erfolgreiche und informierende Toasts werden nach 3 Sekunden automatisch geschlossen.

### Tabelle für Benachrichtigungseinstellungen {/* #notification-settings-table */}

- **Vereinfachtes Layout**: Die Tabelle für Benachrichtigungseinstellungen wurde vereinfacht mit einer kombinierten "Server / Backup"-Spalte und kontextuellen Symbolen, die den Status zusätzlicher Zielkonfiguration anzeigen.

## 🚀 Migrationshinweise {/* #-migration-notes */}

### Von Version 1.2.x {/* #from-version-12x */}

Wann Sie auf Version 1.3.0 aktualisieren:

1. **Passwort-Richtlinie**: Die neue Passwort-Richtlinie erzwingt standardmäßig alle Komplexitätsanforderungen. Wenn Sie eine einfachere Passwort-Richtlinie benötigen, konfigurieren Sie die `PWD_ENFORCE` und `PWD_MIN_LEN` Umgebungsvariablen.

2. **Anwendungsprotokolle**: Alle Container-Ausgaben (Server und Cron-Dienst) sind jetzt in einer einzigen `data/logs/application.log` Datei konsolidiert.

3. **Protokollrotation**: Die Protokollrotation ist über die `LOG_ROTATION_VERSIONS` Umgebungsvariable konfigurierbar (Standard: 5 Versionen).

4. **Keine Datenbankmigration erforderlich**: Diese Version erfordert keine Änderungen am Datenbankschema.

## API-Endpunkte {/* #api-endpoints */}

Der folgende API-Endpunkt wurde in dieser Version eingeführt:

### Passwort-Richtlinien-Endpunkt {/* #password-policy-endpoint */}

- `GET /api/auth/password-policy` - Gibt die aktuelle Passwort-Richtlinienkonfiguration zurück

### Anwendungsprotokolle-Endpunkte {/* #application-logs-endpoints */}

- `GET /api/application-logs` - Protokolle mit Dateiauswahl und Tail-Funktionalität anzeigen
- `GET /api/application-logs/export` - Gefilterte Protokolle als Textdatei exportieren

### Entfernte Endpunkte {/* #removed-endpoints */}

Die folgenden ungenutzten API-Endpunkte wurden in dieser Version entfernt:

- `DELETE /api/backups/[backupId]` - Entwicklungsendpunkt, der nie verwendet wurde
- `GET /api/audit-log/stats` - Endpunkt wurde nicht vom Prüfprotokoll-Viewer aufgerufen

## Changelog {/* #changelog */}

### Änderungen in Version 1.3.0 {/* #version-130-changes */}

- **Hinzugefügt**: Konfigurierbare Passwort-Richtlinie über `PWD_ENFORCE` und `PWD_MIN_LEN` Umgebungsvariablen
- **Hinzugefügt**: Anwendungsprotokolle-Viewer in Einstellungen (nur für Admins)
- **Hinzugefügt**: Protokollrotation mit konfigurierbarer Versionsanzahl (`LOG_ROTATION_VERSIONS`)
- **Hinzugefügt**: Kontextabhängiger Benutzerhandbuch-Button, der relevante Dokumentation öffnet
- **Hinzugefügt**: Rechtsklick auf die Serverkonfiguration, um die Duplicati Legacy UI zu öffnen
- **Hinzugefügt**: API-Endpunkt `GET /api/auth/password-policy` zur Konfiguration der Passwort-Richtlinie
- **Hinzugefügt**: API-Endpunkte zum Anzeigen und Exportieren von Anwendungsprotokollen
- **Geändert**: Die Anzeige der Wochentage respektiert jetzt die Browserspracheinstellungen
- **Geändert**: Fehlerbenachrichtigungen bleiben bestehen, bis sie manuell geschlossen werden
- **Geändert**: Erfolgsbenachrichtigungen werden nach 3 Sekunden automatisch geschlossen (zuvor 5 Sekunden)
- **Geändert**: Die Tabelle der Benachrichtigungseinstellungen wurde vereinfacht mit einer kombinierten "Server / Backup"-Spalte
- **Geändert**: Alle Containerprotokolle wurden in einer einzigen `application.log` Datei konsolidiert
- **Verbessert**: SMTP-Fehlermeldungen bieten genauere Hinweise
- **Entfernt**: Unbenutzte API-Endpunkte (`DELETE /api/backups/[backupId]` und `GET /api/audit-log/stats`), die nicht von der Anwendung aufgerufen wurden
