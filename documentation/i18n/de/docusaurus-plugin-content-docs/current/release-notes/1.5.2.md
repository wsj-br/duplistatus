# Version 1.5.2 {/* #version-152 */}

## Übersicht {/* #overview */}

Version 1.5.2 ist eine Wartungsversion. Ab duplicati 2.4.1.0 werden Aufbewahrungsdaten in Sicherungsberichten durch `-redacted-` ersetzt, sofern nicht `--allow-paths-in-log-messages=true` festgelegt ist, was die Liste der verfügbaren Versionen leer lässt. Die empfohlenen Berichtsoptionen und die Fehlerbehebung beinhalten nun diese Einstellung.

---

## Verbesserungen {/* #improvements */}

### duplicati-Berichterstattung {/* #duplicati-reporting */}

- **Aufbewahrungsdaten ab duplicati 2.4.1.0**: Hinzufügen von `--allow-paths-in-log-messages=true` unter **Einstellungen → Standardoptionen** (oder den erweiterten Optionen der Sicherung). Ohne diese Einstellung ersetzt duplicati die Daten in `Backups to consider` durch `-redacted-`, sodass die Anzahl der verfügbaren Versionen zwar angezeigt werden kann, die Liste der Zeitstempel jedoch leer bleibt. Lassen Sie `--reduced-reporting` nicht festgelegt, da diese Option den Nachrichtentext entfernt, und führen Sie die Sicherung erneut aus. Bereits gespeicherte Berichte bleiben redigiert. Die Option umfasst auch lokale Dateipfade aus Warnungen und Fehler in den HTTP-Berichten. Der Hinweis zum gekürzten Protokoll auf der Detailseite einer Sicherung nennt dieselbe Option.

---

## Migrationshinweise {/* #migration-notes */}

### Von Version 1.5.1 {/* #from-version-151 */}

Wann ein Upgrade auf Version 1.5.2 durchgeführt wird:

1. **Keine Datenbankmigration erforderlich**: Diese Version ändert das Datenbankschema nicht.
2. **Abhängigkeiten**: Führen Sie `pnpm install` aus, um die aktualisierte Lockfile und die Überschreibungen anzuwenden.
3. **duplicati 2.4.1.0 und später**: Wenn die Liste der verfügbaren Versionen leer ist, Hinzufügen von `--allow-paths-in-log-messages=true` auf jedem duplicati-Server und führen Sie die Sicherung erneut aus. Bestehende gespeicherte Berichte bleiben unverändert.
