# Version 1.1.x {/* #version-11x */}

## Übersicht {/* #overview */}

Version 1.1.x ist eine kleine Veröffentlichung, die kritische Probleme bei der Erkennung überfälliger Backups behebt, die Podman-Container-Kompatibilität verbessert und Verbesserungen an der Container-Architektur einführt. Diese Version konzentriert sich darauf, die Genauigkeit der Erkennung überfälliger Backups zu verbessern und Netzwerkprobleme in Podman-Umgebungen zu beheben.

## Neue Funktionen {/* #new-features */}

### Benutzeroberflächenverbesserungen {/* #user-interface-enhancements */}

- **Rechtsklick-Kontextmenü auf der Auto-Aktualisierungs-Schaltfläche** - Ein Rechtsklick auf die Auto-Aktualisierungs-Schaltfläche in der Anwendungsleiste öffnet die Seite "Anzeigeeinstellungen" für schnellen Zugriff auf die Anzeigepräferenzen
- **Verbessertes "Backups sammeln"-Modal** - Das Passwort-Feld-Label gibt nun klar an "(nur ausfüllen, wenn Passwort geändert wurde)", wenn ein Server ausgewählt ist, was klarer macht, wann das Feld benötigt wird

### Dokumentationsverbesserungen {/* #documentation-improvements */}

- **Migration der Dokumentations-Hosting** - Die Dokumentation wurde vom Docker-Container-Image auf GitHub Pages an https://wsj-br.github.io/duplistatus/user-guide/overview verschoben, um eine verbesserte Zugänglichkeit und einfachere Updates zu gewährleisten
- Der Link "Benutzerhandbuch" in der App-Kopfzeile zeigt nun auf die externe Dokumentationsseite

## 🐛 Fehlerbehebungen {/* #-bug-fixes */}

### Kritisch: Erkennung überfälliger Backups - Komplette Neuimplementierung {/* #critical-overdue-backup-detection---complete-reimplementation */}

- **Behobene Erkennung überfälliger Backups** - Das System zur Erkennung überfälliger Backups wurde vollständig neu implementiert mit einem neuen Algorithmus, der die erwarteten Backup-Daten korrekt verfolgt:
  - Der Algorithmus stellt sicher, dass manuelle Backups die geplante Backup-Zeit nicht ändern (z. B. ein manuelles Backup um 22 Uhr ändert nicht eine 14 Uhr geplante Zeit)
  - Behobene "Nächste Ausführung"-Spalte in den Einstellungen für die Backup-Überwachung zeigt nun korrekte Daten an
  - Backup-Einstellungen werden jetzt sofort nach dem Empfang von Backups über `/api/upload` oder `/api/backups/collect` aktualisiert
  - Für neue Server ohne Duplicati-Synchronisation wird die Zeit des ersten Backups als Referenz für den Zeitplan verwendet
  - Für weitere Details siehe die [Dokumentation zur Erkennung überfälliger Backups](https://github.com/wsj-br/duplistatus/blob/main/dev/OVERDUE_DETECTION_ALGORITHM.md)

### Podman-Container-Fixes {/* #podman-container-fixes */}

- **Behobene Podman-Pod-Netzwerkprobleme** - Behobenes Problem, das den externen Zugriff auf die Anwendung verhinderte, wenn sie in Podman-Pods ausgeführt wurde. Der Server bindet sich jetzt korrekt an alle Schnittstellen (`0.0.0.0:9666`) in beiden Podman-Pod- und eigenständigen Container-Modi
- **Behobene DNS-Auflösung für Tailscale-Hostnamen** - Behobene DNS-Auflösung in Podman-Containern, die die Verbindung zu Tailscale-Hostnamen oder benutzerdefinierten DNS-Servern verhinderten. Die Installationsdokumentation wurde mit Anweisungen aktualisiert.

### E-Mail-Konfigurations-Fixes {/* #email-configuration-fixes */}

- **Behobene SMTP-Leerbenutzername/Passwort-Handhabung** - Behobenes Problem, bei dem das Löschen der Benutzername- oder Passwortfelder in der E-Mail-Konfiguration weiterhin verschlüsselte Werte in der Datenbank speicherte. Leere Felder werden jetzt korrekt als leere Zeichenfolgen gespeichert und können richtig gelöscht werden

### Systemverbesserungen {/* #system-improvements */}

- **Reduziertes Konsolen-Logging** - AuditLogger protokolliert jetzt nur noch fehlgeschlagene Anmeldeversuche in der Konsole; alle anderen Audit-Einträge werden nur noch in der Datenbank geschrieben

## 🚀 Migrationshinweise {/* #-migration-notes */}

### Von Version 1.0.x {/* #from-version-10x */}

Beim Upgrade auf Version 1.1.0:

1. **Änderung des Dokumentationsstandorts** - Die Dokumentation wird jetzt auf GitHub Pages gehostet und nicht mehr im Docker-Container enthalten sein. Der Link "Benutzerhandbuch" in der App-Kopfzeile zeigt jetzt auf die externe Dokumentationsseite

2. **Podman-Container-Konfiguration** - Wenn Podman-Pods verwendet werden, stellen Sie sicher, dass die DNS-Konfiguration auf Pod-Ebene mit den Flags `--dns` und `--dns-search` gesetzt ist. Die Anwendung funktioniert jetzt korrekt in Podman-Pods und eigenständigen Containern

3. **Erkennung überfälliger Backups** - Das System zur Erkennung überfälliger Backups wurde vollständig neu implementiert mit einem neuen Algorithmus, der die Zeit des geplanten Backups beibehält. Bestehende Backup-Überwachungskonfigurationen werden weiterhin funktionieren, aber Sie werden möglicherweise genauere "Nächste Ausführung"-Daten in den Einstellungen für die Backup-Überwachung bemerken. Der neue Algorithmus stellt sicher, dass manuelle Backups die geplante Backup-Zeit nicht verschieben

4. **Keine Datenbank-Migration erforderlich** - Diese Version erfordert keine Änderungen am Datenbankschema
