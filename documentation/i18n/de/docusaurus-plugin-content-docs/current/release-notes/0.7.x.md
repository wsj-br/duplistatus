# Version 0.7.x {/* #version-07x */}

## Übersicht {/* #overview */}

Version 0.7.x ist eine Hauptversion, die erhebliche Verbesserungen an der Datenbankschema, API-Struktur und Benutzeroberfläche einbringt. Diese Version enthält rückwärts-inkompatible Änderungen, die Updates für externe Integrationen erfordern.

## Rückwärts-inkompatible Änderungen {/* #breaking-changes */}

### Änderungen am Datenbankschema {/* #database-schema-changes */}
- **Tabellenumbenennung**: `machines` Tabelle umbenannt in `servers`
- **Neue Felder**: Hinzugefügte Felder `alias`, `notes`, `created_at` und `updated_at`
- **Änderungen in API-Antworten**: Aktualisierte Feldnamen für Konsistenz

### Rückwärts-inkompatible API-Änderungen {/* #backward-incompatible-api-changes */}
- **Feldumbenennung**: `totalMachines` → `totalServers`
- **Objektumbenennung**: `machine` → `server` in API-Antworten
- **Feldumbenennung**: `backup_types_count` → `backupJobsCount`

:::warning
**Externe Integrationen, die die API verwenden, müssen aktualisiert werden**, um mit Version 0.7.x zu funktionieren. Weitere Informationen finden Sie im Leitfaden zu [rückwärts-inkompatiblen API-Änderungen](../migration/api-changes).
:::

## Migrationsanleitung {/* #migration-guide */}

### Automatische Migration {/* #automatic-migration */}
Die Migration von 0.6.x zu 0.7.x erfolgt automatisch:

1. **Backup-Erstellung**: Automatisches Datenbank-Backup wird erstellt
2. **Schema-Update**: Datenbankschema wird automatisch aktualisiert
3. **Datenmigration**: Bestehende Daten werden beibehalten und migriert
4. **Überprüfung**: Migration wird überprüft und protokolliert

### Manuelle Schritte erforderlich {/* #manual-steps-required */}
- **Aktualisierung externer Integrationen**: Aktualisieren Sie alle externen Tools, die die API verwenden
- **Funktionalität testen**: Überprüfen Sie, ob alle Funktionen korrekt funktionieren
- **Dokumentation aktualisieren**: Aktualisieren Sie alle benutzerdefinierten Dokumentationen

### Docker Compose {/* #docker-compose */}

```yaml

  duplistatus:
    image: wsjbr/duplistatus:0.7.x
    container_name: duplistatus
```

## Upgrade-Anweisungen {/* #upgrade-instructions */}

### Von Version 0.6.x {/* #from-version-06x */}
1. **Sichern Sie Ihre Daten** (automatische Sicherung während des Upgrades)
2. **Docker-Image aktualisieren**: `docker pull wsjbr/duplistatus:0.7.x`
3. **Container neu starten**: `docker-compose down && docker-compose up -d`
4. **Protokolle überwachen**: `docker logs -f duplistatus`
5. **Integrationen aktualisieren**: Aktualisieren Sie alle externen Tools, die die API verwenden
6. **Upgrade überprüfen**: Stellen Sie sicher, dass alle Funktionen korrekt arbeiten

### Von Version 0.5.x oder früher {/* #from-version-05x-or-earlier */}
1. **Zuerst auf 0.6.x aktualisieren** (falls verfügbar)
2. **Dann auf 0.7.x aktualisieren** mit den obigen Schritten
