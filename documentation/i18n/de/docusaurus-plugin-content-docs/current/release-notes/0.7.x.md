# Version 0.7.x {/* #version-07x */}

## Übersicht {/* #overview */}

Version 0.7.x ist eine Hauptversion, die signifikante Verbesserungen am Datenbankschema, der API-Struktur und der Benutzeroberfläche einführt. Diese Version enthält Änderungen, die Updates externer Integrationen erfordern.

## Wichtige Änderungen {/* #breaking-changes */}

### Änderungen am Datenbankschema {/* #database-schema-changes */}
- **Tabellenumbenennung**: `machines` Tabelle umbenannt zu `servers`
- **Neue Felder**: Hinzugefügt wurden `alias`, `notes`, `created_at` und `updated_at` Felder
- **Änderungen an API-Antworten**: Aktualisierte Feldnamen zur Vereinheitlichung

### Nicht rückwärtskompatible API-Änderungen {/* #backward-incompatible-api-changes */}
- **Feldumbenennung**: `totalMachines` → `totalServers`
- **Objektumbenennung**: `machine` → `server` in API-Antworten
- **Feldumbenennung**: `backup_types_count` → `backupJobsCount`

:::warning
**Externe Integrationen, die die API verwenden, müssen aktualisiert werden**, um mit Version 0.7.x zu funktionieren. Siehe den Leitfaden zu [Nicht rückwärtskompatiblen API-Änderungen](../migration/api-changes) für weitere Details.
:::

## Migrationsanleitung {/* #migration-guide */}

### Automatische Migration {/* #automatic-migration */}
Die Migration von 0.6.x auf 0.7.x erfolgt automatisch:

1. **Sicherungserstellung**: Automatische Datenbanksicherung wird erstellt
2. **Schema-Aktualisierung**: Datenbankschema wird automatisch aktualisiert
3. **Datenmigration**: Vorhandene Daten werden erhalten und migriert
4. **Verifizierung**: Migration wird überprüft und protokolliert

### Erforderliche manuelle Schritte {/* #manual-steps-required */}
- **Externe Integrationen aktualisieren**: Aktualisieren Sie alle externen Tools, die die API verwenden
- **Funktionalität testen**: Stellen Sie sicher, dass alle Funktionen korrekt arbeiten
- **Dokumentation aktualisieren**: Aktualisieren Sie alle benutzerdefinierten Dokumentationen

### Docker Compose {/* #docker-compose */}

```yaml

  duplistatus:
    image: wsjbr/duplistatus:0.7.x
    container_name: duplistatus
    restart: unless-stopped
    ports:

    volumes:
      - duplistatus_data:/app/data
    environment:
      - TZ=UTC
```

## Upgrade-Anleitung {/* #upgrade-instructions */}

### Von Version 0.6.x {/* #from-version-06x */}
1. **Sichern Sie Ihre Daten** (automatische Sicherung wird während des Upgrades erstellt)
2. **Docker-Image aktualisieren**: `docker pull wsjbr/duplistatus:0.7.x`
3. **Container neu starten**: `docker-compose down && docker-compose up -d`
4. **Protokolle überwachen**: `docker logs -f duplistatus`
5. **Integrationen aktualisieren**: Aktualisieren Sie alle externen Tools, die die API verwenden
6. **Upgrade überprüfen**: Stellen Sie sicher, dass alle Funktionen korrekt funktionieren

### Von Version 0.5.x oder älter {/* #from-version-05x-or-earlier */}
1. **Zuerst auf 0.6.x aktualisieren** (falls verfügbar)
2. **Anschließend auf 0.7.x aktualisieren** unter Verwendung der obigen Schritte
