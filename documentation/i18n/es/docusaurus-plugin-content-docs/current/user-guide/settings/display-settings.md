# Visualización {/* #display */}

Configurar la interfaz de usuario y las preferencias de visualización.

![Configuración de visualización](../../assets/screen-settings-display.png)

<br/>

| Configuración             | Descripción                                         | Valor predeterminado |
|:--------------------------|:----------------------------------------------------|:---------------------|
| **Tamaño de tabla**       | Número de filas por página en la página de detalles del servidor. | 5 filas              |
| **Mostrar versión en el panel** | Mostrar u ocultar la versión de Duplicati en las tarjetas del panel. La tabla del panel siempre muestra la columna Versión. También disponible en [Versiones de Duplicati](duplicati-versions.md). | Activado |
| **Tema**                  | Elegir claro, oscuro o coincidir con la apariencia de su sistema operativo (modo claro/oscuro preferido). | Seguir SO cuando no esté definido |
| **Rango de tiempo de gráfico** | Intervalo de tiempo mostrado en los gráficos. Opciones disponibles: **1S** (últimos 7 días), **2S** (últimos 14 días), **1M** (últimos 30 días), **3M** (últimos 90 días). También puede alternar el rango de tiempo directamente desde los encabezados de gráfico. | 1 mes                |
| **Estilo de gráfico**     | Elegir entre gráficos de líneas suaves o visualización de gráfico de barras. Ambos modos utilizan agregación por intervalos de tiempo para una visualización óptima. También puede alternar directamente desde los encabezados de gráfico. | Líneas suaves        |
| **Configuración regional** | Seleccionar una configuración regional de formato independiente de su idioma de interfaz de usuario (416 configuraciones regionales admitidas). Esto afecta cómo se muestran las fechas, horas y números. Las frases de tiempo relativo (por ejemplo, "en 2 horas") siguen la configuración regional de formato a menos que esté habilitado **Mantener el tiempo relativo en el idioma de la interfaz de usuario**. Una vista previa en vivo incluye fecha, hora, número y una muestra de tiempo relativo. Ejemplo: Idioma de interfaz = Alemán, Configuración regional de formato = Inglés (Reino Unido) → Interfaz de usuario en alemán con formatos de fecha del Reino Unido. | Basado en idioma de interfaz de usuario |
| **Mantener el tiempo relativo en el idioma de la interfaz de usuario** | Cuando está habilitado, frases como "en 2 horas" siguen **Usuario → Idioma** en lugar de la configuración regional de formato. Las fechas, horas y números aún utilizan la configuración regional de formato. Desactivado de forma predeterminada. | Desactivado |
| **Intervalo de actualización automática** | Con qué frecuencia se actualizan automáticamente las páginas. | 1 minuto             |
| **Orden de clasificación de tarjetas** | Cómo se ordenan las tarjetas en el panel. | Nombre de servidor (a-z) |
| **Inicio de semana**      | Configurar cuándo comienza la semana.               | Basado en configuración regional |

<br/>

:::tip
**Acceso rápido**: Puede acceder rápidamente a esta página haciendo clic derecho en el botón de actualización automática en la barra de herramientas de la aplicación.
:::
