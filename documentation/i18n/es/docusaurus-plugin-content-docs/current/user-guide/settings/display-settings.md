# Visualización {/* #display */}

Configurar preferencias de interfaz de usuario y visualización.

![Configuración de visualización](../../assets/screen-settings-display.png)

<br/>

| Configuración              | Descripción                                         | Valor predeterminado |
|:--------------------------|:----------------------------------------------------|:-------------------|
| **Tamaño de tabla**       | Número de filas por página en la página de detalles del servidor. | 5 filas            |
| **Mostrar versión en el panel** | Mostrar u ocultar la versión de Duplicati en las tarjetas del panel. La tabla del panel siempre muestra la columna Versión. También disponible en [Versiones de Duplicati](duplicati-versions.md). | Activado |
| **Tema**                  | Elegir entre tema claro, oscuro o seguir la apariencia del sistema operativo (modo claro/oscuro). | Seguir el sistema cuando no se establece |
| **Rango de tiempo de gráfico** | Intervalo de tiempo mostrado en los gráficos. Opciones disponibles: **1S** (últimos 7 días), **2S** (últimos 14 días), **1M** (últimos 30 días), **3M** (últimos 90 días). También puedes alternar el rango de tiempo directamente desde los encabezados de los gráficos. | 1 mes              |
| **Estilo de gráfico**     | Elegir entre gráficos de líneas suaves o visualización de gráfico de barras. Ambos modos usan agregación por intervalos de tiempo para una visualización óptima. También puedes alternar directamente desde los encabezados de los gráficos. | Líneas suaves      |
| **Configuración regional** | Seleccionar una configuración regional de formato independiente del idioma de la interfaz de usuario (416 configuraciones regionales admitidas). Esto afecta cómo se muestran las fechas, horas y números. Las frases de tiempo relativo (por ejemplo, "en 2 horas") siguen la configuración regional a menos que **Mantener el tiempo relativo en el idioma de la interfaz de usuario** esté habilitado. Una vista previa en vivo incluye fecha, hora, número y una muestra de tiempo relativo. Ejemplo: idioma de la interfaz de usuario = Alemán, configuración regional = Inglés (Reino Unido) → interfaz de usuario en alemán con formatos de fecha del Reino Unido. | Basado en el idioma de la interfaz de usuario |
| **Mantener el tiempo relativo en el idioma de la interfaz de usuario** | Cuando está habilitado, las frases como "en 2 horas" siguen **Usuario → Idioma** en lugar de la configuración regional. Las fechas, horas y números siguen usando la configuración regional. Desactivado por defecto. | Desactivado |
| **Intervalo de actualización automática** | Con qué frecuencia se actualizan automáticamente las páginas. | 1 minuto           |
| **Orden de clasificación de tarjetas** | Cómo se ordenan las tarjetas en el panel. | Nombre de servidor (a-z) |
| **Inicio de semana**      | Configurar cuándo comienza la semana. | Basado en configuración regional |

<br/>

:::tip
**Acceso rápido**: Puedes acceder rápidamente a esta página haciendo clic derecho en el botón de actualización automática de la barra de herramientas de la aplicación.
:::
