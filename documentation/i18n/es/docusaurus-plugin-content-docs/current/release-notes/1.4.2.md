# Versión 1.4.2 {/* #version-142 */}

## Vista general {/* #overview */}

La versión 1.4.2 es una versión de mantenimiento centrada en un soporte más amplio de idiomas, fiabilidad e higiene de dependencias. Introduce una interfaz completamente localizada en chino simplificado y hindi, amplía la documentación a siete idiomas y resuelve un importante fallo de inicio en Docker, junto con varios problemas de fusión de panel de control y servidor. Las dependencias también se han actualizado, incluyendo una actualización importante a `nodemailer`.

---

## Nuevas características {/* #new-features */}

### Soporte de idioma {/* #language-support */}

- **Interfaz en chino simplificado y hindi**: La interfaz de la aplicación ahora está completamente disponible en chino simplificado y hindi, uniéndose al inglés, francés, alemán, español y portugués brasileño. Selecciónelos desde el menú de idioma en Configuración.
- **Idiomas de documentación ampliados**: La documentación en línea ahora se publica en siete idiomas, añadiendo hindi y chino simplificado junto con las traducciones existentes.

---

## Mejoras {/* #improvements */}

### Recolección de copias de seguridad {/* #backup-collection */}

- **Identidad de servidor estable al recopilar registros**: Al recopilar registros de copia de seguridad, duplistatus ahora compara el nombre de máquina de Duplicati con sus servidores existentes y reutiliza el registro de ese servidor, en lugar de depender del ID de máquina de Duplicati. Esto mantiene el historial de copia de seguridad adjunto al mismo servidor incluso si cambia el ID de máquina de Duplicati (por ejemplo, después de una reinstalación), reduciendo las entradas de servidores duplicados.

### Documentación {/* #documentation */}

- **Lista de idiomas actualizada**: El README y la documentación ahora describen los siete idiomas admitidos y enlazan a cada versión traducida.
- **Banderas del menú de idioma de documentación**: Se añadieron iconos de bandera para la nueva documentación en hindi y chino simplificado, y se cambió el portugués a la bandera de Portugal para mantener la coherencia. Las banderas ahora se renderizan de forma fiable en Windows, Linux y Chromium sin descargas externas de fuentes.
- **Guía expandida de servidores duplicados**: La guía de usuario ahora explica ambas causas de servidores duplicados (un ID de máquina Duplicati cambiado y un error de API de Duplicati que mezcla el ID de identidad y el ID de máquina) y documenta la solución alternativa del lado de Duplicati junto con el paso de fusión de duplistatus.

### Rendimiento del panel de control {/* #dashboard-performance */}

- **Menos comprobaciones de inicio de sesión al cargar**: El panel de control ahora obtiene su usuario actual una vez y lo comparte en toda la página (encabezado, protección de configuración, tema y widgets) en lugar de que cada componente lo solicite por separado, reduciendo solicitudes redundantes cuando se carga una página.

---

## Correcciones de errores {/* #bug-fixes */}

- **Fallo de inicio de Docker**: Se corrigió un fallo al iniciar el contenedor que reportaba `Cannot find module '.../@swc/helpers/...'`, que podía impedir que la aplicación se iniciara. Los contenedores ahora se inician de forma fiable.
- **Entradas duplicadas en el panel de control**: El panel de control ya no muestra múltiples filas para la misma copia de seguridad cuando varios registros comparten la misma fecha de copia de seguridad más reciente.
- **Fusión de servidores duplicados**: La fusión de servidores ahora también consolida IDs de copia de seguridad duplicados de Duplicati que comparten el mismo nombre de copia de seguridad, manteniendo el ID de la copia de seguridad más reciente. Las operaciones de fusión ahora se registran en el Registro de auditoría.

---

## Seguridad {/* #security */}

### Actualizaciones de dependencias {/* #dependency-updates */}

- **`nodemailer` actualizado a 9.x**: Se actualizó la biblioteca de correo electrónico a la última versión principal. El único cambio importante en v9 (validación TLS más estricta al obtener archivos adjuntos remotos, OAuth2 o contenido de proxy) no afecta a duplistatus, que solo envía correos electrónicos de texto e HTML en línea.
- **Otras actualizaciones de dependencias**: Se actualizaron varias dependencias de compilación y tipos a sus últimas versiones compatibles.

---

## Notas de migración {/* #migration-notes */}

### Desde la versión 1.4.1 {/* #from-version-141 */}

Al actualizar a la versión 1.4.2:

1. **No se requiere migración de base de datos**: Esta versión no requiere ningún cambio en el esquema de la base de datos.
2. **Dependencias**: Ejecute `pnpm install` para aplicar el archivo de bloqueo y las anulaciones actualizadas.
3. **No se necesitan cambios en la configuración**: La configuración existente, incluido su idioma elegido, se conserva.
