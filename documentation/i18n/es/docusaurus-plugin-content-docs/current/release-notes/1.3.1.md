# Versión 1.3.1 {/* #version-131 */}

## Vista general {/* #overview */}

La versión 1.3.1 introduce compatibilidad completa con múltiples idiomas para la interfaz de la aplicación, fortalece la seguridad de la API con autenticación obligatoria en puntos finales adicionales y corrige varios errores relacionados con la detección de claves maestras, formato regional y configuración de notificaciones. Esta versión se centra en mejoras de internacionalización y endurecimiento de seguridad.

## Nuevas características {/* #new-features */}

### Compatibilidad con interfaz multilingüe {/* #multi-language-interface-support */}

- **Selector de idioma en el encabezado de la aplicación**: Elija su idioma de interfaz preferido desde un menú desplegable en el menú de usuario. Idiomas admitidos: inglés, alemán, francés, español y portugués (BR). Su selección se guarda y persiste entre sesiones.
- **Navegación consciente de la configuración regional**: Todas las páginas y enlaces ahora admiten URL con prefijo regional para una navegación coherente en su idioma seleccionado.

### Internacionalización de plantillas de notificación {/* #notification-templates-internationalization */}

- **Selector de idioma de plantilla**: Las plantillas de notificación ahora admiten múltiples idiomas con un selector de idioma dedicado. Hay disponibles plantillas predeterminadas pretraducidas para los 5 idiomas admitidos.
- **Opciones de restablecimiento**: Botones "Restablecer esta plantilla a valores predeterminados" y "Restablecer todo a valores predeterminados" con cuadros de diálogo de confirmación para facilitar la gestión de plantillas al cambiar de idioma.
- **Contenido de notificación consciente de la configuración regional**: Fechas, horas, números y valores de estado de copia de seguridad en las notificaciones ahora se formatean según el idioma de la plantilla.

### Localización de fechas y números {/* #date-and-number-localization */}

- **Formato de fecha y hora consciente de la configuración regional**: Las fechas y horas en toda la aplicación (panel de control, detalles del servidor, gráficos, información sobre herramientas) ahora se muestran en el formato adecuado para su configuración regional (por ejemplo, DD/MM/AAAA para configuraciones regionales europeas, MM/DD/AAAA para inglés).
- **Formato de número consciente de la configuración regional**: Los números, tamaños de archivo y estadísticas utilizan formato adecuado para la configuración regional (por ejemplo, 1.234,56 para alemán, 1,234.56 para inglés).

### Preparación para compatibilidad con RTL {/* #rtl-support-preparation */}

- **Fundamento para idiomas de derecha a izquierda**: Se ha añadido infraestructura para admitir futuros idiomas RTL (árabe, hebreo). Los idiomas actuales siguen siendo de izquierda a derecha.

## Seguridad {/* #security */}

### Autenticación de API {/* #api-authentication */}

- **Autenticación obligatoria en puntos finales adicionales**: Los siguientes puntos finales ahora requieren una sesión válida y un token CSRF (anteriormente tenían autenticación opcional):
  - `/api/backups/collect`
  - `/api/backups/sync-schedule`
  - `/api/cron-config` (POST)
  - `/api/notifications/check-overdue`
  - `/api/notifications/clear-overdue-timestamps`
- **Actualizaciones de seguridad de dependencias**: Se actualizaron las dependencias vulnerables (fast-xml-parser, brace-expansion) para abordar problemas de seguridad conocidos.

## Correcciones de errores {/* #bug-fixes */}

- **Detección de cambio de clave maestra**: Se corrigió la detección incorrecta de "clave cambiada" al restaurar la base de datos y el archivo `.duplistatus.key` juntos (misma clave). El sistema ahora utiliza una huella digital de clave para una detección confiable en lugar de verificaciones basadas en descifrado que podrían interpretar erróneamente la corrupción de datos como un cambio de clave.
- **Carga inicial de página de detalles**: La página de detalles del servidor ahora muestra correctamente mensajes y datos vencidos en la primera carga en lugar de solo después de la primera actualización automática.

## Mejoras {/* #improvements */}

### Coherencia de internacionalización {/* #internationalisation-consistency */}

- **Etiquetas coherentes**: Las unidades de tiempo, intervalos, etiquetas de estado y términos comunes ahora aparecen de manera coherente en toda la aplicación.
- **Ordenamiento de días de la semana consciente de la configuración regional**: La visualización de días de la semana en el monitoreo de copias de seguridad respeta su idioma/configuración regional. Puede sobrescribirse en la Configuración de visualización.

### Códigos de error y de éxito de la API de autenticación (i18n) {/* #auth-api-error-and-success-codes-i18n */}

- **Códigos estables de error y éxito**: Los puntos finales de autenticación (`/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/change-password`, `/api/auth/password-policy`) ahora devuelven un `errorCode` (y, en caso de éxito, un `successCode`) además del campo `error` o `message` en inglés. Los clientes utilizan estos códigos para mostrar mensajes localizados en el idioma del usuario.
- **Página de inicio de sesión**: Todos los mensajes de error de inicio de sesión (por ejemplo, "Se requiere nombre de usuario y contraseña", "Nombre de usuario o contraseña no válidos", "Cuenta bloqueada") ahora están traducidos en la página de inicio de sesión para las cinco configuraciones regionales.
- **Modal de cambio de contraseña**: Todos los mensajes de error y éxito de la API de cambio de contraseña ahora están traducidos en el modal de cambio de contraseña.
- **Referencia de API**: La documentación de API [Autenticación y Seguridad](../api-reference/authentication-security.md#auth-api-error-and-success-codes-i18n) enumera todos los códigos de error y éxito y explica cómo usarlos para i18n.

### Mejoras de IU {/* #ui-improvements */}

- **Ancho del filtro de servidor**: Se aumentó el ancho del filtro de servidor en el formulario de notificaciones de copia de seguridad (260px → 360px) para una mejor usabilidad.
- **Selección masiva**: Se mejoró la interfaz de usuario de selección masiva con soporte adecuado de pluralización para recuentos de copias de seguridad.
- **Información sobre herramientas de ayuda**: Se mejoró el texto de información sobre herramientas de ayuda con contexto del nombre de página.

### Documentación {/* #documentation */}

- **Cambio de nombre de página de configuración**: La página de configuración de zona horaria e idioma ha sido renombrada de `configure-tz-lang` a `configure-tz`.
- **Guía de plantillas de notificación**: Guía de usuario actualizada para documentar el nuevo selector de idioma de plantilla, botones de restablecimiento y comportamiento de idioma.
- **Documentación multilingüe**: La guía de usuario ahora documenta cómo cambiar el idioma de la interfaz mediante el selector de idioma en el menú de usuario.

## Notas de migración {/* #migration-notes */}

### Desde la versión 1.3.0 {/* #from-version-130 */}

Al actualizar a la versión 1.3.1:

1. **Autenticación de API**: Los scripts o herramientas que llaman a los puntos finales de recopilación de copias de seguridad, programación de sincronización, configuración de cron o comprobación/limpieza de notificaciones deben incluir ahora autenticación de sesión válida y tokens CSRF.

2. **No se requiere migración de base de datos**: Esta versión no requiere cambios en el esquema de base de datos.

3. **Soporte de configuración regional**: La variable de entorno `LANG` ya no se utiliza. Puede definir el idioma para notificaciones en la página `Settings > Templates`.
