# Versión 1.3.1 {/* #version-131 */}

## Vista general {/* #overview */}

La versión 1.3.1 introduce soporte completo para múltiples idiomas en la interfaz de la aplicación, refuerza la seguridad de las API con autenticación obligatoria en puntos finales adicionales y corrige varios errores relacionados con la detección de la clave maestra, el formato de la configuración regional y la configuración de notificaciones. Esta versión se centra en mejoras de internacionalización y endurecimiento de seguridad.

## Nuevas características {/* #new-features */}

### Soporte de interfaz multilingüe {/* #multi-language-interface-support */}

- **Selector de idioma en el encabezado de la aplicación**: Elija su idioma de interfaz preferido desde un menú desplegable en el menú de usuario. Idiomas admitidos: inglés, alemán, francés, español y portugués (BR). Su selección se guarda y persiste en todas las sesiones.
- **Navegación sensible al idioma**: Todas las páginas y enlaces ahora admiten URLs con prefijo de idioma para una navegación consistente en su idioma seleccionado.

### Internacionalización de plantillas de notificaciones {/* #notification-templates-internationalization */}

- **Selector de idioma de plantillas**: Las plantillas de notificaciones ahora admiten múltiples idiomas con un selector de idioma dedicado. Plantillas predeterminadas pre-traducidas están disponibles para todos los 5 idiomas admitidos.
- **Opciones de restablecimiento**: Botones "Restablecer esta plantilla a valores predeterminados" y "Restablecer todo a valores predeterminados" con cuadros de diálogo de confirmación para una gestión fácil de plantillas al cambiar de idioma.
- **Contenido de notificaciones sensible al idioma**: Las fechas, horas, números y valores de estado de copia de seguridad en las notificaciones ahora se muestran según el idioma de la plantilla.

### Localización de fechas y números {/* #date-and-number-localization */}

- **Formato de fecha y hora sensible al idioma**: Las fechas y horas en toda la aplicación (panel de control, detalles del servidor, gráficos, sugerencias) ahora se muestran en el formato adecuado para su configuración regional (por ejemplo, DD/MM/AAAA para configuraciones regionales europeas, MM/DD/AAAA para inglés).
- **Formato de números sensible al idioma**: Los números, tamaños de archivos y estadísticas utilizan el formato adecuado para su configuración regional (por ejemplo, 1.234,56 para alemán, 1,234.56 para inglés).

### Preparación de soporte RTL {/* #rtl-support-preparation */}

- **Base para idiomas de derecha a izquierda**: Se ha añadido infraestructura para admitir futuros idiomas de derecha a izquierda (árabe, hebreo). Los idiomas actuales siguen siendo de izquierda a derecha.

## Seguridad {/* #security */}

### Autenticación de API {/* #api-authentication */}

- **Autenticación obligatoria en puntos finales adicionales**: Los siguientes puntos finales ahora requieren una sesión válida y un token CSRF (anteriormente tenían autenticación opcional):
  - `/api/backups/collect`
  - `/api/backups/sync-schedule`
  - `/api/cron-config` (POST)
  - `/api/notifications/check-overdue`
  - `/api/notifications/clear-overdue-timestamps`
- **Actualizaciones de seguridad de dependencias**: Se han actualizado las dependencias vulnerables (fast-xml-parser, brace-expansion) para abordar problemas de seguridad conocidos.

## Corrección de errores {/* #bug-fixes */}

- **Detección de cambio de clave maestra**: Se ha corregido la detección incorrecta de "clave cambiada" al restaurar la base de datos y el archivo `.duplistatus.key` juntos (misma clave). El sistema ahora utiliza una huella digital de clave para una detección confiable en lugar de comprobaciones basadas en descifrado que podían malinterpretar la corrupción de datos como un cambio de clave.
- **Carga inicial de la página de detalles**: La página de detalles del servidor ahora muestra correctamente los mensajes vencidos y los datos en la primera carga en lugar de solo después de la primera actualización automática.

## Mejoras {/* #improvements */}

### Consistencia de internacionalización {/* #internationalisation-consistency */}

- **Etiquetas consistentes**: Las unidades de tiempo, intervalos, etiquetas de estado y términos comunes ahora aparecen de manera consistente en toda la aplicación.
- **Orden de días de la semana sensible al idioma**: La visualización de los días de la semana en el monitoreo de copias de seguridad respeta su idioma/configuración regional. Puede ser sobrescrito en la Configuración de visualización.

### Códigos de error y éxito de la API de autenticación (i18n) {/* #auth-api-error-and-success-codes-i18n */}

- **Códigos de error y éxito estables**: Los puntos finales de autenticación (`/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/change-password`, `/api/auth/password-policy`) ahora devuelven un `errorCode` (y, en caso de éxito, un `successCode`) además del campo `error` o `message` en inglés. Los clientes utilizan estos códigos para mostrar mensajes localizados en el idioma del usuario.
- **Página de inicio de sesión**: Todos los mensajes de error de inicio de sesión (por ejemplo, "Se requiere nombre de usuario y contraseña", "Nombre de usuario o contraseña no válidos", "Cuenta bloqueada") ahora están traducidos en la página de inicio de sesión para todas las cinco configuraciones regionales.
- **Modal de cambio de contraseña**: Todos los mensajes de error y éxito de la API de cambio de contraseña ahora están traducidos en el modal de cambio de contraseña.
- **Referencia de API**: La documentación de la API [Autenticación y seguridad](../api-reference/authentication-security.md#auth-api-error-and-success-codes-i18n) enumera todos los códigos de error y éxito y explica cómo usarlos para la internacionalización.

### Mejoras de la interfaz de usuario {/* #ui-improvements */}

- **Ancho del filtro de servidor**: Se ha aumentado el ancho del filtro de servidor en el formulario de notificaciones de copia de seguridad (260px → 360px) para mejorar la usabilidad.
- **Selección masiva**: Se ha mejorado la interfaz de usuario de selección masiva con soporte de pluralización adecuado para los recuentos de copia de seguridad.
- **Descripciones de ayuda**: Se ha mejorado el texto de las descripciones de ayuda con el contexto del nombre de la página.

### Documentación {/* #documentation */}

- **Renombrar página de configuración**: La página de configuración de zona horaria e idioma se ha renombrado de `configure-tz-lang` a `configure-tz`.
- **Guía de plantillas de notificaciones**: Se ha actualizado la guía del usuario para documentar el nuevo selector de idioma de plantillas, los botones de restablecimiento y el comportamiento del idioma.
- **Documentación multilingüe**: La guía del usuario ahora documenta cómo cambiar el idioma de la interfaz a través del selector de idioma en el menú de usuario.

## Notas de migración {/* #migration-notes */}

### Desde la versión 1.3.0 {/* #from-version-130 */}

Al actualizar a la versión 1.3.1:

1. **Autenticación de API**: Los scripts o herramientas que llamen a los puntos finales de recolección de copias de seguridad, sincronización de programación, configuración de cron o comprobación/borrado de notificaciones deben incluir ahora tokens de autenticación de sesión y CSRF válidos.

2. **No se requiere migración de base de datos**: Esta versión no requiere cambios en el esquema de la base de datos.

3. **Soporte de localización**: La variable de entorno `LANG` ya no se utiliza. Puede definir el idioma para las notificaciones en la página `Settings > Templates`.
