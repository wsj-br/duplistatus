# Versión 0.8.x {/* #version-08x */}

## Vista general {/* #overview */}

La versión 0.8.x es una actualización importante que introduce mejoras significativas de seguridad, capacidades mejoradas de gestión de servidores y un sistema integral de notificaciones con soporte de correo electrónico SMTP. Esta versión se centra en fortalecer la seguridad, mejorar la experiencia del usuario y proporcionar opciones más flexibles de monitoreo de copias de seguridad.

## Nuevas características {/* #new-features */}

### Mejoras en la gestión de servidores {/* #server-management-enhancements */}

- **Persistencia automática de URL y contraseña del servidor** al recopilar copias de seguridad
  - Los usuarios pueden actualizar la URL y la contraseña utilizando dos métodos:
     - Volviendo a recopilar copias de seguridad con valores actualizados
     - Modificando la configuración en [Configuración → Configuración del Servidor](../user-guide/settings/server-settings.md)

### Monitoreo de copias de seguridad mejorado {/* #enhanced-backup-monitoring */}

- **Nueva pestaña de configuración `Backup monitoring`** con ajustes de intervalo compatibles con el servidor Duplicati
    - Soporte para intervalos personalizados (por ejemplo, "1D12h")
    - Actualizaciones automáticas de intervalos vencidos desde la configuración de Duplicati durante la recopilación de registros de copias de seguridad
    - **Recomendado:** Ejecute la recopilación después de cambiar los intervalos de trabajos de copia de seguridad en el servidor Duplicati para sincronizar la configuración de duplistatus
    - Las plantillas de notificaciones ahora utilizan `{backup_interval}` en lugar de `{backup_interval_value}` y `{backup_interval_type}`.

### Configuración de dispositivo NTFY {/* #ntfy-device-configuration */}

- **Generación de código QR** para la configuración automática del dispositivo para recibir notificaciones de **duplistatus**
   - Haga clic derecho en el botón `View NTFY Messages` en la barra de herramientas de la aplicación
   - Botón "Configurar dispositivo" en [Configuración → Configuración de NTFY](../user-guide/settings/ntfy-settings.md)

### Recopilación de copias de seguridad mejorada {/* #improved-backup-collection */}

- **Detección automática de HTTP/HTTPS**, las conexiones se intentan en este orden: HTTPS → HTTPS con certificado autofirmado → fallback HTTP
- **Desplegable de selección de servidor** en la interfaz `Collect Backup Logs` para recopilación específica por servidor
- **Múltiples direcciones** en el nombre de host (separadas por comas) ahora son aceptadas (deben compartir la misma contraseña y puerto)
- **Botones de recopilación de copias de seguridad por servidor individual** añadidos a `Dashboard (table)`, [Configuración → Monitoreo de copias de seguridad](../user-guide/settings/backup-monitoring-settings.md) y [Configuración → Servidores](../user-guide/settings/server-settings.md)
- **Funcionalidad de recopilación masiva** para todos los servidores con configuración válida (url y contraseña)
   - Botones `Collect All` en [Configuración → Monitoreo de copias de seguridad](../user-guide/settings/backup-monitoring-settings.md) y [Configuración → Servidores](../user-guide/settings/server-settings.md)
   - Menú contextual de clic derecho en el botón `Collect Backup Logs` en la barra de herramientas de la aplicación

### Sistema de notificaciones mejorado {/* #enhanced-notification-system */}

- **Soporte de notificación por correo electrónico SMTP:**
    - Configuración del servidor SMTP en [Configuración → Configuración de correo electrónico](../user-guide/settings/email-settings.md)
    - Configuración por trabajo de copia de seguridad para notificaciones NTFY y/o por correo electrónico
    - Plantillas con formato HTML usando las existentes [Configuración → Plantillas de notificaciones](../user-guide/settings/notification-templates.md)
- **Configuración de notificaciones por trabajo de copia de seguridad:**
    - Preferencias individuales de notificación en [Configuración → Notificaciones de copia de seguridad](../user-guide/settings/backup-notifications-settings.md)
    - Indicadores visuales (iconos atenuados) cuando NTFY o el correo electrónico no están correctamente configurados

- **Soporte de idioma local:**
    - se creó una nueva variable de entorno `LANG` para establecer el idioma en la aplicación
    - ahora es predecible el formato de fechas y números en las notificaciones y registros

## 🔒 Mejoras de seguridad {/* #-security-enhancements */}

### Protección CSRF {/* #csrf-protection */}

- **Autenticación basada en sesiones** con gestión robusta de sesiones
- **Validación de token CSRF** aplicada a todas las solicitudes de API que cambian estado
- **Las sesiones expiran automáticamente** después de 24 horas; los tokens CSRF se actualizan cada 30 minutos
- Garantiza protección contra falsificación de solicitudes entre sitios manteniendo la compatibilidad con APIs externas

### Minimización de contraseñas en texto plano {/* #plaintext-password-minimization */}

- **Las contraseñas solo se pueden establecer a través de la interfaz de usuario**; ningún punto final de API expone contraseñas almacenadas
- **La manipulación de contraseñas en texto plano está minimizada** en todo el sistema

### Criptografía avanzada para datos sensibles {/* #advanced-cryptography-for-sensitive-data */}

- **Cifrado de datos sensibles** (por ejemplo, contraseñas, credenciales SMTP) mediante AES-256-GCM
- **La clave maestra se genera automáticamente** y se almacena de forma segura en `.duplistatus.key`
- **PBKDF2 con 100,000 iteraciones** utilizado para la derivación de claves y fortalecer la seguridad
- **Las etiquetas de autenticación se verifican** y la memoria se borra de forma segura tras su uso
- Los **permisos del archivo de clave maestra** están estrictamente configurados como 0400 para una protección máxima

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 0.7.x {/* #from-version-07x */}

Esta versión incluye importantes mejoras de seguridad y nuevas características. Al actualizar desde la versión 0.7.x:

1. **Migración automática de base de datos:** La aplicación migrará automáticamente el esquema de su base de datos para admitir nuevas características
2. **Generación de clave maestra:** Se generará una nueva clave maestra para el cifrado de datos sensibles
3. **Gestión de sesiones:** Las sesiones existentes se invalidarán y se establecerán nuevas sesiones protegidas por CSRF
4. **Actualizaciones de configuración:** Algunas claves de configuración se han actualizado para admitir nuevas características
5. **Cambios en plantillas:** Las variables `{backup_interval_value}` y `{backup_interval_type}` fueron reemplazadas por `{backup_interval}`. Las plantillas predeterminadas se ajustarán automáticamente, pero las plantillas personalizadas no se migrarán. Por favor, compruebe sus plantillas.

### Consideraciones de Seguridad {/* #security-considerations */}

- **Archivo de clave maestra:** Asegúrese de que el archivo `.duplistatus.key` esté debidamente respaldado y protegido
- **Permisos de archivo:** El archivo de clave maestra tendrá permisos restringidos (0400) por motivos de seguridad
- **Cifrado de contraseña:** Las contraseñas existentes se cifrarán mediante el nuevo sistema criptográfico
