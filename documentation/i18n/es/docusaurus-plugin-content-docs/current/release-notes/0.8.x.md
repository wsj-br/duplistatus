# Versión 0.8.x {/* #version-08x */}

## Vista general {/* #overview */}

La versión 0.8.x es una actualización importante que introduce mejoras significativas en seguridad, capacidades mejoradas de gestión de servidores y un sistema de notificaciones completo con soporte para correo electrónico SMTP. Esta versión se centra en fortalecer la seguridad, mejorar la experiencia del usuario y proporcionar opciones más flexibles de monitoreo de copias de seguridad.

## Nuevas características {/* #new-features */}

### Mejoras en la gestión de servidores {/* #server-management-enhancements */}

- **Persistencia automática de la URL del servidor y la contraseña** al recopilar copias de seguridad
  - Los usuarios pueden actualizar la URL y la contraseña utilizando dos métodos:
     - Recolectar copias de seguridad con valores actualizados
     - Modificar la configuración en [Configuración → Configuración del servidor](../user-guide/settings/server-settings.md)

### Monitoreo de copias de seguridad mejorado {/* #enhanced-backup-monitoring */}

- **Nueva pestaña de configuración `Backup monitoring`** con ajustes de intervalo compatibles con el servidor Duplicati
    - Soporte para intervalos personalizados (por ejemplo, "1D12h")
    - Actualizaciones automáticas de intervalos vencidos desde la configuración de Duplicati durante la recopilación de registros de copia de seguridad
    - **Recomendado:** Ejecutar la recopilación después de cambiar los intervalos de trabajo de copia de seguridad en el servidor Duplicati para sincronizar la configuración de duplistatus
    - Las plantillas de notificaciones ahora usan `{backup_interval}` en lugar de `{backup_interval_value}` y `{backup_interval_type}`.

### Configuración del dispositivo NTFY {/* #ntfy-device-configuration */}

- **Generación de código QR** para la configuración automática del dispositivo para recibir notificaciones de **duplistatus**
   - Haga clic con el botón derecho en el botón `View NTFY Messages` de la barra de herramientas de la aplicación
   - Botón "Configurar dispositivo" en [Configuración → Configuración de NTFY](../user-guide/settings/ntfy-settings.md)

### Recopilación de copias de seguridad mejorada {/* #improved-backup-collection */}

- **Detección automática de HTTP/HTTPS**, las conexiones se intentan en este orden: HTTPS → HTTPS con certificado autofirmado → HTTP como alternativa
- **Menú desplegable de selección de servidor** en la interfaz `Collect Backup Logs` para la recopilación específica del servidor
- **Múltiples direcciones** en el nombre de host (separadas por comas) ahora son aceptadas (deben compartir la misma contraseña y puerto)
- **Botones de recopilación de copia de seguridad de un solo servidor** agregados a `Dashboard (table)`, [Configuración → Monitoreo de copias de seguridad](../user-guide/settings/backup-monitoring-settings.md) y [Configuración → Servidores](../user-guide/settings/server-settings.md)
- **Funcionalidad de recopilación masiva** para todos los servidores con configuración válida (url y contraseña)
   - Botones `Collect All` en [Configuración → Monitoreo de copias de seguridad](../user-guide/settings/backup-monitoring-settings.md) y [Configuración → Servidores](../user-guide/settings/server-settings.md)
   - Menú contextual con clic derecho en el botón `Collect Backup Logs` de la barra de herramientas de la aplicación

### Sistema de notificaciones mejorado {/* #enhanced-notification-system */}

- **Soporte para notificaciones por correo electrónico SMTP:**
    - Configuración del servidor SMTP en [Configuración → Configuración de correo electrónico](../user-guide/settings/email-settings.md)
    - Configuración por trabajo de copia de seguridad para notificaciones NTFY y/o por correo electrónico
    - Plantillas formateadas en HTML utilizando las existentes [Configuración → Plantillas de notificaciones](../user-guide/settings/notification-templates.md)
- **Configuración de notificaciones por trabajo de copia de seguridad:**
    - Preferencias de notificación individuales en [Configuración → Notificaciones de copia de seguridad](../user-guide/settings/backup-notifications-settings.md)
    - Indicadores visuales (iconos en gris) cuando NTFY o el correo electrónico no están configurados correctamente

- **Soporte de configuración regional:**
    - se creó una nueva variable de entorno `LANG` para establecer la configuración regional en la aplicación
    - ahora es predecible el formato de las fechas y números en las notificaciones y registros

## 🔒 Mejoras de seguridad {/* #-security-enhancements */}

### Protección contra CSRF {/* #csrf-protection */}

- **Autenticación basada en sesión** con gestión robusta de sesiones
- **Validación de token CSRF** aplicada a todas las solicitudes de API que cambian el estado
- **Las sesiones expiran automáticamente** después de 24 horas; los tokens CSRF se actualizan cada 30 minutos
- Garantiza protección contra falsificación de solicitudes entre sitios mientras se mantiene la compatibilidad con APIs externas

### Minimización de contraseñas en texto plano {/* #plaintext-password-minimization */}

- **Las contraseñas solo pueden configurarse a través de la interfaz de usuario**; ningún punto final de la API expone las contraseñas almacenadas
- **La manipulación de contraseñas en texto plano se minimiza** en todo el sistema

### Criptografía avanzada para datos sensibles {/* #advanced-cryptography-for-sensitive-data */}

- **Cifrado de datos sensibles** (por ejemplo, contraseñas, credenciales SMTP) usando AES-256-GCM
- **Clave maestra generada automáticamente** y almacenada de forma segura en `.duplistatus.key`
- **PBKDF2 con 100,000 iteraciones** utilizado para la derivación de claves para fortalecer la seguridad
- **Etiquetas de autenticación verificadas** y memoria limpiada de forma segura después del uso
- **Los permisos del archivo de clave maestra** se establecen estrictamente en 0400 para máxima protección

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 0.7.x {/* #from-version-07x */}

Esta versión incluye mejoras significativas en seguridad y nuevas características. Al actualizar desde la versión 0.7.x:

1. **Migración automática de la base de datos:** La aplicación migrará automáticamente el esquema de la base de datos para admitir las nuevas características
2. **Generación de clave maestra:** Se generará una nueva clave maestra para el cifrado de datos sensibles
3. **Gestión de sesiones:** Las sesiones existentes se invalidarán y se establecerán nuevas sesiones protegidas contra CSRF
4. **Actualizaciones de configuración:** Algunas claves de configuración se han actualizado para admitir las nuevas características
5. **Cambios en las plantillas:** Las variables `{backup_interval_value}` y `{backup_interval_type}` se reemplazaron por `{backup_interval}`. Las plantillas predeterminadas se ajustarán automáticamente, pero las plantillas personalizadas no se migrarán. Por favor, compruebe sus plantillas.

### Consideraciones de seguridad {/* #security-considerations */}

- **Archivo de clave maestra:** Asegúrese de que el archivo `.duplistatus.key` esté respaldado y protegido adecuadamente
- **Permisos de archivo:** El archivo de clave maestra tendrá permisos restringidos (0400) por seguridad
- **Cifrado de contraseñas:** Las contraseñas existentes se cifrarán utilizando el nuevo sistema criptográfico
