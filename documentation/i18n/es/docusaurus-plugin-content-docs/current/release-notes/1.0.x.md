# Versión 1.0.x {/* #version-10x */}

## Vista general {/* #overview */}

La versión 1.0.x es una versión de características que introduce mejoras significativas en la configuración de correo electrónico, capacidades de gestión de servidores y herramientas de mantenimiento de bases de datos. Esta versión se centra en mejorar la fiabilidad de las notificaciones por correo electrónico, expandir las opciones de conexión SMTP y proporcionar mejores herramientas para gestionar servidores e integridad de bases de datos.

## Nuevas características {/* #new-features */}

### Mejoras en la gestión de servidores {/* #server-management-enhancements */}

- **Funcionalidad de cambio de contraseña del servidor** - Los usuarios ahora pueden cambiar las contraseñas del servidor directamente desde la página de detalles del servidor haciendo clic en el icono de la llave
- **Detección y fusión de servidores duplicados** - Nueva función en el formulario de mantenimiento de base de datos para detectar servidores duplicados y fusionarlos en una única entrada de servidor

### Mejoras en el registro de auditoría {/* #audit-logging-enhancements */}

- **Registro de auditoría de carga de copias de seguridad** - Todas las cargas de registros de copias de seguridad a través del endpoint `/api/upload` ahora se registran automáticamente en el registro de auditoría. Cada entrada incluye detalles de la copia de seguridad (ID del servidor, nombre del servidor, nombre de la copia de seguridad, estado, fecha, duración, conteos de archivos, tamaños, advertencias y errores) junto con la dirección IP del cliente y la información del agente de usuario para fines de seguimiento y seguridad

### Mejoras en la configuración de correo electrónico {/* #email-configuration-enhancements */}

- **Aviso de configuración incompleta** - Alerta visual mostrada cuando la configuración del correo electrónico no está correctamente configurada
- **Indicadores de estado del servicio** - Etiquetas "(desactivado)" mostradas en las casillas de verificación de notificación cuando los servicios de correo electrónico no están configurados
- **Información del remitente personalizable**:
  - `Sender Name` campo para personalizar el nombre mostrado como remitente en las notificaciones por correo electrónico
  - `From Address` campo para especificar la dirección de correo electrónico mostrada como remitente
  - Nota: Algunos proveedores de correo electrónico sobrescribirán el `From Address` con el `SMTP Server Username`
- **Alternar autenticación SMTP** - Opción para activar o desactivar la autenticación SMTP, soportando servidores que no requieren autenticación
- **Validación del formato de correo electrónico** - Validación para los campos de dirección de destinatario y de origen para asegurar el formato correcto de la dirección de correo electrónico
- **Correo electrónico de prueba mejorado** - El correo electrónico de prueba ahora muestra detalles de conexión completos incluyendo el nombre de host del servidor SMTP, puerto, tipo de conexión, estado de autenticación, nombre de usuario (si aplica), correo electrónico del destinatario, dirección de origen, nombre del remitente y marca de tiempo de la prueba

### Soporte para tipos de conexión SMTP {/* #smtp-connection-type-support */}

- **Múltiples tipos de conexión** - Soporte para tres tipos de conexión:
  - `Plain SMTP` (sin cifrado) en el puerto 25
  - `STARTTLS` (actualización a TLS) en el puerto 587
  - `Direct SSL/TLS` (cifrado desde el inicio) en el puerto 465
- **Tipo de conexión predeterminado** - Cambiado a `Direct SSL/TLS` para nuevas configuraciones
- **Requisitos específicos de conexión** - El campo `From Address` es obligatorio para conexiones `Plain SMTP` para asegurar la correcta identificación del remitente de correo electrónico y el cumplimiento de RFC 5322

## 🐛 Correcciones de errores {/* #-bug-fixes */}

### Correcciones del sistema de correo electrónico {/* #email-system-fixes */}

- **Corregido encabezado `From` faltante** - Resueltos errores de cumplimiento de RFC 5322 asegurando que todos los mensajes de correo electrónico incluyan encabezados `From` adecuados
- **Corregida la encriptación de correo electrónico para STARTTLS** - Corregida la gestión de encriptación para conexiones `STARTTLS` (puerto 587)
- **Corregidas conexiones SMTP simples** - Resueltos errores de negociación TLS que causaban fallos en conexiones `Plain SMTP`
- **Corregida pérdida de configuración no guardada** - Prevención de la eliminación de la configuración de correo electrónico no guardada al cambiar la contraseña
- **Corregida configuración SMTP obsoleta** - Resuelto el problema donde el endpoint de correo electrónico de prueba estaba utilizando una configuración SMTP desactualizada

### Correcciones de la interfaz de usuario {/* #user-interface-fixes */}

- **Corregido el interruptor de visibilidad de la contraseña** - Comportamiento corregido de la función de ver contraseña en el formulario de cambio de contraseña; al hacer clic en el icono del ojo ahora se muestra la contraseña para ambos campos de contraseña simultáneamente

### Correcciones del sistema {/* #system-fixes */}

- **Corregido el registro de entrada de Docker** - Resuelto el problema donde el script de entrada de Docker estaba omitiendo mensajes de registro
- **Corregida la cálculo de la fecha de próxima ejecución** - Añadida la recalculación automática de la fecha `Next Run` después de recopilar registros de copias de seguridad, asegurando que la fecha se actualice correctamente después de la recopilación de registros

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 0.9.x {/* #from-version-09x */}

Esta versión incluye mejoras en la configuración de correo electrónico y la gestión de servidores. Al actualizar desde la versión 0.9.x:

1. **No se requiere migración de base de datos** - Esta versión no requiere cambios en el esquema de la base de datos
2. **Actualizaciones de configuración de correo electrónico** - Las configuraciones de correo electrónico existentes seguirán funcionando, pero es posible que desee revisar y actualizar sus ajustes para aprovechar las nuevas características:
   - Considere establecer un `Sender Name` personalizado para una mejor identificación de correo electrónico
   - Verifique que su `From Address` esté configurado correctamente, especialmente si está utilizando conexiones `Plain SMTP`
   - Pruebe su configuración de correo electrónico utilizando la función mejorada de correo de prueba
3. **Tipo de conexión predeterminada** - Las nuevas configuraciones de correo electrónico tendrán como predeterminado el tipo de conexión `Direct SSL/TLS`
4. **Gestión de contraseñas de servidores** - Ahora puede cambiar las contraseñas de los servidores directamente desde la página de detalles del servidor sin necesidad de volver a recopilar las copias de seguridad

### Recomendaciones de configuración de correo electrónico {/* #email-configuration-recommendations */}

- **Para uso en producción**: Utilice conexiones `STARTTLS` o `Direct SSL/TLS` para una entrega segura de correo electrónico
- **Para pruebas locales**: Las conexiones `Plain SMTP` están disponibles para redes locales de confianza
- **Requisito de dirección de origen**: Al utilizar `Plain SMTP` o cuando la autenticación está desactivada, asegúrese de que el campo `From Address` esté configurado correctamente
- **Pruebe su configuración**: Siempre utilice el botón "Enviar correo de prueba" para verificar que su configuración de correo electrónico funcione correctamente

## Puntos de conexión de API {/* #api-endpoints */}

### Endpoints de configuración de correo electrónico {/* #email-configuration-endpoints */}

- `GET /api/email/config` - Obtener configuración de correo electrónico
- `POST /api/email/config` - Actualizar configuración de correo electrónico
- `POST /api/email/test` - Enviar correo de prueba
- `DELETE /api/email/config` - Eliminar configuración de correo electrónico

### Endpoints de gestión de servidores {/* #server-management-endpoints */}

- `PATCH /api/servers/{id}/password` - Actualizar contraseña del servidor
- `POST /api/database/maintenance/merge-duplicate-servers` - Combinar servidores duplicados
