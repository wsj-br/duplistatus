# Versión 0.9.x {/* #version-09x */}

## Vista general {/* #overview */}

La versión 0.9.x es un lanzamiento importante que introduce un sistema completo de **Control de Acceso de Usuario y Seguridad**. Este lanzamiento transforma **duplistatus** de una aplicación de acceso abierto a un sistema seguro de múltiples usuarios con control de acceso basado en roles, registro de auditoría completo y características de seguridad de nivel empresarial. Todas las funcionalidades existentes ahora están protegidas por autenticación, asegurando que solo los usuarios autorizados puedan acceder y gestionar el monitoreo de copias de seguridad.

## Cambios importantes {/* #breaking-changes */}

### Autenticación Requerida {/* #authentication-required */}

- **Todas las páginas ahora requieren autenticación** - Los usuarios deben iniciar sesión para acceder a la aplicación
- **Cuenta de administrador predeterminada** se crea automáticamente:
  - Nombre de usuario: `admin`
  - Contraseña: `Duplistatus09` (debe cambiarse en el primer inicio de sesión)
- **Sesiones existentes se invalidan** - Todos los usuarios deben iniciar sesión después de la actualización
- **Puntos finales de API ahora requieren autenticación** - Las integraciones externas deben incluir cookies de sesión o usar solicitudes autenticadas

:::warning
**Todos los usuarios deben iniciar sesión después de actualizar a la versión 0.9.x.** Las credenciales de administrador predeterminadas son admin/Duplistatus09. Cambie la contraseña inmediatamente después del primer inicio de sesión.
:::

### Migración del Esquema de Base de Datos {/* #database-schema-migration */}

- **Migración automática de v3.1 a v4.0** para instalaciones existentes
- **Nuevas tablas añadidas**: `users`, `sessions`, `audit_log`
- **Copia de seguridad de la base de datos creada automáticamente** antes de la migración
- **Nuevas instalaciones** comienzan directamente con el esquema v4.0 (no se necesita migración)

## Nuevas características {/* #new-features */}

### Sistema de Control de Acceso de Usuario y Seguridad {/* #user-access-control--security-system */}

#### Sistema de Autenticación {/* #authentication-system */}

- **Funcionalidad de inicio/cierre de sesión de usuario** con gestión segura de sesiones
- **Autenticación basada en contraseña** con hash bcrypt (factor de costo 12)
- **Mecanismo de bloqueo de cuenta** (5 intentos fallidos, bloqueo de 15 minutos)
- **Cambio forzado de contraseña** en el primer inicio de sesión
- **Cumplimiento de políticas de contraseña**:
  - Mínimo 8 caracteres
  - Al menos una letra mayúscula
  - Al menos una letra minúscula
  - Al menos un número
  - Caracteres especiales opcionales
- **Funcionalidad "Recordarme"** con persistencia de nombre de usuario en localStorage
- **Autenticación basada en sesiones** con sesiones respaldadas por base de datos (reemplaza en memoria)
- **Protección CSRF** integrada con autenticación
- **Cookies HTTP-only** para seguridad de sesiones
- **Seguimiento de dirección IP y agente de usuario** para monitoreo de seguridad

#### Gestión de Usuarios (Solo Administrador) {/* #user-management-admin-only */}

- **Creación de usuarios** con generación automática de contraseña temporal
- **Lista de usuarios** con búsqueda, paginación y filtrado
- **Edición de usuarios** (nombre de usuario, estado de administrador, requerimiento de cambio de contraseña)
- **Funcionalidad de restablecimiento de contraseña** con visualización de contraseña temporal
- **Eliminación de usuarios** con medidas de seguridad (evita la eliminación del último administrador)
- **Control de acceso basado en roles** (roles de Administrador/Usuario)
- **Indicadores de estado** (Activo, Bloqueado, Debe cambiar la contraseña)
- **Seguimiento y visualización del último inicio de sesión**

#### Sistema de Registro de Auditoría {/* #audit-logging-system */}

- **Registro de auditoría completo** para todos los cambios del sistema y acciones de usuario
- **Visor de registro de auditoría** con filtrado avanzado:
  - Filtrado por rango de fechas
  - Filtrado por usuario
  - Filtrado por acción
  - Filtrado por categoría
  - Filtrado por estado
- **Funcionalidad de exportación** (formatos CSV y JSON)
- **Estadísticas del registro de auditoría** y análisis
- **Período de retención configurable** (30-365 días, predeterminado: 90 días)
- **Trabajo cron de limpieza automática** (se ejecuta diariamente a las 2 AM UTC)
- **API de limpieza manual** con soporte para ejecución en seco
- **Registro de auditoría para**:
  - Eventos de autenticación (inicio de sesión, cierre de sesión, cambios de contraseña, bloqueos de cuenta)
  - Operaciones de gestión de usuarios (crear, actualizar, eliminar, restablecimiento de contraseña)
  - Cambios de configuración (correo electrónico, NTFY, plantillas, tolerancia de vencimiento, configuración de copia de seguridad)
  - Operaciones de copia de seguridad (colección, eliminación, limpieza)
  - Gestión de servidores (agregar, actualizar, eliminar)
  - Operaciones del sistema (migraciones, limpieza, notificaciones)

### Rediseño de la página de configuración {/* #settings-page-redesign */}

- **Navegación lateral moderna** con barra lateral plegable
- **Persistencia del estado de la barra lateral específica del usuario** (preferencia de plegado/desplegado guardada por usuario)
- **Secciones de configuración agrupadas**:
  - **Notificaciones**: Notificaciones de Copia de Seguridad, Monitoreo de copias de seguridad, Plantillas
  - **Integraciones**: NTFY, Correo electrónico
  - **Sistema**: Servidores, Usuarios (solo administrador), Registro de auditoría
- **Barra lateral fija** que permanece visible mientras se desplaza
- **Diseño adaptable** con espaciado optimizado
- **Icono de configuración y título "Configuración del sistema"** en el encabezado de la barra lateral
- **Botón de retroceso** integrado en el encabezado de la aplicación

### Mejoras en la interfaz de usuario {/* #user-interface-enhancements */}

- **Página de inicio de sesión independiente** con diseño moderno
- **Casilla de verificación "Recordarme"** en el formulario de inicio de sesión para persistencia del nombre de usuario
- **Botones para mostrar/ocultar contraseña** en los formularios de inicio de sesión y cambio de contraseña
- **Modal de cambio de contraseña** con lista de verificación de validación en tiempo real
- **Indicador de usuario y botón de cierre de sesión** en el encabezado de la aplicación
- **Visibilidad de la interfaz basada en roles** (características solo para administradores ocultas para usuarios regulares)
- **Insignias y indicadores de estado** en toda la interfaz de usuario
- **Preferencias específicas del usuario** almacenadas en localStorage (por ejemplo, estado de la barra lateral plegada)

### Características de seguridad {/* #security-features */}

- **Hashing de contraseñas** con bcrypt (estándar de la industria)
- **Sanitización de datos sensibles** en registros de auditoría (contraseñas, tokens, secretos nunca registrados)
- **Límite de velocidad** para intentos de inicio de sesión
- **Expiración de sesión** (24 horas)
- **Validación de token CSRF** para todas las operaciones que cambian el estado
- **Herramienta CLI de recuperación de administrador** para restablecimiento de contraseña si se bloquea

### Herramientas para desarrolladores {/* #developer-tools */}

- **Script CLI de recuperación de administrador** (`admin-recovery`) para ejecución fácil en contenedores Docker
- **Funciona tanto localmente como en Docker** con detección automática de rutas
- **Interfaces de TypeScript completas** (sin tipos `any`)
- **Middleware de autenticación** para protección de rutas
- **Clase de utilidad de registro de auditoría** con métodos de conveniencia

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 0.8.x {/* #from-version-08x */}

Esta versión introduce autenticación y requiere que todos los usuarios inicien sesión. Al actualizar desde la versión 0.8.x:

1. **Migración de base de datos automática**: La aplicación migrará automáticamente el esquema de su base de datos de v3.1 a v4.0
2. **Copia de seguridad de la base de datos**: Se crea una copia de seguridad automática antes de la migración
3. **Cuenta de administrador predeterminada**: Se crea una cuenta de administrador predeterminada:
   - Nombre de usuario: `admin`
   - Contraseña: `Duplistatus09`
   - **Debe cambiar esta contraseña en el primer inicio de sesión**
4. **Invalidación de sesión**: Todas las sesiones existentes se invalidan
5. **Inicio de sesión de usuario requerido**: Todos los usuarios deben iniciar sesión después de la actualización
6. **Autenticación de API**: Las integraciones externas deben actualizarse para incluir autenticación

### Consideraciones de seguridad {/* #security-considerations */}

- **Cambiar contraseña predeterminada**: Cambiar la contraseña del administrador predeterminada inmediatamente después del primer inicio de sesión
- **Crear cuentas de usuario**: Crear cuentas de usuario individuales para cada persona que necesite acceso
- **Revisar registros de auditoría**: Comprobar los registros de auditoría regularmente para la supervisión de seguridad
- **Configurar retención**: Establecer el período de retención de registros de auditoría adecuado según sus requisitos de cumplimiento
- **Copia de seguridad de la clave maestra**: Si se actualiza desde 0.8.x, asegúrese de que el archivo `.duplistatus.key` esté respaldado

### Pasos para el primer inicio de sesión {/* #first-login-steps */}

1. **Iniciar sesión** con las credenciales predeterminadas (`admin` / `Duplistatus09`)
2. **Cambiar contraseña** cuando se le solicite (obligatorio en el primer inicio de sesión)
3. **Crear cuentas de usuario** para otros usuarios (Configuración → Usuarios)
4. **Configurar la retención de registros de auditoría** si es necesario (Configuración → Registro de auditoría)
5. **Revisar registros de auditoría** para verificar que el sistema funciona correctamente

## Puntos de conexión de API {/* #api-endpoints */}

### Puntos de conexión de autenticación {/* #authentication-endpoints */}

- `POST /api/auth/login` - Autenticación de usuario
- `POST /api/auth/logout` - Terminación de sesión
- `GET /api/auth/me` - Información del usuario actual
- `POST /api/auth/change-password` - Cambio de contraseña

### Puntos de conexión de gestión de usuarios (solo administrador) {/* #user-management-endpoints-admin-only */}

- `GET /api/users` - Listar usuarios
- `POST /api/users` - Crear usuario
- `PATCH /api/users/{id}` - Actualizar usuario
- `DELETE /api/users/{id}` - Eliminar usuario

### Puntos de conexión de registro de auditoría {/* #audit-log-endpoints */}

- `GET /api/audit-log` - Consultar registros de auditoría
- `GET /api/audit-log/download` - Exportar registros de auditoría
- `GET /api/audit-log/stats` - Estadísticas de auditoría
- `POST /api/audit-log/cleanup` - Limpieza manual (solo administrador)
- `GET /api/audit-log/retention` - Obtener configuración de retención
- `PATCH /api/audit-log/retention` - Actualizar retención (solo administrador)

:::note
Todos los puntos de conexión de la API ahora requieren autenticación. Consulte la [Referencia de API](../api-reference/authentication-security.md) para obtener detalles sobre la autenticación.
:::
