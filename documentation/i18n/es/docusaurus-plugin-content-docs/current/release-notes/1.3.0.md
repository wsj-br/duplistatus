# Versión 1.3.0 {/* #version-130 */}

## Vista general {/* #overview */}

La versión 1.3.0 introduce políticas de contraseña configurables, un nuevo visor de registros de aplicación para administradores, visualización de días de la semana basada en la configuración regional y varias mejoras en la experiencia del usuario. Esta versión se centra en herramientas administrativas mejoradas y soporte internacionalizado mejorado.

## Nuevas características {/* #new-features */}

### Política de Contraseña Configurable {/* #configurable-password-policy */}

- **Variables de entorno para la política de contraseña**: Configure los requisitos de validación de contraseña a través de variables de entorno:
  - `PWD_ENFORCE`: Establezca en `false` para desactivar los requisitos de complejidad de contraseña (mayúsculas, minúsculas, números). Por defecto, se aplican todas las reglas. Cuando se desactiva, solo se aplica la longitud mínima.
  - `PWD_MIN_LEN`: Establece la longitud mínima de la contraseña en caracteres. Por defecto, son 8 caracteres.
  - La comprobación de contraseña predeterminada (que evita el uso de la contraseña de administrador predeterminada) siempre se aplica, independientemente de la configuración de `PWD_ENFORCE`.

### Visor de Registros de Aplicación {/* #application-logs-viewer */}

- **Nuevo visor de registros solo para administradores**: Vea y descargue los registros de la aplicación directamente desde la página de Configuración:
  - Acceda al archivo `application.log` consolidado y a las versiones rotadas de los registros
  - Selector de recuento de líneas configurable (100, 500, 1000, 5000, 10000 líneas)
  - Filtro de búsqueda en tiempo real con coincidencia de texto sin distinción de mayúsculas y minúsculas
  - Alternar el desplazamiento automático para el monitoreo de registros en tiempo real con sondeo automático
  - Copiar al portapapeles y exportar registros filtrados como archivo de texto
  - Visualización de metadatos de archivos que muestra el recuento de líneas, el tamaño del archivo y la marca de tiempo de la última modificación
  - Rotación de registros al iniciar el contenedor (configurable a través de `LOG_ROTATION_VERSIONS`, por defecto: 5)

### Guía de Usuario Contextual {/* #context-aware-user-guide */}

- **Botón de ayuda dinámico**: El botón de la Guía del Usuario en la cabecera de la aplicación ahora abre la documentación relevante para la página actual. La descripción emergente se actualiza para mostrar "Ayuda para `Page Name`" para indicar qué documentación se abrirá.

### Mejora de Configuración del Servidor {/* #server-configuration-enhancement */}

- **Acceso rápido a la interfaz de Duplicati**: Hacer clic con el botón derecho en el botón de configuración del servidor o en cualquier elemento del servidor en el menú emergente de selección del servidor abre la interfaz de usuario heredada de Duplicati (`/ngax`) en una nueva pestaña.

## 🔧 Mejoras {/* #-improvements */}

### Visualización de Días de la Semana Basada en Configuración Regional {/* #locale-aware-weekday-display */}

- **Orden de días de la semana internacionalizado**: La visualización de los días de la semana en el formulario de monitoreo de copias de seguridad ahora respeta la configuración regional de su navegador. Los días de la semana se muestran en el orden correcto según la configuración regional (Lunes-Domingo para Reino Unido/Europa, Domingo-Sábado para EE.UU./Brasil).

### Manejo Mejorado de Errores SMTP {/* #enhanced-smtp-error-handling */}

- **Mensajes de error mejorados**: Los mensajes de error SMTP ahora proporcionan orientación más precisa:
  - Los errores de autenticación indican claramente problemas con el nombre de usuario/contraseña
  - Los errores de versión SSL/TLS se identifican correctamente
  - Las sugerencias de tipo de conexión solo aparecen cuando son realmente relevantes

### Comportamiento de Notificaciones Toast {/* #toast-notification-behaviour */}

- **Notificaciones de error persistentes**: Las notificaciones de error ahora persisten hasta que se cierran manualmente, asegurando que no se pierdan mensajes de error importantes. Las notificaciones de éxito e informativas se descartan automáticamente después de 3 segundos.

### Tabla de Configuración de Notificaciones {/* #notification-settings-table */}

- **Diseño simplificado**: La tabla de configuración de notificaciones se ha simplificado con una columna combinada "Servidor / Copia de seguridad" e iconos contextuales que indican el estado de configuración adicional de los destinos.

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 1.2.x {/* #from-version-12x */}

Al actualizar a la versión 1.3.0:

1. **Política de contraseñas**: La nueva política de contraseñas exige por defecto todos los requisitos de complejidad. Si necesita una política de contraseñas más simple, configure las variables de entorno `PWD_ENFORCE` y `PWD_MIN_LEN`.

2. **Registros de la aplicación**: Toda la salida de los contenedores (servidor y servicio cron) se consolida ahora en un único archivo `data/logs/application.log`.

3. **Rotación de registros**: La rotación de registros se puede configurar mediante la variable de entorno `LOG_ROTATION_VERSIONS` (predeterminada: 5 versiones).

4. **No se requiere migración de la base de datos**: Esta versión no requiere ningún cambio en el esquema de la base de datos.

## Puntos de conexión de API {/* #api-endpoints */}

Se ha introducido el siguiente punto de acceso a la API en esta versión:

### Punto de acceso a la política de contraseñas {/* #password-policy-endpoint */}

- `GET /api/auth/password-policy` - Devuelve la configuración actual de la política de contraseñas

### Puntos de acceso a los registros de la aplicación {/* #application-logs-endpoints */}

- `GET /api/application-logs` - Ver registros con selección de archivos y funcionalidad de cola
- `GET /api/application-logs/export` - Exportar registros filtrados como archivo de texto

### Puntos de acceso eliminados {/* #removed-endpoints */}

Los siguientes puntos de acceso a la API no utilizados se han eliminado en esta versión:

- `DELETE /api/backups/[backupId]` - Punto de acceso solo para desarrollo que nunca se utilizó
- `GET /api/audit-log/stats` - Punto de acceso no llamado por el visor de registro de auditoría
