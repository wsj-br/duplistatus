# Versión 1.2.1 {/* #version-121 */}

## Vista general {/* #overview */}

La versión 1.2.1 es una versión menor que introduce mejoras significativas en la gestión de notificaciones de copia de seguridad, mejora las capacidades de registro de auditoría, corrige la detección de próxima ejecución/vencida en casos extremos y añade funcionalidad de copia de seguridad y restauración de base de datos. Esta versión se centra en mejorar la experiencia del usuario con la configuración de notificaciones.

## Nuevas características {/* #new-features */}

### Gestión Mejorada de Notificaciones de Copia de Seguridad {/* #enhanced-backup-notifications-management */}

- **Sistema de valores predeterminados e herencia a nivel de servidor**: Configure destinos adicionales predeterminados (eventos de notificación, correos electrónicos y temas NTFY) a nivel de servidor que todas las copias de seguridad heredan automáticamente. Las copias de seguridad pueden anular estos valores predeterminados cuando sea necesario, con indicadores visuales claros que muestran el estado de herencia.
- **Jerarquía visual mejorada**: Las copias de seguridad ahora se agrupan por servidor con filas de encabezado de servidor distintas. Los valores heredados están claramente marcados con iconos de enlace, y los valores anulados se pueden revertir fácilmente a la herencia.
- **Operaciones masivas**: El botón "Sincronizar a todos" borra todas las anulaciones de copias de seguridad para hacer que todas las copias de seguridad hereden de los valores predeterminados del servidor. El botón "Limpiar todo" borra todos los destinos adicionales manteniendo la estructura de herencia.
- **Funcionalidad de prueba**: Se han añadido botones de correo electrónico de prueba y notificación de prueba directamente en la página de configuración de Notificaciones de Copia de Seguridad. Los botones de prueba están disponibles tanto para la configuración individual de copias de seguridad como para operaciones de edición masiva, permitiéndole verificar la entrega de notificaciones antes de aplicar cambios.
- **Soporte de código QR**: Se ha añadido un botón de código QR para temas NTFY para compartir fácilmente temas de notificación con dispositivos móviles.

### Mejoras en Plantillas de Notificación {/* #notification-template-enhancements */}

- **Nueva variable `{log_text}`**: Se ha añadido la variable `{log_text}` a las plantillas de notificación, proporcionando acceso al texto de los mensajes de registro para su uso en mensajes de notificación. La variable contiene el texto completo de advertencias y errores combinados, formateado como texto plano con un elemento por línea.
- **Migración automática de plantillas**: El sistema incluye un mecanismo de actualización perezosa que detecta y actualiza automáticamente las plantillas predeterminadas antiguas cuando se leen por primera vez después de una actualización. Las plantillas personalizadas se conservan sin cambios.

### Gestión de Base de Datos {/* #database-management */}

- **Funcionalidad de copia de seguridad de base de datos**: Los administradores ahora pueden crear copias de seguridad de toda la base de datos desde la página de configuración de Mantenimiento de Base de Datos. Soporta ambos formatos, binario (.db) y texto SQL (.sql) para mayor flexibilidad.
- **Funcionalidad de restauración de base de datos**: Restaure la base de datos desde archivos de copia de seguridad creados previamente con creación automática de copia de seguridad de seguridad, validación de integridad y reversión en caso de fallo. Todas las sesiones se borran después de la restauración por seguridad.

### Detección de Clave Maestra {/* #master-key-detection */}

- **Detección automática de cambio de clave maestra**: Después de iniciar sesión, el sistema comprueba automáticamente si el archivo `.duplistatus.key` ha cambiado. Si se detecta, todas las contraseñas cifradas se borran y aparece un cuadro modal informando a los usuarios de que las contraseñas deben volver a configurarse. Esto evita errores al restaurar desde copias de seguridad o al migrar a un nuevo sistema.

### Mejoras en Monitoreo de Copias de Seguridad {/* #backup-monitoring-improvements */}

- **Exportación CSV mejorada**: Se ha añadido la columna "Marca de tiempo de Última Copia de Seguridad (BD)" al archivo CSV generado por el botón "Descargar CSV" en la configuración de monitoreo de copias de seguridad. Esto permite a los usuarios comparar la marca de tiempo real de la última copia de seguridad de la base de datos con la marca de tiempo "Última Copia de Seguridad" configurada.
- **Información sobre herramienta de Próxima Ejecución**: Al pasar el cursor sobre el valor "Próxima Ejecución" en cada fila ahora se muestra una información sobre herramienta que muestra la marca de tiempo de la última copia de seguridad de la base de datos, formateada de la misma manera que la visualización de "Próxima Ejecución".

### Mejoras en Registro de Auditoría {/* #audit-logging-enhancements */}

- **Entradas individuales de auditoría de notificaciones**: Cada notificación y correo electrónico enviado ahora genera una entrada separada en el registro de auditoría con detalles sobre el canal, la configuración y el resultado (éxito o error). Esto incluye notificaciones de prueba, proporcionando una mejor trazabilidad para la entrega de notificaciones.
- **Registro de errores robusto**: Todas las operaciones de registro de auditoría para fallos de notificación ahora están envueltas en bloques try-catch para evitar que los errores de registro de auditoría interrumpan los flujos de notificación. El sistema intenta recuperar la configuración SMTP si no está disponible inmediatamente al registrar fallos de correo electrónico.
- **Registro de auditoría mejorado para actualizaciones de configuración**: Tanto las entradas de registro de auditoría `email_config_updated` como `ntfy_config_updated` ahora solo registran cuando hay cambios reales en la configuración. Cuando se detectan cambios, el registro de auditoría incluye valores antiguos y nuevos para cada campo modificado, facilitando hacer seguimiento de qué cambió específicamente.

### Mejoras en la documentación {/* #documentation-improvements */}

- El estilo de la documentación se ha actualizado para alinearse con la apariencia de la aplicación. La barra lateral también se ha revisado para mejorar la visibilidad y facilitar la navegación.

## 🐛 Correcciones de errores {/* #-bug-fixes */}

- **Marcas de tiempo corregidas en el registro de auditoría**: Las marcas de tiempo en el visor de registro de auditoría ahora se muestran correctamente en la zona horaria del navegador del usuario en lugar de GMT. Las marcas de tiempo de SQLite (almacenadas en UTC) ahora se analizan correctamente como UTC y se convierten a la zona horaria local del navegador para su visualización.
- **Cálculo corregido de "Próxima ejecución" y detección de vencimientos**: La columna "Próxima ejecución" en la configuración de monitoreo de copias de seguridad ahora calcula y muestra con precisión la próxima fecha prevista de copia de seguridad, teniendo en cuenta tanto el horario de copia de seguridad como la marca de tiempo de la última copia de seguridad. Esto se aplica tanto a trabajos de copia de seguridad programados como ejecutados manualmente, resultando en una detección más confiable de vencimientos.

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 1.1.x {/* #from-version-11x */}

Al actualizar a la versión 1.2.1:

1. **Plantillas de notificación**: El sistema actualizará automáticamente las plantillas de notificación predeterminadas para incluir la nueva variable `{log_text}` la primera vez que se accedan después de la actualización. Las plantillas personalizadas permanecerán sin cambios. Si desea utilizar la nueva variable `{log_text}` en sus propias plantillas, deberá actualizarlas o restaurar las plantillas predeterminadas manualmente.

2. **Cambios en la clave maestra**: Si restaura desde una copia de seguridad o migra a un nuevo sistema con un archivo `.duplistatus.key` diferente, el sistema lo detectará automáticamente y le pedirá que vuelva a configurar las contraseñas cifradas (contraseñas SMTP y contraseñas del servidor Duplicati).

3. **Copia de seguridad/Restauración de base de datos**: Nueva funcionalidad de copia de seguridad y restauración de base de datos está disponible en la página de configuración de Mantenimiento de base de datos. Se recomienda crear una copia de seguridad antes de actualizar, aunque no se requieren cambios en el esquema de base de datos para esta versión.

4. **No se requiere migración de base de datos**: Esta versión no requiere ningún cambio en el esquema de base de datos.

## Puntos finales de la API {/* #api-endpoints */}

Los siguientes puntos finales de la API han sido introducidos en esta versión.

### Puntos finales de autenticación y seguridad {/* #authentication--security-endpoints */}

- `GET /api/auth/admin-must-change-password` - Comprobar si el usuario administrador debe cambiar la contraseña

### Puntos finales de gestión de base de datos {/* #database-management-endpoints */}

- `GET /api/database/backup` - Crear copia de seguridad de base de datos (formato binario o SQL)
- `POST /api/database/restore` - Restaurar base de datos desde archivo de copia de seguridad

### Puntos finales de gestión de copias de seguridad {/* #backup-management-endpoints */}

- `GET /api/backups/last-timestamps` - Obtener marcas de tiempo de la última copia de seguridad para todas las combinaciones de servidor-copia de seguridad
