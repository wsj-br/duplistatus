# Versión 1.2.1 {/* #version-121 */}

## Vista general {/* #overview */}

La versión 1.2.1 es una versión menor que introduce mejoras significativas en la gestión de notificaciones de copia de seguridad, mejora las capacidades de registro de auditoría, corrige la detección de ejecución próxima/vencida en casos límite y añade funcionalidad de copia de seguridad y restauración de base de datos. Esta versión se centra en mejorar la experiencia del usuario con la configuración de notificaciones.

## Nuevas características {/* #new-features */}

### Gestión mejorada de notificaciones de copia de seguridad {/* #enhanced-backup-notifications-management */}

- **Valores predeterminados a nivel de servidor e sistema de herencia**: Configura valores predeterminados adicionales (eventos de notificación, correos electrónicos y temas NTFY) a nivel de servidor que todas las copias de seguridad heredan automáticamente. Las copias de seguridad pueden anular estos valores predeterminados cuando sea necesario, con indicadores visuales claros que muestran el estado de herencia.
- **Jerarquía visual mejorada**: Las copias de seguridad ahora se agrupan por servidor con filas de encabezado de servidor distintas. Los valores heredados se marcan claramente con iconos de enlace, y los valores anulados se pueden revertir fácilmente a la herencia.
- **Operaciones masivas**: El botón "Sincronizar a todos" borra todas las anulaciones de copia de seguridad para que todas hereden de los valores predeterminados del servidor. El botón "Borrar todo" borra todos los destinos adicionales mientras se mantiene la estructura de herencia.
- **Funcionalidad de prueba**: Se han añadido botones de prueba de correo electrónico y prueba de notificación directamente en la página de configuración de notificaciones de copia de seguridad. Los botones de prueba están disponibles tanto para la configuración individual de copia de seguridad como para operaciones de edición masiva, lo que permite verificar la entrega de notificaciones antes de aplicar los cambios.
- **Soporte de código QR**: Se ha añadido un botón de código QR para temas NTFY para compartir fácilmente los temas de notificación con dispositivos móviles.

### Mejoras en las plantillas de notificación {/* #notification-template-enhancements */}

- **Nueva variable `{log_text}`**: Se ha añadido la variable `{log_text}` a las plantillas de notificación, proporcionando acceso a los mensajes de texto de registro para su uso en los mensajes de notificación. La variable contiene el texto completo de las advertencias y errores combinados, formateado como texto plano con un elemento por línea.
- **Migración automática de plantillas**: El sistema incluye un mecanismo de actualización perezosa que detecta y actualiza automáticamente las plantillas predeterminadas antiguas cuando se leen por primera vez después de una actualización. Las plantillas personalizadas se conservan sin cambios.

### Gestión de base de datos {/* #database-management */}

- **Funcionalidad de copia de seguridad de base de datos**: Los administradores ahora pueden crear copias de seguridad de toda la base de datos desde la página de configuración de mantenimiento de base de datos. Soporta ambos formatos binario (.db) y texto SQL (.sql) para mayor flexibilidad.
- **Funcionalidad de restauración de base de datos**: Restaura la base de datos desde archivos de copia de seguridad previamente creados con creación automática de copia de seguridad de seguridad, validación de integridad y reversión en caso de fallo. Todas las sesiones se borran después de la restauración por seguridad.

### Detección de clave maestra {/* #master-key-detection */}

- **Detección automática de cambio de clave maestra**: Después del inicio de sesión, el sistema comprueba automáticamente si el archivo `.duplistatus.key` ha cambiado. Si se detecta, todas las contraseñas cifradas se borran y aparece una ventana emergente modal que informa a los usuarios de que las contraseñas necesitan ser reconfiguradas. Esto evita errores al restaurar desde copias de seguridad o al migrar a un nuevo sistema.

### Mejoras en el monitoreo de copias de seguridad {/* #backup-monitoring-improvements */}

- **Exportación mejorada a CSV**: Se ha añadido la columna "Marca de tiempo de la última copia de seguridad (BD)" al archivo CSV generado por el botón "Descargar" en la configuración de monitoreo de copias de seguridad. Esto permite a los usuarios comparar la marca de tiempo de la última copia de seguridad real de la base de datos con la marca de tiempo "Última copia de seguridad" configurada.
- **Información sobre herramientas de ejecución próxima**: Al pasar el cursor sobre el valor "Próxima ejecución" en cada fila, ahora se muestra una información sobre herramientas que muestra la marca de tiempo de la última copia de seguridad de la base de datos, formateada de la misma manera que la visualización de "Próxima ejecución".

### Mejoras en el registro de auditoría {/* #audit-logging-enhancements */}

- **Entradas individuales de auditoría de notificaciones**: Cada notificación y correo electrónico enviado ahora genera una entrada de registro de auditoría separada con detalles sobre el canal, la configuración y el resultado (éxito o error). Esto incluye notificaciones de prueba, lo que proporciona una mejor trazabilidad para la entrega de notificaciones.
- **Registro robusto de errores**: Todas las operaciones de registro de auditoría para errores de notificación ahora están envueltas en bloques try-catch para evitar que los errores de registro de auditoría interrumpan los flujos de notificación. El sistema intenta recuperar la configuración SMTP si no está disponible de inmediato al registrar errores de correo electrónico.
- **Registro de auditoría mejorado para actualizaciones de configuración**: Las entradas de registro de auditoría para `email_config_updated` y `ntfy_config_updated` ahora solo se registran cuando hay cambios reales en la configuración. Cuando se detectan cambios, el registro de auditoría incluye los valores antiguos y nuevos de cada campo modificado, lo que facilita el seguimiento de lo que cambió específicamente.

### Mejoras en la documentación {/* #documentation-improvements */}

- El estilo de la documentación se ha actualizado para alinearse con la apariencia de la aplicación. La barra lateral también se ha revisado para mejorar la visibilidad y facilitar la navegación.

## 🐛 Correcciones de errores {/* #-bug-fixes */}

- **Corrección de marcas de tiempo en el registro de auditoría**: Las marcas de tiempo en el visor de registro de auditoría ahora se muestran correctamente en la zona horaria del navegador del usuario en lugar de GMT. Las marcas de tiempo de SQLite (almacenadas en UTC) ahora se analizan correctamente como UTC y se convierten a la zona horaria local del navegador para su visualización.
- **Cálculo corregido de "Próxima ejecución" y detección de vencimiento**: La columna "Próxima ejecución" en la configuración de monitoreo de copias de seguridad ahora calcula y muestra correctamente la próxima fecha de copia de seguridad esperada, teniendo en cuenta tanto el horario de copia de seguridad como la marca de tiempo de la última copia de seguridad. Esto se aplica tanto a los trabajos de copia de seguridad programados como a los ejecutados manualmente, lo que resulta en una detección de vencimiento más confiable.

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 1.1.x {/* #from-version-11x */}

Al actualizar a la versión 1.2.1:

1. **Plantillas de Notificaciones**: El sistema actualizará automáticamente las plantillas de notificación predeterminadas para incluir la nueva variable `{log_text}` la primera vez que se accedan después de la actualización. Las plantillas personalizadas se mantendrán sin cambios. Si desea utilizar la nueva variable `{log_text}` en sus propias plantillas, deberá actualizarlas o restaurar las plantillas predeterminadas manualmente.

2. **Cambios en la Clave Maestra**: Si restaura desde una copia de seguridad o migra a un nuevo sistema con un archivo `.duplistatus.key` diferente, el sistema detectará esto automáticamente y le pedirá que reconfigure las contraseñas cifradas (contraseñas SMTP y contraseñas del servidor Duplicati).

3. **Copia de seguridad y Restauración de la Base de Datos**: La nueva funcionalidad de copia de seguridad y restauración de la base de datos está disponible en la página de configuración de mantenimiento de la base de datos. Se recomienda crear una copia de seguridad antes de actualizar, aunque no se requieren cambios en el esquema de la base de datos para esta versión.

4. **No se requiere migración de la base de datos**: Esta versión no requiere ningún cambio en el esquema de la base de datos.

## Puntos de conexión de API {/* #api-endpoints */}

Los siguientes puntos de acceso de API se han introducido en esta versión.

### Puntos de acceso de API de Autenticación y Seguridad {/* #authentication--security-endpoints */}

- `GET /api/auth/admin-must-change-password` - Comprobar si el usuario administrador debe cambiar la contraseña

### Puntos de acceso de API de Gestión de Bases de Datos {/* #database-management-endpoints */}

- `GET /api/database/backup` - Crear copia de seguridad de la base de datos (formato binario o SQL)
- `POST /api/database/restore` - Restaurar base de datos desde archivo de copia de seguridad

### Puntos de acceso de API de Gestión de Copias de Seguridad {/* #backup-management-endpoints */}

- `GET /api/backups/last-timestamps` - Obtener marcas de tiempo de la última copia de seguridad para todas las combinaciones servidor-copia de seguridad
