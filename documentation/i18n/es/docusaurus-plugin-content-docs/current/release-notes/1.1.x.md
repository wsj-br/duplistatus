# Versión 1.1.x {/* #version-11x */}

## Vista general {/* #overview */}

La versión 1.1.x es una versión menor que aborda problemas críticos con la detección de copias de seguridad vencidas, mejora la compatibilidad con contenedores Podman e introduce mejoras en la arquitectura de contenedores. Esta versión se centra en corregir la precisión de la detección de copias de seguridad vencidas y resolver problemas de red en entornos Podman.

## Nuevas características {/* #new-features */}

### Mejoras en la interfaz de usuario {/* #user-interface-enhancements */}

- **Menú contextual con clic derecho en el botón de actualización automática** - Hacer clic derecho en el botón de actualización automática en la barra de herramientas de la aplicación abre la página Configuración de visualización para acceder rápidamente a las preferencias de visualización
- **Modal mejorado para recopilar copias de seguridad** - La etiqueta del campo de contraseña ahora indica claramente "(solo rellenar si se cambió la contraseña)" cuando se selecciona un servidor, lo que hace más claro cuándo se necesita el campo

### Mejoras en la documentación {/* #documentation-improvements */}

- **Migración del alojamiento de documentación** - La documentación se ha movido de la imagen del contenedor Docker a GitHub Pages en https://wsj-br.github.io/duplistatus/user-guide/overview para mejorar la accesibilidad y facilitar las actualizaciones
- El enlace de la Guía del usuario en la cabecera de la aplicación ahora apunta al sitio de documentación externo

## 🐛 Correcciones de errores {/* #-bug-fixes */}

### Crítico: Detección de copias de seguridad vencidas - Reimplementación completa {/* #critical-overdue-backup-detection---complete-reimplementation */}

- **Corregida la detección de copias de seguridad vencidas** - Sistema de detección de copias de seguridad vencidas completamente reimplementado con un nuevo algoritmo que rastrear correctamente las fechas de copia de seguridad esperadas:
  - El algoritmo asegura que las copias de seguridad manuales no cambien los tiempos de copia de seguridad programados (por ejemplo, una copia de seguridad manual a las 10pm no cambiará un horario de 2pm)
  - Corregida la columna "Próxima ejecución" en la configuración de monitoreo de copias de seguridad que mostraba fechas incorrectas
  - La configuración de copias de seguridad se actualiza inmediatamente después de recibir copias de seguridad a través de `/api/upload` o `/api/backups/collect`
  - Para servidores nuevos sin sincronización Duplicati, utiliza la hora del día de la primera copia de seguridad como referencia del horario
  - Para más detalles, consulte la documentación [Algoritmo de detección de vencimiento](https://github.com/wsj-br/duplistatus/blob/main/dev/OVERDUE_DETECTION_ALGORITHM.md)

### Correcciones en contenedores Podman {/* #podman-container-fixes */}

- **Corregido el pod de red de Podman** - Resuelto el problema que impedía el acceso externo a la aplicación cuando se ejecuta en pods de Podman. El servidor ahora se vincula correctamente a todas las interfaces (`0.0.0.0:9666`) en ambos modos de pod de Podman y contenedor independiente
- **Corregida la resolución de DNS para nombres de host de Tailscale** - Resueltos los problemas de resolución de DNS en contenedores Podman que impedían conectarse a nombres de host de Tailscale o servidores DNS personalizados. Actualizada la documentación de instalación con instrucciones.

### Correcciones en la configuración de correo electrónico {/* #email-configuration-fixes */}

- **Corregido el manejo de nombre de usuario/contraseña vacíos en SMTP** - Resuelto el problema en el que borrar los campos de nombre de usuario o contraseña en la configuración de correo electrónico seguía almacenando valores cifrados en la base de datos. Los campos vacíos se almacenan ahora correctamente como cadenas vacías y pueden borrarse correctamente

### Mejoras en el sistema {/* #system-improvements */}

- **Reducido el registro en la consola** - AuditLogger ahora solo registra intentos de inicio de sesión fallidos en la consola; todas las demás entradas de auditoría se escriben solo en la base de datos

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 1.0.x {/* #from-version-10x */}

Al actualizar a la versión 1.1.0:

1. **Cambio de ubicación de la documentación** - La documentación ahora se aloja en GitHub Pages en lugar de estar incluida en el contenedor Docker. El enlace de la Guía del usuario en la cabecera de la aplicación ahora apunta al sitio de documentación externo

2. **Configuración de contenedores Podman** - Si usa pods de Podman, asegúrese de que la configuración de DNS esté establecida a nivel de pod usando las banderas `--dns` y `--dns-search`. La aplicación funciona correctamente en ambos modos de pods de Podman y contenedores independientes

3. **Detección de copias de seguridad vencidas** - El sistema de detección de copias de seguridad vencidas se ha reimplementado completamente con un nuevo algoritmo que preserva la hora del día del horario. Las configuraciones existentes de monitoreo de copias de seguridad seguirán funcionando, pero es posible que observe fechas "Próxima ejecución" más precisas en la configuración de monitoreo de copias de seguridad. El nuevo algoritmo asegura que las copias de seguridad manuales no desplacen los tiempos de copia de seguridad programados

4. **No se requiere migración de la base de datos** - Esta versión no requiere cambios en el esquema de la base de datos
