# Versión 1.1.x {/* #version-11x */}

## Vista general {/* #overview */}

La versión 1.1.x es una versión menor que aborda problemas críticos con la detección de copias de seguridad vencidas, mejora la compatibilidad con contenedores Podman e introduce mejoras en la arquitectura de contenedores. Esta versión se centra en corregir la precisión de la detección de copias de seguridad vencidas y resolver problemas de red en entornos Podman.

## Nuevas características {/* #new-features */}

### Mejoras en la interfaz de usuario {/* #user-interface-enhancements */}

- **Menú contextual al hacer clic derecho en el botón de actualización automática** - Al hacer clic derecho en el botón de actualización automática en la barra de herramientas de la aplicación se abre la página de Configuración de visualización para un acceso rápido a las preferencias de visualización
- **Modal de recopilación de copias de seguridad mejorado** - La etiqueta del campo de contraseña ahora indica claramente "(solo rellenar si se cambió la contraseña)" cuando se selecciona un servidor, lo que hace más claro cuándo se necesita el campo

### Mejoras en la documentación {/* #documentation-improvements */}

- **Migración del alojamiento de la documentación** - La documentación se ha trasladado desde la imagen del contenedor Docker a GitHub Pages en https://wsj-br.github.io/duplistatus/user-guide/overview para mejorar la accesibilidad y facilitar las actualizaciones
- El enlace de la Guía de usuario en el encabezado de la aplicación ahora apunta al sitio externo de documentación

## 🐛 Correcciones de errores {/* #-bug-fixes */}

### Crítico: Detección de copias de seguridad vencidas - Reimplementación completa {/* #critical-overdue-backup-detection---complete-reimplementation */}

- **Corregida la detección de copias de seguridad vencidas** - Se ha reimplementado completamente el sistema de detección de copias de seguridad vencidas con un nuevo algoritmo que rastrea correctamente las fechas previstas de copia de seguridad:
  - El algoritmo garantiza que las copias de seguridad manuales no cambien los horarios programados de copia de seguridad (por ejemplo, una copia de seguridad manual a las 10pm no cambiará un horario de 2pm)
  - Se ha corregido la columna "Próxima ejecución" en la configuración de monitoreo de copias de seguridad que mostraba fechas incorrectas
  - La configuración de copias de seguridad ahora se actualiza inmediatamente después de recibir copias de seguridad mediante `/api/upload` o `/api/backups/collect`
  - Para nuevos servidores sin sincronización de Duplicati, utiliza la hora del día de la primera copia de seguridad como referencia del horario
  - Para más detalles, consulte la documentación del [Algoritmo de detección de vencimiento](https://github.com/wsj-br/duplistatus/blob/main/dev/OVERDUE_DETECTION_ALGORITHM.md)

### Correcciones en contenedores Podman {/* #podman-container-fixes */}

- **Corregida la red de pods Podman** - Se resolvió el problema que impedía el acceso externo a la aplicación cuando se ejecutaba en pods Podman. El servidor ahora se enlaza correctamente a todas las interfaces (`0.0.0.0:9666`) tanto en modo de pod Podman como en contenedores independientes
- **Corregida la resolución DNS para nombres de host Tailscale** - Se resolvieron problemas de resolución DNS en contenedores Podman que impedían conectarse a nombres de host Tailscale o servidores DNS personalizados. Se actualizó la documentación de instalación con instrucciones.

### Correcciones en la configuración de correo electrónico {/* #email-configuration-fixes */}

- **Corregido el manejo de nombre de usuario/contraseña SMTP vacíos** - Se resolvió el problema por el cual al borrar los campos de nombre de usuario o contraseña en la configuración de correo electrónico aún se almacenaban valores cifrados en la base de datos. Los campos vacíos ahora se almacenan correctamente como cadenas vacías y pueden borrarse correctamente

### Mejoras del sistema {/* #system-improvements */}

- **Reducción del registro en consola** - AuditLogger ahora solo registra intentos de inicio de sesión fallidos en la consola; todas las demás entradas de auditoría se escriben únicamente en la base de datos

## 🚀 Notas de migración {/* #-migration-notes */}

### Desde la versión 1.0.x {/* #from-version-10x */}

Al actualizar a la versión 1.1.0:

1. **Cambio de ubicación de la documentación** - La documentación ahora se aloja en GitHub Pages en lugar de estar incluida en el contenedor Docker. El enlace de la Guía de usuario en el encabezado de la aplicación ahora apunta al sitio externo de documentación

2. **Configuración del contenedor Podman** - Si utiliza pods Podman, asegúrese de que la configuración de DNS esté establecida a nivel de pod usando las banderas `--dns` y `--dns-search`. La aplicación ahora funciona correctamente tanto en pods Podman como en contenedores independientes

3. **Detección de copias de seguridad vencidas** - El sistema de detección de copias de seguridad vencidas ha sido completamente reimplementado con un nuevo algoritmo que preserva la hora del día programada. Las configuraciones existentes de monitoreo de copias de seguridad continuarán funcionando, pero podrías notar fechas de "Próxima ejecución" más precisas en la configuración de monitoreo de copias de seguridad. El nuevo algoritmo asegura que las copias de seguridad manuales no desplacen los horarios programados de copias de seguridad

4. **No se requiere migración de base de datos** - Esta versión no requiere ningún cambio en el esquema de la base de datos
