# Versión 0.7.x {/* #version-07x */}

## Vista general {/* #overview */}

La versión 0.7.x es una versión importante que introduce mejoras significativas en el esquema de la base de datos, la estructura de la API y la interfaz de usuario. Esta versión incluye cambios que rompen la compatibilidad que requieren actualizaciones en las integraciones externas.

## Cambios importantes {/* #breaking-changes */}

### Cambios en el esquema de base de datos {/* #database-schema-changes */}
- **Renombrado de tablas**: La tabla `machines` se ha renombrado a `servers`
- **Nuevos campos**: Se han añadido los campos `alias`, `notes`, `created_at` y `updated_at`
- **Cambios en las respuestas de la API**: Nombres de campo actualizados para mayor coherencia

### Cambios en la API incompatibles con versiones anteriores {/* #backward-incompatible-api-changes */}
- **Renombrado de campos**: `totalMachines` → `totalServers`
- **Renombrado de objetos**: `machine` → `server` en las respuestas de la API
- **Renombrado de campos**: `backup_types_count` → `backupJobsCount`

:::warning
**Las integraciones externas que utilizan la API deben actualizarse** para funcionar con la versión 0.7.x. Consulte la guía sobre [Cambios en la API incompatibles con versiones anteriores](../migration/api-changes) para obtener más detalles.
:::

## Guía de migración {/* #migration-guide */}

### Migración automática {/* #automatic-migration */}
La migración de 0.6.x a 0.7.x ocurre automáticamente:

1. **Creación de copia de seguridad**: Se crea una copia de seguridad automática de la base de datos
2. **Actualización de esquema**: El esquema de la base de datos se actualiza automáticamente
3. **Migración de datos**: Los datos existentes se conservan y migran
4. **Verificación**: La migración se verifica y registra

### Pasos manuales requeridos {/* #manual-steps-required */}
- **Actualizar integraciones externas**: Actualice cualquier herramienta externa que utilice la API
- **Probar funcionalidad**: Verifique que todas las funciones funcionen correctamente
- **Actualizar documentación**: Actualice cualquier documentación personalizada

## Cambios de configuración {/* #configuration-changes */}

### Nuevas opciones de configuración {/* #new-configuration-options */}

```yaml
# Server management
servers:
  defaultAlias: true
  showNotes: true
  sortBy: "name" # name, status, lastBackup

# API settings
api:
  version: "1.0"
  rateLimit: 100
  timeout: 30000

# Database settings
database:
  backupRetention: 7
  autoVacuum: true
  optimizeInterval: 24
```

### Opciones obsoletas {/* #deprecated-options */}
- Configuración `machines` (utilice `servers` en su lugar)
- Nombres de campo de API antiguos (utilice los nuevos nombres de campo)

    image: wsjbr/duplistatus:0.7.x

## Instrucciones de actualización {/* #upgrade-instructions */}

### Desde la versión 0.6.x {/* #from-version-06x */}
1. **Haga una copia de seguridad de sus datos** (copia de seguridad automática creada durante la actualización)
2. **Actualice la imagen de Docker**: `docker pull wsjbr/duplistatus:0.7.x`
3. **Reinicie el contenedor**: `docker-compose down && docker-compose up -d`
4. **Monitoree los registros**: `docker logs -f duplistatus`
5. **Actualice las integraciones**: Actualice cualquier herramienta externa que utilice la API
6. **Verifique la actualización**: Compruebe que todas las funciones funcionan correctamente

### Desde la versión 0.5.x o anterior {/* #from-version-05x-or-earlier */}
1. **Primero actualice a la versión 0.6.x** (si está disponible)
2. **Luego actualice a la versión 0.7.x** siguiendo los pasos anteriores

## Problemas conocidos {/* #known-issues */}

### Problemas de migración {/* #migration-issues */}
- **Bases de datos grandes**: La migración puede tardar más tiempo con bases de datos grandes
- **Espacio en disco**: Asegúrese de tener suficiente espacio en disco para la copia de seguridad de la migración
- **Permisos**: Compruebe los permisos de archivo para el acceso a la base de datos

### Compatibilidad de la API {/* #api-compatibility */}
- **Herramientas externas**: Las herramientas externas que utilizan la API necesitan actualizaciones
- **Nombres de campos**: Algunos nombres de campos han cambiado
- **Formato de respuesta**: Algunos formatos de respuesta han cambiado

### Soluciones alternativas {/* #workarounds */}
- **Migración**: Asegúrese de tener suficiente espacio en disco y tiempo para la migración
- **API**: Actualice las integraciones externas para usar el nuevo formato de API
- **Pruebas**: Pruebe toda la funcionalidad después de la actualización
