# Versión 0.7.x {/* #version-07x */}

## Vista general {/* #overview */}

Versión 0.7.x es una versión principal que introduce mejoras significativas al esquema de la base de datos, la estructura de la API y la interfaz de usuario. Esta versión incluye cambios incompatibles que requieren actualizaciones en las Integraciones externas.

## Cambios Importantes {/* #breaking-changes */}

### Cambios en el Esquema de la Base de Datos {/* #database-schema-changes */}
- **Renombrado de Tabla**: La tabla `machines` se renombró a `servers`
- **Nuevos Campos**: Se añadieron los campos `alias`, `notes`, `created_at` y `updated_at`
- **Cambios en la Respuesta de la API**: Nombres de campos actualizados para consistencia

### Cambios en la API incompatibles con versiones anteriores {/* #backward-incompatible-api-changes */}
- **Renombrado de Campo**: `totalMachines` → `totalServers`
- **Renombrado de Objeto**: `machine` → `server` en las respuestas de la API
- **Renombrado de Campo**: `backup_types_count` → `backupJobsCount`

:::warning
**Las integraciones externas que utilizan la API deben actualizarse** para funcionar con la versión 0.7.x. Consulte la guía [Cambios de API incompatibles con versiones anteriores](../migration/api-changes) para obtener más detalles.
:::

## Guía de Migración {/* #migration-guide */}

### Migración Automática {/* #automatic-migration */}
La migración de 0.6.x a 0.7.x ocurre automáticamente:

1. **Creación de Backup**: Se crea automáticamente un backup de base de datos
2. **Actualización de Schema**: El esquema de la base de datos se actualiza automáticamente
3. **Migración de Datos**: Los datos existentes se preservan y se migran
4. **Verificación**: La migración se verifica y se registra

### Pasos Manuales Requeridos {/* #manual-steps-required */}
- **Actualizar Integraciones Externas**: Actualizar cualquier herramienta externa que use la API
- **Probar Funcionalidad**: Verificar que todas las funciones funcionen correctamente
- **Actualizar Documentación**: Actualizar cualquier documentación personalizada

## Cambios en la Configuración {/* #configuration-changes */}

### Nuevas opciones de configuración {/* #new-configuration-options */}

```yaml
# Server management
servers:
  defaultAlias: true
  showNotes: true
  sortBy: "name" # name, status, lastBackup

# API settings
api:
  version: "1.0"
  rateLimit: 100
  timeout: 30000

# Database settings
database:
  backupRetention: 7
  autoVacuum: true
  optimizeInterval: 24
```

### Opciones obsoletas {/* #deprecated-options */}
- `machines` configuración (usa `servers` en su lugar)
- Nombres de campos de API antiguos (usa nuevos nombres de campos)

## Instrucciones de actualización {/* #upgrade-instructions */}

### Desde la versión 0.6.x {/* #from-version-06x */}
1. **Copia de seguridad de tus datos** (copia de seguridad automática creada durante la actualización)
2. **Actualizar imagen de Docker**: `docker pull wsjbr/duplistatus:0.7.x`
3. **Reiniciar contenedor**: `docker-compose down && docker-compose up -d`
4. **Monitor logs**: `docker logs -f duplistatus`
5. **Actualizar integraciones**: Actualiza cualquier herramienta externa que use la API
6. **Verificar actualización**: Verifica que todas las funciones funcionen correctamente

### Desde la versión 0.5.x o anterior {/* #from-version-05x-or-earlier */}
1. **Primero actualiza a 0.6.x** (si está disponible)
2. **Luego actualiza a 0.7.x** usando los pasos anteriores

## Problemas conocidos {/* #known-issues */}

### Problemas de migración {/* #migration-issues */}
- **Bases de datos grandes**: La migración puede tardar más para bases de datos grandes
- **Espacio en disco**: Asegúrate de tener suficiente espacio en disco para la copia de seguridad de migración
- **Permisos**: Comprobar permisos de archivo para acceso a la base de datos

### Compatibilidad de API {/* #api-compatibility */}
- **Herramientas externas**: Las herramientas externas que utilizan la API necesitan actualizaciones
- **Nombres de campos**: Algunos nombres de campos han cambiado
- **Formato de respuesta**: Algunos formatos de respuesta han cambiado

### Soluciones alternativas {/* #workarounds */}
- **Migración**: Asegúrate de tener suficiente espacio en disco y tiempo para la migración
- **API**: Actualiza integraciones externas para usar el nuevo formato de API
- **Pruebas**: Probar toda la funcionalidad después de la actualización
