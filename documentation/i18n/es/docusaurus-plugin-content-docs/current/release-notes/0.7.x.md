# Versión 0.7.x {/* #version-07x */}

## Vista general {/* #overview */}

La versión 0.7.x es una versión importante que introduce mejoras significativas en el esquema de la base de datos, la estructura de la API y la interfaz de usuario. Esta versión incluye cambios importantes que requieren actualizaciones en las integraciones externas.

## Cambios importantes {/* #breaking-changes */}

### Cambios en el esquema de la base de datos {/* #database-schema-changes */}
- **Renombrado de tablas**: tabla `machines` renombrada a `servers`
- **Nuevos campos**: Añadidos los campos `alias`, `notes`, `created_at` y `updated_at`
- **Cambios en las respuestas de la API**: Actualizados los nombres de los campos para mayor consistencia

### Cambios incompatibles con versiones anteriores en la API {/* #backward-incompatible-api-changes */}
- **Renombrado de campos**: `totalMachines` → `totalServers`
- **Renombrado de objetos**: `machine` → `server` en las respuestas de la API
- **Renombrado de campos**: `backup_types_count` → `backupJobsCount`

:::warning
**Las integraciones externas que utilicen la API deben actualizarse** para funcionar con la versión 0.7.x. Consulte la guía [Cambios incompatibles con versiones anteriores en la API](../migration/api-changes) para obtener más detalles.
:::

## Guía de migración {/* #migration-guide */}

### Migración automática {/* #automatic-migration */}
La migración de 0.6.x a 0.7.x ocurre automáticamente:

1. **Creación de copia de seguridad**: Se crea automáticamente una copia de seguridad de la base de datos
2. **Actualización de esquema**: El esquema de la base de datos se actualiza automáticamente
3. **Migración de datos**: Los datos existentes se conservan y migran
4. **Verificación**: La migración se verifica y registra

### Pasos manuales requeridos {/* #manual-steps-required */}
- **Actualizar integraciones externas**: Actualizar cualquier herramienta externa que utilice la API
- **Probar funcionalidad**: Verificar que todas las funciones funcionan correctamente
- **Actualizar documentación**: Actualizar cualquier documentación personalizada

## Cambios de configuración {/* #configuration-changes */}

### Nuevas opciones de configuración {/* #new-configuration-options */}

```yaml
# Server management
servers:
  defaultAlias: true
  showNotes: true
  sortBy: "name" # name, status, lastBackup

# API settings
api:
  version: "1.0"
  rateLimit: 100
  timeout: 30000

# Database settings
database:
  backupRetention: 7
  autoVacuum: true
  optimizeInterval: 24
```

### Opciones obsoletas {/* #deprecated-options */}
- Configuración `machines` (use `servers` en su lugar)
- Nombres de campos de API antiguos (use los nuevos nombres de campos)

## Instalación {/* #installation */}

### Docker Compose {/* #docker-compose */}

```yaml
services:
  duplistatus:
    image: wsjbr/duplistatus:0.7.x
    container_name: duplistatus
    restart: unless-stopped
    ports:
      - "9666:9666"
    volumes:
      - duplistatus_data:/app/data
    environment:
      - TZ=UTC
```

### CLI de Docker {/* #docker-cli */}

```bash
docker run -d \
  --name duplistatus \
  --restart unless-stopped \
  -p 9666:9666 \
  -v duplistatus_data:/app/data \
  wsjbr/duplistatus:0.7.x
```

## Instrucciones de actualización {/* #upgrade-instructions */}

### Desde la versión 0.6.x {/* #from-version-06x */}
1. **Realizar copia de seguridad de sus datos** (se crea una copia de seguridad automática durante la actualización)
2. **Actualizar la imagen de Docker**: `docker pull wsjbr/duplistatus:0.7.x`
3. **Reiniciar el contenedor**: `docker-compose down && docker-compose up -d`
4. **Monitorear los registros**: `docker logs -f duplistatus`
5. **Actualizar integraciones**: Actualizar cualquier herramienta externa que utilice la API
6. **Verificar la actualización**: Comprobar que todas las funciones funcionan correctamente

### Desde la versión 0.5.x o anterior {/* #from-version-05x-or-earlier */}
1. **Primero actualizar a 0.6.x** (si está disponible)
2. **Luego actualizar a 0.7.x** utilizando los pasos anteriores

## Problemas conocidos {/* #known-issues */}

### Problemas de migración {/* #migration-issues */}
- **Bases de datos grandes**: La migración puede tardar más en bases de datos grandes
- **Espacio en disco**: Asegúrese de tener suficiente espacio en disco para la copia de seguridad de migración
- **Permisos**: Compruebe los permisos de archivo para el acceso a la base de datos

### Compatibilidad de API {/* #api-compatibility */}
- **Herramientas externas**: Las herramientas externas que utilizan la API necesitan actualizaciones
- **Nombres de campos**: Algunos nombres de campos han cambiado
- **Formato de respuesta**: Algunos formatos de respuesta han cambiado

### Soluciones alternativas {/* #workarounds */}
- **Migración**: Asegúrese de tener suficiente espacio en disco y tiempo para la migración
- **API**: Actualice las integraciones externas para utilizar el nuevo formato de API
- **Pruebas**: Pruebe todas las funcionalidades después de la actualización
