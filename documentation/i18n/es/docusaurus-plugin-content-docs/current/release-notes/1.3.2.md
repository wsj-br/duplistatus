# Versión 1.3.2 {/* #version-132 */}

## Vista general {/* #overview */}

La versión 1.3.2 es una versión de mantenimiento que aborda vulnerabilidades de seguridad en dependencias, soluciona advertencias de instalación de pnpm (webpack de pares y subdependencias obsoletas), resuelve advertencias de lint y construcción en la aplicación y la documentación, y actualiza la documentación para reflejar los nombres actuales de los scripts de Docker y las versiones de los paquetes.

## Seguridad {/* #security */}

### Corrección de vulnerabilidades en dependencias {/* #dependency-vulnerability-fixes */}

- **Actualizaciones de dependencias de Dependabot (documentación)**: Se fusionaron dos PR de Dependabot para abordar vulnerabilidades en el espacio de trabajo de la documentación:
  - **ajv** en `/documentation`: actualizado de 8.17.1 a 8.18.0 y de 6.12.6 a 6.14.0.
  - **fast-xml-parser** en `/documentation`: actualizado de 5.3.5 a 5.3.8.
  Ambos fueron fusionados mediante la actualización múltiple de dependabot para /documentation.

- **Sobrescrituras de pnpm para vulnerabilidades de alta gravedad**: Se agregaron sobrescrituras de pnpm para corregir cuatro problemas de alta gravedad:
  - **minimatch** (>=3.1.4): Corrige GHSA-3ppc-4f35-3m26 (ReDoS a través de comodines repetidos), GHSA-7r86-cg39-jmmj (retroceso combinatorio) y GHSA-23c5-xmqv-rm74 (retroceso de extglobs anidados) en documentation > @docusaurus/core > serve-handler > minimatch.
  - **serialize-javascript** (>=7.0.3): Corrige GHSA-5c6j-r48x-rmvq (RCE a través de RegExp.flags y Date.prototype.toISOString()) en webpack > terser-webpack-plugin > serialize-javascript.

## Corrección de errores {/* #bug-fixes */}

- **Advertencias de instalación de pnpm**: Se resolvieron tres advertencias de instalación: (1) `webpack@5.104.1` de pares no cumplidos de `next-intlayer` > `@intlayer/webpack` (el proyecto tiene webpack 5.105.3) agregando `pnpm.peerDependencyRules.allowedVersions.webpack: "5"` en la raíz `package.json`. (2) Subdependencias obsoletas `prebuild-install@7.1.3` (de better-sqlite3) y `whatwg-encoding@3.1.1` (de documentation > docusaurus-search-local > cheerio) agregando `pnpm.allowedDeprecatedVersions` para ambas para que la instalación se ejecute sin advertencias.
- **Visor de registros de aplicación (exhaustive-deps)**: Se resolvió la advertencia react-hooks/exhaustive-deps para el efecto de desplazamiento automático. `logData` se omite intencionalmente del array de dependencias para que el desplazamiento solo ocurra cuando el desplazamiento automático o el archivo seleccionado cambien, no en cada encuesta; el desplazamiento de nueva línea se maneja en `loadLogs`. Se agregó una línea de deshabilitación de eslint con un comentario corto.
- **Advertencia de construcción vscode-languageserver-types (documentación)**: Se suprimió la advertencia de Webpack "Dependencia crítica: la función require se usa de una manera en la que no se pueden extraer estáticamente las dependencias" para la dependencia transitiva `vscode-languageserver-types` (de intlayer-editor) en la construcción de la documentación (Docusaurus) mediante un plugin en línea en `documentation/docusaurus.config.ts` que agrega `ignoreWarnings`. La advertencia ocurre solo durante la construcción de los documentos, no de la aplicación principal.

Actualizado en AGENTS.md, documentation/docs/development/setup.md, documentation/docs/development/development-guidelines.md y .cursor/rules/project-rule.mdc.

## Notas de migración {/* #migration-notes */}

### Desde la versión 1.3.1 {/* #from-version-131 */}

Al actualizar a la versión 1.3.2:

1. **No se requiere migración de la base de datos**: Esta versión no requiere cambios en el esquema de la base de datos.
2. **Comandos de Docker**: Si usa los scripts de pnpm documentados, use `pnpm docker:up`, `pnpm docker:down`, `pnpm docker:clean` y `pnpm docker:devel` en lugar de los anteriores `docker-up`, `docker-down`, etc.
3. **Dependencias**: Ejecute `pnpm install` para aplicar el archivo de bloqueo y las sobrescrituras actualizados; no se requieren cambios manuales de dependencias para instalaciones típicas.

## Registro de cambios {/* #changelog */}

### Cambios en la versión 1.3.2 {/* #version-132-changes */}

- **Arreglado**: Advertencias de pnpm install — peer webpack (allowedVersions) y subdependencias obsoletas (prebuild-install, whatwg-encoding) mediante allowedDeprecatedVersions en root package.json.
