# क्रॉन सेवा प्रबंधन {/* #cron-service-management */}

## क्रॉन कॉन्फ़िगरेशन प्राप्त करें - `/api/cron-config` {/* #get-cron-configuration---apicron-config */}
- **एंडपॉइंट**: `/api/cron-config`
- **मेथड**: GET
- **विवरण**: वर्तमान क्रॉन सेवा कॉन्फ़िगरेशन पुनर्प्राप्त करता है।
- **प्रमाणीकरण**: मान्य सत्र और CSRF टोकन की आवश्यकता है
- **प्रतिक्रिया**:

  ```json
  {
    "cronExpression": "*/20 * * * *",
    "enabled": true
  }
  ```

- **त्रुटि प्रतिक्रियाएं**:
  - `500`: क्रॉन कॉन्फ़िगरेशन प्राप्त करने में विफल
- **नोट्स**:
  - वर्तमान क्रॉन सेवा कॉन्फ़िगरेशन लौटाता है
  - इसमें क्रॉन एक्सप्रेशन और सक्षम स्थिति शामिल है
  - क्रॉन सेवा प्रबंधन के लिए उपयोग किया जाता है

## क्रॉन कॉन्फ़िगरेशन अपडेट करें - `/api/cron-config` {/* #update-cron-configuration---apicron-config */}
- **एंडपॉइंट**: `/api/cron-config`
- **मेथड**: POST
- **विवरण**: क्रॉन सेवा कॉन्फ़िगरेशन को अपडेट करता है।
- **प्रमाणीकरण**: मान्य सत्र और CSRF टोकन की आवश्यकता होती है
- **अनुरोध बॉडी**:

  ```json
  {
    "interval": "20min"
  }
  ```

- **प्रतिक्रिया**:

  ```json
  {
    "success": true
  }
  ```

- **उपलब्ध अंतराल**: `"disabled"`, `"1min"`, `"5min"`, `"10min"`, `"15min"`, `"20min"`, `"30min"`, `"1hour"`, `"2hours"`
- **त्रुटि प्रतिक्रियाएं**:
  - `400`: अंतराल आवश्यक है
  - `500`: क्रॉन कॉन्फ़िगरेशन अपडेट करने में विफल
- **नोट्स**:
  - क्रॉन सेवा कॉन्फ़िगरेशन अपडेट करता है
  - अनुमत विकल्पों के विरुद्ध अंतराल को सत्यापित करता है
  - अतिदेय बैकअप जांचें आवृत्ति को प्रभावित करता है

## क्रॉन सर्विस प्रॉक्सी - `/api/cron/*` {/* #cron-service-proxy---apicron */}
- **एंडपॉइंट**: `/api/cron/*`
- **मेथड**: GET, POST
- **विवरण**: क्रॉन सेवा के लिए अनुरोधों को प्रॉक्सी करता है। यह एंडपॉइंट एक अलग पोर्ट पर चालू क्रॉन सेवा को सभी अनुरोध अग्रेषित करता है।
- **प्रमाणीकरण**: मान्य सत्र और CSRF टोकन आवश्यक है। प्रमाणित उपयोगकर्ता के लिए GET की अनुमति है; POST (start/stop/trigger/reload) के लिए एक व्यवस्थापक आवश्यक है।
- **पैरामीटर**:
  - `*`: कोई भी पथ जिसे क्रॉन सेवा पर अग्रेषित किया जाएगा
- **प्रतिक्रिया**: एक्सेस किए जा रहे क्रॉन सेवा एंडपॉइंट पर निर्भर करता है
- **त्रुटि Response** (503):

  ```json
  {
    "error": "Cron service is not running",
    "message": "The cron service is not available. Please start it with: npm run cron:start"
  }
  ```

- **नोट्स**:
  - `127.0.0.1` पर क्रॉन सेवा को अनुरोध प्रॉक्सी करता है
  - सेट होने पर `CRON_SERVICE_SECRET` को `X-Cron-Service-Secret` के रूप में अग्रेषित करता है
  - यदि क्रॉन सेवा उपलब्ध नहीं है तो 503 लौटाता है
  - GET और POST दोनों मेथड का समर्थन करता है
  - वेब इंटरफ़ेस से क्रॉन सेवा प्रबंधन के लिए उपयोग किया जाता है
  - `POST /trigger/daily-summary-dispatch` को क्रॉन सेवा द्वारा अस्वीकार कर दिया जाता है; इसके बजाय `/api/configuration/daily-summary/send` का उपयोग करें
  - `POST /trigger/database-compact` साप्ताहिक कॉम्पैक्ट को तुरंत चलाता है (अनाथ बैकअप/सर्वर और अधिसूचना सेटिंग्स, साथ ही SQLite `VACUUM`)
