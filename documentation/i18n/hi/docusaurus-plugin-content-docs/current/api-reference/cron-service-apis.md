# क्रॉन सेवा प्रबंधन {#cron-service-management}

## क्रॉन कॉन्फ़िगरेशन प्राप्त करें - `/api/cron-config` {#get-cron-configuration---apicron-config}
- **एंडपॉइंट**: `/api/cron-config`
- **विधि**: GET
- **विवरण**: वर्तमान क्रॉन सेवा कॉन्फ़िगरेशन प्राप्त करता है।
- **Authentication**: वैध सत्र और CSRF टोकन की आवश्यकता होती है
- **Response**:

  ```json
  {
    "cronExpression": "*/20 * * * *",
    "enabled": true
  }
  ```

- **त्रुटि प्रतिक्रियाएँ**:
  - `500`: क्रॉन कॉन्फ़िगरेशन प्राप्त करने में असफल
- **टिप्पणियाँ**:
  - वर्तमान क्रॉन सेवा कॉन्फ़िगरेशन लौटाता है
  - क्रॉन अभिव्यक्ति और सक्रिय स्थिति शामिल होती है
  - क्रॉन सेवा प्रबंधन के लिए उपयोग किया जाता है

## क्रॉन कॉन्फ़िगरेशन अपडेट करें - `/api/cron-config` {#update-cron-configuration---apicron-config}
- **एंडपॉइंट**: `/api/cron-config`
- **विधि**: POST
- **विवरण**: क्रॉन सेवा कॉन्फ़िगरेशन अपडेट करता है।
- **Authentication**: मान्य सत्र और CSRF टोकन की आवश्यकता होती है
- **Request Body**:

  ```json
  {
    "interval": "20min"
  }
  ```

- **Response**:

  ```json
  {
    "success": true
  }
  ```

- **उपलब्ध अंतराल**: `"disabled"`, `"1min"`, `"5min"`, `"10min"`, `"15min"`, `"20min"`, `"30min"`, `"1hour"`, `"2hours"`
- **त्रुटि प्रतिक्रियाएँ**:
  - `400`: अंतराल आवश्यक है
  - `500`: क्रॉन कॉन्फ़िगरेशन अपडेट करने में असफल
- **टिप्पणियाँ**:
  - क्रॉन सेवा कॉन्फ़िगरेशन अपडेट करता है
  - अनुमत विकल्पों के खिलाफ अंतराल की पुष्टि करता है
  - विलंबित बैकअप जाँच की आवृत्ति को प्रभावित करता है

## क्रॉन सेवा प्रॉक्सी - `/api/cron/*` {#cron-service-proxy---apicron}
- **एंडपॉइंट**: `/api/cron/*`
- **विधि**: GET, POST
- **विवरण**: क्रॉन सेवा को अनुरोध प्रॉक्सी करता है। यह एंडपॉइंट सभी अनुरोधों को एक अलग पोर्ट पर चल रहे क्रॉन सेवा को फॉरवर्ड करता है।
- **प्रमाणीकरण**: मान्य सत्र और CSRF टोकन की आवश्यकता होती है। प्रमाणित उपयोगकर्ताओं के लिए GET की अनुमति है; POST (प्रारंभ/रोक/ट्रिगर/पुनः लोड) के लिए व्यवस्थापक की आवश्यकता होती है।
- **पैरामीटर**:
  - `*`: कोई भी पथ जो क्रॉन सेवा को आगे भेजा जाएगा
- **प्रतिक्रिया**: क्रॉन सेवा एंडपॉइंट पर पहुंचने के आधार पर निर्भर करती है
- **त्रुटि प्रतिक्रिया** (503):

  ```json
  {
    "error": "Cron service is not running",
    "message": "The cron service is not available. Please start it with: npm run cron:start"
  }
  ```

- **नोट्स**:
  - `127.0.0.1` पर क्रॉन सेवा को अनुरोध प्रॉक्सी करता है
  - `CRON_SERVICE_SECRET` को `X-Cron-Service-Secret` के रूप में आगे भेजता है जब सेट किया जाता है
  - 503 लौटाता है यदि क्रॉन सेवा उपलब्ध नहीं है
  - दोनों GET और POST विधियों का समर्थन करता है
  - वेब इंटरफ़ेस से क्रॉन सेवा प्रबंधन के लिए उपयोग किया जाता है
  - `POST /trigger/daily-summary-dispatch` को क्रॉन सेवा द्वारा अस्वीकार किया जाता है; इसके बजाय `/api/configuration/daily-summary/send` का उपयोग करें
