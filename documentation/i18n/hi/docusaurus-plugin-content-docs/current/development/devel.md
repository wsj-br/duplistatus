# सबसे अधिक उपयोग किए जाने वाले कमांड {/* #most-used-commands */}

## dev मोड में चलाएं {/* #run-in-dev-mode */}

```bash
pnpm dev
```

यह Next.js ऐप (पोर्ट 8666) और क्रॉन सर्विस (पोर्ट 8667) दोनों को शुरू करता है। CTRL-C दोनों को रोकता है। किसी भी प्रोसेस को अकेले चलाने के लिए `pnpm dev:next` या `pnpm cron:dev` का उपयोग करें।

- **JSON फ़ाइल संग्रहण**: प्राप्त सभी बैकअप डेटा को `data` डायरेक्टरी में JSON फ़ाइलों के रूप में संग्रहीत किया जाता है। ये फ़ाइलें उनके प्राप्त होने के समय के टाइमस्टैम्प का उपयोग करके `YYYY-MM-DDTHH-mm-ss-sssZ.json` (UTC समय) प्रारूप में नामित की जाती हैं। यह सुविधा केवल डेवलपमेंट मोड में सक्रिय होती है और Duplicati से प्राप्त रॉ डेटा को सुरक्षित रखकर डीबगिंग में मदद करती है।

- **विस्तृत लॉगिंग**: डेवलपमेंट मोड में चलने पर एप्लिकेशन डेटाबेस संचालन और API अनुरोधों के बारे में अधिक विस्तृत जानकारी लॉग करता है।

- **संस्करण अपडेट**: डेवलपमेंट सर्वर शुरू होने से पहले संस्करण की जानकारी को स्वचालित रूप से अपडेट करता है, जिससे यह सुनिश्चित होता है कि एप्लिकेशन में नवीनतम संस्करण प्रदर्शित हो।

- **बैकअप हटाना**: चालू सर्वर विवरण पृष्ठ पर, बैकअप तालिका में एक हटाएं बटन दिखाई देता है जो आपको अलग-अलग बैकअप हटाने की अनुमति देता है। यह सुविधा बकाया बैकअप कार्यक्षमता के परीक्षण और डीबगिंग के लिए विशेष रूप से उपयोगी है।

## प्रोडक्शन सर्वर शुरू करें (डेवलपमेंट परिवेश में) {/* #start-the-production-server-in-development-environment */}

पहले, स्थानीय प्रोडक्शन के लिए एप्लिकेशन बनाएं:

```bash
pnpm build-local
```

फिर प्रोडक्शन सर्वर शुरू करें:

```bash
pnpm start-local
```

## Docker स्टैक शुरू करें (Docker Compose) {/* #start-a-docker-stack-docker-compose */}

```bash
pnpm docker:up
```

या मैन्युअल रूप से:

```bash
docker compose up --build -d
```

## Docker स्टैक रोकें (Docker Compose) {/* #stop-a-docker-stack-docker-compose */}

```bash
pnpm docker:down
```

या मैन्युअल रूप से:

```bash
docker compose down
```

## Docker परिवेश साफ़ करें {/* #clean-docker-environment */}

```bash
pnpm docker:clean
```

या मैन्युअल रूप से:

```bash
./scripts/clean-docker.sh
```

यह स्क्रिप्ट संपूर्ण Docker क्लीनअप करती है, जो निम्नलिखित के लिए उपयोगी है:
- डिस्क स्पेस खाली करना
- पुराने/अप्रयुक्त Docker आर्टिफ़ैक्ट हटाना
- डेवलपमेंट या टेस्टिंग सत्रों के बाद सफ़ाई करना
- एक स्वच्छ Docker परिवेश बनाए रखना

## डेवलपमेंट इमेज बनाएं (स्थानीय रूप से या Podman के साथ जाँचें) {/* #create-a-development-image-to-test-locally-or-with-podman */}

```bash
export $(grep -v '^#' .env | xargs) && docker build . -t wsj-br/duplistatus:devel-$VERSION
```
