# सर्वाधिक उपयोग किए जाने वाले कमांड {#most-used-commands}

## डेवलपमेंट मोड में चलाएँ {#run-in-dev-mode}

```bash
pnpm dev
```

यह Next.js ऐप (पोर्ट 8666) और क्रॉन सेवा (पोर्ट 8667) दोनों को शुरू करता है। CTRL-C दोनों को रोकता है। केवल एक प्रक्रिया चलाने के लिए `pnpm dev:next` या `pnpm cron:dev` का उपयोग करें।

- **JSON फ़ाइल संचयन**: सभी प्राप्त बैकअप डेटा को `data` निर्देशिका में JSON फ़ाइलों के रूप में संग्रहीत किया जाता है। ये फ़ाइलें उन बैकअप के समय के टाइमस्टैम्प का उपयोग करके नामित की जाती हैं, प्रारूप `YYYY-MM-DDTHH-mm-ss-sssZ.json` (UTC समय)। यह सुविधा केवल डेवलपमेंट मोड में सक्रिय है और डुप्लिकेटी से प्राप्त कच्चे डेटा को संरक्षित करने में मदद करती है।

- **वर्बोज़ लॉगिंग**: एप्लिकेशन डेवलपमेंट मोड में चलाते समय डेटाबेस ऑपरेशन और API अनुरोधों के बारे में अधिक विस्तृत जानकारी लॉग करता है।

- **संस्करण अपडेट**: डेवलपमेंट सर्वर स्टार्ट करने से पहले स्वचालित रूप से संस्करण जानकारी अपडेट करता है, यह सुनिश्चित करते हुए कि नवीनतम संस्करण एप्लिकेशन में प्रदर्शित किया जाता है।

- **बैकअप डिलीट**: सर्वर विवरण पृष्ठ पर, बैकअप तालिका में एक डिलीट बटन दिखाई देता है जो आपको व्यक्तिगत बैकअप को डिलीट करने की अनुमति देता है। यह सुविधा परीक्षण और डीबगिंग के लिए विशेष रूप से उपयोगी है।

## प्रोडक्शन सर्वर स्टार्ट करें (डेवलपमेंट पर्यावरण में) {#start-the-production-server-in-development-environment}

पहले, स्थानीय प्रोडक्शन के लिए एप्लिकेशन बिल्ड करें:

```bash
pnpm build-local
```

फिर प्रोडक्शन सर्वर स्टार्ट करें:

```bash
pnpm start-local
```

## एक डॉकर स्टैक स्टार्ट करें (डॉकर कॉम्पोज) {#start-a-docker-stack-docker-compose}

```bash
pnpm docker:up
```

या मैन्युअल रूप से:

```bash
docker compose up --build -d
```

## एक डॉकर स्टैक स्टॉप करें (डॉकर कॉम्पोज) {#stop-a-docker-stack-docker-compose}

```bash
pnpm docker:down
```

या मैन्युअल रूप से:

```bash
docker compose down
```

## डॉकर पर्यावरण साफ करें {#clean-docker-environment}

```bash
pnpm docker:clean
```

या मैन्युअल रूप से:

```bash
./scripts/clean-docker.sh
```

यह स्क्रिप्ट एक पूर्ण डॉकर साफ़-अप करता है, जो निम्नलिखित के लिए उपयोगी है:
- डिस्क स्पेस मुक्त करना
- पुराने/अनुपयोगित डॉकर आर्टिफैक्ट्स को हटाना
- डेवलपमेंट या परीक्षण सत्रों के बाद साफ़-अप करना
- एक साफ डॉकर पर्यावरण बनाए रखना

## एक डेवलपमेंट इमेज बनाएँ (स्थानीय परीक्षण या पॉडमैन के साथ) {#create-a-development-image-to-test-locally-or-with-podman}

```bash
export $(grep -v '^#' .env | xargs) && docker build . -t wsj-br/duplistatus:devel-$VERSION
```
