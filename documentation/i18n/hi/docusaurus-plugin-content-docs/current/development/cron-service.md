# क्रॉन सेवा {/* #cron-service */}

ऐप्लिकेशन में अनुसूचित कार्यों को संभालने के लिए एक अलग क्रॉन सेवा शामिल है:

## डेवलपमेंट मोड में cron सेवा शुरू करें {/* #start-cron-service-in-development-mode */}

`pnpm dev` पहले से ही Next.js के साथ क्रोन सेवा शुरू करता है। क्रोन को अकेले चलाने के लिए (उदाहरण के लिए, एक दूसरे टर्मिनल में):

```bash
pnpm cron:dev
```

## प्रोडक्शन मोड में cron सेवा शुरू करें {/* #start-cron-service-in-production-mode */}

```bash
pnpm cron:start
```

## स्थानीय रूप से cron सेवा शुरू करें (परीक्षण के लिए) {/* #start-cron-service-locally-for-testing */}

```bash
pnpm cron:start-local
```

क्रॉन सेवा एक अलग पोर्ट पर चलती है (विकास में 8667, उत्पादन में 9667) और अनुसूचित कार्य जैसे विलंबित बैकअप सूचनाएं संभालती है। पोर्ट को `CRON_PORT` पर्यावरण चर का उपयोग करके कॉन्फ़िगर किया जा सकता है।

क्रॉन सेवा में शामिल है:
- **स्वास्थ्य जाँच एंडपॉइंट**: `/health` - सेवा स्थिति और सक्रिय कार्य लौटाता है
- **मैनुअल कार्य ट्रिगरिंग**: `POST /trigger/:taskName` - अनुसूचित कार्य मैन्युअल रूप से चलाएं। `daily-summary-dispatch` इस रूट पर कार्य अस्वीकृत होता है; इसके बजाय Sammmaan → दैनिक सारांश **अब सारांश भेजें** का उपयोग करें
- **कार्य प्रबंधन**: `POST /start/:taskName` और `POST /stop/:taskName` - व्यक्तिगत कार्यों को नियंत्रित करें
- **कॉन्फ़िगरेशन रीलोड**: `POST /reload-config` - डेटाबेस से कॉन्फ़िगरेशन पुनः लोड करें
- **स्वचालित पुनरारंभ**: सेवा क्रैश होने पर स्वचालित रूप से पुनरारंभ होती है (डॉकर डिप्लॉयमेंट में `docker-entrypoint.sh` द्वारा प्रबंधित)
- **वॉच मोड**: विकास मोड में कोड परिवर्तनों पर स्वचालित पुनरारंभ के लिए फ़ाइल वॉचिंग शामिल है
- **विलंबित बैकअप मॉनिटरिंग**: विलंबित बैकअप की स्वचालित जांच और सूचना (डिफ़ॉल्ट रूप से हर 5 मिनट में चलती है)
- **दैनिक सारांश प्रेषण**: दैनिक सारांश UTC समय पर वर्तमान स्थिति का स्नैपशॉट एक बार भेजता है (`minute hour * * *`). नए इंस्टॉल के लिए डिफ़ॉल्ट 01:00 UTC है. भेजने का समय बदलने से यह अनुसूची पुनः लोड होती है. कार्य तब भेजता है जब दैनिक सारांश सक्रिय है और घड़ी की पुनः जाँच नहीं करता.
- **ऑडिट लॉग साफ़ करना**: पुराने ऑडिट लॉग प्रविष्टियों का स्वचालित साफ़ करना (दैनिक 2 AM UTC पर चलता है)
- **डेटाबेस कम्पैक्ट**: हफ्ते के रविवार 04:00 UTC. सर्वर के लिए बैकअप पंक्तियाँ जो अब मौजूद नहीं हैं, सर्वर पंक्तियाँ जिनके कोई बैकअप नहीं हैं, बाकी `backup_settings` और `overdue_notifications` कुंजियाँ, पुराने दैनिक सारांश वितरण पंक्तियाँ, और SQLite `VACUUM` चलाता है
- **डुप्लिकेटी संस्करण रिफ्रेश**: GitHub रिलीज़ से डुप्लिकेटी चैनल के नवीनतम संस्करणों को कैश अपडेट करता है. डिफ़ॉल्ट दैनिक 3 AM UTC है; व्यवस्थापक [सेटिंग्स → डुप्लिकेटी संस्करण](../user-guide/settings/duplicati-versions.md) में अंतराल और प्रारंभ समय बदल सकते हैं.
- **लचीला अनुसूचीकरण**: विभिन्न कार्यों के लिए कॉन्फ़िगर करने योग्य क्रॉन अभिव्यक्तियाँ
- **डेटाबेस एकीकरण**: मुख्य एप्लिकेशन के साथ एक ही SQLite डेटाबेस का उपयोग करता है
- **RESTful API**: सेवा प्रबंधन और निगरानी के लिए पूर्ण API
- **स्थानीय बाइंड**: डिफ़ॉल्ट रूप से `127.0.0.1` पर सुनता है (`CRON_BIND_HOST`). लूपबैक बाइंड के लिए `CRON_SERVICE_SECRET` की आवश्यकता होती है
