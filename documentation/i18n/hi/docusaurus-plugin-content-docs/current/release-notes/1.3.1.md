# संस्करण 1.3.1 {#version-131}

## Overview {#overview}

संस्करण 1.3.1 एप्लिकेशन इंटरफेस के लिए पूर्ण बहुभाषा समर्थन, अतिरिक्त एंडपॉइंट्स पर आवश्यक प्रमाणीकरण के साथ एपीआई सुरक्षा को मजबूत करता है, और मास्टर कुंजी पता लगाने, लोकेल स्वरूपण, और सूचना सेटिंग्स से संबंधित कई बग फिक्स करता है। यह रिलीज़ अंतर्राष्ट्रीयकरण सुधारों और सुरक्षा मजबूत करने पर ध्यान केंद्रित करता है।

## New Features {#new-features}

### बहुभाषा इंटरफेस समर्थन {#multi-language-interface-support}

- **ऐप हेडर में भाषा चयनकर्ता**: उपयोगकर्ता मेनू में ड्रॉपडाउन से अपनी पसंदीदा इंटरफेस भाषा चुनें। समर्थित भाषाएँ: अंग्रेजी, जर्मन, फ्रेंच, स्पैनिश, और पुर्तगाली (BR)। आपका चयन सहेजा जाता है और सत्रों के बीच बना रहता है।
- **लोकेल-अवेयर नेविगेशन**: सभी पृष्ठ और लिंक अब लोकेल-प्रिफिक्स यूआरएल का समर्थन करते हैं, जिससे आपकी चयनित भाषा में सुसंगत नेविगेशन हो।

### सूचना टेम्प्लेट अंतर्राष्ट्रीयकरण {#notification-templates-internationalization}

- **टेम्प्लेट भाषा चयनकर्ता**: सूचना टेम्प्लेट अब एक विशेष भाषा चयनकर्ता के साथ कई भाषाओं का समर्थन करते हैं। सभी 5 समर्थित भाषाओं के लिए पूर्व-अनुवादित डिफ़ॉल्ट टेम्प्लेट उपलब्ध हैं।
- **रीसेट विकल्प**: "इस टेम्प्लेट को डिफ़ॉल्ट पर पुनः स्थापित करें" और "सभी को डिफ़ॉल्ट पर पुनः स्थापित करें" बटन, भाषा बदलते समय आसान टेम्प्लेट प्रबंधन के लिए पुष्टिकरण डायलॉग के साथ।
- **लोकेल-अवेयर सूचना सामग्री**: सूचनाओं में तिथियाँ, समय, संख्याएँ, और बैकअप स्थिति मान लोकेल-अवेयर स्वरूपण के अनुसार प्रदर्शित होते हैं।

### तिथि और संख्या स्थानीयकरण {#date-and-number-localization}

- **लोकेल-अवेयर तिथि और समय स्वरूपण**: एप्लिकेशन के सभी भागों में तिथियाँ और समय (डैशबोर्ड, सर्वर विवरण, चार्ट, टूलटिप्स) अब आपके लोकेल के लिए उपयुक्त स्वरूप में प्रदर्शित होते हैं (उदाहरण के लिए यूरोपीय लोकेल के लिए DD/MM/YYYY, अंग्रेजी के लिए MM/DD/YYYY)।
- **लोकेल-अवेयर संख्या स्वरूपण**: संख्याएँ, फ़ाइल आकार, और आँकड़े लोकेल-अनुकूल स्वरूपण का उपयोग करते हैं (उदाहरण के लिए जर्मन के लिए 1.234,56, अंग्रेजी के लिए 1,234.56)।

### आरटीएल समर्थन तैयारी {#rtl-support-preparation}

- **दक्षिण से उत्तर भाषाओं के लिए आधार**: दक्षिण से उत्तर भाषाओं (अरबी, हिब्रू) का समर्थन करने के लिए ढांचा जोड़ा गया है। वर्तमान भाषाएँ बाएँ से दाएँ हैं।

## सुरक्षा {#security}

### एपीआई प्रमाणीकरण {#api-authentication}

- **अतिरिक्त एंडपॉइंट्स पर आवश्यक प्रमाणीकरण**: निम्नलिखित एंडपॉइंट्स अब एक वैध सत्र और सीएसआरएफ टोकन की आवश्यकता होती है (पहले वैकल्पिक प्रमाणीकरण था):
  - `/api/backups/collect`
  - `/api/backups/sync-schedule`
  - `/api/cron-config` (POST)
  - `/api/notifications/check-overdue`
  - `/api/notifications/clear-overdue-timestamps`
- **निर्भरता सुरक्षा अपडेट**: ज्ञात सुरक्षा समस्याओं का पता लगाने के लिए खतरेपूर्ण निर्भरताओं (fast-xml-parser, brace-expansion) को अपग्रेड किया गया।

## बग फिक्स {#bug-fixes}

- **मास्टर कुंजी बदलने का पता लगाना**: डेटाबेस और `.duplistatus.key` फ़ाइल को एक साथ पुनर्स्थापित करते समय गलत "कुंजी बदल गई" पता लगाने को ठीक किया गया (उसी कुंजी के साथ)। प्रणाली अब विश्वसनीय पता लगाने के लिए कुंजी फिंगरप्रिंट का उपयोग करती है, बजाय कि डिक्रिप्शन-आधारित जाँचों का उपयोग करे जो डेटा भ्रष्टता को कुंजी बदलने के रूप में गलतफहमी कर सकते हैं।
- **विवरण पृष्ठ प्रारंभिक लोड**: सर्वर विवरण पृष्ठ अब पहली बार लोड होने पर विलंबित संदेश और डेटा को सही ढंग से प्रदर्शित करता है, बजाय कि केवल पहली ऑटो-रिफ्रेश के बाद।

## सुधार {#improvements}

### अंतर्राष्ट्रीयकरण सुसंगतता {#internationalisation-consistency}

- **सुसंगत लेबल**: समय इकाइयाँ, अंतराल, स्थिति लेबल, और सामान्य शब्द अब एप्लिकेशन के सभी भागों में सुसंगत रूप से दिखाई देते हैं।
- **लोकेल-अवेयर सप्ताहदिन क्रमबद्धता**: बैकअप मॉनिटरिंग में सप्ताहदिन प्रदर्शन आपके भाषा/लोकेल का सम्मान करता है। इसे डिस्प्ले सेटिंग्स में ओवरराइट किया जा सकता है।

### Auth API error and success codes (i18n) {#auth-api-error-and-success-codes-i18n}

- **स्थिर त्रुटि और सफलता कोड**: प्रमाणीकरण एंडपॉइंट्स (`/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/change-password`, `/api/auth/password-policy`) अब एक `errorCode` (और, सफलता पर, एक `successCode`) अंग्रेजी `error` या `message` फ़ील्ड के अलावा लौटाते हैं। क्लाइंट उपयोगकर्ता की भाषा में स्थानीयकृत संदेश दिखाने के लिए इन कोड का उपयोग करते हैं।
- **लॉगिन पृष्ठ**: सभी लॉगिन त्रुटि संदेश (उदाहरण के लिए "Username और password आवश्यक हैं", "गलत username या password", "खाता लॉक किया गया") अब सभी पाँच लोकेल के लिए लॉगिन पृष्ठ पर अनुवादित हैं।
- **पासवर्ड बदलने का मोडल**: सभी पासवर्ड बदलने के एपीआई त्रुटि और सफलता संदेश अब पासवर्ड बदलने के मोडल में अनुवादित हैं।
- **एपीआई संदर्भ**: [प्रमाणीकरण और सुरक्षा](../api-reference/authentication-security.md#auth-api-error-and-success-codes-i18n) एपीआई दस्तावेज़ सभी त्रुटि और सफलता कोडों की सूची देते हैं और बताते हैं कि उन्हें आई18एन के लिए कैसे उपयोग किया जाए।

### यूआई सुधार {#ui-improvements}

- **Server filter width**: Backup suchnaayein form mein server filter width badhaye gaye hain (260px → 360px) betar usability ke liye.
- **Bulk selection**: Backup counts ke liye sahi pluralization support ke saath bulk selection UI badhaye gaye hain.
- **Help tooltips**: Page name context ke saath help tooltip text badhaye gaye hain.

### Documentation {#documentation}

- **Configuration page rename**: Timezone aur bhaasha configuration page ka naam `configure-tz-lang` se `configure-tz` mein badal diya gaya hai.
- **Notification templates guide**: Naye template language selector, reset buttons, aur bhaasha behaviour ke liye user guide update kiya gaya hai.
- **Multi-language documentation**: User guide ab batata hai ki interface language ko user menu mein language selector ke through kaise badalaya ja sakta hai.

## Migration Notes {#migration-notes}

### From Version 1.3.0 {#from-version-130}

Version 1.3.1 par upgrade karte waqt:

1. **API Authentication**: Scripts ya tools jo backups collect, sync-schedule, cron-config, ya notification check/clear endpoints ko call karte hain, ab valid session authentication aur CSRF tokens shamil karne ke liye hone chahiye.

2. **No Database Migration Required**: Is release mein koi database schema changes ki zarurat nahi hai.

3. **Locale Support**: Environment variable `LANG` ab istemaal nahi kiya ja raha hai. Aap notifications ke liye bhaasha ko `Settings > Templates` page par define kar sakte hain.

## चेंजलॉग {#changelog}

### Version 1.3.1 Changes {#version-131-changes}

- **Added**: Multi-language interface support with language selector in app header (en, de, fr, es, pt-BR)
- **Added**: Notification templates internationalisation with language selector and pre-translated defaults
- **Added**: Locale-aware date, time, aur number formatting throughout the application
- **Added**: RTL support preparation for future right-to-left languages
- **Changed**: API authentication ab backups collect, sync-schedule, cron-config, aur notification endpoints par required hai
- **Changed**: Documentation page ka naam configure-tz-lang se configure-tz mein badal diya gaya hai
- **Changed**: Notification templates aur multi-language support ke liye user guide update kiya gaya hai
- **Fixed**: Master key change detection false positives jab database ko same key ke saath restore kiya jata hai
- **Fixed**: "database disk image is malformed" errors restore ke baad fix kiya gaya hai
- **Fixed**: Non-English locales mein relative time formatting (backup monitoring form)
- **Fixed**: Detail page initial load ab overdue message aur data sahi dikhata hai
- **Fixed**: Translated docs ke liye localized documentation screenshots
- **Fixed**: Login aur auth API error messages ab translated hain (auth endpoints errorCode/successCode return karte hain; login page aur change-password modal codes ko localized strings mein map karte hain)
- **Improved**: Internationalisation consistency (labels aur terms across the app)
- **Improved**: Help button ab current interface language mein documentation kholata hai.
- **Improved**: UI improvements (server filter width, bulk selection pluralization, help tooltips)
- **Security**: Vulnerable dependencies upgrade kiya gaya hai (fast-xml-parser, brace-expansion)
