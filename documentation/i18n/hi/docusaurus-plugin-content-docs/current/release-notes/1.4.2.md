# Sanskaran 1.4.2 {#version-142}

## Overview {#overview}

Sanskaran 1.4.2 ek maintenance release hai jo vistrit bhaasha sahayata, vishwasniyata, aur dependency hygiene par kendrit hai. Yah poori tarah se localised Simplified Chinese aur Hindi (Roman) interface prastut karta hai, documentation ko saat bhaashaon tak vistaarit karta hai, aur dashboard aur server merge ki kai samasyaon ke saath-saath Docker startup crash ko suljhata hai. Dependencies ko bhi update kiya gaya hai, jismein `nodemailer` ka ek bada upgrade shaamil hai.

---

## नई सुविधाएँ {#new-features}

### Bhaasha sahayata {#language-support}

- **Simplified Chinese aur Hindi (Roman) interface**: Application interface ab English, French, German, Spanish, aur Brazilian Portuguese ke saath-saath Simplified Chinese aur Hindi (Roman) mein poori tarah uplabdh hai. Inhen Settings ke bhaasha menu se chunein.
- **Vistaarit documentation bhaashaen**: Online documentation ab saat bhaashaon mein prakashit hai, jismein maujooda anuvaadon ke saath Hindi (Roman) aur Simplified Chinese ko joda gaya hai.

---

## सुधार {#improvements}

### Backup sangrah {#backup-collection}

- **Logs sangrah karte samay sthir server pehchaan**: Backup logs sangrah karte samay, duplistatus ab Duplicati machine naam ko aapke maujooda server ke saath match karta hai aur Duplicati ki machine ID par nirbhar rehne ke bajaye us server ke record ka punarupyog karta hai. Yah backup itihas ko usi server se jode rakhta hai bhale hi Duplicati ki machine ID badal jaye (udaharan ke liye, reinstall ke baad), jisse duplicate servers ki entries kam ho jati hain.

### Documentation {#documentation}

- **Up-to-date bhaasha soochi**: README aur documentation ab sabhi saat supported bhaashaon ka varnan karte hain aur pratyek anuvaadit sanskaran se link karte hain.
- **Documentation bhaasha menu flags**: Nayi Hindi aur Simplified Chinese documentation ke liye flag icons jode gaye hain, aur consistency ke liye Portuguese ko Portugal flag mein badal diya gaya hai. Flags ab bina kisi external font download ke Windows, Linux, aur Chromium par bharosemand tareeke se render hote hain.
- **Vistaarit duplicate-servers margdarshan**: User guide ab duplicate servers ke dono kaaranon (ek badli hui Duplicati machine ID, aur ek Duplicati API bug jo identity ID aur machine ID ko mix kar deta hai) ki vyakhya karti hai aur duplistatus merge step ke saath-saath Duplicati-side workaround ka dastaavej bhi prastut karti hai.

### Dashboard pradarshan {#dashboard-performance}

- **Load hone par kam sign-in checks**: Dashboard ab aapke vartaman upyogkarta ko ek baar fetch karta hai aur ise prushth (header, settings guard, theme aur widgets) mein saajha karta hai, bajaye iske ki har component ise alag se request kare, jisse prushth load hone par redundant requests kam ho jati hain.

---

## बग ठीक {#bug-fixes}

- **Docker startup crash**: Container start hone par ek crash ko theek kiya gaya hai jo `Cannot find module '.../@swc/helpers/...'` report karta tha, jo application ko start hone se rok sakta tha. Containers ab bharosemand tareeke se start hote hain.
- **Duplicate dashboard entries**: Jab kai records ek hi latest backup taareekh saajha karte hain, to dashboard ab ek hi backup ke liye ek se adhik rows nahi dikhata hai.
- **Duplicate servers ko merge karna**: Servers ko merge karne se ab ve duplicate Duplicati backup IDs bhi consolidate karte hain jo ek hi backup naam saajha karte hain, aur sabse haal hi ke backup se ID rakhte hain. Merge operations ab audit log mein record kiye jaate hain.

---

## सुरक्षा {#security}

### Dependency updates {#dependency-updates}

- **`nodemailer` ko 9.x mein upgrade kiya gaya**: Email library ko sabse naye major version mein update kiya gaya hai. v9 mein akela breaking change (remote attachment, OAuth2, ya proxy content fetch karte samay sakht TLS validation) duplistatus ko prabhavit nahi karta hai, jo keval inline text aur HTML email bhejta hai.
- **Anya dependency updates**: Kai build aur type dependencies ko unke sabse naye compatible versions mein refresh kiya gaya hai.

---

## माइग्रेशन नोट्स {#migration-notes}

### Sanskaran 1.4.1 se {#from-version-141}

Sanskaran 1.4.2 mein upgrade karte samay:

1. **Kisi database migration ki avashyakta nahi hai**: Is release ke liye kisi bhi database schema badlav ki avashyakta nahi hai.
2. **Dependencies**: Updated lockfile aur overrides ko lagu karne ke liye `pnpm install` chalayein.
3. **Kisi configuration badlav ki avashyakta nahi hai**: Aapki chuni hui bhaasha sahit maujooda sammaan surakshit rakhe jaate hain.

## चेंजलॉग {#changelog}

### Sanskaran 1.4.2 badlav {#version-142-changes}

- **Added**: Full Simplified Chinese and Hindi (Roman) user interface.
- **Added**: Documentation now available in seven languages, including Hindi (Roman) and Simplified Chinese.
- **Changed**: Backup log collection now identifies servers by Duplicati machine name (reusing existing records), keeping history attached even when the machine ID changes.
- **Changed**: Documentation language menu adds flags for the new locales and uses the Portugal flag for Portuguese.
- **Changed**: Documentation and README updated to describe the full set of supported languages, and expanded the duplicate-servers troubleshooting guidance.
- **Changed**: Upgraded `nodemailer` to 9.x and refreshed other build/type dependencies.
- **Fixed**: Docker startup crash caused by a missing `@swc/helpers` module.
- **Fixed**: Duplicate dashboard entries when several backups share the same latest date.
- **Fixed**: Merging duplicate servers now consolidates duplicate backup IDs and is recorded in the audit log.
- **Fixed**: Reduced redundant sign-in checks when loading the dashboard.
