# संस्करण 1.3.0 {/* #version-130 */}

## अवलोकन {/* #overview */}

संस्करण 1.3.0 में कॉन्फ़िगर करने योग्य पासवर्ड नीतियां, एडमिन के लिए एक नया एप्लिकेशन लॉग व्यूअर, लोकेल-अवेयर कार्यदिवस प्रदर्शन और कई उपयोगकर्ता अनुभव सुधार पेश किए गए हैं। यह रिलीज़ उन्नत प्रशासनिक टूल्स और बेहतर अंतर्राष्ट्रीयकरण समर्थन पर केंद्रित है।

## नई सुविधाएं {/* #new-features */}

### कॉन्फ़िगर करने योग्य पासवर्ड नीति {/* #configurable-password-policy */}

- **पासवर्ड नीति एनवायरमेंट वैरिएबल्स**: एनवायरमेंट वैरिएबल्स के माध्यम से पासवर्ड सत्यापन आवश्यकताओं को कॉन्फ़िगर करें:
  - `PWD_ENFORCE`: पासवर्ड जटिलता आवश्यकताओं (अपरकेस, लोअरकेस, संख्याएं) को अक्षम करने के लिए `false` पर सेट करें। डिफ़ॉल्ट रूप से सभी नियमों को लागू किया जाता है। अक्षम होने पर, केवल न्यूनतम लंबाई लागू की जाती है।
  - `PWD_MIN_LEN`: वर्णों में न्यूनतम पासवर्ड लंबाई सेट करता है। डिफ़ॉल्ट रूप से 8 वर्ण हैं।
  - डिफ़ॉल्ट पासवर्ड जांचें (डिफ़ॉल्ट एडमिन पासवर्ड के उपयोग को रोकना) हमेशा `PWD_ENFORCE` सेटिंग की परवाह किए बिना लागू की जाती है।

### एप्लिकेशन लॉग व्यूअर {/* #application-logs-viewer */}

- **केवल एडमिन के लिए नया लॉग व्यूअर**: सेटिंग्स पृष्ठ से सीधे एप्लिकेशन लॉग देखें और डाउनलोड करें:
  - समेकित `application.log` फ़ाइल और रोटेट किए गए लॉग संस्करणों तक पहुंचें
  - कॉन्फ़िगर करने योग्य लाइन गणना चयनकर्ता (100, 500, 1000, 5000, 10000 लाइनें)
  - केस-इनसेंसिटिव टेक्स्ट मिलान के साथ रीयल-टाइम खोजें फ़िल्टर
  - स्वचालित पोलिंग के साथ रीयल-टाइम लॉग निगरानी के लिए ऑटो-स्क्रॉल टॉगल
  - क्लिपबोर्ड पर कॉपी करें और फ़िल्टर किए गए लॉग को टेक्स्ट फ़ाइल के रूप में निर्यात करें
  - लाइन गणना, फ़ाइल आकार और अंतिम संशोधित टाइमस्टैम्प दिखाने वाला फ़ाइल मेटाडेटा प्रदर्शन
  - कंटेनर स्टार्टअप पर लॉग रोटेशन (`LOG_ROTATION_VERSIONS` के माध्यम से कॉन्फ़िगर करने योग्य, डिफ़ॉल्ट: 5)

### संदर्भ-जागरूक उपयोगकर्ता मार्गदर्शिका {/* #context-aware-user-guide */}

- **डायनेमिक सहायता बटन**: ऐप हेडर में उपयोगकर्ता मार्गदर्शिका बटन अब वर्तमान पृष्ठ से संबंधित दस्तावेज़ खोलता है। टूलटिप अपडेट होकर "`Page Name` के लिए सहायता" दिखाती है ताकि यह इंगित किया जा सके कि कौन सा दस्तावेज़ खोला जाएगा।

### सर्वर कॉन्फ़िगरेशन संवर्धन {/* #server-configuration-enhancement */}

- **Duplicati UI तक त्वरित पहुंच**: सर्वर कॉन्फ़िगरेशन बटन या सर्वर चयन पॉपओवर में किसी भी सर्वर आइटम पर राइट-क्लिक करने से एक नए टैब में Duplicati लीगेसी UI (`/ngax`) खुलता है।

## 🔧 सुधार {/* #-improvements */}

### लोकेल-अवेयर कार्यदिवस प्रदर्शन {/* #locale-aware-weekday-display */}

- **अंतर्राष्ट्रीयकृत कार्यदिवस क्रम**: बैकअप निगरानी फ़ॉर्म में कार्यदिवस प्रदर्शन अब आपके ब्राउज़र की लोकेल सेटिंग्स का सम्मान करता है। लोकेल के आधार पर कार्यदिवसों को सही क्रम में प्रदर्शित किया जाता है (यूके/यूरोप के लिए सोमवार-रविवार, यूएस/ब्राजील के लिए रविवार-शनिवार)।

### उन्नत SMTP त्रुटि हैंडलिंग {/* #enhanced-smtp-error-handling */}

- **बेहतर त्रुटि संदेश**: SMTP त्रुटि संदेश अब अधिक सटीक मार्गदर्शन प्रदान करते हैं:
  - प्रमाणीकरण त्रुटियाँ स्पष्ट रूप से उपयोगकर्ता नाम/पासवर्ड समस्याओं का संकेत देती हैं
  - SSL/TLS संस्करण त्रुटियों की सही पहचान की जाती है
  - कनेक्शन प्रकार सुझाव केवल तभी दिखाई देते हैं जब वे वास्तव में प्रासंगिक हों

### टोस्ट सूचना व्यवहार {/* #toast-notification-behaviour */}

- **लगातार बनी रहने वाली त्रुटि सूचनाएं**: त्रुटि टोस्ट अब मैन्युअल रूप से बंद होने तक बने रहते हैं, जिससे यह सुनिश्चित होता है कि आप महत्वपूर्ण त्रुटि संदेश न चूकें। सफलता और जानकारी संबंधी टोस्ट 3 सेकंड के बाद स्वतः खारिज हो जाते हैं।

### नोटिफ़िकेशन सेटिंग्स तालिका {/* #notification-settings-table */}

- **सरलीकृत लेआउट**: संयुक्त "सर्वर / बैकअप" कॉलम और अतिरिक्त गंतव्य कॉन्फ़िगरेशन स्थिति को दर्शाने वाले प्रासंगिक आइकन के साथ नोटिफ़िकेशन सेटिंग्स तालिका को सुव्यवस्थित किया गया है।

## 🚀 माइग्रेशन नोट्स {/* #-migration-notes */}

### संस्करण 1.2.x से {/* #from-version-12x */}

संस्करण 1.3.0 में अपग्रेड करते समय:

1. **पासवर्ड नीति**: नई पासवर्ड नीति में डिफ़ॉल्ट रूप से सभी जटिलता आवश्यकताओं को लागू किया जाता है। यदि आपको अधिक सरल पासवर्ड नीति की आवश्यकता है, तो `PWD_ENFORCE` और `PWD_MIN_LEN` एनवायरनमेंट वैरिएबल्स कॉन्फ़िगर करें।

2. **एप्लिकेशन लॉग**: सभी कंटेनर आउटपुट (सर्वर और क्रॉन सेवा) को अब एक ही `data/logs/application.log` फ़ाइल में समेकित किया गया है।

3. **लॉग रोटेशन**: लॉग रोटेशन को `LOG_ROTATION_VERSIONS` एनवायरनमेंट वैरिएबल के माध्यम से कॉन्फ़िगर किया जा सकता है (डिफ़ॉल्ट: 5 संस्करण)।

4. **किसी डेटाबेस माइग्रेशन की आवश्यकता नहीं**: इस रिलीज़ में किसी भी डेटाबेस स्कीमा परिवर्तन की आवश्यकता नहीं है।

## API एंडपॉइंट {/* #api-endpoints */}

इस संस्करण में निम्नलिखित API एंडपॉइंट प्रस्तुत किया गया है:

### पासवर्ड नीति एंडपॉइंट {/* #password-policy-endpoint */}

- `GET /api/auth/password-policy` - वर्तमान पासवर्ड नीति कॉन्फ़िगरेशन लौटाता है

### एप्लिकेशन लॉग एंडपॉइंट्स {/* #application-logs-endpoints */}

- `GET /api/application-logs` - फ़ाइल चयन और टेल कार्यक्षमता के साथ लॉग देखें
- `GET /api/application-logs/export` - फ़िल्टर किए गए लॉग को टेक्स्ट फ़ाइल के रूप में निर्यात करें

### हटाए गए एंडपॉइंट्स {/* #removed-endpoints */}

इस संस्करण में निम्नलिखित अप्रयुक्त API एंडपॉइंट्स को हटा दिया गया है:

- `DELETE /api/backups/[backupId]` - केवल-डेवलपमेंट एंडपॉइंट जिसका उपयोग कभी नहीं किया गया था
- `GET /api/audit-log/stats` - एंडपॉइंट को ऑडिट लॉग व्यूअर द्वारा कॉल नहीं किया गया था

## परिवर्तन लॉग {/* #changelog */}

### संस्करण 1.3.0 में हुए बदलाव {/* #version-130-changes */}

- **जोड़ा गया**: `PWD_ENFORCE` और `PWD_MIN_LEN` पर्यावरण चरों (environment variables) के माध्यम से कॉन्फ़िगर करने योग्य पासवर्ड नीति
- **जोड़ा गया**: सेटिंग्स में एप्लिकेशन लॉग व्यूअर (केवल एडमिन के लिए)
- **जोड़ा गया**: कॉन्फ़िगर करने योग्य संस्करण गणना (`LOG_ROTATION_VERSIONS`) के साथ लॉग रोटेशन
- **जोड़ा गया**: संदर्भ-जागरूक (context-aware) उपयोगकर्ता गाइड बटन जो प्रासंगिक दस्तावेज़ खोलता है
- **जोड़ा गया**: Duplicati लेगसी UI खोलने के लिए सर्वर कॉन्फ़िगरेशन पर राइट-क्लिक करें
- **जोड़ा गया**: पासवर्ड नीति कॉन्फ़िगरेशन के लिए API एंडपॉइंट `GET /api/auth/password-policy`
- **जोड़ा गया**: एप्लिकेशन लॉग देखने और निर्यात (export) करने के लिए API एंडपॉइंट
- **बदला गया**: कार्यदिवस (Weekday) का प्रदर्शन अब ब्राउज़र लोकेल सेटिंग्स का पालन करता है
- **बदला गया**: त्रुटि टोस्ट (toasts) तब तक बने रहते हैं जब तक कि उन्हें मैन्युअल रूप से बंद न किया जाए
- **बदला गया**: सफलता टोस्ट 3 सेकंड के बाद अपने आप बंद हो जाते हैं (पहले 5 सेकंड था)
- **बदला गया**: संयुक्त "सर्वर / बैकअप" कॉलम के साथ अधिसूचना सेटिंग्स तालिका को सरल बनाया गया
- **बदला गया**: सभी कंटेनर लॉग को एकल `application.log` फ़ाइल में समेकित किया गया
- **सुधार किया गया**: SMTP त्रुटि संदेश अधिक सटीक मार्गदर्शन प्रदान करते हैं
- **हटाया गया**: अप्रयुक्त API एंडपॉइंट (`DELETE /api/backups/[backupId]` और `GET /api/audit-log/stats`) जिन्हें एप्लिकेशन द्वारा कॉल नहीं किया जा रहा था
