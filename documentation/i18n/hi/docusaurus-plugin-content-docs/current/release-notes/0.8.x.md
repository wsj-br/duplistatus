# संस्करण 0.8.x {/* #version-08x */}

## अवलोकन {/* #overview */}

संस्करण 0.8.x एक बड़ा अपडेट है जो महत्वपूर्ण सुरक्षा संवर्द्धन, बेहतर सर्वर प्रबंधन क्षमताएं और SMTP ईमेल समर्थन के साथ एक व्यापक सूचना प्रणाली प्रस्तुत करता है। यह रिलीज़ सुरक्षा को मजबूत करने, उपयोगकर्ता अनुभव को बेहतर बनाने और अधिक लचीले बैकअप निगरानी विकल्प प्रदान करने पर केंद्रित है।

## नई सुविधाएं {/* #new-features */}

### सर्वर प्रबंधन सुधार {/* #server-management-enhancements */}

- बैकअप एकत्र करते समय **स्वचालित सर्वर URL और पासवर्ड परसिस्टेंस**
  - उपयोगकर्ता दो तरीकों का उपयोग करके URL और पासवर्ड अपडेट कर सकते हैं:
     - अपडेट किए गए मानों के साथ बैकअप को फिर से एकत्र करके
     - [सेटिंग्स → सर्वर सेटिंग्स](../user-guide/settings/server-settings.md) में सेटिंग्स संशोधित करके

### बेहतर बैकअप निगरानी {/* #enhanced-backup-monitoring */}

- Duplicati सर्वर-संगत अंतराल सेटिंग्स के साथ **नया `Backup monitoring` कॉन्फ़िगरेशन टैब**
    - कस्टम अंतरालों के लिए समर्थन (जैसे, "1D12h")
    - बैकअप लॉग संग्रह के दौरान Duplicati कॉन्फ़िगरेशन से स्वचालित अतिदेय अंतराल अपडेट
    - **अनुशंसित:** duplistatus कॉन्फ़िगरेशन को सिंक्रनाइज़ करने के लिए Duplicati सर्वर में बैकअप जॉब अंतरालों को बदलने के बाद संग्रह चलाएं
    - सूचनाएं टेम्पलेट अब `{backup_interval_value}` और `{backup_interval_type}` के बजाय `{backup_interval}` का उपयोग करते हैं।

### NTFY डिवाइस कॉन्फ़िगरेशन {/* #ntfy-device-configuration */}

- **duplistatus** से सूचनाएं प्राप्त करने के लिए स्वचालित डिवाइस कॉन्फ़िगरेशन हेतु **QR कोड जनरेशन**
   - एप्लिकेशन टूलबार में `View NTFY Messages` बटन पर राइट-क्लिक करें
   - [सेटिंग्स → NTFY सेटिंग्स](../user-guide/settings/ntfy-settings.md) में "डिवाइस कॉन्फ़िगर करें" बटन

### बेहतर बैकअप संग्रह {/* #improved-backup-collection */}

- **स्वचालित HTTP/HTTPS पहचान**, कनेक्शनों का इस क्रम में प्रयास किया जाता है: HTTPS → स्व-हस्ताक्षरित (self-signed) के साथ HTTPS → HTTP फ़ॉलबैक
- सीधे सर्वर-विशिष्ट संग्रह के लिए `Collect Backup Logs` इंटरफ़ेस में **सर्वर चयन ड्रॉपडाउन**
- होस्टनाम में **एकाधिक पते** (अल्पविराम से अलग किए गए) अब स्वीकार किए जाते हैं (समान पासवर्ड और पोर्ट साझा होने चाहिए)
- `Dashboard (table)`, [सेटिंग्स → बैकअप निगरानी](../user-guide/settings/backup-monitoring-settings.md) और [सेटिंग्स → सर्वर](../user-guide/settings/server-settings.md) में **एकल-सर्वर बैकअप संग्रह बटन** जोड़े गए
- वैध कॉन्फ़िगरेशन (url और पासवर्ड) वाले सभी सर्वरों के लिए **बल्क संग्रह कार्यक्षमता**
   - [सेटिंग्स → बैकअप निगरानी](../user-guide/settings/backup-monitoring-settings.md) और [सेटिंग्स → सर्वर](../user-guide/settings/server-settings.md) में `Collect All` बटन
   - एप्लिकेशन टूलबार में `Collect Backup Logs` बटन पर राइट-क्लिक संदर्भ मेनू

### बेहतर सूचना प्रणाली {/* #enhanced-notification-system */}

- **SMTP ईमेल सूचना समर्थन:**
    - [सेटिंग्स → ईमेल सेटिंग्स](../user-guide/settings/email-settings.md) में SMTP सर्वर कॉन्फ़िगरेशन
    - NTFY और/या ईमेल सूचनाओं के लिए प्रति-बैकअप जॉब कॉन्फ़िगरेशन
    - मौजूदा [सेटिंग्स → सूचनाएं टेम्पलेट](../user-guide/settings/notification-templates.md) का उपयोग करके HTML-फ़ॉर्मेटेड टेम्पलेट
- **प्रति-बैकअप जॉब सूचना कॉन्फ़िगरेशन:**
    - [सेटिंग्स → बैकअप सूचनाएं](../user-guide/settings/backup-notifications-settings.md) में व्यक्तिगत सूचना प्राथमिकताएं
    - NTFY या ईमेल ठीक से कॉन्फ़िगर न होने पर दृश्य संकेतक (ग्रे रंग के आइकन)

- **लोकेल समर्थन:**
    - एप्लिकेशन में लोकेल सेट करने के लिए एक नई एनवायरनमेंट वेरिएबल `LANG` बनाई गई
    - अब सूचनाएं और लॉग में तारीखों और संख्याओं का फ़ॉर्मेट पूर्वानुमानित है

## 🔒 सुरक्षा संवर्द्धन {/* #-security-enhancements */}

### CSRF सुरक्षा {/* #csrf-protection */}

- मजबूत सत्र प्रबंधन के साथ **सत्र-आधारित प्रमाणीकरण**
- सभी स्थिति-परिवर्तनकारी API अनुरोधों के लिए **CSRF टोकन सत्यापन** अनिवार्य
- **सत्र 24 घंटों के बाद स्वचालित रूप से समाप्त हो जाते हैं**; CSRF टोकन हर 30 मिनट में रीफ्रेश होते हैं
- बाहरी API के साथ अनुकूलता बनाए रखते हुए क्रॉस-साइट रिक्वेस्ट फोर्जरी से सुरक्षा सुनिश्चित करता है

### प्लेनटेक्स्ट पासवर्ड न्यूनीकरण {/* #plaintext-password-minimization */}

- **पासवर्ड केवल उपयोगकर्ता इंटरफ़ेस के माध्यम से सेट किए जा सकते हैं**; कोई भी API एंडपॉइंट संग्रहीत पासवर्ड प्रदर्शित नहीं करता है
- पूरे सिस्टम में **प्लेनटेक्स्ट पासवर्ड हेरफेर को न्यूनतम किया गया है**

### संवेदनशील डेटा के लिए उन्नत क्रिप्टोग्राफ़ी {/* #advanced-cryptography-for-sensitive-data */}

- AES-256-GCM का उपयोग करके **संवेदनशील डेटा एन्क्रिप्शन** (उदा., पासवर्ड, SMTP क्रेडेंशियल)
- **मास्टर कुंजी स्वचालित रूप से जनरेट होती है** और `.duplistatus.key` में सुरक्षित रूप से संग्रहीत की जाती है
- सुरक्षा मजबूत करने के लिए की डेरिवेशन हेतु **100,000 इटरेशन वाला PBKDF2** उपयोग किया गया है
- **प्रमाणीकरण टैग सत्यापित किए जाते हैं** और उपयोग के बाद मेमोरी को सुरक्षित रूप से साफ़ कर दिया जाता है
- अधिकतम सुरक्षा के लिए **मास्टर कुंजी फ़ाइल अनुमतियाँ** सख्ती से 0400 पर सेट की गई हैं

## 🚀 माइग्रेशन नोट्स {/* #-migration-notes */}

### संस्करण 0.7.x से {/* #from-version-07x */}

इस रिलीज़ में महत्वपूर्ण सुरक्षा संवर्द्धन और नई सुविधाएँ शामिल हैं। संस्करण 0.7.x से अपग्रेड करते समय:

1. **स्वचालित डेटाबेस माइग्रेशन:** नई सुविधाओं का समर्थन करने के लिए एप्लिकेशन आपके डेटाबेस स्कीमा को स्वचालित रूप से माइग्रेट करेगा
2. **मास्टर कुंजी जनरेशन:** संवेदनशील डेटा के एन्क्रिप्शन के लिए एक नई मास्टर कुंजी जनरेट की जाएगी
3. **सत्र प्रबंधन:** मौजूदा सत्र अमान्य कर दिए जाएंगे और नए CSRF-सुरक्षित सत्र स्थापित किए जाएंगे
4. **कॉन्फ़िगरेशन अपडेट:** नई सुविधाओं का समर्थन करने के लिए कुछ कॉन्फ़िगरेशन कुंजियों को अपडेट किया गया है
5. **टेम्पलेट परिवर्तन:** चर `{backup_interval_value}` और `{backup_interval_type}` को `{backup_interval}` से बदल दिया गया था। डिफ़ॉल्ट टेम्पलेट स्वचालित रूप से समायोजित हो जाएंगे, लेकिन कस्टमाइज़ किए गए टेम्पलेट माइग्रेट नहीं किए जाएंगे। कृपया अपने टेम्पलेट जांचें।

### सुरक्षा संबंधी बातें {/* #security-considerations */}

- **मास्टर कुंजी फ़ाइल:** सुनिश्चित करें कि `.duplistatus.key` फ़ाइल का ठीक से बैकअप लिया गया है और वह सुरक्षित है
- **फ़ाइल अनुमतियाँ:** सुरक्षा के लिए मास्टर कुंजी फ़ाइल में प्रतिबंधित अनुमतियाँ (0400) होंगी
- **पासवर्ड एन्क्रिप्शन:** नए क्रिप्टोग्राफ़िक सिस्टम का उपयोग करके मौजूदा पासवर्ड एन्क्रिप्ट किए जाएंगे
