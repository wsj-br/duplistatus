# Version 0.8.x {#version-08x}

## Overview {#overview}

Version 0.8.x एक प्रमुख अद्यतन है जो महत्वपूर्ण सुरक्षा सुधार, सुधारित सर्वर प्रबंधन क्षमताओं और SMTP ईमेल समर्थन के साथ एक व्यापक सूचना प्रणाली का परिचय देता है। यह रिलीज़ सुरक्षा को मजबूत करने, उपयोगकर्ता अनुभव को सुधारने और अधिक लचीले बैकअप निगरानी विकल्प प्रदान करने पर ध्यान केंद्रित करता है।

## New Features {#new-features}

### Server Management Enhancements {#server-management-enhancements}

- **Automatic server URL and password persistence** when collecting backups
  - Users can update URL and password using two methods:
     - Re-collecting backups with updated values
     - Modifying settings in [Settings → Server Settings](../user-guide/settings/server-settings.md)

### Enhanced Backup monitoring {#enhanced-backup-monitoring}

- **New `Backup monitoring` configuration tab** with Duplicati server-compatible interval settings
    - Support for custom intervals (e.g., "1D12h")
    - Automatic overdue interval updates from Duplicati configuration during backup log collection
    - **Recommended:** Run collection after changing backup job intervals in Duplicati server to synchronise duplistatus configuration
    - Notifications templates now use  `{backup_interval}` instead of `{backup_interval_value}` and `{backup_interval_type}`.

### NTFY Device Configuration {#ntfy-device-configuration}

- **QR code generation** for automatic device configuration to receive notifications from **duplistatus**
   - Right-click on `View NTFY Messages` button in the application toolbar
   - "Configure Device" button in [Settings → NTFY Settings](../user-guide/settings/ntfy-settings.md)

### Improved Backup Collection {#improved-backup-collection}

- **Automatic HTTP/HTTPS detection**, connections are tried in this order: HTTPS → HTTPS with self-signed → HTTP fallback
- **Server selection dropdown** in `Collect Backup Logs` interface for direct server-specific collection
- **Multiple addresses** in the hostname (comma-separated) are now accepted (must share same password and port)
- **Single-server backup collection buttons** added to `Dashboard (table)`, [Settings → Backup Monitoring](../user-guide/settings/backup-monitoring-settings.md) and [Settings → Servers](../user-guide/settings/server-settings.md)
- **Bulk collection functionality** for all servers with valid configuration (url and password)
   - `Collect All` buttons in [Settings → Backup Monitoring](../user-guide/settings/backup-monitoring-settings.md) and [Settings → Servers](../user-guide/settings/server-settings.md)
   - Right-click context menu on `Collect Backup Logs` button in application toolbar

### Enhanced Notification System {#enhanced-notification-system}

- **SMTP Email Notification Support:**
    - SMTP server configuration in [Settings → Email Settings](../user-guide/settings/email-settings.md)
    - Per-backup job configuration for NTFY and/or email notifications
    - HTML-formatted templates using existing [Settings → Notification Templates](../user-guide/settings/notification-templates.md)
- **Per-Backup Job Notification Configuration:**
    - Individual notification preferences in [Settings → Backup Notifications](../user-guide/settings/backup-notifications-settings.md)
    - Visual indicators (greyed icons) when NTFY or email is not properly configured

- **Locale support:**
    - created a new environment variable `LANG` to set the locale in the application
    - now it's predictable the format of dates and numbers in the notifications and logs

## 🔒 Security Enhancements {#-security-enhancements}

### CSRF Protection {#csrf-protection}

- **Session-based authentication** with robust session management
- **CSRF token validation** enforced for all state-changing API requests
- **Sessions expire automatically** after 24 hours; CSRF tokens refresh every 30 minutes
- Ensures protection against Cross-Site Request Forgery while preserving compatibility with external APIs

### Plaintext Password Minimization {#plaintext-password-minimization}

- **Passwords can only be set via the user interface**; no API endpoint exposes stored passwords
- **Plaintext password manipulation is minimized** throughout the system

### Advanced Cryptography for Sensitive Data {#advanced-cryptography-for-sensitive-data}

- **संवेदनशील डेटा एन्क्रिप्शन** (जैसे पासवर्ड, SMTP क्रेडेंशियल्स) AES-256-GCM का उपयोग करके
- **मास्टर की स्वचालित रूप से उत्पन्न की जाती है** और सुरक्षित रूप से `.duplistatus.key` में संग्रहीत की जाती है
- **PBKDF2 के साथ 100,000 पुनरावृत्तियाँ** की डेरिवेशन के लिए की गई है, सुरक्षा को मजबूत करने के लिए
- **प्रमाणीकरण टैग्स की जाँच की जाती है** और उपयोग के बाद मेमोरी को सुरक्षित रूप से साफ किया जाता है
- **मास्टर की फ़ाइल अनुमतियाँ** अधिकतम सुरक्षा के लिए 0400 पर सेट की जाती हैं

## 🚀 माइग्रेशन नोट्स {#-migration-notes}

### Version 0.7.x से {#from-version-07x}

इस रिलीज़ में महत्वपूर्ण सुरक्षा सुधार और नई सुविधाएँ शामिल हैं। Version 0.7.x से अपग्रेड करते समय:

1. **स्वचालित डेटाबेस माइग्रेशन:** एप्लिकेशन नए सुविधाओं का समर्थन करने के लिए अपने डेटाबेस स्कीमा को स्वचालित रूप से माइग्रेट करेगा
2. **मास्टर की जनरेशन:** संवेदनशील डेटा के एन्क्रिप्शन के लिए एक नया मास्टर की उत्पन्न की जाएगी
3. **सेशन प्रबंधन:** मौजूदा सेशन को अमान्य कर दिया जाएगा और नए CSRF-संरक्षित सेशन स्थापित किए जाएंगे
4. **कॉन्फ़िगरेशन अपडेट्स:** कुछ कॉन्फ़िगरेशन कुंजियाँ नए सुविधाओं का समर्थन करने के लिए अपडेट की गई हैं
5. **टेम्पलेट परिवर्तन:** `{backup_interval_value}` और `{backup_interval_type}` को `{backup_interval}` से बदल दिया गया था। डिफ़ॉल्ट टेम्पलेट्स स्वचालित रूप से समायोजित किए जाएंगे, लेकिन कस्टम टेम्पलेट्स को माइग्रेट नहीं किया जाएगा। कृपया अपने टेम्पलेट्स की जाँच करें।

### सुरक्षा विचार {#security-considerations}

- **मास्टर की फ़ाइल:** सुनिश्चित करें कि `.duplistatus.key` फ़ाइल को ठीक से बैकअप और सुरक्षित किया गया है
- **फ़ाइल अनुमतियाँ:** मास्टर की फ़ाइल की सुरक्षा के लिए प्रतिबंधित अनुमतियाँ (0400) होंगी
- **पासवर्ड एन्क्रिप्शन:** मौजूदा पासवर्ड को नए क्रिप्टोग्राफिक सिस्टम का उपयोग करके एन्क्रिप्ट किया जाएगा
