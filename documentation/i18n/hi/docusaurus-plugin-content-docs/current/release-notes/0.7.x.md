# Sanskaran 0.7.x {/* #version-07x */}

## Overview {/* #overview */}

Sanskaran 0.7.x hai ek mahatvapurn release jo database schema, API structure, aur user interface mein mahatvapurn improvements lekar aaya hai. Is sanskaran mein breaking changes hain jo external integrations ko update karne ka vyavaharik hota hai.

## ब्रेकिंग परिवर्तन {/* #breaking-changes */}

### डेटाबेस स्कीमा परिवर्तन {/* #database-schema-changes */}
- **टेबल पुनः नामकरण**: `machines` टेबल का नाम बदलकर `servers` किया गया
- **नए फ़ील्ड**: `alias`, `notes`, `created_at`, aur `updated_at` फ़ील्ड जोड़ें
- **API रिस्पॉन्स परिवर्तन**: सुसंगतता के लिए फ़ील्ड नाम अपडेट किए गए

### बैकवर्ड-इनकम्पैटिबल API परिवर्तन {/* #backward-incompatible-api-changes */}
- **फ़ील्ड पुनः नामकरण**: `totalMachines` → `totalServers`
- **ऑब्जेक्ट पुनः नामकरण**: API रिस्पॉन्स में `machine` → `server`
- **फ़ील्ड पुनः नामकरण**: `backup_types_count` → `backupJobsCount`

:::warning
**External integrations using the API must be updated** to work with version 0.7.x. See the [Backward-incompatible API changes](../migration/api-changes) guide for details.
:::

## माइग्रेशन गाइड {/* #migration-guide */}

### स्वचालित माइग्रेशन {/* #automatic-migration */}
0.6.x से 0.7.x में माइग्रेशन स्वचालित रूप से होता है:

1. **बैकअप निर्माण**: स्वचालित डेटाबेस बैकअप बनाया जाता है
2. **स्कीमा अपडेट**: डेटाबेस स्कीमा स्वचालित रूप से अपडेट की जाती है
3. **डेटा माइग्रेशन**: मौजूदा डेटा संरक्षित और माइग्रेट किया जाता है
4. **सत्यापन**: माइग्रेशन सत्यापित और लॉग किया जाता है

### मैन्युअल चरण आवश्यक {/* #manual-steps-required */}
- **बाहरी Integrations अपडेट करें**: API का उपयोग करने वाले किसी भी बाहरी टूल को अपडेट करें
- **कार्यक्षमता Parikshan**: सभी सुविधाएँ सही काम करती हैं, इसकी पुष्टि करें
- **दस्तावेज़ीकरण अपडेट करें**: किसी भी Anukoolit दस्तावेज़ीकरण को अपडेट करें

## अपग्रेड निर्देश {/* #upgrade-instructions */}

### संस्करण 0.6.x से {/* #from-version-06x */}
1. **अपना डेटा बैकअप करें** (अपग्रेड के दौरान स्वचालित बैकअप बनाया जाता है)
2. **Docker image अपडेट करें**: `docker pull wsjbr/duplistatus:0.7.x`
3. **कंटेनर पुनः प्रारंभ करें**: `docker-compose down && docker-compose up -d`
4. **लॉग्स मॉनिटर करें**: `docker logs -f duplistatus`
5. **इंटीग्रेशन अपडेट करें**: API का उपयोग करके किसी भी बाहरी उपकरण को अपडेट करें
6. **अपग्रेड सत्यापित करें**: जांचें कि सभी सुविधाएँ सही ढंग से काम कर रही हैं

### संस्करण 0.5.x या इससे पहले से {/* #from-version-05x-or-earlier */}
1. **पहले 0.6.x में अपग्रेड करें** (यदि उपलब्ध हो)
2. **फिर ऊपर दिए गए चरणों का उपयोग करके 0.7.x में अपग्रेड करें**
