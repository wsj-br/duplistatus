# Sanskaran 0.7.x {#version-07x}

## Overview {#overview}

Sanskaran 0.7.x hai ek mahatvapurn release jo database schema, API structure, aur user interface mein mahatvapurn improvements lekar aaya hai. Is sanskaran mein breaking changes hain jo external integrations ko update karne ka vyavaharik hota hai.

## Breaking Changes {#breaking-changes}

### Database Schema Changes {#database-schema-changes}
- **Table Renaming**: `machines` table renamed to `servers`
- **New Fields**: Added `alias`, `notes`, `created_at`, and `updated_at` fields
- **API Response Changes**: Updated field names for consistency

### Backward-incompatible API changes {#backward-incompatible-api-changes}
- **Field Renaming**: `totalMachines` → `totalServers`
- **Object Renaming**: `machine` → `server` in API responses
- **Field Renaming**: `backup_types_count` → `backupJobsCount`

:::warning
**External integrations using the API must be updated** to work with version 0.7.x. See the [Backward-incompatible API changes](../migration/api-changes) guide for details.
:::

## माइग्रेशन गाइड {#migration-guide}

### स्वचालित माइग्रेशन {#automatic-migration}
0.6.x से 0.7.x का माइग्रेशन स्वचालित रूप से होता है:

1. **बैकअप निर्माण**: स्वचालित डेटाबेस बैकअप बनाया जाता है
2. **स्कीमा अपडेट**: डेटाबेस स्कीमा स्वचालित रूप से अपडेट की जाती है
3. **डेटा माइग्रेशन**: मौजूदा डेटा संरक्षित और माइग्रेट किया जाता है
4. **सत्यापन**: माइग्रेशन सत्यापित और लॉग किया जाता है

### मैनुअल चरण आवश्यक {#manual-steps-required}
- **बाहरी एकीकरण अपडेट करें**: API का उपयोग करने वाले किसी भी बाहरी उपकरणों को अपडेट करें
- **कार्यक्षमता परीक्षण करें**: सभी सुविधाएँ सही ढंग से काम करती हैं, यह सत्यापित करें
- **दस्तावेज़ीकरण अपडेट करें**: किसी भी अनुकूलित दस्तावेज़ीकरण को अपडेट करें

## अपग्रेड निर्देश {#upgrade-instructions}

### संस्करण 0.6.x से {#from-version-06x}
1. **अपना डेटा बैकअप करें** (अपग्रेड के दौरान स्वचालित बैकअप बनाया जाता है)
2. **Docker इमेज अपडेट करें**: `docker pull wsjbr/duplistatus:0.7.x`
3. **कंटेनर पुनरारंभ करें**: `docker-compose down && docker-compose up -d`
4. **लॉग्स मॉनिटर करें**: `docker logs -f duplistatus`
5. **इंटीग्रेशन अपडेट करें**: API का उपयोग करके किसी भी बाहरी उपकरण को अपडेट करें
6. **अपग्रेड सत्यापित करें**: जांचें कि सभी सुविधाएँ सही ढंग से काम कर रही हैं

### Sanskaran 0.5.x या उससे पहले से {#from-version-05x-or-earlier}
1. **पहले 0.6.x पर अपग्रेड करें** (यदि उपलब्ध हो)
2. **फिर ऊपर दिए गए चरणों का उपयोग करके 0.7.x पर अपग्रेड करें**
