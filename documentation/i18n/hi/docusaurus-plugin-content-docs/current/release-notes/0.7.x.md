# संस्करण 0.7.x {/* #version-07x */}

## अवलोकन {/* #overview */}

संस्करण 0.7.x एक प्रमुख रिलीज़ है जो डेटाबेस स्कीमा, API संरचना और उपयोगकर्ता इंटरफ़ेस में महत्वपूर्ण सुधार पेश करता है। इस संस्करण में ऐसे ब्रेकिंग बदलाव शामिल हैं जिनके लिए बाहरी एकीकरण में अपडेट की आवश्यकता होती है।

## महत्वपूर्ण परिवर्तन {/* #breaking-changes */}

### डेटाबेस स्कीमा बदलाव {/* #database-schema-changes */}
- **तालिका का नाम बदलना**: `machines` तालिका का नाम बदलकर `servers` किया गया
- **नए फ़ील्ड**: `alias`, `notes`, `created_at` और `updated_at` फ़ील्ड जोड़े गए
- **API प्रतिक्रिया बदलाव**: निरंतरता के लिए फ़ील्ड नाम अपडेट किए गए

### बैकवर्ड-असंगत API बदलाव {/* #backward-incompatible-api-changes */}
- **फ़ील्ड का नाम बदलना**: `totalMachines` → `totalServers`
- **ऑब्जेक्ट का नाम बदलना**: API प्रतिक्रियाओं में `machine` → `server`
- **फ़ील्ड का नाम बदलना**: `backup_types_count` → `backupJobsCount`

:::warning
संस्करण 0.7.x के साथ काम करने के लिए **API का उपयोग करने वाले बाहरी एकीकरण को अपडेट किया जाना चाहिए**। विवरण के लिए [बैकवर्ड-असंगत API बदलाव](../migration/api-changes) गाइड देखें।
:::

## माइग्रेशन गाइड {/* #migration-guide */}

### स्वचालित माइग्रेशन {/* #automatic-migration */}
0.6.x से 0.7.x में माइग्रेशन स्वचालित रूप से होता है:

1. **बैकअप निर्माण**: स्वचालित डेटाबेस बैकअप बनाई गई है
2. **स्कीमा अपडेट**: डेटाबेस स्कीमा स्वचालित रूप से अपडेट किया जाता है
3. **डेटा माइग्रेशन**: मौजूदा डेटा सुरक्षित रखा जाता है और माइग्रेट किया जाता है
4. **सत्यापन**: माइग्रेशन सत्यापित और लॉग किया जाता है

### आवश्यक मैन्युअल चरण {/* #manual-steps-required */}
- **बाहरी एकीकरण अपडेट करें**: API का उपयोग करने वाले किसी भी बाहरी टूल को अपडेट करें
- **कार्यक्षमता जाँचें**: सत्यापित करें कि सभी सुविधाएँ ठीक से काम करती हैं
- **दस्तावेज़ीकरण अपडेट करें**: किसी भी कस्टम दस्तावेज़ीकरण को अपडेट करें

## अपग्रेड निर्देश {/* #upgrade-instructions */}

### संस्करण 0.6.x से {/* #from-version-06x */}
1. **अपने डेटा का बैकअप लें** (अपग्रेड के दौरान स्वचालित बैकअप बनाई गई)
2. **Docker छवि अपडेट करें**: `docker pull wsjbr/duplistatus:0.7.x`
3. **कंटेनर रीस्टार्ट करें**: `docker-compose down && docker-compose up -d`
4. **लॉग मॉनिटर करें**: `docker logs -f duplistatus`
5. **एकीकरण अपडेट करें**: API का उपयोग करने वाले किसी भी बाहरी टूल को अपडेट करें
6. **अपग्रेड सत्यापित करें**: जांचें कि सभी सुविधाएँ ठीक से काम करती हैं

### संस्करण 0.5.x या उससे पहले से {/* #from-version-05x-or-earlier */}
1. **पहले 0.6.x पर अपग्रेड करें** (यदि उपलब्ध हो)
2. **फिर ऊपर दिए गए चरणों का उपयोग करके 0.7.x पर अपग्रेड करें**
