# समय क्षेत्र {/* #timezone */}

एप्लिकेशन उपयोगकर्ता इंटरफ़ेस तिथि और समय ब्राउज़र की सेटिंग्स के अनुसार प्रदर्शित किया जाएगा। लॉगिंग अभी भी `TZ` पर्यावरण चर का उपयोग करता है। दैनिक सारांश सूचनाएं [सेटिंग्स → दैनिक सारांश](../user-guide/settings/daily-summary-settings.md) में सहेजे गए IANA समय क्षेत्र का उपयोग करती हैं, `TZ` नहीं। अन्य सूचना टाइमस्टैम्प जो दैनिक सारांश नहीं हैं, अभी भी `TZ` का पालन करते हैं।

यदि यह पर्यावरण चर सेट नहीं है तो डिफ़ॉल्ट मान `TZ=Europe/London` है।

:::note
सूचनाओं के लिए भाषा और स्थान सेटिंग्स (संख्या और तिथि प्रारूप) को [सेटिंग्स → टेम्पलेट](../user-guide/settings/notification-templates.md) में कॉन्फ़िगर किया जा सकता है।
:::

## समय क्षेत्र कॉन्फ़िगर करना {/* #configuring-the-timezone */}

एप्लिकेशन उपयोगकर्ता इंटरफ़ेस तिथि और समय ब्राउज़र की सेटिंग्स के अनुसार प्रदर्शित किया जाएगा। लॉगिंग अभी भी `TZ` पर्यावरण चर का उपयोग करता है। दैनिक सारांश सूचनाएं [सेटिंग्स → दैनिक सारांश](../user-guide/settings/daily-summary-settings.md) में सहेजे गए IANA समय क्षेत्र का उपयोग करती हैं, `TZ` नहीं। अन्य सूचना टाइमस्टैम्प जो दैनिक सारांश नहीं हैं, अभी भी `TZ` का पालन करते हैं।

यदि यह पर्यावरण चर सेट नहीं है तो डिफ़ॉल्ट मान `TZ=Europe/London` है।

उदाहरण के लिए, समय क्षेत्र को साओ पाउलो में बदलने के लिए, निर्देशिका `duplistatus` में `compose.yml` में ये पंक्तियां जोड़ें:

```yaml
environment:
  - TZ=America/Sao_Paulo
```

या कमांड लाइन (Docker या Podman) में पर्यावरण चर पास करें:

```bash
  --env TZ=America/Sao_Paulo
```

### अपनी Linux कॉन्फ़िगरेशन का उपयोग करना {/* #using-your-linux-configuration */}

अपने Linux होस्ट की कॉन्फ़िगरेशन प्राप्त करने के लिए, आप निष्पादित कर सकते हैं:

```bash
echo TZ=\"$(</etc/timezone)\"
```
