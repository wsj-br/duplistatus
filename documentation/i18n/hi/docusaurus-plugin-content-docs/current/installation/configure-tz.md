# समय क्षेत्र {#timezone}

अनुप्रयोग उपयोगकर्ता इंटरफ़ेस की तारीख और समय ब्राउज़र की सेटिंग्स के अनुसार प्रदर्शित की जाएगी। लॉगिंग अभी भी `TZ` पर्यावरण चर का उपयोग करती है। दैनिक सारांश सूचनाएं [सेटिंग्स → दैनिक सारांश](../user-guide/settings/daily-summary-settings.md) में सहेजी गई IANA समय क्षेत्र का उपयोग करती हैं, न कि `TZ`। अन्य सूचना टाइमस्टैम्प जो दैनिक सारांश नहीं हैं अभी भी `TZ` का पालन करती हैं।

यदि यह पर्यावरण चर सेट नहीं किया गया है, तो डिफ़ॉल्ट मान `TZ=Europe/London` होगा।

:::note
सूचनाओं के लिए भाषा और लोकल सेटिंग्स (संख्या और तिथि प्रारूप) [सेटिंग्स → टेम्प्लेट्स](../user-guide/settings/notification-templates.md) में कॉन्फ़िगर की जा सकती हैं।
:::

## समय क्षेत्र कॉन्फ़िगर करना {#configuring-the-timezone}

अनुप्रयोग उपयोगकर्ता इंटरफ़ेस की तारीख और समय ब्राउज़र की सेटिंग्स के अनुसार प्रदर्शित की जाएगी। लॉगिंग अभी भी `TZ` पर्यावरण चर का उपयोग करती है। दैनिक सारांश सूचनाएं [सेटिंग्स → दैनिक सारांश](../user-guide/settings/daily-summary-settings.md) में सहेजी गई IANA समय क्षेत्र का उपयोग करती हैं, न कि `TZ`। अन्य सूचना टाइमस्टैम्प जो दैनिक सारांश नहीं हैं अभी भी `TZ` का पालन करती हैं।

यदि यह पर्यावरण चर सेट नहीं किया गया है, तो डिफ़ॉल्ट मान `TZ=Europe/London` होगा।

उदाहरण के लिए, समय क्षेत्र को साओ पाउलो में बदलने के लिए, निम्न लाइनों को `compose.yml` में डायरेक्टरी `duplistatus` में जोड़ें:

```yaml
environment:
  - TZ=America/Sao_Paulo
```

या कमांड लाइन में पर्यावरण चर पास करें (डॉकर या पॉडमैन):

```bash
  --env TZ=America/Sao_Paulo
```

### अपनी लिनक्स कॉन्फ़िगरेशन का उपयोग करना {#using-your-linux-configuration}

अपनी लिनक्स होस्ट की कॉन्फ़िगरेशन प्राप्त करने के लिए, आप निम्नलिखित को निष्पादित कर सकते हैं:

```bash
echo TZ=\"$(</etc/timezone)\"
```
