# एनवायरनमेंट वैरियेबल्स {/* #environment-variables */}

कॉन्फ़िगरेशन के लिए एप्लिकेशन निम्नलिखित एनवायरनमेंट वैरियेबल्स का समर्थन करता है:

| वैरिएबल                  | विवरण                                                                                 | डिफ़ॉल्ट                    |
|---------------------------|---------------------------------------------------------------------------------------------|:---------------------------|
| `PORT`                    | मुख्य वेब एप्लिकेशन के लिए पोर्ट                                                           | `9666`                     |
| `CRON_PORT`               | क्रॉन सेवा (शेड्यूलिंग) के लिए पोर्ट। यदि सेट नहीं है, तो `PORT + 1` का उपयोग करता है                                      | `9667`                     |
| `CRON_BIND_HOST`          | वह पता जिस पर क्रॉन सेवा सुनती है। लूपबैक डिफ़ॉल्ट है ताकि कंट्रोल API एक्सपोज़ न हो।          | `127.0.0.1`                |
| `CRON_SERVICE_SECRET`     | जब सेवा लूपबैक से बाउंड नहीं होती है, तो क्रॉन-सर्विस रूट्स को म्यूटेट करने के लिए आवश्यक शेयर्ड सीक्रेट। Next.js प्रॉक्सी इसे `X-Cron-Service-Secret` के रूप में फ़ॉरवर्ड करता है। | अनसेट (यदि लूपबैक नहीं है तो आवश्यक) |
| `NODE_ENV`                | Node.js एनवायरनमेंट (`development` या `production`)                                         | `production`               |
| `NEXT_TELEMETRY_DISABLED` | Next.js टेलीमेट्री अक्षम करें (सभी Next.js स्क्रिप्ट्स पर और Docker में सेट)                        | `1`                        |
| `TZ`                      | एप्लिकेशन के लिए टाइमज़ोन                                                                | `Europe/London`            |
| `PWD_ENFORCE`             | पासवर्ड जटिलता आवश्यकताओं (अपरकेस, लोअरकेस, संख्याएं) को अक्षम करने के लिए `false` पर सेट करें। | लागू (पूर्ण सत्यापन) |
| `PWD_MIN_LEN`             | वर्णों में न्यूनतम पासवर्ड लंबाई (हमेशा लागू)                                    | `8`                        |
| `IP_TRUSTED_PROXIES`      | `X-Forwarded-For` सेट करने की अनुमति प्राप्त रिवर्स प्रॉक्सी के कॉमा-सेपरेटेड CIDR                   | अनसेट                      |
| `ADMIN_IP_ALLOWLIST_ENABLED` | एडमिन IP अनुमति सूची सक्षम फ़्लैग को ओवरराइड करें (`true` / `false`)                           | अनसेट (सेटिंग्स का उपयोग करें)       |
| `ADMIN_IP_ALLOWLIST`      | एडमिन इंटरफ़ेस के लिए कॉमा-सेपरेटेड CIDR                                               | अनसेट                      |
| `EXTERNAL_API_IP_ALLOWLIST_ENABLED` | बाहरी-API अनुमति सूची सक्षम फ़्लैग को ओवरराइड करें (`true` / `false`)                | अनसेट (सेटिंग्स का उपयोग करें)       |
| `EXTERNAL_API_IP_ALLOWLIST` | `/api/upload`, `/api/summary` और `/api/lastbackup*` के लिए कॉमा-सेपरेटेड CIDR           | अनसेट                      |
| `DUPLISTATUS_PUBLIC_URL`    | duplistatus वेब UI का सार्वजनिक बेस URL (कोई अंतिम स्लैश नहीं)। सेट होने पर, यह सेटिंग्स → दैनिक सारांश **सार्वजनिक डैशबोर्ड URL** को ओवरराइड करता है और दैनिक सारांश ईमेल में `{duplistatus_link}` शामिल होता है। अनसेट होने पर, सहेजी गई सेटिंग का उपयोग किया जाता है; यदि वह भी खाली है, तो कोई डैशबोर्ड लिंक नहीं जोड़ा जाता है। | अनसेट                      |

`NEXT_TELEMETRY_DISABLED=1` Docker इमेज द्वारा और `pnpm build`, `pnpm build-local`, `pnpm start`, `pnpm start-local` और `pnpm dev` द्वारा सेट किया गया है, ताकि Next.js अज्ञात CLI टेलीमेट्री एकत्र न करे। नए डेवलपमेंट एनवायरनमेंट का उपयोग करते समय या सोर्स से कंपाइल करते समय, अपने उपयोगकर्ता कॉन्फ़िग में भी ऑप्ट-आउट को बनाए रखने के लिए, `npx next telemetry disable` चलाएं।
