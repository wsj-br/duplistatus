# पर्यावरण चर {/* #environment-variables */}

यह अनुप्रयोग कॉन्फ़िगरेशन के लिए निम्नलिखित पर्यावरण चर का समर्थन करता है:

| चर                       | विवरण                                                                                     | डिफ़ॉल्ट                   |
|---------------------------|-------------------------------------------------------------------------------------------|:---------------------------|
| `PORT`                    | मुख्य वेब अनुप्रयोग के लिए पोर्ट                                                           | `9666`                     |
| `CRON_PORT`               | क्रोन सेवा (शेड्यूलिंग) के लिए पोर्ट। यदि सेट नहीं किया गया है, तो `PORT + 1` का उपयोग करता है।                                      | `9667`                     |
| `CRON_BIND_HOST`          | वह पता जिस पर क्रोन सेवा सुनती है। लूपबैक डिफ़ॉल्ट है ताकि नियंत्रण एपीआई उजागर न हो।          | `127.0.0.1`                |
| `CRON_SERVICE_SECRET`     | साझा रहस्य जो क्रोन-सेवा रूट को परिवर्तित करने के लिए आवश्यक है जब सेवा लूपबैक से बंधी नहीं होती है। Next.js प्रॉक्सी इसे `X-Cron-Service-Secret` के रूप में अग्रेषित करती है। | unset (लूपबैक नहीं होने पर आवश्यक) |
| `NODE_ENV`                | Node.js वातावरण (`development` या `production`)                                         | `production`               |
| `NEXT_TELEMETRY_DISABLED` | Next.js टेलीमेट्री को अक्षम करें (सभी Next.js स्क्रिप्ट और Docker में सेट करें)                        | `1`                        |
| `TZ`                      | अनुप्रयोग के लिए समय क्षेत्र                                                                | `Europe/London`            |
| `PWD_ENFORCE`             | पासवर्ड जटिलता आवश्यकताओं (बड़े अक्षर, छोटे अक्षर, संख्याएँ) को अक्षम करने के लिए `false` पर सेट करें। | लागू (पूर्ण सत्यापन) |
| `PWD_MIN_LEN`             | वर्णों में न्यूनतम पासवर्ड लंबाई (हमेशा लागू)                                            | `8`                        |
| `IP_TRUSTED_PROXIES`      | कॉमा से पृथक CIDRs जो `X-Forwarded-For` सेट करने की अनुमति देते हैं                   | unset                      |
| `ADMIN_IP_ALLOWLIST_ENABLED` | व्यवस्थापक आईपी अनुमति सूची सक्षम ध्वज को ओवरराइड करें (`true` / `false`)                           | unset (सेटिंग्स का उपयोग करें)       |
| `ADMIN_IP_ALLOWLIST`      | व्यवस्थापक इंटरफेस के लिए कॉमा से पृथक CIDRs                                               | unset                      |
| `EXTERNAL_API_IP_ALLOWLIST_ENABLED` | बाहरी-एपीआई अनुमति सूची सक्षम ध्वज को ओवरराइड करें (`true` / `false`)                | unset (सेटिंग्स का उपयोग करें)       |
| `EXTERNAL_API_IP_ALLOWLIST` | `/api/upload`, `/api/summary`, और `/api/lastbackup*` के लिए कॉमा से पृथक CIDRs           | unset                      |
| `DUPLISTATUS_PUBLIC_URL`    | डुप्लिकेट स्थिति वेब UI का सार्वजनिक आधार URL (कोई ट्रेलिंग स्लैश नहीं)। जब सेट किया जाता है, तो यह सेटिंग्स → दैनिक सारांश **सार्वजनिक डैशबोर्ड यूआरएल** और दैनिक सारांश ईमेल में `{duplistatus_link}` को ओवरराइड करता है। जब unset होता है, तो सहेजी गई सेटिंग का उपयोग किया जाता है; यदि वह भी खाली है, तो कोई डैशबोर्ड लिंक नहीं जोड़ा जाता। | unset                      |

`NEXT_TELEMETRY_DISABLED=1` Docker इमेज और `pnpm build`, `pnpm build-local`, `pnpm start`, `pnpm start-local`, और `pnpm dev` द्वारा सेट किया जाता है, इसलिए Next.js अनाम CLI टेलीमेट्री संग्रहित नहीं करता है। नए विकास वातावरण का उपयोग करते समय या स्रोत से संकलित करते समय, अपने उपयोक्ता कॉन्फ़िग में ऑप्ट-आउट को भी संरक्षित करें, और `npx next telemetry disable` चलाएँ।
