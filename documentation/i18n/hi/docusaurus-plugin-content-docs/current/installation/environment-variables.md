# पर्यावरण चर {/* #environment-variables */}

कॉन्फ़िगरेशन के लिए एप्लिकेशन निम्नलिखित पर्यावरण चर का समर्थन करता है:

| चर                       | विवरण                                                                                      | डिफ़ॉल्ट                   |
|---------------------------|---------------------------------------------------------------------------------------------|:---------------------------|
| `PORT`                    | मुख्य वेब एप्लिकेशन के लिए पोर्ट                                                            | `9666`                     |
| `CRON_PORT`               | क्रॉन सेवा (शेड्यूलिंग) के लिए पोर्ट। यदि सेट नहीं है, तो `PORT + 1` का उपयोग करता है                                      | `9667`                     |
| `CRON_BIND_HOST`          | पता जहां क्रॉन सेवा सुनती है। लूपबैक डिफ़ॉल्ट है ताकि नियंत्रण एपीआई एक्सपोज़ न हो।          | `127.0.0.1`                |
| `CRON_SERVICE_SECRET`     | क्रॉन-सेवा रूट्स को बदलने के लिए आवश्यक साझा रहस्य जब सेवा लूपबैक पर बाउंड नहीं है। नेक्स्ट.जेएस प्रॉक्सी इसे `X-Cron-Service-Secret` के रूप में फॉरवर्ड करता है। | सेट नहीं है (यदि लूपबैक नहीं है तो आवश्यक) |
| `NODE_ENV`                | नोड.जेएस वातावरण (`development` या `production`)                                         | `production`               |
| `NEXT_TELEMETRY_DISABLED` | नेक्स्ट.जेएस टेलीमेट्री अक्षम करें (सभी नेक्स्ट.जेएस स्क्रिप्ट्स और डॉकर में सेट किया गया)                        | `1`                        |
| `TZ`                      | एप्लिकेशन के लिए समय क्षेत्र                                                                | `Europe/London`            |
| `PWD_ENFORCE`             | `false` पर सेट करें ताकि पासवर्ड जटिलता आवश्यकताओं (अपरकेस, लोअरकेस, संख्याएं) को अक्षम किया जा सके। | लागू (पूर्ण सत्यापन) |
| `PWD_MIN_LEN`             | वर्णों में न्यूनतम पासवर्ड लंबाई (हमेशा लागू)                                    | `8`                        |
| `IP_TRUSTED_PROXIES`      | रिवर्स प्रॉक्सीज़ के अल्पविराम से अलग किए गए सीआईडीआर जिन्हें `X-Forwarded-For` सेट करने की अनुमति है                   | सेट नहीं है                      |
| `ADMIN_IP_ALLOWLIST_ENABLED` | एडमिन आईपी अनुमति सूची सक्षम फ्लैग को ओवरराइड करें (`true` / `false`)                           | सेट नहीं है (सेटिंग्स का उपयोग करें)       |
| `ADMIN_IP_ALLOWLIST`      | एडमिन इंटरफ़ेस के लिए अल्पविराम से अलग किए गए सीआईडीआर                                               | सेट नहीं है                      |
| `EXTERNAL_API_IP_ALLOWLIST_ENABLED` | बाहरी एपीआई अनुमति सूची सक्षम फ्लैग को ओवरराइड करें (`true` / `false`)                | सेट नहीं है (सेटिंग्स का उपयोग करें)       |
| `EXTERNAL_API_IP_ALLOWLIST` | `/api/upload`, `/api/summary`, और `/api/lastbackup*` के लिए अल्पविराम से अलग किए गए सीआईडीआर           | सेट नहीं है                      |
| `DUPLISTATUS_PUBLIC_URL`    | डुप्लिस्टैटस वेब यूआई का सार्वजनिक आधार यूआरएल (कोई ट्रेलिंग स्लैश नहीं)। जब सेट किया जाता है, तो सेटिंग्स → दैनिक सारांश **सार्वजनिक डैशबोर्ड यूआरएल** और दैनिक सारांश ईमेल शामिल करता है `{duplistatus_link}`। जब सेट नहीं किया जाता है, तो सहेजी गई सेटिंग का उपयोग किया जाता है; यदि वह भी खाली है, तो कोई डैशबोर्ड लिंक नहीं जोड़ा जाता है। | सेट नहीं है                      |

`NEXT_TELEMETRY_DISABLED=1` को डॉकर इमेज और `pnpm build`, `pnpm build-local`, `pnpm start`, `pnpm start-local`, और `pnpm dev` द्वारा सेट किया गया है, इसलिए नेक्स्ट.जेएस कोई अनाम सीएलआई टेलीमेट्री एकत्र नहीं करता है। जब नए विकास वातावरण का उपयोग कर रहे हों या स्रोत से कंपाइल कर रहे हों, तो अपने उपयोगकर्ता कॉन्फ़िग में ऑप्ट-आउट को भी बनाए रखें, `npx next telemetry disable` चलाएं।
