# duplistatus - कई [Duplicati के](https://github.com/duplicati/duplicati) सर्वर की निगरानी करें {/* #duplistatus----monitor-multiple-duplicatishttpsgithubcomduplicatiduplicati-servers */}

![संस्करण](https://img.shields.io/badge/version-{VERSION}-blue) 
[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?logo=github)](https://github.com/wsj-br/duplistatus)

<br/>

यह वेब एप्लिकेशन [Duplicati](https://github.com/duplicati/duplicati) से बैकअप संचालन की निगरानी और विज़ुअलाइज़ेशन करता है। **duplistatus** कई सर्वर पर बैकअप स्थितियों को ट्रैक करने, बकाया बैकअप की सूचना देने, कार्य इतिहास,
मेट्रिक्स और प्रदर्शन के लिए एक व्यापक डैशबोर्ड प्रदान करता है।

Docker, Podman, या Portainer के साथ तैनात (डिप्लॉय) करना आसान है और 7 भाषाओं (अंग्रेज़ी, जर्मन, फ्रेंच, स्पैनिश, पुर्तगाली, हिंदी और सरलीकृत चीनी) में उपलब्ध है, साथ ही प्रत्येक भाषा में संपूर्ण दस्तावेज़ीकरण भी मौजूद है।
