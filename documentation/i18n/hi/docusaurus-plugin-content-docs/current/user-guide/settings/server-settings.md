# सर्वर {/* #server */}

आप अपने सर्वर के लिए एक वैकल्पिक नाम (उपनाम), इसके कार्य का वर्णन करने के लिए एक नोट और अपने Duplicati सर्वर के वेब पते यहां कॉन्फ़िगर कर सकते हैं।

![सर्वर सेटिंग्स](../../assets/screen-settings-server.png)

| सेटिंग                         | विवरण                                                                                                                                                                                  |
|:--------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **सर्वर नाम**                 | Duplicati सर्वर में कॉन्फ़िगर किया गया सर्वर नाम। यदि सर्वर के लिए पासवर्ड सेट किया गया है तो एक <IIcon2 icon="lucide:key-round" color="#42A5F5"/> प्रकट होगा।                                         |
| **उपनाम**                       | आपके सर्वर का एक उपनाम या मानव-पठनीय नाम। जब किसी उपनाम पर होवर किया जाता है तो यह इसका नाम दिखाएगा; कुछ मामलों में स्पष्ट करने के लिए यह कोष्ठकों के बीच उपनाम और नाम दिखाएगा। |
| **नोट**                        | सर्वर कार्यशीलता, स्थापना स्थान या कोई अन्य जानकारी का वर्णन करने के लिए मुक्त पाठ। जब कॉन्फ़िगर किया जाता है, तो यह सर्वर के नाम या उपनाम के बगल में प्रदर्शित किया जाएगा।                 |
| **संस्करण**                     | नवीनतम बैकअप लॉग से Duplicati संस्करण, [डैशबोर्ड](../dashboard.md#duplicati-server-version) के समान रंग और टूलटिप के साथ। म्यूटेड पाठ वर्तमान या अनुपलब्ध है; चेतावनी पीला पुराना है। |
| **वेब इंटरफ़ेस पता (URL)** | Duplicati सर्वर के UI तक पहुंचने के लिए URL कॉन्फ़िगर करें। `HTTP` और `HTTPS` दोनों URLs समर्थित हैं।                                                                                           |
| **स्थिति**                      | जांच या बैकअप लॉग एकत्र करने के परिणाम प्रदर्शित करें                                                                                                                                              |
| **कार्रवाइयाँ**                     | आप जांच सकते हैं, Duplicati इंटरफ़ेस खोल सकते हैं, लॉग एकत्र कर सकते हैं और पासवर्ड सेट कर सकते हैं, अधिक विवरण के लिए नीचे देखें।                                                                                         |

<br/>

:::note
यदि वेब इंटरफ़ेस पता (URL) कॉन्फ़िगर नहीं है, तो <SvgIcon svgFilename="duplicati_logo.svg" /> बटन 
सभी पृष्ठों में अक्षम हो जाएगा और सर्वर [Duplicati कॉन्फ़िगरेशन](../duplicati-configuration.md) <SvgButton svgFilename="duplicati_logo.svg" href="../duplicati-configuration"/> सूची में दिखाया नहीं जाएगा।
:::

## प्रत्येक सर्वर के लिए उपलब्ध कार्रवाइयाँ {/* #available-actions-for-each-server */}

| बटन                                                                                                      | विवरण                                                             |
|:------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------|
| <IconButton icon="lucide:play" label="जाँचें"/>                                                               | Duplicati सर्वर से कनेक्शन की जांच करें।                            |
| <SvgButton svgFilename="duplicati_logo.svg" />                                                              | एक नए ब्राउज़र टैब में Duplicati सर्वर का वेब इंटरफ़ेस खोलें।         |
| <IconButton icon="lucide:download" />                                                                       | Duplicati सर्वर से बैकअप लॉग एकत्र करें।                          |
| <IconButton icon="lucide:rectangle-ellipsis" /> &nbsp; या <IIcon2 icon="lucide:key-round" color="#42A5F5"/> | एकत्रित बैकअप के लिए Duplicati सर्वर के लिए पासवर्ड बदलें या सेट करें। |

<br/>

:::info[महत्वपूर्ण]

आपकी सुरक्षा की रक्षा के लिए, आप केवल निम्नलिखित कार्रवाइयाँ कर सकते हैं:
- सर्वर के लिए पासवर्ड सेट करें
- पासवर्ड को पूरी तरह से हटा (मिटा) दें
 
पासवर्ड को डेटाबेस में एन्क्रिप्ट किया गया है और उपयोगकर्ता इंटरफ़ेस में कभी भी प्रदर्शित नहीं किया जाता है।
:::
