# सर्वर {/* #server */}

आप यहां अपने सर्वर के लिए एक वैकल्पिक नाम (उपनाम), इसके कार्य का विवरण देने के लिए एक नोट और अपने Duplicati सर्वर के वेब पते कॉन्फ़िगर कर सकते हैं।

![सर्वर सेटिंग्स](../../assets/screen-settings-server.png)

| सेटिंग                         | विवरण                                                                                                                                                                                  |
|:--------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **सर्वर नाम**                 | Duplicati सर्वर में कॉन्फ़िगर किया गया सर्वर नाम। यदि सर्वर के लिए कोई पासवर्ड सेट किया गया है, तो <IIcon2 icon="lucide:key-round" color="#42A5F5"/> दिखाई देगा।                                         |
| **उपनाम**                       | आपके सर्वर का एक उपनाम या आसानी से पढ़ा जाने वाला नाम। किसी उपनाम पर कर्सर ले जाने पर यह इसका नाम दिखाएगा; कुछ मामलों में इसे स्पष्ट करने के लिए यह उपनाम और कोष्ठक के बीच नाम प्रदर्शित करेगा। |
| **नोट**                        | सर्वर की कार्यक्षमता, स्थापना स्थल या किसी अन्य जानकारी का विवरण देने के लिए मुक्त पाठ। कॉन्फ़िगर किए जाने पर, यह सर्वर के नाम या उपनाम के बगल में प्रदर्शित होगा।                 |
| **संस्करण**                     | नवीनतम बैकअप लॉग से Duplicati संस्करण, [डैशबोर्ड](../dashboard.md#duplicati-server-version) के समान रंग और टूलटिप के साथ। म्यूट किया गया पाठ वर्तमान या अनुपलब्ध है; चेतावनी पीला पुराना है। |
| **वेब इंटरफ़ेस पता (URL)** | Duplicati सर्वर के UI तक पहुँचने के लिए URL कॉन्फ़िगर करें। `HTTP` और `HTTPS` दोनों URL समर्थित हैं।                                                                                           |
| **स्थिति**                      | जाँच या बैकअप लॉग एकत्र करने के परिणाम प्रदर्शित करता है                                                                                                                                              |
| **कार्रवाइयाँ**                     | आप जाँच कर सकते हैं, Duplicati इंटरफ़ेस खोल सकते हैं, लॉग एकत्र कर सकते हैं और पासवर्ड सेट कर सकते हैं, अधिक विवरण के लिए नीचे देखें।                                                                                         |

<br/>

:::note
यदि वेब इंटरफ़ेस पता (URL) कॉन्फ़िगर नहीं है, तो <SvgIcon svgFilename="duplicati_logo.svg" /> बटन 
सभी पृष्ठों में अक्षम रहेगा और सर्वर [Duplicati कॉन्फ़िगरेशन](../duplicati-configuration.md) <SvgButton svgFilename="duplicati_logo.svg" href="../duplicati-configuration"/>  सूची में नहीं दिखाया जाएगा।
:::

## प्रत्येक सर्वर के लिए उपलब्ध कार्रवाइयाँ {/* #available-actions-for-each-server */}

| बटन                                                                                                      | विवरण                                                             |
|:------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------|
| <IconButton icon="lucide:play" label="जाँचें"/>                                                               | Duplicati सर्वर से कनेक्शन की जाँच करें।                            |
| <SvgButton svgFilename="duplicati_logo.svg" />                                                              | Duplicati सर्वर के वेब इंटरफ़ेस को एक नए ब्राउज़र टैब में खोलें।         |
| <IconButton icon="lucide:download" />                                                                       | Duplicati सर्वर से बैकअप लॉग एकत्र करें।                          |
| <IconButton icon="lucide:rectangle-ellipsis" /> &nbsp; या <IIcon2 icon="lucide:key-round" color="#42A5F5"/> | एकत्रित बैकअप के लिए Duplicati सर्वर का पासवर्ड बदलें या सेट करें। |

<br/>

:::info[महत्वपूर्ण]

अपनी सुरक्षा की रक्षा के लिए, आप केवल निम्नलिखित कार्रवाइयाँ कर सकते हैं:
- सर्वर के लिए पासवर्ड सेट करें
- पासवर्ड को पूरी तरह से निकालें (हटाएं)
 
पासवर्ड डेटाबेस में एन्क्रिप्टेड संग्रहीत होता है और उपयोगकर्ता इंटरफ़ेस में कभी नहीं दिखाया जाता है।
:::
