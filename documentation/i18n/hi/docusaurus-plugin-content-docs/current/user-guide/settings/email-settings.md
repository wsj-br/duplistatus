# ईमेल {/* #email */}

**duplistatus** NTFY सूचनाएं के विकल्प या पूरक के रूप में SMTP के ज़रिए ईमेल सूचनाएं भेजने का समर्थन करता है। बेहतर सुरक्षा के लिए डेटाबेस में एन्क्रिप्टेड संग्रहण के साथ अब ईमेल कॉन्फ़िगरेशन वेब इंटरफ़ेस के माध्यम से प्रबंधित किया जाता है।

![ईमेल कॉन्फ़िगरेशन](../../assets/screen-settings-email.png)

| Setting                 | Description                                                      |
|:------------------------|:-----------------------------------------------------------------|
| **SMTP Server Host**    | आपके ईमेल प्रदाता का SMTP सर्वर (उदा., `smtp.gmail.com`)।      |
| **SMTP Server Port**    | पोर्ट संख्या (आमतौर पर प्लेन SMTP के लिए `25`, STARTTLS के लिए `587`, या डायरेक्ट SSL/TLS के लिए `465`)। |
| **Connection Type**     | प्लेन SMTP, STARTTLS, या डायरेक्ट SSL/TLS में से चुनें। नए कॉन्फ़िगरेशन के लिए डिफ़ॉल्ट रूप से डायरेक्ट SSL/TLS पर सेट होता है। |
| **SMTP Authentication** | SMTP प्रमाणीकरण को सक्षम या अक्षम करने के लिए टॉगल करें। अक्षम होने पर, उपयोगकर्ता नाम और पासवर्ड फ़ील्ड आवश्यक नहीं होते हैं। |
| **SMTP Username**       | आपका ईमेल पता या उपयोगकर्ता नाम (प्रमाणीकरण सक्षम होने पर आवश्यक)। |
| **SMTP Password**       | आपका ईमेल पासवर्ड या ऐप-विशिष्ट पासवर्ड (प्रमाणीकरण सक्षम होने पर आवश्यक)। |
| **Sender Name**         | ईमेल सूचनाओं में प्रेषक के रूप में प्रदर्शित नाम (वैकल्पिक, डिफ़ॉल्ट रूप से "duplistatus")। |
| **From Address**        | प्रेषक के रूप में दिखाया गया ईमेल पता। प्लेन SMTP कनेक्शन के लिए या प्रमाणीकरण अक्षम होने पर आवश्यक। प्रमाणीकरण सक्षम होने पर डिफ़ॉल्ट रूप से SMTP उपयोगकर्ता नाम पर सेट होता है। ध्यान दें कि कुछ ईमेल प्रदाता `From Address` को `SMTP Server Username` से ओवरराइड कर देंगे। |
| **Recipient Email**     | सूचनाएं प्राप्त करने के लिए ईमेल पता। यह एक मान्य ईमेल पता प्रारूप होना चाहिए। |

साइडबार में **Email** के बगल में एक <IIcon2 icon="lucide:mail" color="green"/> हरा आइकन इंगित करता है कि आपकी सेटिंग्स मान्य हैं। यदि आइकन <IIcon2 icon="lucide:mail" color="yellow"/> पीला है, तो आपकी सेटिंग्स मान्य नहीं हैं या कॉन्फ़िगर नहीं है।

जब सभी आवश्यक फ़ील्ड सेट होते हैं, तो आइकन हरा दिखाई देता है: SMTP Server Host, SMTP Server Port, Recipient Email, और या तो (प्रमाणीकरण आवश्यक होने पर SMTP Username + Password) या (प्रमाणीकरण आवश्यक न होने पर From Address)।

जब कॉन्फ़िगरेशन पूरी तरह से कॉन्फ़िगर नहीं होता है, तो एक पीला चेतावनी बॉक्स प्रदर्शित होता है जो आपको सूचित करता है कि जब तक ईमेल सेटिंग्स सही ढंग से नहीं भरी जाती हैं, तब तक कोई ईमेल नहीं भेजा जाएगा। [बैकअप सूचनाएं](backup-notifications-settings.md) टैब में ईमेल चेकबॉक्स भी धूसर (ग्रे) हो जाएंगे और "(disabled)" लेबल दिखाएंगे।

## सामान्य SMTP प्रदाता {/* #common-smtp-providers */}

**Gmail:**

- होस्ट: `smtp.gmail.com`
- पोर्ट: `587` (STARTTLS) या `465` (डायरेक्ट SSL/TLS)
- कनेक्शन प्रकार: पोर्ट 587 के लिए STARTTLS, पोर्ट 465 के लिए डायरेक्ट SSL/TLS
- उपयोगकर्ता नाम: आपका Gmail पता
- पासवर्ड: ऐप पासवर्ड का उपयोग करें (अपना सामान्य पासवर्ड नहीं)। https://myaccount.google.com/apppasswords पर एक पासवर्ड जनरेट करें
- प्रमाणीकरण: आवश्यक

**Outlook/Hotmail:**

- होस्ट: `smtp-mail.outlook.com`
- पोर्ट: `587`
- कनेक्शन प्रकार: STARTTLS
- उपयोगकर्ता नाम: आपका Outlook ईमेल पता
- पासवर्ड: आपके खाते का पासवर्ड
- प्रमाणीकरण: आवश्यक

**Yahoo Mail:**

- होस्ट: `smtp.mail.yahoo.com`
- पोर्ट: `587`
- कनेक्शन प्रकार: STARTTLS
- उपयोगकर्ता नाम: आपका Yahoo ईमेल पता
- पासवर्ड: ऐप पासवर्ड का उपयोग करें
- प्रमाणीकरण: आवश्यक

### सुरक्षा सर्वोत्तम अभ्यास {/* #security-best-practices */}

- सूचनाएं के लिए एक समर्पित ईमेल खाते का उपयोग करने पर विचार करें
 - "परीक्षण ईमेल भेजें" बटन का उपयोग करके अपने कॉन्फ़िगरेशन को जाँचें
 - सेटिंग्स एन्क्रिप्टेड हैं और डेटाबेस में सुरक्षित रूप से संग्रहीत हैं
 - **एन्क्रिप्टेड कनेक्शन का उपयोग करें** - प्रोडक्शन में उपयोग के लिए STARTTLS और डायरेक्ट SSL/TLS की अनुशंसा की जाती है
 - प्लेन SMTP कनेक्शन (पोर्ट 25) विश्वसनीय स्थानीय नेटवर्क के लिए उपलब्ध हैं लेकिन अविश्वसनीय नेटवर्क पर प्रोडक्शन उपयोग के लिए अनुशंसित नहीं हैं
