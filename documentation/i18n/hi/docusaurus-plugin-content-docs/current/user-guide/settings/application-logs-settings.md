# एप्लिकेशन लॉग {/* #application-logs */}

एप्लिकेशन लॉग व्यूअर व्यवस्थापकों को वेब इंटरफेस से सीधे एक ही स्थान पर सभी एप्लिकेशन लॉग की निगरानी करने की अनुमति देता है, जिसमें फ़िल्टरिंग, निर्यात और वास्तविक समय अद्यतन शामिल हैं।

![एप्लिकेशन लॉग व्यूअर](../../assets/screen-settings-application-logs.png)

<br/>

## उपलब्ध कार्रवाइयाँ {/* #available-actions */}

| बटन | विवरण |
|:--------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------|
| <IconButton icon="lucide:refresh-cw" label="ताज़ा करें" /> | चयनित फ़ाइल से मैन्युअल रूप से लॉग पुनः लोड करें। ताज़ा करते समय लोडिंग स्पिनर दिखाता है और नई लाइन का पता लगाने के लिए ट्रैकिंग रीसेट करता है। |
| <IconButton icon="lucide:copy" label="क्लिपबोर्ड पर कॉपी करें" /> | अपने क्लिपबोर्ड पर सभी फ़िल्टर किए गए लॉग लाइन कॉपी करें। वर्तमान खोज फ़िल्टर का सम्मान करता है। त्वरित साझाकरण या अन्य उपकरणों में पेस्ट करने के लिए उपयोगी। |
| <IconButton icon="lucide:download" label="निर्यात करें" /> | लॉग को टेक्स्ट फ़ाइल के रूप में डाउनलोड करें। वर्तमान में चयनित फ़ाइल संस्करण से निर्यात करता है और वर्तमान खोज फ़िल्टर लागू करता है (यदि कोई हो)। फ़ाइल नाम प्रारूप: `duplistatus-logs-YYYY-MM-DD.txt` (ISO प्रारूप में तिथि)। |
| <IconButton icon="lucide:arrow-down-from-line" /> | प्रदर्शित लॉग की शुरुआत पर जल्दी से जाएँ। उपयोगी जब ऑटो-स्क्रॉल अक्षम हो या लंबी लॉग फ़ाइल के माध्यम से नेविगेट करते समय। |
| <IconButton icon="lucide:arrow-down-to-line" /> | प्रदर्शित लॉग के अंत पर जल्दी से जाएँ। उपयोगी जब ऑटो-स्क्रॉल अक्षम हो या लंबी लॉग फ़ाइल के माध्यम से नेविगेट करते समय। |

<br/>

## नियंत्रण और फ़िल्टर {/* #controls-and-filters */}

| नियंत्रण | विवरण |
|:--------|:-----------|
| **फ़ाइल संस्करण** | देखने के लिए लॉग फ़ाइल का चयन करें: **वर्तमान** (सक्रिय फ़ाइल) या घुमाए गए फ़ाइल (`.1`, `.2`, आदि., जहां उच्च संख्या पुरानी है)। |
| **दिखाई जाने वाली पंक्तियां** | चयनित फ़ाइल से सबसे हाल की **100**, **500**, **1000** (डिफ़ॉल्ट), **5000**, या **10000** पंक्तियां प्रदर्शित करें। |
| **ऑटो-स्क्रॉल** | जब सक्षम (वर्तमान फ़ाइल के लिए डिफ़ॉल्ट) हो, तो स्वचालित रूप से नए लॉग प्रविष्टियों पर स्क्रॉल करें और हर 2 सेकंड में ताज़ा करें। केवल **वर्तमान** फ़ाइल संस्करण के लिए काम करता है। |
| **खोजें** | पाठ द्वारा लॉग लाइन फ़िल्टर करें (अक्षर संवेदनशील नहीं)। फ़िल्टर वर्तमान में प्रदर्शित लाइन पर लागू होता है। |

<br/>

लॉग प्रदर्शन शीर्षलेख फ़िल्टर किए गए लाइन गिनती, कुल लाइन, फ़ाइल आकार और अंतिम संशोधित टाइमस्टैम्प दिखाता है।
