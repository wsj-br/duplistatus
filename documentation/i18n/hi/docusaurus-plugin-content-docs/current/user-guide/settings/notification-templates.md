# टेम्पलेट {/* #templates */}

**duplistatus** सूचना संदेशों के लिए चार टेम्पलेट का उपयोग करता है। ईमेल निकाय मार्कडाउन (शीर्षक, सूचियाँ, लिंक और तालिकाएँ) हैं। सफलता, चेतावनी/त्रुटि और अतिदेय के लिए NTFY एक ही मार्कडाउन निकाय का उपयोग करता है, जिसे `Markdown: yes` के साथ भेजा जाता है ताकि ntfy क्लाइंट इसे प्रस्तुत कर सकें। कोई भी जीएफएम तालिका अपनी शीर्षक पंक्ति को छोड़ देती है और निकाय को सादा पाठ के रूप में भेजती है, क्योंकि ntfy तालिकाओं को प्रस्तुत नहीं करता है। दैनिक सारांश केवल ईमेल के लिए है।

पृष्ठ में एक **टेम्पलेट की भाषा** चयनकर्ता शामिल है जो डिफ़ॉल्ट टेम्पलेट के लिए स्थान को सेट करता है। भाषा बदलने से नए डिफ़ॉल्ट के लिए स्थान अपडेट हो जाता है, लेकिन यह मौजूदा टेम्पलेट के पाठ को **नहीं** बदलता है। अपने टेम्पलेट पर एक नई भाषा लागू करने के लिए, उन्हें मैन्युअल रूप से संपादित करें या **इस टेम्पलेट को डिफ़ॉल्ट पर रीसेट करें** (वर्तमान टैब के लिए) या **सभी को डिफ़ॉल्ट पर रीसेट करें** (सभी टेम्पलेट के लिए) का उपयोग करें।

![अधिसूचना टेम्पलेट](../../assets/screen-settings-templates.png)

| टेम्पलेट | विवरण |
| :----------------- | :-------------------------------------------------- |
| **सफलता** | जब बैकअप सफलतापूर्वक पूरा होता है तो उपयोग किया जाता है। |
| **चेतावनी/त्रुटि** | जब बैकअप चेतावनियों या त्रुटियों के साथ पूरा होता है तो उपयोग किया जाता है। |
| **अतिदेय बैकअप** | जब बैकअप अतिदेय होते हैं तो उपयोग किया जाता है। |
| **दैनिक सारांश** | वैकल्पिक दैनिक स्नैपशॉट के लिए मार्कडाउन ईमेल टेम्पलेट। |

## टेम्पलेट भाषा {/* #template-language */}

पृष्ठ के शीर्ष पर एक **टेम्पलेट भाषा** चयनकर्ता आपको डिफ़ॉल्ट टेम्पलेट के लिए भाषा चुनने देता है (अंग्रेजी, जर्मन, फ्रेंच, स्पेनिश, पुर्तगाली, हिंदी और सरलीकृत चीनी)। भाषा बदलने से डिफ़ॉल्ट के लिए स्थानीय अपडेट हो जाता है, लेकिन मौजूदा अनुकूलित टेम्पलेट अपना वर्तमान पाठ बनाए रखते हैं जब तक आप उन्हें अपडेट नहीं करते या रीसेट बटन में से किसी एक का उपयोग नहीं करते।

## चर {/* #variables */}

ईमेल निकाय मार्कडाउन हैं। शीर्षक, सूचियाँ, लिंक और तालिकाएँ समर्थित हैं। प्लेसहोल्डर मानों को एस्केप्ड पाठ के रूप में डाला जाता है और वे मार्कडाउन या एचटीएमएल प्रस्तुत नहीं कर सकते। अब अनुकूलित टेम्पलेट में पहले से एम्बेडेड रॉ एचटीएमएल को एस्केप कर दिया गया है। एनटीएफवाई को एक ही मार्कडाउन प्राप्त होता है, सिवाय जीएफएम तालिकाओं के: शीर्षक पंक्ति छोड़ दी जाती है और निकाय पंक्तियों को किसी भी स्तंभ लेआउट के लिए सादा पाठ के रूप में भेजा जाता है।

डिफ़ॉल्ट सफलता, चेतावनी/त्रुटि और अतिदेय निकाय दैनिक सारांश के समान मार्कडाउन शैली का उपयोग करते हैं: एक शीर्षक, बोल्ड मान और एक अवलोकन तालिका। लोड पर अपरिवर्तित संग्रहीत डिफ़ॉल्ट अपग्रेड किए जाते हैं; अनुकूलित टेम्पलेट बनाए रखे जाते हैं।

सभी सफलता, चेतावनी/त्रुटि और अतिदेय टेम्पलेट चर का समर्थन करते हैं जिन्हें वास्तविक मानों से प्रतिस्थापित किया जाएगा। निम्नलिखित तालिका उपलब्ध चर दिखाती है:

| चर | विवरण | उपलब्ध है | 
|:-----------------------|:------------------------------------------------|:-----------------|
| `{server_name}` | सर्वर का नाम। | सफलता, चेतावनी, अतिदेय |
| `{server_alias}` | सर्वर का उपनाम। | सफलता, चेतावनी, अतिदेय |
| `{server_note}`        | सर्वर के लिए नोट।                              | Success, Warning, Overdue |
| `{server_url}`         | Duplicati सर्वर वेब कॉन्फ़िगरेशन का URL         | Success, Warning, Overdue |
| `{backup_name}`        | बैकअप का नाम।                                   | Success, Warning, Overdue |
| `{status}`             | बैकअप स्थिति (Success, Warning, Error, Fatal)।   | Success, Warning |
| `{backup_date}`        | बैकअप की तिथि और समय।                          | Success, Warning |
| `{duration}`           | बैकअप की अवधि।                                  | Success, Warning |
| `{uploaded_size}`      | अपलोड किए गए डेटा की मात्रा।                   | Success, Warning |
| `{storage_size}`       | संग्रहण उपयोग जानकारी।                        | Success, Warning |
| `{available_versions}` | उपलब्ध बैकअप संस्करणों की संख्या।              | Success, Warning |
| `{file_count}`         | संसाधित फ़ाइलों की संख्या।                     | Success, Warning |
| `{file_size}`          | बैकअप की गई फ़ाइलों का कुल आकार।                | Success, Warning |
| `{messages_count}`     | संदेशों की संख्या।                             | Success, Warning |
| `{warnings_count}`     | चेतावनियों की संख्या।                          | Success, Warning |
| `{errors_count}`       | त्रुटियों की संख्या।                            | Success, Warning |
| `{log_text}`           | केवल चेतावनी और त्रुटि लॉग पंक्तियाँ (पूर्ण जानकारी लॉग नहीं)। NTFY एक संक्षिप्त सारांश का उपयोग करता है और छोटा कर सकता है। | Success, Warning |
| `{last_backup_date}`   | अंतिम बैकअप की तिथि।                           | Overdue          |
| `{last_elapsed}`       | अंतिम बैकअप के बाद से बीता समय।                | Overdue          |
| `{expected_date}`      | अपेक्षित बैकअप तिथि।                            | Overdue          |
| `{expected_elapsed}`   | अपेक्षित तिथि के बाद से बीता समय।              | Overdue          |
| `{backup_interval}`    | अंतराल स्ट्रिंग (जैसे, "1D", "2W", "1M")।    | Overdue          |
| `{overdue_tolerance}`  | अतिदेय सहिष्णुता सेटिंग।                      | अतिदेय          |

दैनिक सारांश टेम्पलेट में वर्तमान-स्थिति स्नैपशॉट के लिए चरों का एक अलग सेट उपयोग करता है:

| चर | विवरण |
|:---------|:------------|
| `{summary_date}` | स्नैपशॉट की स्थानीय कैलेंडर तिथि |
| `{generated_at}` | तिथि और समय जिसमें स्नैपशॉट जनरेट किया गया था |
| `{time_zone}` | सहेजा गया IANA टाइमज़ोन |
| `{server_count}` / `{job_count}` | सर्वर और ज्ञात जॉब्स |
| `{success_count}` / `{warning_count}` / `{error_count}` / `{fatal_count}` / `{unknown_count}` / `{no_report_count}` | परस्पर अनन्य स्थिति बकेट |
| `{overdue_count}` | अतिदेय जॉब्स (स्थिति के लंबवत; ऊपर के बकेट के साथ ओवरलैप कर सकता है) |
| `{problem_table}` / `{all_jobs_table}` | ध्यान आवश्यक और सभी जॉब्स की जनरेट की गई तालिकाएँ। कॉलम: सर्वर, बैकअप, अतिदेय, अंतिम स्थिति, अंतिम परिणाम, अवधि, चेतावनियाँ, त्रुटियाँ, अपलोड किया गया। |
| `{duplistatus_link}` | duplistatus डैशबोर्ड पर लिंक (जब कोई सार्वजनिक URL कॉन्फ़िगर नहीं किया गया हो तो छोड़ दिया जाता है)। मैन्युअल बनाए गए मार्कडाउन लिंक पर प्राथमिकता दें। |
| `{duplistatus_url}` | सादा पाठ के रूप में समान URL (जब कोई सार्वजनिक URL कॉन्फ़िगर नहीं किया गया हो तो खाली)। |
| `{latest_uploaded_size}` / `{latest_source_size}` / `{latest_storage_size}` / `{latest_file_count}` / `{total_warnings}` / `{total_errors}` | नवीनतम परिणाम कुल |

डिफ़ॉल्ट दैनिक सारांश ईमेल विषय है:

```text
Daily Backup Summary — {summary_date} — ✅ {success_count} Success, ⚠️ {warning_count} Warning, 🕑 {overdue_count} Overdue, 🛑 {error_count} Error, ❌ {fatal_count} Fatal
```

अपरिवर्तित संग्रहीत डिफ़ॉल्ट विषय इस प्रारूप में अपग्रेड किए जाते हैं। कस्टमाइज़ किए गए विषय अपरिवर्तित छोड़ दिए जाते हैं। `{unknown_count}` और `{no_report_count}` ईमेल शरीर में रहते हैं, डिफ़ॉल्ट विषय में नहीं।

भेजे बिना ईमेल विषय, HTML, और सादा पाठ रेंडर करने के लिए **पूर्वावलोकन** का उपयोग करें। सफलता, चेतावनी/त्रुटि, और अतिदेय पूर्वावलोकन में NTFY मार्कडाउन पेलोड भी शामिल होता है। पूर्वावलोकन एक संवाद में खुलता है। ईमेल HTML / सादा पाठ / NTFY बटन विषय के ऊपर स्थित हैं। ईमेल HTML वर्तमान हल्की या डार्क थीम का पालन करता है।
