# टेम्पलेट {/* #templates */}

**duplistatus** सूचना संदेशों के लिए चार टेम्पलेट का उपयोग करता है। ईमेल के मुख्य भाग (बॉडी) Markdown (शीर्षक, सूचियाँ, लिंक और तालिकाएँ) होते हैं। Success, चेतावनी/त्रुटि और अतिदेय के लिए NTFY उसी Markdown बॉडी का उपयोग करता है, जिसे `Markdown: yes` के साथ भेजा जाता है ताकि ntfy क्लाइंट इसे रेंडर कर सकें। कोई भी GFM तालिका अपनी हेडर पंक्ति को छोड़ देती है और बॉडी को सादा पाठ के रूप में भेजती है, क्योंकि ntfy तालिकाओं को रेंडर नहीं करता है। दैनिक सारांश केवल ईमेल के लिए है।

पृष्ठ में एक **टेम्पलेट की भाषा** चयनकर्ता शामिल है जो डिफ़ॉल्ट टेम्पलेट के लिए लोकेल सेट करता है। भाषा बदलने से नए डिफ़ॉल्ट के लिए लोकेल अपडेट हो जाता है, लेकिन यह मौजूदा टेम्पलेट के पाठ को **नहीं** बदलता है। अपने टेम्पलेट पर नई भाषा लागू करने के लिए, या तो उन्हें मैन्युअल रूप से संपादित करें या **इस टेम्पलेट को डिफ़ॉल्ट पर रीसेट करें** (वर्तमान टैब के लिए) या **सभी को डिफ़ॉल्ट पर रीसेट करें** (सभी टेम्पलेट के लिए) का उपयोग करें।

| :----------------- | :-------------------------------------------------- |

| **चेतावनी/त्रुटि**  | चेतावनियों या त्रुटियों के साथ बैकअप पूरा होने पर उपयोग किया जाता है। |
| **अतिदेय बैकअप** | बैकअप अतिदेय होने पर उपयोग किया जाता है।                      |
| **दैनिक सारांश**  | वैकल्पिक दैनिक स्नैपशॉट के लिए Markdown ईमेल टेम्पलेट। |

## टेम्पलेट की भाषा {/* #template-language */}

पृष्ठ के शीर्ष पर स्थित एक **टेम्पलेट की भाषा** चयनकर्ता आपको डिफ़ॉल्ट टेम्पलेट के लिए भाषा चुनने की सुविधा देता है (अंग्रेजी, जर्मन, फ्रेंच, स्पेनिश, पुर्तगाली, हिंदी और सरलीकृत चीनी)। भाषा बदलने से डिफ़ॉल्ट के लिए लोकेल अपडेट हो जाता है, लेकिन मौजूदा अनुकूलित टेम्पलेट अपने वर्तमान पाठ को तब तक बनाए रखते हैं जब तक आप उन्हें अपडेट नहीं करते या रीसेट बटनों में से किसी एक का उपयोग नहीं करते।

## वेरिएबल्स {/* #variables */}

ईमेल बॉडी Markdown होती हैं। शीर्षक, सूचियाँ, लिंक और तालिकाएँ समर्थित हैं। प्लेसहोल्डर मानों को एस्केप किए गए पाठ के रूप में डाला जाता है और वे Markdown या HTML प्रस्तुत नहीं कर सकते। अनुकूलित टेम्पलेट में पहले एम्बेड किए गए रॉ HTML को अब एस्केप कर दिया गया है। NTFY समान Markdown प्राप्त करता है, सिवाय GFM तालिकाओं के: किसी भी कॉलम लेआउट के लिए हेडर पंक्ति को छोड़ दिया जाता है और बॉडी पंक्तियों को सादा पाठ के रूप में भेजा जाता है।

डिफ़ॉल्ट Success, चेतावनी/त्रुटि और अतिदेय बॉडी उसी Markdown शैली का उपयोग करते हैं जैसा कि दैनिक सारांश करता है: एक शीर्षक, बोल्ड मान और एक अवलोकन तालिका। अपरिष्कृत संग्रहीत डिफ़ॉल्ट लोड होने पर अपग्रेड हो जाते हैं; अनुकूलित टेम्पलेट बनाए रखे जाते हैं।

सभी Success, चेतावनी/त्रुटि और अतिदेय टेम्पलेट उन वेरिएबल्स का समर्थन करते हैं जिन्हें वास्तविक मानों से बदल दिया जाएगा। निम्न तालिका उपलब्ध वेरिएबल्स दिखाती है:

| वेरिएबल               | विवरण                                     | इसमें उपलब्ध     |
|:-----------------------|:------------------------------------------------|:-----------------|
| `{server_name}`        | सर्वर का नाम।                             | Success, Warning, Overdue |
| `{server_alias}`       | सर्वर का उपनाम।                            | सफलता, चेतावनी, अतिदेय |
| `{server_note}`        | सर्वर के लिए नोट।                            | सफलता, चेतावनी, अतिदेय |
| `{server_url}`         | Duplicati सर्वर वेब कॉन्फ़िगरेशन का URL   | सफलता, चेतावनी, अतिदेय |
| `{backup_name}`        | बैकअप का नाम।                             | सफलता, चेतावनी, अतिदेय |
| `{status}`             | बैकअप स्थिति (सफलता, चेतावनी, त्रुटि, Fatal)। | सफलता, चेतावनी |
| `{backup_date}`        | बैकअप की तिथि और समय।                    | सफलता, चेतावनी |
| `{duration}`           | बैकअप की अवधि।                         | सफलता, चेतावनी |
| `{uploaded_size}`      | अपलोड किए गए डेटा की मात्रा।                        | सफलता, चेतावनी |
| `{storage_size}`       | संग्रहण उपयोग की जानकारी।                      | सफलता, चेतावनी |
| `{available_versions}` | उपलब्ध बैकअप वर्शन की संख्या।            | सफलता, चेतावनी |
| `{file_count}`         | संसाधित फ़ाइलों की संख्या।                      | सफलता, चेतावनी |
| `{file_size}`          | बैकअप ली गई फ़ाइलों का कुल आकार।                  | सफलता, चेतावनी |
| `{messages_count}`     | संदेशों की संख्या।                             | सफलता, चेतावनी |
| `{warnings_count}`     | चेतावनियों की संख्या।                             | सफलता, चेतावनी |
| `{errors_count}`       | त्रुटियों की संख्या।                               | सफलता, चेतावनी |
| `{log_text}`           | केवल चेतावनी और त्रुटि लॉग पंक्तियाँ (पूर्ण Information लॉग नहीं)। NTFY एक संक्षिप्त सारांश का उपयोग करता है और इसे छोटा कर सकता है। | सफलता, चेतावनी |
| `{last_backup_date}`   | अंतिम बैकअप की तिथि।                        | अतिदेय          |
| `{last_elapsed}`       | अंतिम बैकअप के बाद से बीता हुआ समय।             | अतिदेय          |
| `{expected_date}`      | अपेक्षित बैकअप तिथि।                           | अतिदेय          |
| `{expected_elapsed}`   | अपेक्षित तिथि के बाद से बीता हुआ समय।           | अतिदेय          |
| `{backup_interval}`    | अंतराल स्ट्रिंग (उदा., "1D", "2W", "1M")।       | अतिदेय          |
| `{overdue_tolerance}`  | अतिदेय टॉलरेंस सेटिंग।                      | अतिदेय          |

दैनिक सारांश टेम्पलेट वर्तमान स्थिति स्नैपशॉट के लिए वेरिएबल्स के एक अलग सेट का उपयोग करते हैं:

| वेरिएबल | विवरण |
|:---------|:------------|
| `{summary_date}` | स्नैपशॉट की स्थानीय कैलेंडर तिथि |
| `{generated_at}` | स्नैपशॉट जनरेट होने की तिथि और समय |
| `{time_zone}` | सहेजा गया IANA टाइमज़ोन |
| `{server_count}` / `{job_count}` | सर्वर और ज्ञात जॉब्स |
| `{success_count}` / `{warning_count}` / `{error_count}` / `{fatal_count}` / `{unknown_count}` / `{no_report_count}` | परस्पर अपवर्जित स्थिति बकेट |
| `{overdue_count}` | अतिदेय जॉब्स (स्थिति से ऑर्थोगोनल; ऊपर दिए गए बकेट के साथ ओवरलैप हो सकते हैं) |
| `{problem_table}` / `{all_jobs_table}` | ध्यान देने योग्य और सभी जॉब्स की जनरेट की गई टेबलें। कॉलम: सर्वर, बैकअप, अतिदेय, अंतिम स्थिति, अंतिम परिणाम, अवधि, चेतावनियाँ, त्रुटियाँ, अपलोड किया गया। |
| `{duplistatus_link}` | duplistatus डैशबोर्ड का लिंक (सार्वजनिक URL कॉन्फ़िगर न होने पर छोड़ दिया जाता है)। मैन्युअली बनाए गए Markdown लिंक की तुलना में इसे प्राथमिकता दें। |
| `{duplistatus_url}` | सादा पाठ के रूप में वही URL (कोई सार्वजनिक URL कॉन्फ़िगर न होने पर खाली)। |
| `{latest_uploaded_size}` / `{latest_source_size}` / `{latest_storage_size}` / `{latest_file_count}` / `{total_warnings}` / `{total_errors}` | नवीनतम-परिणाम कुल |

डिफ़ॉल्ट दैनिक सारांश ईमेल विषय है:

```text
Daily Backup Summary — {summary_date} — ✅ {success_count} Success, ⚠️ {warning_count} Warning, 🕑 {overdue_count} Overdue, 🛑 {error_count} Error, ❌ {fatal_count} Fatal
```

अपरिवर्तित संग्रहीत डिफ़ॉल्ट विषयों को इस प्रारूप में अपग्रेड किया जाता है। कस्टमाइज़ किए गए विषयों को अपरिवर्तित छोड़ दिया जाता है। `{unknown_count}` और `{no_report_count}` ईमेल बॉडी में रहते हैं, न कि डिफ़ॉल्ट विषय में।

बिना भेजे ईमेल विषय, HTML और सादा पाठ को रेंडर करने के लिए **पूर्वावलोकन** का उपयोग करें। सफलता, चेतावनी/त्रुटि और अतिदेय के पूर्वावलोकन में NTFY Markdown पेलोड भी शामिल होता है। पूर्वावलोकन एक संवाद में खुलता है। ईमेल HTML / सादा पाठ / NTFY बटन विषय के ऊपर स्थित होते हैं। ईमेल HTML वर्तमान लाइट या डार्क थीम का अनुसरण करता है।
