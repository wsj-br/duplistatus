# प्रदर्शन {/* #display */}

उपयोगकर्ता इंटरफ़ेस और प्रदर्शन प्राथमिकताएं कॉन्फ़िगर करें।

![प्रदर्शन सेटिंग्स](../../assets/screen-settings-display.png)

<br/>

| सेटिंग                   | विवरण                                         | डिफ़ॉल्ट मान      |
|:--------------------------|:----------------------------------------------------|:-------------------|
| **तालिका आकार**            | सर्वर विवरण पृष्ठ पर प्रति पृष्ठ पंक्तियों की संख्या। | 5 पंक्तियाँ             |
| **डैशबोर्ड पर संस्करण दिखाएं** | डैशबोर्ड कार्ड पर Duplicati संस्करण दिखाएं या छिपाएं। डैशबोर्ड तालिका हमेशा संस्करण कॉलम दिखाती है। [Duplicati संस्करण](duplicati-versions.md) में भी उपलब्ध। | चालू |
| **थीम**                 | हल्का, गहरा या अपने ऑपरेटिंग सिस्टम की उपस्थिति से मेल खाएं (हल्का/गहरा मोड पसंद करता है)। | जब अनसेट हो तो ओएस का पालन करें |
| **चार्ट समय सीमा**      | चार्ट में दिखाया गया समय अंतराल। उपलब्ध विकल्प: **1W** (अंतिम 7 दिन), **2W** (अंतिम 14 दिन), **1M** (अंतिम 30 दिन), **3M** (अंतिम 90 दिन)। आप चार्ट शीर्षलेख से सीधे समय सीमा टॉगल भी कर सकते हैं। | 1 माह            |
| **चार्ट शैली**           | स्मूथ लाइन चार्ट या बार चार्ट विज़ुअलाइज़ेशन के बीच चुनें। दोनों मोड इष्टतम प्रदर्शन के लिए समय-बकेट एग्रीगेशन का उपयोग करते हैं। आप चार्ट शीर्षलेख से सीधे टॉगल भी कर सकते हैं। | स्मूथ रेखाएं       |
| **फ़ॉर्मैट लोकेल**         | अपनी यूआई भाषा से स्वतंत्र एक फ़ॉर्मेटिंग लोकेल चुनें (416 लोकेल समर्थित)। इससे प्रभावित होता है कि तिथियां, समय और संख्याएं कैसे प्रदर्शित होती हैं। सापेक्ष-समय वाक्यांश (उदाहरण के लिए "2 घंटे में") फ़ॉर्मेट लोकेल का पालन करते हैं जब तक कि **यूआई भाषा में सापेक्ष समय रखें** सक्षम न हो। एक लाइव पूर्वावलोकन में तिथि, समय, संख्या और एक सापेक्ष-समय नमूना शामिल है। उदाहरण: यूआई भाषा = जर्मन, फ़ॉर्मेट लोकेल = अंग्रेज़ी (यूके) → जर्मन यूआई के साथ यूके तिथि प्रारूप। | यूआई भाषा के आधार पर |
| **यूआई भाषा में सापेक्ष समय रखें** | जब सक्षम हो, तो वाक्यांश जैसे "2 घंटे में" **उपयोगकर्ता → भाषा** का पालन करते हैं बजाय फ़ॉर्मेट लोकेल के। तिथियां, समय और संख्याएं अभी भी फ़ॉर्मेट लोकेल का उपयोग करते हैं। डिफ़ॉल्ट रूप से बंद। | बंद |
| **स्वतः-रीफ़्रेश अंतराल** | पृष्ठ कितनी बार स्वचालित रूप से रीफ्रेश होते हैं।              | 1 मिनट           |
| **कार्ड क्रम**      | डैशबोर्ड पर कार्ड कैसे क्रमबद्ध किए जाते हैं।              | सर्वर नाम (a-z)  |
| **सप्ताह की शुरुआत**         | कॉन्फ़िगर करें कि सप्ताह कब शुरू होता है।                     | लोकेल के आधार पर    |

<br/>

:::tip
**त्वरित पहुंच**: आप एप्लिकेशन टूलबार में स्वतः-रीफ़्रेश बटन पर दाएं क्लिक करके इस पृष्ठ पर त्वरित पहुंच प्राप्त कर सकते हैं।
:::
