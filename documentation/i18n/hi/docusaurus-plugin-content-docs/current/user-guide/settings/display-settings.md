# प्रदर्शन {/* #display */}

उपयोगकर्ता इंटरफ़ेस और प्रदर्शन प्राथमिकताओं को कॉन्फ़िगर करें।

![प्रदर्शन सेटिंग्स](../../assets/screen-settings-display.png)

<br/>

| सेटिंग | विवरण | डिफ़ॉल्ट मान |
|:---|:---|:---|
| **तालिका आकार** | सर्वर विवरण पृष्ठ पर प्रति पृष्ठ पंक्तियों की संख्या। | 5 पंक्तियाँ |
| **डैशबोर्ड पर संस्करण दिखाएं** | डैशबोर्ड कार्ड पर Duplicati संस्करण दिखाएँ या छिपाएँ। डैशबोर्ड तालिका हमेशा संस्करण कॉलम दिखाती है। [Duplicati संस्करण](duplicati-versions.md) में भी उपलब्ध है। | चालू |
| **थीम** | लाइट, डार्क चुनें, या अपने ऑपरेटिंग सिस्टम के रंग-रूप (लाइट/डार्क मोड प्राथमिकता) से मिलाएँ। | अनसेट होने पर OS का अनुसरण करें |
| **चार्ट समय सीमा** | चार्ट में दिखाया गया समय अंतराल। उपलब्ध विकल्प: **1W** (अंतिम 7 दिन), **2W** (अंतिम 14 दिन), **1M** (अंतिम 30 दिन), **3M** (अंतिम 90 दिन)। आप सीधे चार्ट हेडर से भी समय सीमा टॉगल कर सकते हैं। | 1 महीना |
| **चार्ट शैली** | स्मूथ लाइन चार्ट या बार चार्ट विज़ुअलाइज़ेशन के बीच चुनें। दोनों मोड अनुकूलतम प्रदर्शन के लिए टाइम-बकेट एग्रीगेशन का उपयोग करते हैं। आप सीधे चार्ट हेडर से भी टॉगल कर सकते हैं। | स्मूथ रेखाएं |
| **फ़ॉर्मैट लोकेल** | अपनी UI भाषा से स्वतंत्र एक फ़ॉर्मैटिंग लोकेल चुनें (416 लोकेल समर्थित)। यह तिथियों, समयों और संख्याओं के प्रदर्शित होने के तरीके को प्रभावित करता है। सापेक्ष-समय वाक्यांश (उदाहरण के लिए "2 घंटे में") फ़ॉर्मैट लोकेल का पालन करते हैं जब तक कि **सापेक्ष समय को UI भाषा में रखें** सक्षम न हो। एक लाइव पूर्वावलोकन में तिथि, समय, संख्या और एक सापेक्ष-समय नमूना शामिल होता है। उदाहरण: UI भाषा = जर्मन, फ़ॉर्मैट लोकेल = अंग्रेज़ी (UK) → UK तिथि फ़ॉर्मैट के साथ जर्मन UI। | UI भाषा के आधार पर |
| **सापेक्ष समय को UI भाषा में रखें** | जब सक्षम हो, तो "2 घंटे में" जैसे वाक्यांश फ़ॉर्मैट लोकेल के बजाय **उपयोगकर्ता → भाषा** का पालन करते हैं। तिथियां, समय और संख्याएं फिर भी फ़ॉर्मैट लोकेल का उपयोग करते हैं। डिफ़ॉल्ट रूप से बंद। | बंद |
| **स्वतः-रीफ़्रेश अंतराल** | पृष्ठ कितनी बार स्वतः रीफ़्रेश होते हैं। | 1 मिनट |
| **कार्ड क्रम** | डैशबोर्ड पर कार्ड कैसे क्रमबद्ध किए जाते हैं। | सर्वर नाम (a-z) |
| **सप्ताह की शुरुआत** | कॉन्फ़िगर करें कि सप्ताह कब शुरू होता है। | लोकेल के आधार पर |

<br/>

:::tip
**त्वरित पहुँच**: आप एप्लिकेशन टूलबार में स्वतः-रीफ़्रेश बटन पर राइट-क्लिक करके इस पृष्ठ पर तेज़ी से पहुँच सकते हैं।
:::
