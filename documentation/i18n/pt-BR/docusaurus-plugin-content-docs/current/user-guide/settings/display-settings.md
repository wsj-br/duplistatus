# Exibição {/* #display */}

Configurar preferências de interface e exibição do usuário.

![Configurações de Exibição](../../assets/screen-settings-display.png)

<br/>

| Configuração             | Descrição                                           | Valor Padrão       |
|:-------------------------|:----------------------------------------------------|:-------------------|
| **Tamanho da Tabela**   | Número de linhas por página na página de detalhes do servidor. | 5 linhas             |
| **Mostrar versão no painel** | Mostrar ou ocultar a versão do Duplicati nos cartões do painel. A tabela do painel sempre mostra a coluna Versão. Também disponível em [Versões do Duplicati](duplicati-versions.md). | Em |
| **Tema**                | Escolha claro, escuro ou combinar com a aparência do seu sistema operacional (modo claro/escuro preferido). | Seguir SO quando não definido |
| **Intervalo de Tempo do Gráfico** | Intervalo de tempo mostrado nos gráficos. Opções disponíveis: **1S** (últimos 7 dias), **2S** (últimos 14 dias), **1M** (últimos 30 dias), **3M** (últimos 90 dias). Você também pode alternar o intervalo de tempo diretamente nos cabeçalhos dos gráficos. | 1 mês              |
| **Estilo do Gráfico**   | Escolha entre gráficos de linha suave ou visualização em gráfico de barras. Ambos os modos usam agregação por intervalo de tempo para exibição ideal. Você também pode alternar diretamente nos cabeçalhos dos gráficos. | Linhas suaves        |
| **Localidade de Formatação** | Selecione uma localidade de formatação independente do seu idioma da interface (416 localidades suportadas). Isso afeta como datas, horas e números são exibidos. Frases de tempo relativo (por exemplo "em 2 horas") seguem a Localidade de Formatação, a menos que **Manter tempo relativo na linguagem da interface** esteja habilitado. Uma visualização ao vivo inclui data, hora, número e um exemplo de tempo relativo. Exemplo: Idioma da interface = Alemão, Localidade de formatação = Inglês (Reino Unido) → Interface em alemão com formatos de data do Reino Unido. | Baseado no idioma da interface |
| **Manter tempo relativo na linguagem da interface** | Quando habilitado, frases como "em 2 horas" seguem **Usuário → Idioma** em vez da Localidade de Formatação. Datas, horas e números ainda usam a Localidade de Formatação. Desativado por padrão. | Desativado |
| **Intervalo de Atualização Automática** | Com que frequência as páginas são atualizadas automaticamente. | 1 minuto           |
| **Ordem de Classificação dos Cartões** | Como os cartões são ordenados no painel. | Nome do servidor (a-z) |
| **Início da Semana**    | Configurar quando a semana começa.                  | Baseado na localidade |

<br/>

:::tip
**Acesso Rápido**: Você pode acessar rapidamente esta página clicando com o botão direito no botão de atualização automática na barra de ferramentas do aplicativo.
:::
