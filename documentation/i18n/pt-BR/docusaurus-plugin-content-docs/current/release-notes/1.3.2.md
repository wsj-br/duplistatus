# Versão 1.3.2 {/* #version-132 */}

## Visão Geral {/* #overview */}

A versão 1.3.2 é uma versão de manutenção que aborda vulnerabilidades de segurança em dependências, corrige avisos de instalação do pnpm (webpack de peer e subdependências obsoletas), resolve avisos de lint e build no aplicativo e na documentação, e atualiza a documentação para refletir os nomes atuais dos scripts Docker e versões dos pacotes.

## Segurança {/* #security */}

### Correções de vulnerabilidades de dependência {/* #dependency-vulnerability-fixes */}

- **Atualizações de dependência do Dependabot (documentação)**: Mesclou duas PRs do Dependabot para abordar vulnerabilidades no espaço de trabalho da documentação:
  - **ajv** em `/documentation`: atualizado de 8.17.1 para 8.18.0 e de 6.12.6 para 6.14.0.
  - **fast-xml-parser** em `/documentation`: atualizado de 5.3.5 para 5.3.8.
  Ambos foram mesclados via o dependabot multi-update para /documentation.

- **Sobrescritas do pnpm para vulnerabilidades de alta severidade**: Adicionou sobrescritas do pnpm para corrigir quatro problemas de alta severidade:
  - **minimatch** (>=3.1.4): Corrige GHSA-3ppc-4f35-3m26 (ReDoS via curingas repetidos), GHSA-7r86-cg39-jmmj (backtracking combinatório) e GHSA-23c5-xmqv-rm74 (backtracking de extglobs aninhados) em documentation > @docusaurus/core > serve-handler > minimatch.
  - **serialize-javascript** (>=7.0.3): Corrige GHSA-5c6j-r48x-rmvq (RCE via RegExp.flags e Date.prototype.toISOString()) em webpack > terser-webpack-plugin > serialize-javascript.

## Correções de bugs {/* #bug-fixes */}

- **Avisos de instalação do pnpm**: Resolveu três avisos de instalação: (1) Peer não atendido `webpack@5.104.1` de `next-intlayer` > `@intlayer/webpack` (o projeto tem webpack 5.105.3) adicionando `pnpm.peerDependencyRules.allowedVersions.webpack: "5"` na raiz `package.json`. (2) Subdependências obsoletas `prebuild-install@7.1.3` (de better-sqlite3) e `whatwg-encoding@3.1.1` (de documentation > docusaurus-search-local > cheerio) adicionando `pnpm.allowedDeprecatedVersions` para ambas para que a instalação seja executada sem avisos.
- **Visualizador de logs do aplicativo (exhaustive-deps)**: Resolveu o aviso react-hooks/exhaustive-deps para o efeito de rolagem automática. `logData` é intencionalmente omitido do array de dependências para que a rolagem ocorra apenas quando a rolagem automática ou o arquivo selecionado mudar, não em toda pesquisa; a rolagem de nova linha é tratada em `loadLogs`. Adicionou um eslint-disable-next-line com um comentário curto.
- **Aviso de build vscode-languageserver-types (documentação)**: Suprimiu o aviso "Critical dependency: require function is used in a way in which dependencies cannot be statically extracted" para a dependência transitiva `vscode-languageserver-types` (de intlayer-editor) na build da documentação (Docusaurus) via um plugin em linha em `documentation/docusaurus.config.ts` que adiciona `ignoreWarnings`. O aviso ocorre apenas durante a build da documentação, não do aplicativo principal.

## Notas de migração {/* #migration-notes */}

### Da versão 1.3.1 {/* #from-version-131 */}

Ao atualizar para a versão 1.3.2:

1. **Nenhuma migração de banco de dados necessária**: Esta versão não requer alterações no esquema do banco de dados.
2. **Comandos Docker**: Se você usa os scripts pnpm documentados, use `pnpm docker:up`, `pnpm docker:down`, `pnpm docker:clean` e `pnpm docker:devel` em vez dos anteriores `docker-up`, `docker-down`, etc.
3. **Dependências**: Execute `pnpm install` para aplicar o lockfile atualizado e as sobrescritas; nenhuma alteração manual de dependência é necessária para instalações típicas.
