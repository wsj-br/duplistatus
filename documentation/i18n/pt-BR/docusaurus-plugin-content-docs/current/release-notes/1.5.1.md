# Versão 1.5.1 {/* #version-151 */}

## Visão geral {/* #overview */}

A Versão 1.5.1 é uma versão de manutenção e segurança. Ela atualiza o Next.js para resolver problemas de SSRF de otimização de imagem, envenenamento de cache e questões relacionadas, fortalece a criptografia de segredos armazenados e abre links de servidor NTFY Personalizado no servidor que você configurou. As imagens de contêiner Publicado para amd64 e arm64 compartilham novamente um único digest.

---

## Melhorias {/* #improvements */}

### Documentação {/* #documentation */}

- **Página inicial da documentação**: A raiz do site de documentação agora é uma página de produto que cobre status de Backup, capturas de tela, segurança e instalação, em vez de um redirecionamento para a introdução. **Docs** e `/intro` ainda abrem o guia.

---

## Correções de bugs {/* #bug-fixes */}

- **Links de servidor NTFY Personalizado (problema #85)**: O link do tópico de Configurações e o ícone do NTFY na barra de ferramentas abrem o servidor que você configurou. Eles não direcionam mais sempre para `https://ntfy.sh`.
- **Imagens multiarquitetura**: As compilações de versão não anexam mais atestados de procedência, portanto, o GitHub Container Registry e o Docker Hub compartilham um único digest e `linux/amd64` e `linux/arm64` são marcados juntos.

---

## Segurança {/* #security */}

### Framework e segredos armazenados {/* #framework-and-stored-secrets */}

- **Next.js 16.4.3**: `package.json` declara 16.3.8 (Dependabot #84). A substituição de dependência instala a 16.4.3, que inclui as correções dessa versão para SSRF de otimização de imagem, problemas de rota de metadados e envenenamento de cache, vazamento do Modo de Rascunho através de `use cache` e uma divulgação de informações no Servidor de desenvolvimento.
- **Criptografia de segredo mais forte**: Segredos novos e re-Salvo usam PBKDF2-SHA256 com 600.000 iterações, acima das 100.000 anteriores. Segredos já armazenados com a contagem anterior ainda descriptografam. Salvar um segredo novamente o reescreve com a contagem mais alta.

## Notas de migração {/* #migration-notes */}

### Da Versão 1.5.0 {/* #from-version-150 */}

Quando atualizar para a Versão 1.5.1:

1. **Nenhuma migração de banco de dados necessária**: Esta versão não altera o esquema do banco de dados. Segredos criptografados existentes continuam funcionando.
2. **Dependências**: Execute `pnpm install` para aplicar o arquivo de bloqueio e as substituições atualizados.
3. **Nenhuma alteração de Configurações necessária**: Chaves de API, listas de permissão, configurações de notificação e URLs de servidor NTFY permanecem inalteradas.
