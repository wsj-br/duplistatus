# Versão 0.8.x {/* #version-08x */}

## Visão Geral {/* #overview */}

A versão 0.8.x é uma atualização significativa que introduz melhorias de segurança, capacidades aprimoradas de gerenciamento de servidores e um sistema de notificações abrangente com suporte a e-mail SMTP. Este lançamento se concentra em fortalecer a segurança, melhorar a experiência do usuário e fornecer opções mais flexíveis de monitoramento de backups.

## Novos recursos {/* #new-features */}

### Melhorias no Gerenciamento de Servidores {/* #server-management-enhancements */}

- **Persistência automática de URL e senha do servidor** ao coletar backups
  - Os usuários podem atualizar a URL e a senha usando dois métodos:
     - Recoletando backups com valores atualizados
     - Modificando as configurações em [Configurações → Configurações do Servidor](../user-guide/settings/server-settings.md)

### Monitoramento Aprimorado de Backups {/* #enhanced-backup-monitoring */}

- **Nova aba de configuração `Backup monitoring`** com configurações de intervalo compatíveis com o servidor Duplicati
    - Suporte para intervalos personalizados (por exemplo, "1D12h")
    - Atualizações automáticas de intervalos vencidos da configuração do Duplicati durante a coleta de logs de backup
    - **Recomendado:** Execute a coleta após alterar os intervalos de trabalho de backup no servidor Duplicati para sincronizar a configuração do duplistatus
    - Os modelos de notificações agora usam `{backup_interval}` em vez de `{backup_interval_value}` e `{backup_interval_type}`.

### Configuração de Dispositivo NTFY {/* #ntfy-device-configuration */}

- **Geração de código QR** para configuração automática de dispositivo para receber notificações do **duplistatus**
   - Clique com o botão direito no botão `View NTFY Messages` na barra de ferramentas do aplicativo
   - Botão "Configurar Dispositivo" em [Configurações → Configurações NTFY](../user-guide/settings/ntfy-settings.md)

### Coleta Aprimorada de Backups {/* #improved-backup-collection */}

- **Detecção automática de HTTP/HTTPS**, as conexões são tentadas nesta ordem: HTTPS → HTTPS com certificado autoassinado → HTTP como fallback
- **Menu suspenso de seleção de servidor** na interface `Collect Backup Logs` para coleta específica do servidor
- **Múltiplos endereços** no nome do host (separados por vírgula) são agora aceitos (devem compartilhar a mesma senha e porta)
- **Botões de coleta de backup de servidor único** adicionados a `Dashboard (table)`, [Configurações → Monitoramento de Backup](../user-guide/settings/backup-monitoring-settings.md) e [Configurações → Servidores](../user-guide/settings/server-settings.md)
- **Funcionalidade de coleta em massa** para todos os servidores com configuração válida (url e senha)
   - Botões `Collect All` em [Configurações → Monitoramento de Backup](../user-guide/settings/backup-monitoring-settings.md) e [Configurações → Servidores](../user-guide/settings/server-settings.md)
   - Menu de contexto com clique direito no botão `Collect Backup Logs` na barra de ferramentas do aplicativo

### Sistema Aprimorado de Notificações {/* #enhanced-notification-system */}

- **Suporte a Notificações por E-mail SMTP:**
    - Configuração do servidor SMTP em [Configurações → Configurações de E-mail](../user-guide/settings/email-settings.md)
    - Configuração por trabalho de backup para notificações NTFY e/ou por e-mail
    - Modelos formatados em HTML usando as [Configurações → Modelos de Notificação](../user-guide/settings/notification-templates.md) existentes
- **Configuração de Notificação por Trabalho de Backup:**
    - Preferências de notificação individuais em [Configurações → Notificações de Backup](../user-guide/settings/backup-notifications-settings.md)
    - Indicadores visuais (ícones cinzentos) quando NTFY ou e-mail não estão configurados corretamente

- **Suporte a localidade:**
    - criada uma nova variável de ambiente `LANG` para definir a localidade no aplicativo
    - agora é previsível o formato de datas e números nas notificações e logs

## 🔒 Melhorias de Segurança {/* #-security-enhancements */}

### Proteção CSRF {/* #csrf-protection */}

- **Autenticação baseada em sessão** com gerenciamento robusto de sessão
- **Validação de token CSRF** aplicada a todas as solicitações de API que alteram o estado
- **Sessões expiram automaticamente** após 24 horas; tokens CSRF são atualizados a cada 30 minutos
- Garante proteção contra Cross-Site Request Forgery enquanto preserva a compatibilidade com APIs externas

### Minimização de Senhas em Texto Simples {/* #plaintext-password-minimization */}

- **Senhas só podem ser definidas via interface do usuário**; nenhum endpoint de API expõe senhas armazenadas
- **Manipulação de senhas em texto simples é minimizada** em todo o sistema

### Criptografia Avançada para Dados Sensíveis {/* #advanced-cryptography-for-sensitive-data */}

- **Criptografia de dados sensíveis** (por exemplo, senhas, credenciais SMTP) usando AES-256-GCM
- **Chave mestra é gerada automaticamente** e armazenada com segurança em `.duplistatus.key`
- **PBKDF2 com 100.000 iterações** usado para derivação de chaves para fortalecer a segurança
- **Tags de autenticação são verificadas** e a memória é limpa com segurança após o uso
- **Permissões do arquivo de chave mestra** são definidas estritamente como 0400 para máxima proteção

## 🚀 Notas de Migração {/* #-migration-notes */}

### Da Versão 0.7.x {/* #from-version-07x */}

Esta versão inclui melhorias significativas de segurança e novos recursos. Ao atualizar da versão 0.7.x:

1. **Migração Automática de Banco de Dados:** A aplicação migrará automaticamente o esquema do banco de dados para suportar novos recursos
2. **Geração de Chave Mestra:** Uma nova chave mestra será gerada para criptografia de dados sensíveis
3. **Gerenciamento de Sessão:** Sessões existentes serão invalidadas e novas sessões protegidas por CSRF serão estabelecidas
4. **Atualizações de Configuração:** Algumas chaves de configuração foram atualizadas para suportar novos recursos
5. **Alterações de modelo:** As variáveis `{backup_interval_value}` e `{backup_interval_type}` foram substituídas por `{backup_interval}`. Modelos padrão serão ajustados automaticamente, mas modelos personalizados não serão migrados. Por favor, verifique seus modelos.

### Considerações de Segurança {/* #security-considerations */}

- **Arquivo de Chave Mestra:** Certifique-se de que o arquivo `.duplistatus.key` esteja devidamente salvo e protegido
- **Permissões de Arquivo:** O arquivo de chave mestra terá permissões restritas (0400) para segurança
- **Criptografia de Senha:** Senhas existentes serão criptografadas usando o novo sistema criptográfico
