# Versão 0.8.x {/* #version-08x */}

## Visão geral {/* #overview */}

A Versão 0.8.x é uma atualização importante que introduz melhorias significativas de segurança, capacidades aprimoradas de gerenciamento de servidor e um sistema abrangente de notificações com suporte a e-mail SMTP. Esta versão se concentra em fortalecer a segurança, aprimorar a experiência do usuário e fornecer opções mais flexíveis de monitoramento de backup.

## Novos Recursos {/* #new-features */}

### Melhorias no Gerenciamento de Servidor {/* #server-management-enhancements */}

- **Persistência automática de URL e senha do servidor** ao coletar backups
  - Os usuários podem atualizar a URL e a senha usando dois métodos:
     - Recoletar backups com valores atualizados
     - Modificar configurações em [Configurações → Configurações de Servidor](../user-guide/settings/server-settings.md)

### Monitoramento de Backup aprimorado {/* #enhanced-backup-monitoring */}

- **Nova aba de configuração `Backup monitoring`** com configurações de intervalo compatíveis com servidor Duplicati
    - Suporte para intervalos personalizados (por exemplo, "1D12h")
    - Atualizações automáticas de intervalo atrasado da configuração do Duplicati durante a coleta de log de backup
    - **Recomendado:** Execute a coleta após alterar intervalos de trabalho de backup no servidor Duplicati para sincronizar a configuração do duplistatus
    - Os modelos de notificações agora usam `{backup_interval}` em vez de `{backup_interval_value}` e `{backup_interval_type}`.

### Configuração de Dispositivo NTFY {/* #ntfy-device-configuration */}

- **Geração de código QR** para configuração automática de dispositivo para receber notificações do **duplistatus**
   - Clique com o botão direito no botão `View NTFY Messages` na barra de ferramentas da aplicação
   - Botão "Configurar Dispositivo" em [Configurações → Configurações de NTFY](../user-guide/settings/ntfy-settings.md)

### Coleta de Backup Melhorada {/* #improved-backup-collection */}

- **Detecção automática de HTTP/HTTPS**, as conexões são tentadas nesta ordem: HTTPS → HTTPS com auto-assinado → fallback HTTP
- **Menu suspenso de seleção de servidor** na interface `Collect Backup Logs` para coleta específica do servidor direto
- **Múltiplos endereços** no nome do host (separados por vírgula) agora são aceitos (devem compartilhar a mesma senha e porta)
- **Botões de coleta de backup de servidor único** adicionados a `Dashboard (table)`, [Configurações → Monitoramento de Backup](../user-guide/settings/backup-monitoring-settings.md) e [Configurações → Servidores](../user-guide/settings/server-settings.md)
- **Funcionalidade de coleta em massa** para todos os servidores com configuração válida (url e senha)
   - Botões `Collect All` em [Configurações → Monitoramento de Backup](../user-guide/settings/backup-monitoring-settings.md) e [Configurações → Servidores](../user-guide/settings/server-settings.md)
   - Menu de contexto com clique direito no botão `Collect Backup Logs` na barra de ferramentas da aplicação

### Sistema de Notificação Aprimorado {/* #enhanced-notification-system */}

- **Suporte a Notificação por E-mail SMTP:**
    - Configuração de servidor SMTP em [Configurações → Configurações de E-mail](../user-guide/settings/email-settings.md)
    - Configuração por trabalho de backup para notificações NTFY e/ou e-mail
    - Modelos formatados em HTML usando [Configurações → Modelos de Notificações](../user-guide/settings/notification-templates.md) existentes
- **Configuração de Notificação por Trabalho de Backup:**
    - Preferências de notificação individuais em [Configurações → Notificações de Backup](../user-guide/settings/backup-notifications-settings.md)
    - Indicadores visuais (ícones acinzentados) quando NTFY ou e-mail não está configurado corretamente

- **Suporte a localidade:**
    - criada uma nova variável de ambiente `LANG` para definir a localidade na aplicação
    - agora é previsível o formato de datas e números nas notificações e logs

## 🔒 Melhorias de Segurança {/* #-security-enhancements */}

### Proteção CSRF {/* #csrf-protection */}

- **Autenticação baseada em sessão** com gerenciamento robusto de sessão
- **Validação de token CSRF** aplicada a todas as solicitações de API que alteram estado
- **As sessões expiram automaticamente** após 24 horas; os tokens CSRF são atualizados a cada 30 minutos
- Garante proteção contra Falsificação de Solicitação Entre Sites, mantendo compatibilidade com APIs externas

### Minimização de Senha em Texto Simples {/* #plaintext-password-minimization */}

- **As senhas podem ser definidas apenas pela interface do usuário**; nenhum endpoint de API expõe senhas armazenadas
- **A manipulação de senha em texto simples é minimizada** em todo o sistema

### Criptografia Avançada para Dados Sensíveis {/* #advanced-cryptography-for-sensitive-data */}

- **Criptografia de dados sensíveis** (por exemplo, senhas, credenciais SMTP) usando AES-256-GCM
- **Chave mestra é gerada automaticamente** e armazenada com segurança em `.duplistatus.key`
- **PBKDF2 com 100.000 iterações** usado para derivação de chave para fortalecer a segurança
- **Tags de autenticação são verificadas** e a memória é limpa com segurança após o uso
- **Permissões de arquivo de chave mestra** são definidas estritamente como 0400 para proteção máxima

## 🚀 Notas de Migração {/* #-migration-notes */}

### Da Versão 0.7.x {/* #from-version-07x */}

Esta versão inclui melhorias significativas de segurança e novos recursos. Ao atualizar da versão 0.7.x:

1. **Migração Automática de Banco de Dados:** O aplicativo migrará automaticamente seu esquema de banco de dados para suportar novos recursos
2. **Geração de Chave Mestra:** Uma nova chave mestra será gerada para criptografia de dados sensíveis
3. **Gerenciamento de Sessão:** As sessões existentes serão invalidadas e novas sessões protegidas por CSRF serão estabelecidas
4. **Atualizações de Configuração:** Algumas chaves de configuração foram atualizadas para suportar novos recursos
5. **Alterações de modelo:** As variáveis `{backup_interval_value}` e `{backup_interval_type}` foram substituídas por `{backup_interval}`. Os modelos padrão serão ajustados automaticamente, mas os modelos personalizados não serão migrados. Verifique seus modelos.

### Considerações de Segurança {/* #security-considerations */}

- **Arquivo de Chave Mestra:** Certifique-se de que o arquivo `.duplistatus.key` está devidamente feito backup e seguro
- **Permissões de Arquivo:** O arquivo de chave mestra terá permissões restritas (0400) para segurança
- **Criptografia de Senha:** As senhas existentes serão criptografadas usando o novo sistema criptográfico
