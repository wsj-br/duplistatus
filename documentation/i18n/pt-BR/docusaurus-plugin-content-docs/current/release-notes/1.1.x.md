# Versão 1.1.x {/* #version-11x */}

## Visão geral {/* #overview */}

A versão 1.1.x é uma versão menor que aborda problemas críticos com a detecção de backup atrasado, melhora a compatibilidade com contêineres Podman e introduz melhorias na arquitetura de contêineres. Esta versão foca em corrigir a precisão da detecção de backup atrasado e resolver problemas de rede em ambientes Podman.

## Novos Recursos {/* #new-features */}

### Melhorias na Interface do Usuário {/* #user-interface-enhancements */}

- **Menu de contexto com clique direito no botão de atualização automática** - Clicar com o botão direito no botão de atualização automática na barra de ferramentas do aplicativo abre a página de Configurações de Exibição para acesso rápido às preferências de exibição
- **Modal de coletar backups melhorado** - O rótulo do campo de senha agora indica claramente "(preencha apenas se a senha for alterada)" quando um servidor é selecionado, tornando mais claro quando o campo é necessário

### Melhorias na Documentação {/* #documentation-improvements */}

- **Migração de hospedagem da documentação** - A documentação foi movida da imagem do contêiner Docker para o GitHub Pages em https://wsj-br.github.io/duplistatus/user-guide/overview para melhor acessibilidade e atualizações mais fáceis
- O link do Guia do Usuário no cabeçalho do aplicativo agora aponta para o site de documentação externa

## 🐛 Correções de Bugs {/* #-bug-fixes */}

### Crítico: Detecção de Backup Atrasado - Reimplementação Completa {/* #critical-overdue-backup-detection---complete-reimplementation */}

- **Detecção de backup atrasado corrigida** - Sistema de detecção de backup atrasado completamente reimplementado com um novo algoritmo que rastreia corretamente as datas de backup esperadas:
  - O algoritmo garante que backups manuais não mudem os horários de backup programados (por exemplo, um backup manual às 22h não mudará um agendamento às 14h)
  - Corrigida a coluna "Próxima Execução" nas configurações de monitoramento de backup que mostrava datas incorretas
  - As configurações de backup agora são atualizadas imediatamente após receber backups via `/api/upload` ou `/api/backups/collect`
  - Para novos servidores sem sincronização Duplicati, usa o horário do primeiro backup como referência de agendamento
  - Para mais detalhes, consulte a documentação do [Algoritmo de Detecção Atrasada](https://github.com/wsj-br/duplistatus/blob/main/dev/OVERDUE_DETECTION_ALGORITHM.md)

### Correções de Contêiner Podman {/* #podman-container-fixes */}

- **Rede de pod Podman corrigida** - Resolvido problema que impedia o acesso externo ao aplicativo quando executado em pods Podman. O servidor agora se vincula corretamente a todas as interfaces (`0.0.0.0:9666`) tanto em modos de pod Podman quanto em contêineres autônomos
- **Correção na resolução de DNS para nomes de host Tailscale** - Resolvidos problemas de resolução de DNS em contêineres Podman que impediam a conexão com nomes de host Tailscale ou servidores DNS personalizados. Atualizada a documentação de instalação com instruções.

### Correções de Configuração de E-mail {/* #email-configuration-fixes */}

- **Correção no manuseio de nome de usuário/senha vazios no SMTP** - Resolvido problema em que limpar os campos de nome de usuário ou senha na configuração de e-mail ainda armazenaria valores criptografados no banco de dados. Campos vazios agora são armazenados corretamente como strings vazias e podem ser limpos corretamente

### Melhorias no Sistema {/* #system-improvements */}

- **Redução de logs no console** - AuditLogger agora registra apenas tentativas de login falhadas no console; todas as outras entradas de auditoria são escritas apenas no banco de dados

## 🚀 Notas de Migração {/* #-migration-notes */}

### Da Versão 1.0.x {/* #from-version-10x */}

Ao atualizar para a versão 1.1.0:

1. **Mudança na Localização da Documentação** - A documentação agora é hospedada no GitHub Pages em vez de ser incluída no contêiner Docker. O link do Guia do Usuário no cabeçalho do aplicativo agora aponta para o site de documentação externa

2. **Configuração do Contêiner Podman** - Se estiver usando pods Podman, certifique-se de que a configuração de DNS esteja definida no nível do pod usando as flags `--dns` e `--dns-search`. O aplicativo agora funciona corretamente tanto em pods Podman quanto em contêineres autônomos

3. **Detecção de Backup Atrasado** - O sistema de detecção de backup atrasado foi completamente reimplementado com um novo algoritmo que preserva o horário do agendamento. As configurações de monitoramento de backup existentes continuarão a funcionar, mas você pode notar datas de "Próxima Execução" mais precisas nas configurações de monitoramento de backup. O novo algoritmo garante que backups manuais não mudem os horários de backup programados

4. **Nenhuma Migração de Banco de Dados Necessária** - Esta versão não requer alterações no esquema do banco de dados
