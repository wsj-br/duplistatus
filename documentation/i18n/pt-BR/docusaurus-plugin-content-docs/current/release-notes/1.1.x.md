# Versão 1.1.x {/* #version-11x */}

## Visão Geral {/* #overview */}

A versão 1.1.x é uma versão menor que aborda problemas críticos com a detecção de backups atrasados, melhora a compatibilidade com contêineres Podman e introduz melhorias na arquitetura de contêineres. Esta versão se concentra em corrigir a precisão da detecção de backups atrasados e resolver problemas de rede em ambientes Podman.

## Novos recursos {/* #new-features */}

### Melhorias na Interface do Usuário {/* #user-interface-enhancements */}

- **Menu de contexto com clique direito no botão de atualização automática** - Clicar com o botão direito no botão de atualização automática na barra de ferramentas do aplicativo abre a página Configurações de Exibição para acesso rápido às preferências de exibição
- **Modal de coleta de backups aprimorado** - O rótulo do campo de senha agora indica claramente "(preencha apenas se a senha for alterada)" quando um servidor é selecionado, tornando mais claro quando o campo é necessário

### Melhorias na Documentação {/* #documentation-improvements */}

- **Migração do hospedagem da documentação** - A documentação foi movida da imagem do contêiner Docker para o GitHub Pages em https://wsj-br.github.io/duplistatus/user-guide/overview para melhor acessibilidade e atualizações mais fáceis
- O link do Guia do Usuário no cabeçalho do aplicativo agora aponta para o site de documentação externo

## 🐛 Correções de Bugs {/* #-bug-fixes */}

### Crítico: Detecção de Backup Atrasado - Reimplementação Completa {/* #critical-overdue-backup-detection---complete-reimplementation */}

- **Detecção de backup atrasado corrigida** - Sistema de detecção de backup atrasado completamente reimplementado com um novo algoritmo que rastreia corretamente as datas de backup esperadas:
  - O algoritmo garante que backups manuais não alterem os horários de backup programados (por exemplo, um backup manual às 22h não alterará um agendamento às 14h)
  - A coluna "Próxima Execução" nas configurações de monitoramento de backup agora mostra datas corretas
  - As configurações de backup são atualizadas imediatamente após receber backups via `/api/upload` ou `/api/backups/collect`
  - Para servidores novos sem sincronização Duplicati, usa o horário do primeiro backup como referência do agendamento
  - Para mais detalhes, consulte a documentação [Algoritmo de Detecção de Atraso](https://github.com/wsj-br/duplistatus/blob/main/dev/OVERDUE_DETECTION_ALGORITHM.md)

### Correções para Contêineres Podman {/* #podman-container-fixes */}

- **Rede de pod do Podman corrigida** - Resolvido o problema que impedia o acesso externo ao aplicativo quando executado em pods do Podman. O servidor agora vincula corretamente a todas as interfaces (`0.0.0.0:9666`) em ambos os modos de pod e contêineres independentes
- **Resolução de DNS para hostnames do Tailscale** - Resolvido problemas de resolução de DNS em contêineres Podman que impediam a conexão com hostnames do Tailscale ou servidores DNS personalizados. Atualizada a documentação de instalação com instruções.

### Correções de Configuração de E-mail {/* #email-configuration-fixes */}

- **Tratamento de nome de usuário/senha SMTP vazio corrigido** - Resolvido o problema em que a limpeza dos campos de nome de usuário ou senha na configuração de e-mail ainda armazenava valores criptografados no banco de dados. Campos vazios são armazenados como strings vazias e podem ser limpos corretamente

### Melhorias no Sistema {/* #system-improvements */}

- **Redução de logs no console** - O AuditLogger agora registra apenas tentativas de login falhas no console; todas as outras entradas de auditoria são gravadas apenas no banco de dados

## 🚀 Notas de Migração {/* #-migration-notes */}

### Da Versão 1.0.x {/* #from-version-10x */}

Ao atualizar para a versão 1.1.0:

1. **Mudança na Localização da Documentação** - A documentação agora é hospedada no GitHub Pages em vez de ser incluída no contêiner Docker. O link do Guia do Usuário no cabeçalho do aplicativo agora aponta para o site de documentação externo

2. **Configuração de Contêiner Podman** - Se estiver usando pods Podman, certifique-se de que a configuração de DNS esteja definida no nível do pod usando as bandeiras `--dns` e `--dns-search`. O aplicativo agora funciona corretamente em pods Podman e contêineres independentes

3. **Detecção de Backup Atrasado** - O sistema de detecção de backup atrasado foi completamente reimplementado com um novo algoritmo que preserva o horário do agendamento. As configurações de monitoramento de backup existentes continuarão a funcionar, mas você pode notar datas "Próxima Execução" mais precisas nas configurações de monitoramento de backup. O novo algoritmo garante que backups manuais não desloquem os horários de backup programados

4. **Nenhuma Migração de Banco de Dados Necessária** - Esta versão não requer nenhuma alteração no esquema do banco de dados
