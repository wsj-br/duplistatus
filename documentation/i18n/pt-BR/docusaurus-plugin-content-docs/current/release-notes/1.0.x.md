# Versão 1.0.x {/* #version-10x */}

## Visão Geral {/* #overview */}

A versão 1.0.x é uma versão de recursos que introduz melhorias significativas na configuração de e-mail, nas capacidades de gerenciamento de servidores e nas ferramentas de manutenção do banco de dados. Esta versão se concentra em melhorar a confiabilidade das notificações por e-mail, expandir as opções de conexão SMTP e fornecer melhores ferramentas para gerenciar servidores e a integridade do banco de dados.

## Novos recursos {/* #new-features */}

### Melhorias no Gerenciamento de Servidores {/* #server-management-enhancements */}

- **Funcionalidade de alteração de senha do servidor** - Os usuários agora podem alterar as senhas dos servidores diretamente da página de detalhes do servidor, clicando no ícone da chave
- **Detecção e mesclagem de servidores duplicados** - Nova função no formulário de manutenção do banco de dados para detectar servidores duplicados e mesclá-los em uma única entrada de servidor

### Melhorias no Registro de Auditoria {/* #audit-logging-enhancements */}

- **Registro de auditoria de upload de backup** - Todos os uploads de logs de backup via o endpoint `/api/upload` são agora registrados automaticamente no log de auditoria. Cada entrada inclui detalhes do backup (ID do servidor, nome do servidor, nome do backup, status, data, duração, contagens de arquivos, tamanhos, avisos e erros) junto com informações de endereço IP do cliente e agente do usuário para fins de rastreamento e segurança

### Melhorias na Configuração de E-mail {/* #email-configuration-enhancements */}

- **Aviso de configuração incompleta** - Alerta visual exibido quando as configurações de e-mail não estão configuradas corretamente
- **Indicadores de status do serviço** - Rótulos "(desativado)" mostrados nas caixas de seleção de notificações quando os serviços de e-mail não estão configurados
- **Informações do remetente personalizáveis**:
  - Campo `Sender Name` para personalizar o nome de exibição mostrado como remetente nas notificações por e-mail
  - Campo `From Address` para especificar o endereço de e-mail mostrado como remetente
  - Nota: Alguns provedores de e-mail substituirão o `From Address` pelo `SMTP Server Username`
- **Alternância de autenticação SMTP** - Opção para ativar ou desativar a autenticação SMTP, suportando servidores que não exigem autenticação
- **Validação de formato de e-mail** - Validação para campos de endereço de e-mail do destinatário e do remetente para garantir o formato correto de endereço de e-mail
- **E-mail de teste aprimorado** - O e-mail de teste agora exibe detalhes de conexão abrangentes, incluindo o nome do servidor SMTP, porta, tipo de conexão, status de autenticação, nome de usuário (se aplicável), e-mail do destinatário, endereço de origem, nome do remetente e timestamp do teste

### Suporte a Tipos de Conexão SMTP {/* #smtp-connection-type-support */}

- **Vários tipos de conexão** - Suporte para três tipos de conexão:
  - `Plain SMTP` (sem criptografia) na porta 25
  - `STARTTLS` (atualização para TLS) na porta 587
  - `Direct SSL/TLS` (criptografado desde o início) na porta 465
- **Tipo de conexão padrão** - Alterado para `Direct SSL/TLS` para novas configurações
- **Requisitos específicos da conexão** - O campo `From Address` é obrigatório para conexões `Plain SMTP` para garantir a identificação adequada do remetente de e-mail e a conformidade com o RFC 5322

## 🐛 Correções de Bugs {/* #-bug-fixes */}

### Correções no Sistema de E-mail {/* #email-system-fixes */}

- **Cabeçalho `From` ausente corrigido** - Resolvido erros de conformidade com o RFC 5322 garantindo que todas as mensagens de e-mail incluam cabeçalhos `From` adequados
- **Criptografia de e-mail para STARTTLS corrigida** - Corrigido o tratamento de criptografia para conexões `STARTTLS` (porta 587)
- **Conexões Plain SMTP corrigidas** - Resolvido erros de negociação TLS que estavam causando falhas nas conexões `Plain SMTP`
- **Perda de configuração não salva corrigida** - Impedido que configurações de e-mail não salvas fossem limpas ao alterar a senha
- **Configuração SMTP obsoleta corrigida** - Resolvido problema em que o endpoint de e-mail de teste estava usando configuração SMTP desatualizada

### Correções na Interface do Usuário {/* #user-interface-fixes */}

- **Alternância de visibilidade de senha corrigida** - Corrigido o comportamento do recurso de visualização de senha no formulário de alteração de senha; clicar no ícone do olho agora mostra a senha para ambos os campos de senha simultaneamente

### Correções no Sistema {/* #system-fixes */}

- **Registro de entrada do Docker corrigido** - Resolvido problema em que o script de entrada do Docker estava descartando mensagens de log
- **Cálculo da data da próxima execução corrigido** - Adicionado recálculo automático da data `Next Run` após a coleta de logs de backup, garantindo que a data seja atualizada corretamente após a coleta de logs

## 🚀 Notas de Migração {/* #-migration-notes */}

### A partir da Versão 0.9.x {/* #from-version-09x */}

Esta versão inclui melhorias na configuração de e-mail e gerenciamento de servidores. Ao atualizar da versão 0.9.x:

1. **Nenhuma Migração de Banco de Dados Necessária** - Esta versão não requer alterações no esquema do banco de dados
2. **Atualizações na Configuração de E-mail** - Configurações de e-mail existentes continuarão a funcionar, mas você pode querer revisar e atualizar suas configurações para aproveitar os novos recursos:
   - Considere definir um `Sender Name` personalizado para melhor identificação de e-mail
   - Verifique se seu `From Address` está configurado corretamente, especialmente se estiver usando conexões `Plain SMTP`
   - Teste sua configuração de e-mail usando o recurso aprimorado de e-mail de teste
3. **Tipo de Conexão Padrão** - Novas configurações de e-mail terão o tipo de conexão padrão definido como `Direct SSL/TLS`
4. **Gerenciamento de Senha do Servidor** - Agora você pode alterar senhas de servidores diretamente da página de detalhes do servidor sem precisar recolher backups novamente

### Recomendações de Configuração de E-mail {/* #email-configuration-recommendations */}

- **Para uso em produção**: Use conexões `STARTTLS` ou `Direct SSL/TLS` para entrega segura de e-mail
- **Para teste local**: Conexões `Plain SMTP` estão disponíveis para redes locais confiáveis
- **Requisito de Endereço de Origem**: Quando usando `Plain SMTP` ou quando a autenticação está desativada, certifique-se de que o campo `From Address` está configurado corretamente
- **Teste sua configuração**: Sempre use o botão "Enviar E-mail de Teste" para verificar se sua configuração de e-mail está funcionando corretamente

## Pontos de Extremidade da API {/* #api-endpoints */}

### Endpoints de Configuração de E-mail {/* #email-configuration-endpoints */}

- `GET /api/email/config` - Obter configuração de e-mail
- `POST /api/email/config` - Atualizar configuração de e-mail
- `POST /api/email/test` - Enviar e-mail de teste
- `DELETE /api/email/config` - Excluir configuração de e-mail

### Endpoints de Gerenciamento de Servidores {/* #server-management-endpoints */}

- `PATCH /api/servers/{id}/password` - Atualizar senha do servidor
- `POST /api/database/maintenance/merge-duplicate-servers` - Mesclar servidores duplicados
