# Versão 1.0.x {/* #version-10x */}

## Visão geral {/* #overview */}

A Versão 1.0.x é um lançamento de recursos que introduz melhorias significativas na configuração de e-mail, capacidades de gerenciamento de servidores e ferramentas de manutenção de banco de dados. Este lançamento se concentra em melhorar a confiabilidade das notificações por e-mail, expandir as opções de conexão SMTP e fornecer melhores ferramentas para gerenciar servidores e integridade do banco de dados.

## Novos Recursos {/* #new-features */}

### Melhorias no Gerenciamento de Servidores {/* #server-management-enhancements */}

- **Funcionalidade de alteração de senha do servidor** - Os usuários agora podem alterar senhas do servidor diretamente na página de detalhes do servidor clicando no ícone de chave
- **Detecção e mesclagem de servidores duplicados** - Nova função no formulário de manutenção do banco de dados para detectar servidores duplicados e mesclá-los em uma única entrada de servidor

### Melhorias no Log de Auditoria {/* #audit-logging-enhancements */}

- **Log de auditoria de carregamento de backup** - Todos os carregamentos de log de backup via o endpoint `/api/upload` agora são automaticamente registrados no log de auditoria. Cada entrada inclui detalhes de backup (ID do servidor, nome do servidor, nome do backup, status, data, duração, contagens de arquivos, tamanhos, avisos e erros) junto com endereço IP do cliente e informações de agente do usuário para rastreamento e fins de segurança

### Melhorias na Configuração de E-mail {/* #email-configuration-enhancements */}

- **Aviso de configuração incompleta** - Alerta visual exibido quando as configurações de e-mail não estão adequadamente configuradas
- **Indicadores de status do serviço** - Rótulos "(desativado)" mostrados nas caixas de seleção de notificação quando os serviços de e-mail não estão configurados
- **Informações de remetente personalizáveis**:
  - Campo `Sender Name` para personalizar o nome de exibição mostrado como remetente nas notificações por e-mail
  - Campo `From Address` para especificar o endereço de e-mail mostrado como remetente
  - Nota: Alguns provedores de e-mail substituirão o `From Address` pelo `SMTP Server Username`
- **Alternância de autenticação SMTP** - Opção para ativar ou desativar a autenticação SMTP, suportando servidores que não exigem autenticação
- **Validação de formato de e-mail** - Validação para campos de endereço de destinatário e origem para garantir o formato correto do endereço de e-mail
- **E-mail de teste aprimorado** - O e-mail de teste agora exibe detalhes de conexão abrangentes, incluindo nome do servidor SMTP, porta, tipo de conexão, status de autenticação, nome de usuário (se aplicável), e-mail do destinatário, endereço de origem, nome do remetente e timestamp do teste

### Suporte de Tipo de Conexão SMTP {/* #smtp-connection-type-support */}

- **Múltiplos tipos de conexão** - Suporte para três tipos de conexão:
  - `Plain SMTP` (sem criptografia) na porta 25
  - `STARTTLS` (atualizar para TLS) na porta 587
  - `Direct SSL/TLS` (criptografado desde o início) na porta 465
- **Tipo de conexão padrão** - Alterado para `Direct SSL/TLS` para novas configurações
- **Requisitos específicos de conexão** - Campo `From Address` é obrigatório para conexões `Plain SMTP` para garantir a identificação adequada do remetente de e-mail e conformidade com RFC 5322

## 🐛 Correções de Bugs {/* #-bug-fixes */}

### Correções do Sistema de E-mail {/* #email-system-fixes */}

- **Cabeçalho `From` ausente corrigido** - Resolvidos erros de conformidade com RFC 5322 garantindo que todas as mensagens de e-mail incluam cabeçalhos `From` adequados
- **Criptografia de e-mail para STARTTLS corrigida** - Corrigido o tratamento de criptografia para conexões `STARTTLS` (porta 587)
- **Conexões SMTP Simples corrigidas** - Resolvidos erros de negociação TLS que estavam causando falha nas conexões `Plain SMTP`
- **Perda de configuração não salva corrigida** - Impedida a limpeza da configuração de e-mail não salva ao alterar a senha
- **Configuração SMTP obsoleta corrigida** - Resolvido o problema em que o endpoint de e-mail de teste estava usando configuração SMTP desatualizada

### Correções da Interface do Usuário {/* #user-interface-fixes */}

- **Alternância de visibilidade de senha corrigida** - Corrigido o comportamento do recurso de visualização de senha no formulário de alteração de senha; clicar no ícone de olho agora mostra a senha para ambos os campos de senha simultaneamente

### Correções do Sistema {/* #system-fixes */}

- **Corrigido logging do entrypoint do Docker** - Resolvido problema em que o script de entrypoint do Docker estava descartando mensagens de log
- **Corrigida cálculo da data de Próxima Execução** - Adicionado recálculo automático da data `Next Run` após coletar logs de backup, garantindo que a data seja atualizada corretamente após a coleta de logs

## 🚀 Notas de Migração {/* #-migration-notes */}

### Da Versão 0.9.x {/* #from-version-09x */}

Esta versão inclui melhorias na configuração de e-mail e gerenciamento de servidores. Ao atualizar da versão 0.9.x:

1. **Nenhuma Migração de Banco de Dados Necessária** - Esta versão não requer alterações no esquema do banco de dados
2. **Atualizações de Configuração de E-mail** - As configurações de e-mail existentes continuarão funcionando, mas você pode querer revisar e atualizar suas configurações para aproveitar os novos recursos:
   - Considere definir um `Sender Name` personalizado para melhor identificação de e-mail
   - Verifique se seu `From Address` está configurado corretamente, especialmente se usar conexões `Plain SMTP`
   - Teste sua configuração de e-mail usando o recurso aprimorado de teste de e-mail
3. **Padrão de Tipo de Conexão** - Novas configurações de e-mail usarão o tipo de conexão `Direct SSL/TLS` por padrão
4. **Gerenciamento de Senha do Servidor** - Agora você pode alterar senhas do servidor diretamente na página de detalhes do servidor sem precisar recoletar backups

### Recomendações de Configuração de E-mail {/* #email-configuration-recommendations */}

- **Para uso em produção**: Use conexões `STARTTLS` ou `Direct SSL/TLS` para entrega segura de e-mail
- **Para testes locais**: Conexões `Plain SMTP` estão disponíveis para redes locais confiáveis
- **Requisito de Endereço de Origem**: Ao usar `Plain SMTP` ou quando a autenticação está desativada, certifique-se de que o campo `From Address` está configurado corretamente
- **Teste sua configuração**: Sempre use o botão "Enviar E-mail de Teste" para verificar se sua configuração de e-mail funciona corretamente

## Endpoints da API {/* #api-endpoints */}

### Endpoints de Configuração de E-mail {/* #email-configuration-endpoints */}

- `GET /api/email/config` - Obter configuração de e-mail
- `POST /api/email/config` - Atualizar configuração de e-mail
- `POST /api/email/test` - Enviar e-mail de teste
- `DELETE /api/email/config` - Excluir configuração de e-mail

### Endpoints de Gerenciamento de Servidor {/* #server-management-endpoints */}

- `PATCH /api/servers/{id}/password` - Atualizar senha do servidor
- `POST /api/database/maintenance/merge-duplicate-servers` - Mesclar servidores duplicados
