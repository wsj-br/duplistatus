# Versão 1.5.2 {/* #version-152 */}

## Visão geral {/* #overview */}

A Versão 1.5.2 é uma versão de manutenção. Em duplicati 2.4.1.0 e posterior, as datas de retenção nos relatórios de Backup são substituídas por `-redacted-` a menos que `--allow-paths-in-log-messages=true` esteja definido, o que deixa a lista de versões disponíveis vazia. As opções de relatório recomendadas e a solução de problemas agora incluem essa configuração.

---

## Melhorias {/* #improvements */}

### Relatórios do duplicati {/* #duplicati-reporting */}

- **Datas de retenção no duplicati 2.4.1.0 e posterior**: Adicionar `--allow-paths-in-log-messages=true` em **Configurações → Padrão opções** (ou nas opções avançadas do Backup). Sem isso, o duplicati substitui as datas em `Backups to consider` por `-redacted-`, portanto, a contagem de versões disponíveis ainda pode aparecer enquanto a lista de Timestamp permanece vazia. Deixe `--reduced-reporting` sem definir, porque essa opção remove o texto da mensagem, e então execute o Backup novamente. Relatórios já armazenados permanecem editados. A opção também inclui caminhos de arquivo locais de Avisos e Erros no relatório HTTP. A dica de log truncado na Página de detalhes de um Backup nomeia a mesma opção.

---

## Notas de migração {/* #migration-notes */}

### Da Versão 1.5.1 {/* #from-version-151 */}

Quando atualizar para a versão 1.5.2:

1. **Nenhuma migração de banco de dados necessária**: Esta versão não altera o esquema do banco de dados.
2. **Dependências**: Execute `pnpm install` para aplicar o lockfile atualizado e as substituições.
3. **duplicati 2.4.1.0 e posterior**: Se a lista de versões disponíveis estiver vazia, adicione `--allow-paths-in-log-messages=true` em cada Servidor duplicati e execute o Backup novamente. Relatórios armazenados existentes permanecem inalterados.
