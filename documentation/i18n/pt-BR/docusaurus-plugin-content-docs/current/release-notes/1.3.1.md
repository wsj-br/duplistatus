# Versão 1.3.1 {/* #version-131 */}

## Visão geral {/* #overview */}

A Versão 1.3.1 introduz suporte completo a múltiplos idiomas para a interface do aplicativo, fortalece a segurança da API com autenticação obrigatória em endpoints adicionais e corrige diversos bugs relacionados à detecção de chave mestra, formatação de localidade e configurações de notificação. Esta versão concentra-se em melhorias de internacionalização e no reforço da segurança.

## Novos Recursos {/* #new-features */}

### Suporte à Interface Multi-idioma {/* #multi-language-interface-support */}

- **Seletor de idioma no cabeçalho do aplicativo**: Escolha seu idioma preferido da interface a partir de um menu suspenso no menu do usuário. Idiomas suportados: Inglês, Alemão, Francês, Espanhol e Português (BR). Sua seleção é salva e persiste entre sessões.
- **Navegação com base na localidade**: Todas as páginas e links agora suportam URLs prefixados com localidade para navegação consistente no seu idioma selecionado.

### Internacionalização dos Modelos de Notificação {/* #notification-templates-internationalization */}

- **Seletor de idioma do modelo**: Modelos de notificação agora suportam múltiplos idiomas com um seletor de idioma dedicado. Modelos padrão pré-traduzidos estão disponíveis para todos os 5 idiomas suportados.
- **Opções de redefinição**: Botões "Redefinir este modelo para o padrão" e "Redefinir tudo para padrão" com diálogos de confirmação para fácil gerenciamento de modelos ao mudar idiomas.
- **Conteúdo de notificação com base na localidade**: Datas, horas, números e valores de status de backup nas notificações agora são formatados de acordo com o idioma do modelo.

### Localização de Datas e Números {/* #date-and-number-localization */}

- **Formatação de datas e horas com base na localidade**: Datas e horas em todo o aplicativo (painel, detalhes do servidor, gráficos, dicas) agora aparecem no formato apropriado para sua localidade (ex: DD/MM/AAAA para localidades europeias, MM/DD/AAAA para inglês).
- **Formatação de números com base na localidade**: Números, tamanhos de arquivos e estatísticas usam formatação apropriada para a localidade (ex: 1.234,56 para alemão, 1.234,56 para inglês).

### Preparação para Suporte a RTL {/* #rtl-support-preparation */}

- **Fundação para idiomas da direita para esquerda**: Infraestrutura foi adicionada para suportar futuros idiomas RTL (árabe, hebraico). Os idiomas atuais permanecem da esquerda para direita.

## Segurança {/* #security */}

### Autenticação de API {/* #api-authentication */}

- **Autenticação obrigatória em endpoints adicionais**: Os seguintes endpoints agora exigem uma sessão válida e token CSRF (anteriormente tinham autenticação opcional):
  - `/api/backups/collect`
  - `/api/backups/sync-schedule`
  - `/api/cron-config` (POST)
  - `/api/notifications/check-overdue`
  - `/api/notifications/clear-overdue-timestamps`
- **Atualizações de segurança de dependências**: Atualizadas dependências vulneráveis (fast-xml-parser, brace-expansion) para resolver problemas de segurança conhecidos.

## Correções de Bugs {/* #bug-fixes */}

- **Detecção de alteração da chave mestra**: Corrigida detecção incorreta de "chave alterada" ao restaurar o banco de dados e o arquivo `.duplistatus.key` juntos (mesma chave). O sistema agora usa uma impressão digital da chave para detecção confiável em vez de verificações baseadas em descriptografia que poderiam interpretar erroneamente corrupção de dados como uma alteração de chave.
- **Carregamento inicial da página de detalhes**: A página de detalhes do servidor agora exibe corretamente mensagens e dados atrasados no primeiro carregamento, em vez de apenas após a primeira atualização automática.

## Melhorias {/* #improvements */}

### Consistência na Internacionalização {/* #internationalisation-consistency */}

- **Rótulos consistentes**: Unidades de tempo, intervalos, rótulos de status e termos comuns agora aparecem consistentemente em todo o aplicativo.
- **Ordenação de dias da semana com base na localidade**: A exibição dos dias da semana no monitoramento de backup respeita seu idioma/localidade. Pode ser substituída nas Configurações de Exibição.

### Códigos de erro e sucesso da API de autenticação (i18n) {/* #auth-api-error-and-success-codes-i18n */}

- **Códigos estáveis de erro e sucesso**: Endpoints de autenticação (`/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/change-password`, `/api/auth/password-policy`) agora retornam um `errorCode` (e, em caso de sucesso, um `successCode`) além do campo `error` ou `message` em inglês. Clientes usam esses códigos para mostrar mensagens localizadas no idioma do usuário.
- **Página de login**: Todas as mensagens de erro de login (ex: "Nome de usuário e senha são obrigatórios", "Nome de usuário ou senha inválidos", "Conta bloqueada") agora são traduzidas na página de login para todas as cinco localidades.
- **Modal de alteração de senha**: Todas as mensagens de erro e sucesso da API de alteração de senha agora são traduzidas no modal de alteração de senha.
- **Referência da API**: A documentação da API [Autenticação e Segurança](../api-reference/authentication-security.md#auth-api-error-and-success-codes-i18n) lista todos os códigos de erro e sucesso e explica como utilizá-los para i18n.

### Melhorias na IU {/* #ui-improvements */}

- **Largura do filtro de servidor**: Aumentada a largura do filtro de servidor no formulário de notificações de backup (260px → 360px) para melhor usabilidade.
- **Seleção em massa**: Interface de seleção em massa aprimorada com suporte adequado de pluralização para contagem de backups.
- **Dicas de ajuda**: Texto de dica de ajuda aprimorado com contexto de nome da página.

### Documentação {/* #documentation */}

- **Renomeação da página de configuração**: A página de configuração de fuso horário e idioma foi renomeada de `configure-tz-lang` para `configure-tz`.
- **Guia de modelos de notificação**: Guia do usuário atualizado para documentar o novo seletor de idioma do modelo, botões de redefinição e comportamento de idioma.
- **Documentação multilíngue**: O guia do usuário agora documenta como alterar o idioma da interface por meio do seletor de idioma no menu do usuário.

## Notas de Migração {/* #migration-notes */}

### Da Versão 1.3.0 {/* #from-version-130 */}

Ao atualizar para a versão 1.3.1:

1. **Autenticação de API**: Scripts ou ferramentas que chamam os endpoints de coleta de backups, sync-schedule, cron-config ou verificação/limpeza de notificação agora devem incluir autenticação de sessão válida e tokens CSRF.

2. **Nenhuma migração de banco de dados necessária**: Esta versão não requer nenhuma alteração no esquema do banco de dados.

3. **Suporte a localidade**: A variável de ambiente `LANG` não é mais utilizada. Você pode definir o idioma para notificações na página `Settings > Templates`.
