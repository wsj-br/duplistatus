# Versão 0.7.x {/* #version-07x */}

## Visão Geral {/* #overview */}

A versão 0.7.x é um lançamento importante que introduz significativas melhorias no esquema do banco de dados, na estrutura da API e na interface do usuário. Esta versão inclui alterações que quebram a compatibilidade que exigem atualizações em integrações externas.

## Alterações que quebram a compatibilidade {/* #breaking-changes */}

### Alterações no esquema do banco de dados {/* #database-schema-changes */}
- **Renomeação de tabelas**: Tabela `machines` renomeada para `servers`
- **Novos campos**: Adicionados campos `alias`, `notes`, `created_at` e `updated_at`
- **Alterações nas respostas da API**: Nomes de campos atualizados para consistência

### Alterações na API incompatíveis com versões anteriores {/* #backward-incompatible-api-changes */}
- **Renomeação de campos**: `totalMachines` → `totalServers`
- **Renomeação de objetos**: `machine` → `server` nas respostas da API
- **Renomeação de campos**: `backup_types_count` → `backupJobsCount`

:::warning
**Integrações externas usando a API devem ser atualizadas** para funcionar com a versão 0.7.x. Consulte o guia [Alterações na API incompatíveis com versões anteriores](../migration/api-changes) para obter detalhes.
:::

## Guia de Migração {/* #migration-guide */}

### Migração Automática {/* #automatic-migration */}
A migração da versão 0.6.x para 0.7.x ocorre automaticamente:

1. **Criação de Backup**: Backup do banco de dados é criado automaticamente
2. **Atualização do Esquema**: Esquema do banco de dados é atualizado automaticamente
3. **Migração de Dados**: Dados existentes são preservados e migrados
4. **Verificação**: Migração é verificada e registrada

### Etapas Manuais Requeridas {/* #manual-steps-required */}
- **Atualizar Integrações Externas**: Atualize quaisquer ferramentas externas que usam a API
- **Testar Funcionalidade**: Verifique se todos os recursos estão funcionando corretamente
- **Atualizar Documentação**: Atualize qualquer documentação personalizada

## Alterações de Configuração {/* #configuration-changes */}

### Novas Opções de Configuração {/* #new-configuration-options */}

```yaml
# Server management
servers:
  defaultAlias: true
  showNotes: true
  sortBy: "name" # name, status, lastBackup

# API settings
api:
  version: "1.0"
  rateLimit: 100
  timeout: 30000

# Database settings
database:
  backupRetention: 7
  autoVacuum: true
  optimizeInterval: 24
```

### Opções Descontinuadas {/* #deprecated-options */}
- Configuração `machines` (use `servers` em vez disso)
- Nomes de campos da API antigos (use os novos nomes de campos)

```yaml

    image: wsjbr/duplistatus:0.7.x
```

## Instruções de Atualização {/* #upgrade-instructions */}

### Da Versão 0.6.x {/* #from-version-06x */}
1. **Faça backup dos seus dados** (backup automático criado durante a atualização)
2. **Atualize a imagem Docker**: `docker pull wsjbr/duplistatus:0.7.x`
3. **Reinicie o container**: `docker-compose down && docker-compose up -d`
4. **Monitore os logs**: `docker logs -f duplistatus`
5. **Atualize as integrações**: Atualize quaisquer ferramentas externas usando a API
6. **Verifique a atualização**: Verifique se todos os recursos estão funcionando corretamente

### Da Versão 0.5.x ou Anterior {/* #from-version-05x-or-earlier */}
1. **Primeiro atualize para 0.6.x** (se disponível)
2. **Em seguida, atualize para 0.7.x** usando os passos acima

## Problemas Conhecidos {/* #known-issues */}

### Problemas de Migração {/* #migration-issues */}
- **Bancos de Dados Grandes**: A migração pode levar mais tempo para bancos de dados grandes
- **Espaço em Disco**: Certifique-se de ter espaço em disco suficiente para o backup de migração
- **Permissões**: Verifique as permissões de arquivo para acesso ao banco de dados

### Compatibilidade da API {/* #api-compatibility */}
- **Ferramentas Externas**: Ferramentas externas usando a API precisam de atualizações
- **Nomes dos Campos**: Alguns nomes de campos foram alterados
- **Formato da Resposta**: Alguns formatos de resposta foram alterados

### Soluções Alternativas {/* #workarounds */}
- **Migração**: Certifique-se de ter espaço em disco e tempo suficientes para a migração
- **API**: Atualize as integrações externas para usar o novo formato da API
- **Testes**: Teste todas as funcionalidades após a atualização
