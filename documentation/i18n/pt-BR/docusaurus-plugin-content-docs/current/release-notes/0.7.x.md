# Versão 0.7.x {/* #version-07x */}

## Visão geral {/* #overview */}

Versão 0.7.x é uma versão principal que introduz melhorias significativas no esquema de banco de dados, estrutura de API e interface do usuário. Esta versão inclui alterações significativas que exigem atualizações nas Integrações externas.

## Mudanças Significativas {/* #breaking-changes */}

### Mudanças no Esquema do Banco de Dados {/* #database-schema-changes */}
- **Renomeação de Tabela**: tabela `machines` renomeada para `servers`
- **Novos Campos**: Adicionados os campos `alias`, `notes`, `created_at` e `updated_at`
- **Mudanças na Resposta da API**: Nomes de campos atualizados para consistência

### Mudanças de API incompatíveis com versões anteriores {/* #backward-incompatible-api-changes */}
- **Renomeação de Campo**: `totalMachines` → `totalServers`
- **Renomeação de Objeto**: `machine` → `server` nas respostas da API
- **Renomeação de Campo**: `backup_types_count` → `backupJobsCount`

:::warning
**Integrações externas que usam a API devem ser atualizadas** para funcionar com a versão 0.7.x. Consulte o guia [Alterações de API incompatíveis com versões anteriores](../migration/api-changes) para mais detalhes.
:::

## Guia de Migração {/* #migration-guide */}

### Migração Automática {/* #automatic-migration */}
A migração de 0.6.x para 0.7.x acontece automaticamente:

1. **Criação de Backup**: Backup automático do banco de dados é criado
2. **Atualização de Schema**: Schema do banco de dados é atualizado automaticamente
3. **Migração de Dados**: Dados existentes são preservados e migrados
4. **Verificação**: Migração é verificada e registrada

### Passos Manuais Necessários {/* #manual-steps-required */}
- **Atualizar Integrações Externas**: Atualize quaisquer ferramentas externas que utilizem a API
- **Testar Funcionalidade**: Verifique se todos os recursos funcionam corretamente
- **Atualizar Documentação**: Atualize qualquer documentação personalizada

## Mudanças de Configuração {/* #configuration-changes */}

### Novas Opções de Configuração {/* #new-configuration-options */}

```yaml
# Server management
servers:
  defaultAlias: true
  showNotes: true
  sortBy: "name" # name, status, lastBackup

# API settings
api:
  version: "1.0"
  rateLimit: 100
  timeout: 30000

# Database settings
database:
  backupRetention: 7
  autoVacuum: true
  optimizeInterval: 24
```

### Opções Obsoletas {/* #deprecated-options */}
- `machines` configuração (use `servers` em vez disso)
- Nomes de campos da API antigos (use novos nomes de campos)

### Docker Compose {/* #docker-compose */}

```yaml

  duplistatus:
    image: wsjbr/duplistatus:0.7.x
    container_name: duplistatus
    restart: unless-stopped
    ports:

    volumes:
      - duplistatus_data:/app/data

  --name duplistatus \

```

## Instruções de Atualização {/* #upgrade-instructions */}

### Da Versão 0.6.x {/* #from-version-06x */}
1. **Backup dos seus dados** (backup automático criado durante a atualização)
2. **Atualizar imagem Docker**: `docker pull wsjbr/duplistatus:0.7.x`
3. **Reiniciar contêiner**: `docker-compose down && docker-compose up -d`
4. **Monitorar logs**: `docker logs -f duplistatus`
5. **Atualizar integrações**: Atualize todas as ferramentas externas que usam a API
6. **Verificar atualização**: Verifique se todos os recursos estão funcionando corretamente

### Da Versão 0.5.x ou Anterior {/* #from-version-05x-or-earlier */}
1. **Primeiro atualize para 0.6.x** (se disponível)
2. **Depois atualize para 0.7.x** usando os passos acima

## Problemas Conhecidos {/* #known-issues */}

### Problemas de Migração {/* #migration-issues */}
- **Bancos de Dados Grandes**: A migração pode demorar mais para bancos de dados grandes
- **Espaço em Disco**: Garanta espaço em disco suficiente para o backup da migração
- **Permissões**: Verifique as permissões de arquivo para acesso ao banco de dados

### Compatibilidade da API {/* #api-compatibility */}
- **Ferramentas Externas**: Ferramentas externas que usam a API precisam de atualizações
- **Nomes de Campos**: Alguns nomes de campos mudaram
- **Formato de Resposta**: Alguns formatos de resposta mudaram

### Soluções Alternativas {/* #workarounds */}
- **Migração**: Garanta espaço em disco e tempo suficientes para a migração
- **API**: Atualize integrações externas para usar o novo formato da API
- **Testes**: Teste toda a funcionalidade após a atualização
