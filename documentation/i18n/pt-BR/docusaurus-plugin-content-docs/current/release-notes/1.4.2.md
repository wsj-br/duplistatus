# Versão 1.4.2 {/* #version-142 */}

## Visão geral {/* #overview */}

A versão 1.4.2 é uma versão de manutenção focada em suporte mais amplo de idiomas, confiabilidade e higiene de dependências. Ela introduz uma interface totalmente localizada em chinês simplificado e hindi, expande a documentação para sete idiomas e resolve um importante erro de inicialização no Docker, além de diversos problemas com mesclagem de painel e servidor. As dependências também foram atualizadas, incluindo uma atualização importante para `nodemailer`.

---

## Novos recursos {/* #new-features */}

### Suporte de idioma {/* #language-support */}

- **Interface em chinês simplificado e hindi**: A interface do aplicativo agora está totalmente disponível em chinês simplificado e hindi, juntando-se ao inglês, francês, alemão, espanhol e português brasileiro. Selecione-os no menu de idioma nas Configurações.
- **Expansão dos idiomas da documentação**: A documentação online agora é publicada em sete idiomas, adicionando o hindi e o chinês simplificado às traduções existentes.

---

## Melhorias {/* #improvements */}

### Coleção de backups {/* #backup-collection */}

- **Identidade estável do servidor ao coletar logs**: Ao coletar logs de backup, o duplistatus agora associa o nome da máquina Duplicati aos seus servidores existentes e reutiliza o registro desse servidor, em vez de depender do ID da máquina Duplicati. Isso mantém o histórico de backup vinculado ao mesmo servidor mesmo que o ID da máquina Duplicati mude (por exemplo, após uma reinstalação), reduzindo entradas duplicadas de servidores.

### Documentação {/* #documentation */}

- **Lista atualizada de idiomas**: O README e a documentação agora descrevem todos os sete idiomas suportados e fazem link para cada versão traduzida.
- **Bandeiras no menu de idioma da documentação**: Adicionadas bandeiras para a nova documentação em hindi e chinês simplificado, e alterada a bandeira do português para a bandeira de Portugal por consistência. As bandeiras agora são exibidas corretamente no Windows, Linux e Chromium sem necessidade de download de fontes externas.
- **Expansão da orientação sobre servidores duplicados**: O guia do usuário agora explica ambas as causas de servidores duplicados (uma alteração no ID da máquina Duplicati e um bug da API Duplicati que mistura o ID de identidade e o ID da máquina) e documenta a solução alternativa do lado Duplicati juntamente com a etapa de mesclagem duplistatus.

### Desempenho do painel {/* #dashboard-performance */}

- **Menos verificações de login ao carregar**: O painel agora busca seu usuário atual uma vez e compartilha-o entre a página (cabeçalho, proteção de configurações, tema e widgets) em vez de cada componente solicitá-lo separadamente, reduzindo solicitações redundantes quando uma página é carregada.

---

## Correções de bugs {/* #bug-fixes */}

- **Falha na inicialização do Docker**: Corrigido um erro na inicialização do contêiner que reportava `Cannot find module '.../@swc/helpers/...'`, o qual poderia impedir o aplicativo de iniciar. Os contêineres agora iniciam com confiabilidade.
- **Entradas duplicadas no painel**: O painel não mostra mais múltiplas linhas para o mesmo backup quando vários registros compartilham a mesma data do último backup.
- **Mesclagem de servidores duplicados**: A mesclagem de servidores agora também consolida IDs de backup Duplicati duplicados que compartilham o mesmo nome de backup, mantendo o ID do backup mais recente. As operações de mesclagem agora são registradas no Log de Auditoria.

---

## Segurança {/* #security */}

### Atualizações de dependências {/* #dependency-updates */}

- **`nodemailer` atualizado para 9.x**: Atualizada a biblioteca de e-mail para a versão principal mais recente. A única alteração significativa na v9 (validação TLS mais rigorosa ao buscar anexos remotos, OAuth2 ou conteúdo de proxy) não afeta o duplistatus, que envia apenas e-mails de texto e HTML embutidos.
- **Outras atualizações de dependências**: Atualizados diversos builds e dependências de tipo para suas versões compatíveis mais recentes.

---

## Notas de migração {/* #migration-notes */}

### Da versão 1.4.1 {/* #from-version-141 */}

Ao atualizar para a versão 1.4.2:

1. **Nenhuma migração de banco de dados necessária**: Esta versão não exige nenhuma alteração no esquema do banco de dados.
2. **Dependências**: Execute `pnpm install` para aplicar o arquivo de bloqueio e as substituições atualizadas.
3. **Nenhuma alteração de configuração necessária**: As configurações existentes, incluindo o idioma escolhido, são mantidas.
