# Versão 1.3.0 {/* #version-130 */}

## Visão Geral {/* #overview */}

A versão 1.3.0 introduz políticas de senha configuráveis, um novo visualizador de logs do aplicativo para administradores, exibição de dias da semana sensível à localidade e várias melhorias na experiência do usuário. Este lançamento se concentra em ferramentas administrativas aprimoradas e suporte internacionalizado aprimorado.

## Novos recursos {/* #new-features */}

### Política de Senha Configurável {/* #configurable-password-policy */}

- **Variáveis de ambiente de política de senha**: Configure os requisitos de validação de senha por meio de variáveis de ambiente:
  - `PWD_ENFORCE`: Defina como `false` para desativar os requisitos de complexidade de senha (maiúsculas, minúsculas, números). Padrão é aplicar todas as regras. Quando desativado, apenas o comprimento mínimo é aplicado.
  - `PWD_MIN_LEN`: Define o comprimento mínimo da senha em caracteres. Padrão é 8 caracteres.
  - A verificação de senha padrão (evitando o uso da senha padrão do administrador) é sempre aplicada, independentemente da configuração de `PWD_ENFORCE`.

### Visualizador de Logs do Aplicativo {/* #application-logs-viewer */}

- **Novo visualizador de logs apenas para administradores**: Visualize e baixe logs do aplicativo diretamente da página de Configurações:
  - Acesse o arquivo consolidado de `application.log` e as versões rotacionadas de logs
  - Seletor de contagem de linhas configurável (100, 500, 1000, 5000, 10000 linhas)
  - Filtro de pesquisa em tempo real com correspondência de texto insensível a maiúsculas e minúsculas
  - Alternância de rolagem automática para monitoramento de logs em tempo real com polling automático
  - Copiar para a área de transferência e exportar logs filtrados como arquivo de texto
  - Exibição de metadados do arquivo mostrando contagem de linhas, tamanho do arquivo e timestamp da última modificação
  - Rotação de logs na inicialização do contêiner (configurável via `LOG_ROTATION_VERSIONS`, padrão: 5)

### Guia de Usuário Sensível ao Contexto {/* #context-aware-user-guide */}

- **Botão de ajuda dinâmico**: O botão do Guia do Usuário no cabeçalho do aplicativo agora abre a documentação relevante à página atual. A dica de ferramenta é atualizada para mostrar "Ajuda para `Page Name`" para indicar qual documentação será aberta.

### Aprimoramento de Configuração do Servidor {/* #server-configuration-enhancement */}

- **Acesso rápido à UI do Duplicati**: Clicar com o botão direito no botão de configuração do servidor ou em qualquer item do servidor no popover de seleção do servidor abre a UI legada do Duplicati (`/ngax`) em uma nova guia.

## 🔧 Melhorias {/* #-improvements */}

### Exibição de Dias da Semana Sensível à Localidade {/* #locale-aware-weekday-display */}

- **Ordenação de dias da semana internacionalizada**: A exibição de dias da semana no formulário de monitoramento de backup agora respeita as configurações de localidade do seu navegador. Os dias da semana são exibidos na ordem correta com base na localidade (Segunda-Sábado para Reino Unido/Europa, Domingo-Sábado para EUA/Brasil).

### Tratamento Aprimorado de Erros SMTP {/* #enhanced-smtp-error-handling */}

- **Mensagens de erro aprimoradas**: As mensagens de erro SMTP agora fornecem orientação mais precisa:
  - Erros de autenticação indicam claramente problemas de nome de usuário/senha
  - Erros de versão SSL/TLS são corretamente identificados
  - Sugestões de tipo de conexão aparecem apenas quando realmente relevantes

### Comportamento de Notificações por Toast {/* #toast-notification-behaviour */}

- **Notificações de erro persistentes**: As notificações de erro agora persistem até serem fechadas manualmente, garantindo que você não perca mensagens de erro importantes. Notificações de sucesso e informativas são dispensadas automaticamente após 3 segundos.

### Tabela de Configurações de Notificações {/* #notification-settings-table */}

- **Layout simplificado**: A tabela de configurações de notificações foi simplificada com uma coluna combinada "Servidor / Backup" e ícones contextuais indicando o status de configuração adicional de destino.

## 🚀 Notas de Migração {/* #-migration-notes */}

### Da Versão 1.2.x {/* #from-version-12x */}

Ao atualizar para a versão 1.3.0:

1. **Política de Senha**: A nova política de senha exige por padrão todos os requisitos de complexidade. Se você precisar de uma política de senha mais simples, configure as variáveis de ambiente `PWD_ENFORCE` e `PWD_MIN_LEN`.

2. **Logs do Aplicativo**: Todas as saídas do contêiner (servidor e serviço cron) agora são consolidadas em um único arquivo `data/logs/application.log`.

3. **Rotação de Logs**: A rotação de logs é configurável via a variável de ambiente `LOG_ROTATION_VERSIONS` (padrão: 5 versões).

4. **Nenhuma Migração de Banco de Dados Necessária**: Esta versão não requer nenhuma alteração no esquema do banco de dados.

## Pontos de Extremidade da API {/* #api-endpoints */}

O seguinte endpoint da API foi introduzido nesta versão:

### Endpoint de Política de Senha {/* #password-policy-endpoint */}

- `GET /api/auth/password-policy` - Retorna a configuração atual da política de senha

### Endpoints de Logs do Aplicativo {/* #application-logs-endpoints */}

- `GET /api/application-logs` - Visualizar logs com seleção de arquivo e funcionalidade de tail
- `GET /api/application-logs/export` - Exportar logs filtrados como arquivo de texto

### Endpoints Removidos {/* #removed-endpoints */}

Os seguintes endpoints da API não utilizados foram removidos nesta versão:

- `DELETE /api/backups/[backupId]` - Endpoint de desenvolvimento que nunca foi utilizado
- `GET /api/audit-log/stats` - Endpoint não foi chamado pelo visualizador de log de auditoria
