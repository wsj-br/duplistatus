# Versão 1.3.0 {/* #version-130 */}

## Visão geral {/* #overview */}

A versão 1.3.0 introduz políticas de senha configuráveis, um novo visualizador de logs do aplicativo para administradores, exibição de dias da semana com base na localidade e várias melhorias na experiência do usuário. Esta versão foca em ferramentas administrativas aprimoradas e suporte melhorado à internacionalização.

## Novos Recursos {/* #new-features */}

### Política de Senha Configurável {/* #configurable-password-policy */}

- **Variáveis de ambiente para política de senha**: Configure os requisitos de validação de senha através de variáveis de ambiente:
  - `PWD_ENFORCE`: Defina como `false` para desativar os requisitos de complexidade de senha (maiúsculas, minúsculas, números). O padrão é aplicar todas as regras. Quando desativado, apenas o comprimento mínimo é aplicado.
  - `PWD_MIN_LEN`: Define o comprimento mínimo da senha em caracteres. O padrão é 8 caracteres.
  - A verificação padrão de senha (impedindo o uso da senha padrão do administrador) é sempre aplicada independentemente da configuração `PWD_ENFORCE`.

### Visualizador de Logs do Aplicativo {/* #application-logs-viewer */}

- **Novo visualizador de logs exclusivo para administradores**: Visualize e baixe logs do aplicativo diretamente da página de Configurações:
  - Acesse o arquivo consolidado `application.log` e versões de logs rotacionados
  - Seletor configurável de contagem de linhas (100, 500, 1000, 5000, 10000 linhas)
  - Filtro de pesquisa em tempo real com correspondência de texto sem diferenciação de maiúsculas/minúsculas
  - Alternância de rolagem automática para monitoramento de logs em tempo real com atualização automática
  - Copiar para área de transferência e exportar logs filtrados como arquivo de texto
  - Exibição de metadados do arquivo mostrando contagem de linhas, tamanho do arquivo e timestamp da última modificação
  - Rotação de logs na inicialização do contêiner (configurável via `LOG_ROTATION_VERSIONS`, padrão: 5)

### Guia de Usuário com Contexto {/* #context-aware-user-guide */}

- **Botão de ajuda dinâmico**: O botão Guia do Usuário no cabeçalho do aplicativo agora abre documentação relevante para a página atual. A dica de ferramenta é atualizada para mostrar "Ajuda para `Page Name`" para indicar qual documentação será aberta.

### Aprimoramento da Configuração do Servidor {/* #server-configuration-enhancement */}

- **Acesso rápido à interface do Duplicati**: Clicar com o botão direito no botão de configuração do servidor ou em qualquer item de servidor no pop-over de seleção de servidor abre a interface legada do Duplicati (`/ngax`) em uma nova aba.

## 🔧 Melhorias {/* #-improvements */}

### Exibição de Dias da Semana com Base na Localidade {/* #locale-aware-weekday-display */}

- **Ordenação internacionalizada dos dias da semana**: A exibição dos dias da semana no formulário de monitoramento de backup agora respeita as configurações de localidade do seu navegador. Os dias da semana são exibidos na ordem correta com base na localidade (segunda-feira a domingo para Reino Unido/Europa, domingo a sábado para Estados Unidos/Brasil).

### Tratamento Aprimorado de Erros SMTP {/* #enhanced-smtp-error-handling */}

- **Mensagens de erro aprimoradas**: As mensagens de erro SMTP agora fornecem orientações mais precisas:
  - Erros de autenticação indicam claramente problemas com nome de usuário/senha
  - Erros de versão SSL/TLS são identificados corretamente
  - Sugestões de tipo de conexão aparecem apenas quando realmente relevantes

### Comportamento das Notificações Toast {/* #toast-notification-behaviour */}

- **Notificações de erro persistentes**: As notificações toast de erro agora permanecem até serem fechadas manualmente, garantindo que você não perca mensagens de erro importantes. As notificações de sucesso e informativas são fechadas automaticamente após 3 segundos.

### Tabela de Configurações de Notificação {/* #notification-settings-table */}

- **Layout simplificado**: A tabela de configurações de notificação foi otimizada com uma coluna combinada "Servidor / Backup" e ícones contextuais indicando o status de configuração de destino adicional.

## 🚀 Notas de Migração {/* #-migration-notes */}

### Da Versão 1.2.x {/* #from-version-12x */}

Ao atualizar para a versão 1.3.0:

1. **Política de Senha**: A nova política de senha tem como padrão a imposição de todos os requisitos de complexidade. Se você precisar de uma política de senha mais simples, configure as variáveis de ambiente `PWD_ENFORCE` e `PWD_MIN_LEN`.

2. **Logs do Aplicativo**: Toda a saída do contêiner (servidor e serviço cron) agora está consolidada em um único arquivo `data/logs/application.log`.

3. **Rotação de Log**: A rotação de log é configurável através da variável de ambiente `LOG_ROTATION_VERSIONS` (padrão: 5 versões).

4. **Nenhuma Migração de Banco de Dados Necessária**: Esta versão não requer alterações no esquema do banco de dados.

## Endpoints da API {/* #api-endpoints */}

O seguinte endpoint de API foi introduzido nesta versão:

### Endpoint de Política de Senha {/* #password-policy-endpoint */}

- `GET /api/auth/password-policy` - Retorna a configuração atual da política de senha

### Endpoints de Logs do Aplicativo {/* #application-logs-endpoints */}

- `GET /api/application-logs` - Visualizar logs com seleção de arquivo e funcionalidade de finalização
- `GET /api/application-logs/export` - Exportar logs filtrados como arquivo de texto

### Endpoints Removidos {/* #removed-endpoints */}

Os seguintes endpoints de API não utilizados foram removidos nesta versão:

- `DELETE /api/backups/[backupId]` - Endpoint exclusivo para desenvolvimento que nunca foi utilizado
- `GET /api/audit-log/stats` - O endpoint não era chamado pelo visualizador de log de auditoria
