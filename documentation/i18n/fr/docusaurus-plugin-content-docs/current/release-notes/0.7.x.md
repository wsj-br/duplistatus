# Version 0.7.x {/* #version-07x */}

## Aperçu {/* #overview */}

La Version 0.7.x est une version majeure qui introduit des améliorations significatives au schéma de la base de données, à la structure de l'API et à l'interface utilisateur. Cette version inclut des modifications incompatibles qui nécessitent des mises à jour des intégrations externes.

## Modifications incompatibles {/* #breaking-changes */}

### Modifications du schéma de la base de données {/* #database-schema-changes */}
- **Renommage de table** : table `machines` renommée en `servers`
- **Nouveaux champs** : ajout des champs `alias`, `notes`, `created_at` et `updated_at`
- **Modifications des réponses API** : noms de champs mis à jour pour la cohérence

### Modifications d'API incompatibles {/* #backward-incompatible-api-changes */}
- **Renommage de champ** : `totalMachines` → `totalServers`
- **Renommage d'objet** : `machine` → `server` dans les réponses API
- **Renommage de champ** : `backup_types_count` → `backupJobsCount`

:::warning
**Les intégrations externes utilisant l'API doivent être mises à jour** pour fonctionner avec la version 0.7.x. Consultez le guide [Modifications d'API incompatibles](../migration/api-changes) pour plus de détails.
:::

## Guide de migration {/* #migration-guide */}

### Migration automatique {/* #automatic-migration */}
La migration de 0.6.x vers 0.7.x se fait automatiquement :

1. **Création de sauvegarde** : Une sauvegarde de la base de données automatique est créée
2. **Mise à jour du schéma** : Le schéma de la base de données est mis à jour automatiquement
3. **Migration des données** : Les données existantes sont conservées et migrées
4. **Vérification** : La migration est vérifiée et enregistrée

### Étapes manuelles requises {/* #manual-steps-required */}
- **Mettre à jour les Intégrations externes** : Mettez à jour tous les outils externes utilisant l'API
- **Tester la fonctionnalité** : Vérifiez que toutes les fonctionnalités fonctionnent correctement
- **Mettre à jour la documentation** : Mettez à jour toute documentation personnalisée

## Modifications de configuration {/* #configuration-changes */}

### Nouvelles options de configuration {/* #new-configuration-options */}

```yaml
# Server management
servers:
  defaultAlias: true
  showNotes: true
  sortBy: "name" # name, status, lastBackup

# API settings
api:
  version: "1.0"
  rateLimit: 100
  timeout: 30000

# Database settings
database:
  backupRetention: 7
  autoVacuum: true
  optimizeInterval: 24
```

### Options obsolètes {/* #deprecated-options */}
- `machines` configuration (utilisez `servers` à la place)
- Anciens noms de champs API (utilisez les nouveaux noms de champs)

    image: wsjbr/duplistatus:0.7.x

## Instructions de mise à jour {/* #upgrade-instructions */}

### À partir de la Version 0.6.x {/* #from-version-06x */}
1. **Sauvegardez vos données** (sauvegarde automatique créée lors de la mise à jour)
2. **Mettez à jour l'image Docker** : `docker pull wsjbr/duplistatus:0.7.x`
3. **Redémarrez le conteneur** : `docker-compose down && docker-compose up -d`
4. **Surveillez les journaux** : `docker logs -f duplistatus`
5. **Mettez à jour les intégrations** : Mettez à jour tous les outils externes utilisant l'API
6. **Vérifiez la mise à jour** : Vérifiez que toutes les fonctionnalités fonctionnent correctement

### À partir de la Version 0.5.x ou antérieure {/* #from-version-05x-or-earlier */}
1. **Mettez d'abord à jour vers 0.6.x** (si disponible)
2. **Puis mettez à jour vers 0.7.x** en utilisant les étapes ci-dessus

## Problèmes connus {/* #known-issues */}

### Problèmes de migration {/* #migration-issues */}
- **Grandes bases de données** : La migration peut prendre plus de temps pour les grandes bases de données
- **Espace disque** : Assurez-vous d'avoir suffisamment d'espace disque pour la sauvegarde de migration
- **Permissions** : Vérifiez les permissions de fichier pour l'accès à la base de données

### Compatibilité de l'API {/* #api-compatibility */}
- **Outils externes** : Les outils externes utilisant l'API nécessitent des mises à jour
- **Noms de champs** : Certains noms de champs ont changé
- **Format de réponse** : Certains formats de réponse ont changé

### Solutions de contournement {/* #workarounds */}
- **Migration** : Assurez-vous d'avoir suffisamment d'espace disque et de temps pour la migration
- **API** : Mettez à jour les intégrations externes pour utiliser le nouveau format d'API
- **Test** : Testez toutes les fonctionnalités après la mise à jour
