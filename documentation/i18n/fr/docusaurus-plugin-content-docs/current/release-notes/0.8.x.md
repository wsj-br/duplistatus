# Version 0.8.x {/* #version-08x */}

## Aperçu {/* #overview */}

La Version 0.8.x est une mise à jour majeure qui introduit des améliorations de sécurité importantes, des capacités de gestion de serveur améliorées, et un système de notification complet avec support du courrier électronique SMTP. Cette version se concentre sur le renforcement de la sécurité, l'amélioration de l'expérience utilisateur, et la fourniture d'options de Surveillance des sauvegardes plus flexibles.

## Nouvelles fonctionnalités {/* #new-features */}

### Améliorations de la gestion des serveurs {/* #server-management-enhancements */}

- **Persistance automatique de l'URL du serveur et du mot de passe** lors de la collecte de sauvegardes
  - Les utilisateurs peuvent mettre à jour l'URL et le mot de passe en utilisant deux méthodes :
     - Recollecte de sauvegardes avec des valeurs mises à jour
     - Modification des paramètres dans [Paramètres → Paramètres du serveur](../user-guide/settings/server-settings.md)

### Surveillance améliorée des sauvegardes {/* #enhanced-backup-monitoring */}

- **Nouvel onglet de configuration `Backup monitoring`** avec des paramètres d'intervalle compatibles avec le serveur Duplicati
    - Support des intervalles personnalisés (par exemple, « 1D12h »)
    - Mises à jour automatiques de l'intervalle en retard à partir de la configuration Duplicati lors de la collecte du journal de sauvegarde
    - **Recommandé :** Exécutez la collecte après avoir modifié les intervalles des tâches de sauvegarde sur le serveur Duplicati pour synchroniser la configuration de duplistatus
    - Les modèles de notifications utilisent maintenant `{backup_interval}` au lieu de `{backup_interval_value}` et `{backup_interval_type}`.

### Configuration de l'appareil NTFY {/* #ntfy-device-configuration */}

- **Génération de code QR** pour la configuration automatique de l'appareil afin de recevoir des notifications de **duplistatus**
   - Clic droit sur le bouton `View NTFY Messages` dans la barre d'outils de l'application
   - Bouton « Configurer l'appareil » dans [Paramètres → Paramètres NTFY](../user-guide/settings/ntfy-settings.md)

### Collecte améliorée des sauvegardes {/* #improved-backup-collection */}

- **Détection automatique HTTP/HTTPS**, les connexions sont essayées dans cet ordre : HTTPS → HTTPS avec certificat auto-signé → secours HTTP
- **Menu déroulant de sélection du serveur** dans l'interface `Collect Backup Logs` pour la collecte directe spécifique au serveur
- **Plusieurs adresses** dans le nom d'hôte (séparées par des virgules) sont maintenant acceptées (doivent partager le même mot de passe et port)
- **Boutons de collecte de sauvegarde pour serveur unique** ajoutés à `Dashboard (table)`, [Paramètres → Surveillance des sauvegardes](../user-guide/settings/backup-monitoring-settings.md) et [Paramètres → Serveurs](../user-guide/settings/server-settings.md)
- **Fonctionnalité de collecte en masse** pour tous les serveurs avec une configuration valide (URL et mot de passe)
   - `Collect All` boutons dans [Paramètres → Surveillance des sauvegardes](../user-guide/settings/backup-monitoring-settings.md) et [Paramètres → Serveurs](../user-guide/settings/server-settings.md)
   - Menu contextuel au clic droit sur le bouton `Collect Backup Logs` dans la barre d'outils de l'application

### Système de notifications amélioré {/* #enhanced-notification-system */}

- **Support des notifications par courriel SMTP :**
    - Configuration du serveur SMTP dans [Paramètres → Paramètres de messagerie](../user-guide/settings/email-settings.md)
    - Configuration par tâche de sauvegarde pour les notifications NTFY et/ou par courriel
    - Modèles au format HTML utilisant les [Paramètres → Modèles de notification](../user-guide/settings/notification-templates.md)
- **Configuration des notifications par tâche de sauvegarde :**
    - Préférences de notification individuelles dans [Paramètres → Notifications de sauvegarde](../user-guide/settings/backup-notifications-settings.md)
    - Indicateurs visuels (icônes grisées) quand NTFY ou le courriel n'est pas correctement configuré

- **Support des paramètres régionaux :**
    - création d'une nouvelle variable d'environnement `LANG` pour définir les paramètres régionaux dans l'application
    - le format des dates et des nombres dans les notifications et les journaux est maintenant prévisible

## 🔒 Améliorations de la sécurité {/* #-security-enhancements */}

### Protection CSRF {/* #csrf-protection */}

- **Authentification basée sur les sessions** avec une gestion robuste des sessions
- **Validation du jeton CSRF** appliquée pour toutes les demandes d'API modifiant l'état
- **Les sessions expirent automatiquement** après 24 heures ; les jetons CSRF se rafraîchissent toutes les 30 minutes
- Assure la protection contre les attaques par falsification de requête intersite tout en préservant la compatibilité avec les API externes

### Minimisation des mots de passe en texte brut {/* #plaintext-password-minimization */}

- **Les mots de passe ne peuvent être définis que via l'interface utilisateur** ; aucun point de terminaison d'API n'expose les mots de passe stockés
- **La manipulation des mots de passe en texte brut est minimisée** dans tout le système

### Cryptographie avancée pour les données sensibles {/* #advanced-cryptography-for-sensitive-data */}

- **Chiffrement des données sensibles** (par exemple, mots de passe, identifiants SMTP) utilisant AES-256-GCM
- **La clé maître est générée automatiquement** et stockée de manière sécurisée dans `.duplistatus.key`
- **PBKDF2 avec 100 000 itérations** utilisé pour la dérivation de clé afin de renforcer la sécurité
- **Les étiquettes d'authentification sont vérifiées** et la mémoire est effacée de manière sécurisée après utilisation
- **Les permissions du fichier de clé maître** sont strictement définies sur 0400 pour une protection maximale

## 🚀 Notes de migration {/* #-migration-notes */}

### À partir de la Version 0.7.x {/* #from-version-07x */}

Cette version inclut des améliorations de sécurité importantes et de nouvelles fonctionnalités. Lors de la mise à niveau à partir de la version 0.7.x :

1. **Migration automatique de la base de données :** L'application migrera automatiquement votre schéma de base de données pour prendre en charge les nouvelles fonctionnalités
2. **Génération de clé maître :** Une nouvelle clé maître sera générée pour le chiffrement des données sensibles
3. **Gestion des sessions :** Les sessions existantes seront invalidées et de nouvelles sessions protégées par CSRF seront établies
4. **Mises à jour de configuration :** Certaines clés de configuration ont été mises à jour pour prendre en charge les nouvelles fonctionnalités
5. **Modifications des modèles :** Les variables `{backup_interval_value}` et `{backup_interval_type}` ont été remplacées par `{backup_interval}`. Les modèles par défaut seront ajustés automatiquement, mais les modèles personnalisés ne seront pas migrés. Veuillez vérifier vos modèles.

### Considérations de sécurité {/* #security-considerations */}

- **Fichier de clé maître :** Assurez-vous que le fichier `.duplistatus.key` est correctement sauvegardé et sécurisé
- **Permissions de fichier :** Le fichier de clé maître aura des permissions restreintes (0400) pour la sécurité
- **Chiffrement du mot de passe :** Les mots de passe existants seront chiffrés à l'aide du nouveau système cryptographique
