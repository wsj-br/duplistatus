# Version 0.8.x {/* #version-08x */}

## Aperçu {/* #overview */}

La version 0.8.x est une mise à jour majeure qui introduit des améliorations de sécurité significatives, des capacités de gestion de serveur améliorées et un système de notification complet avec prise en charge des e-mails SMTP. Cette version se concentre sur le renforcement de la sécurité, l'amélioration de l'expérience utilisateur et la fourniture d'options de surveillance des sauvegardes plus flexibles.

## Nouvelles fonctionnalités {/* #new-features */}

### Améliorations de la gestion des serveurs {/* #server-management-enhancements */}

- **Persistance automatique de l'URL du serveur et du mot de passe** lors de la collecte des sauvegardes
  - Les utilisateurs peuvent mettre à jour l'URL et le mot de passe en utilisant deux méthodes :
     - Re-collecter les sauvegardes avec les valeurs mises à jour
     - Modifier les paramètres dans [Paramètres → Paramètres du serveur](../user-guide/settings/server-settings.md)

### Surveillance des sauvegardes améliorée {/* #enhanced-backup-monitoring */}

- **Nouvel onglet de configuration `Backup monitoring`** avec des paramètres d'intervalle compatibles avec le serveur Duplicati
    - Prise en charge des intervalles personnalisés (par exemple, "1D12h")
    - Mises à jour automatiques des intervalles en retard à partir de la configuration de Duplicati lors de la collecte des journaux de sauvegarde
    - **Recommandé :** Exécuter la collecte après avoir modifié les intervalles des travaux de sauvegarde dans le serveur Duplicati pour synchroniser la configuration de duplistatus
    - Les modèles de notifications utilisent maintenant `{backup_interval}` au lieu de `{backup_interval_value}` et `{backup_interval_type}`.

### Configuration de l'appareil NTFY {/* #ntfy-device-configuration */}

- **Génération de codes QR** pour la configuration automatique de l'appareil afin de recevoir des notifications de **duplistatus**
   - Clic droit sur le bouton `View NTFY Messages` dans la barre d'outils de l'application
   - Bouton "Configurer l'appareil" dans [Paramètres → Paramètres NTFY](../user-guide/settings/ntfy-settings.md)

### Collecte des sauvegardes améliorée {/* #improved-backup-collection */}

- **Détection automatique HTTP/HTTPS**, les connexions sont tentées dans cet ordre : HTTPS → HTTPS avec certificat auto-signé → HTTP en dernier recours
- **Liste déroulante de sélection du serveur** dans l'interface `Collect Backup Logs` pour la collecte spécifique au serveur
- **Plusieurs adresses** dans le nom d'hôte (séparées par des virgules) sont maintenant acceptées (doivent partager le même mot de passe et le même port)
- **Boutons de collecte de sauvegarde pour un seul serveur** ajoutés à `Dashboard (table)`, [Paramètres → Surveillance des sauvegardes](../user-guide/settings/backup-monitoring-settings.md) et [Paramètres → Serveurs](../user-guide/settings/server-settings.md)
- **Fonctionnalité de collecte en masse** pour tous les serveurs avec une configuration valide (URL et mot de passe)
   - Boutons `Collect All` dans [Paramètres → Surveillance des sauvegardes](../user-guide/settings/backup-monitoring-settings.md) et [Paramètres → Serveurs](../user-guide/settings/server-settings.md)
   - Menu contextuel par clic droit sur le bouton `Collect Backup Logs` dans la barre d'outils de l'application

### Système de notification amélioré {/* #enhanced-notification-system */}

- **Prise en charge des notifications par e-mail SMTP :**
    - Configuration du serveur SMTP dans [Paramètres → Paramètres de messagerie](../user-guide/settings/email-settings.md)
    - Configuration par travail de sauvegarde pour les notifications NTFY et/ou par e-mail
    - Modèles au format HTML utilisant les [Paramètres → Modèles de notification](../user-guide/settings/notification-templates.md) existants
- **Configuration des notifications par travail de sauvegarde :**
    - Préférences de notification individuelles dans [Paramètres → Notifications de sauvegarde](../user-guide/settings/backup-notifications-settings.md)
    - Indicateurs visuels (icônes grisées) lorsque NTFY ou l'e-mail n'est pas correctement configuré

- **Prise en charge des paramètres régionaux :**
    - création d'une nouvelle variable d'environnement `LANG` pour définir la langue dans l'application
    - le format des dates et des nombres dans les notifications et les journaux est maintenant prévisible

## 🔒 Améliorations de sécurité {/* #-security-enhancements */}

### Protection CSRF {/* #csrf-protection */}

- **Authentification basée sur les sessions** avec une gestion robuste des sessions
- **Validation des jetons CSRF** imposée pour toutes les requêtes API modifiant l'état
- **Expiration automatique des sessions** après 24 heures ; les jetons CSRF se rafraîchissent toutes les 30 minutes
- Garantit la protection contre la falsification de requêtes intersites tout en préservant la compatibilité avec les API externes

### Minimisation des mots de passe en clair {/* #plaintext-password-minimization */}

- **Les mots de passe ne peuvent être définis que via l'interface utilisateur** ; aucun point de terminaison API n'expose les mots de passe stockés
- **La manipulation des mots de passe en clair est minimisée** dans tout le système

### Cryptographie avancée pour les données sensibles {/* #advanced-cryptography-for-sensitive-data */}

- **Chiffrement des données sensibles** (par exemple, mots de passe, informations d'identification SMTP) à l'aide d'AES-256-GCM
- **Clé principale générée automatiquement** et stockée en toute sécurité dans `.duplistatus.key`
- **PBKDF2 avec 100 000 itérations** utilisé pour la dérivation de clés afin d'améliorer la sécurité
- **Les balises d'authentification sont vérifiées** et la mémoire est effacée de manière sécurisée après utilisation
- **Les autorisations du fichier de clé principale** sont strictement définies sur 0400 pour une protection maximale

## 🚀 Notes de migration {/* #-migration-notes */}

### De la version 0.7.x {/* #from-version-07x */}

Cette version comprend des améliorations de sécurité significatives et de nouvelles fonctionnalités. Lors de la mise à niveau depuis la version 0.7.x :

1. **Migration automatique de la base de données :** L'application migrera automatiquement le schéma de votre base de données pour prendre en charge les nouvelles fonctionnalités
2. **Génération de la clé principale :** Une nouvelle clé principale sera générée pour le chiffrement des données sensibles
3. **Gestion des sessions :** Les sessions existantes seront invalidées et de nouvelles sessions protégées par CSRF seront établies
4. **Mises à jour de la configuration :** Certaines clés de configuration ont été mises à jour pour prendre en charge les nouvelles fonctionnalités
5. **Changements de modèle :** Les variables `{backup_interval_value}` et `{backup_interval_type}` ont été remplacées par `{backup_interval}`. Les modèles par défaut seront ajustés automatiquement, mais les modèles personnalisés ne seront pas migrés. Veuillez vérifier vos modèles.

### Considérations de sécurité {/* #security-considerations */}

- **Fichier de clé principale :** Assurez-vous que le fichier `.duplistatus.key` est correctement sauvegardé et sécurisé
- **Autorisations de fichier :** Le fichier de clé principale aura des autorisations restreintes (0400) pour des raisons de sécurité
- **Chiffrement des mots de passe :** Les mots de passe existants seront chiffrés à l'aide du nouveau système cryptographique
