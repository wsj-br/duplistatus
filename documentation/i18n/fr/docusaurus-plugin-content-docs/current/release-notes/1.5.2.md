# Version 1.5.2 {/* #version-152 */}

## Aperçu {/* #overview */}

La version 1.5.2 est une version de maintenance. Sur duplicati 2.4.1.0 et versions ultérieures, les dates de rétention dans les rapports de sauvegarde sont remplacées par `-redacted-` sauf si `--allow-paths-in-log-messages=true` est défini, ce qui laisse la liste des versions disponibles vide. Les options de rapport recommandées et le dépannage incluent désormais ce paramètre.

---

## Améliorations {/* #improvements */}

### Rapports duplicati {/* #duplicati-reporting */}

- **Dates de rétention sur duplicati 2.4.1.0 et versions ultérieures** : Ajouter `--allow-paths-in-log-messages=true` dans **Paramètres → Paramètres par défaut** (ou dans les options avancées de la sauvegarde). Sans cela, duplicati remplace les dates dans `Backups to consider` par `-redacted-`, de sorte que le nombre de versions disponibles peut toujours apparaître alors que la liste d'horodatage reste vide. Laissez `--reduced-reporting` non défini, car cette option supprime le texte du message, puis exécutez à nouveau la sauvegarde. Les rapports déjà stockés restent expurgés. L'option inclut également les chemins de fichiers locaux des avertissements et des erreurs dans le rapport HTTP. L'indication de journal tronqué sur la Page de détails d'une sauvegarde mentionne la même option.

---

## Notes de migration {/* #migration-notes */}

### Depuis la version 1.5.1 {/* #from-version-151 */}

Lors de la mise à niveau vers la version 1.5.2 :

1. **Aucune migration de base de données requise** : Cette version ne modifie pas le schéma de la base de données.
2. **Dépendances** : Exécutez `pnpm install` pour appliquer le fichier de verrouillage mis à jour et les remplacements.
3. **duplicati 2.4.1.0 et versions ultérieures** : Si la liste des versions disponibles est vide, ajoutez `--allow-paths-in-log-messages=true` sur chaque Serveur duplicati et exécutez à nouveau la sauvegarde. Les rapports stockés existants restent inchangés.
