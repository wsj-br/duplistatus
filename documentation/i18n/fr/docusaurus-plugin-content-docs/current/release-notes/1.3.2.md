# Version 1.3.2 {/* #version-132 */}

## Aperçu {/* #overview */}

La version 1.3.2 est une version de maintenance qui corrige les vulnérabilités de sécurité dans les dépendances, résout les avertissements d'installation pnpm (webpack homologue et sous-dépendances obsolètes), corrige les avertissements de lint et de build dans l'application et la documentation, et met à jour la documentation pour refléter les noms actuels des scripts Docker et les versions des packages.

## Sécurité {/* #security */}

### Corrections de vulnérabilités de dépendances {/* #dependency-vulnerability-fixes */}

- **Mises à jour de dépendances Dependabot (documentation)** : Fusion de deux PR Dependabot pour corriger les vulnérabilités dans l'espace de travail de la documentation :
  - **ajv** dans `/documentation` : mis à jour de 8.17.1 à 8.18.0 et de 6.12.6 à 6.14.0.
  - **fast-xml-parser** dans `/documentation` : mis à jour de 5.3.5 à 5.3.8.
  Les deux ont été fusionnés via la mise à jour multiple dependabot pour /documentation.

- **Remplacements pnpm pour les vulnérabilités graves** : Ajout de remplacements pnpm pour corriger quatre problèmes graves :
  - **minimatch** (>=3.1.4) : Corrige GHSA-3ppc-4f35-3m26 (ReDoS via caractères génériques répétés), GHSA-7r86-cg39-jmmj (retour combinatoire) et GHSA-23c5-xmqv-rm74 (retour sur extglobs imbriqués) dans documentation > @docusaurus/core > serve-handler > minimatch.
  - **serialize-javascript** (>=7.0.3) : Corrige GHSA-5c6j-r48x-rmvq (RCE via RegExp.flags et Date.prototype.toISOString()) dans webpack > terser-webpack-plugin > serialize-javascript.

## Corrections de bogues {/* #bug-fixes */}

- **Avertissements d'installation pnpm** : Résolution de trois avertissements au moment de l'installation : (1) Homologue `webpack@5.104.1` non satisfait provenant de `next-intlayer` > `@intlayer/webpack` (le projet utilise webpack 5.105.3) en ajoutant `pnpm.peerDependencyRules.allowedVersions.webpack: "5"` dans le fichier racine `package.json`. (2) Sous-dépendances obsolètes `prebuild-install@7.1.3` (provenant de better-sqlite3) et `whatwg-encoding@3.1.1` (provenant de documentation > docusaurus-search-local > cheerio) en ajoutant `pnpm.allowedDeprecatedVersions` pour les deux afin que l'installation s'exécute sans avertissements.
- **Visionneuse de journaux d'application (exhaustive-deps)** : Résolution de l'avertissement react-hooks/exhaustive-deps pour l'effet de défilement automatique. `logData` est intentionnellement omis du tableau des dépendances afin que le défilement se produise uniquement lorsque le défilement automatique ou le fichier sélectionné change, pas à chaque interrogation ; le défilement de nouvelle ligne est géré dans `loadLogs`. Ajout d'un eslint-disable-next-line avec un commentaire court.
- **Avertissement de build vscode-languageserver-types (documentation)** : Suppression du message « Critical dependency: require function is used in a way in which dependencies cannot be statically extracted » de Webpack pour la dépendance transitive `vscode-languageserver-types` (provenant de intlayer-editor) dans le build de la documentation (Docusaurus) via un plugin en ligne dans `documentation/docusaurus.config.ts` qui ajoute `ignoreWarnings`. L'avertissement ne survient que pendant le build de la documentation, pas dans l'application principale.

## Notes de migration {/* #migration-notes */}

### Depuis la version 1.3.1 {/* #from-version-131 */}

Lors de la mise à niveau vers la version 1.3.2 :

1. **Aucune migration de base de données requise** : Cette version ne nécessite aucune modification du schéma de base de données.
2. **Commandes Docker** : Si vous utilisez les scripts pnpm documentés, utilisez `pnpm docker:up`, `pnpm docker:down`, `pnpm docker:clean` et `pnpm docker:devel` au lieu des anciens `docker-up`, `docker-down`, etc.
3. **Dépendances** : Exécutez `pnpm install` pour appliquer le fichier verrouillé et les remplacements mis à jour ; aucune modification manuelle des dépendances n'est nécessaire pour les installations classiques.
