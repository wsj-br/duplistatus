# Version 1.3.2 {/* #version-132 */}

## Aperçu {/* #overview */}

La version 1.3.2 est une version de maintenance qui corrige des vulnérabilités de sécurité dans les dépendances, résout les avertissements d'installation pnpm (webpack peer et sous-dépendances obsolètes), corrige les avertissements de lint et de build dans l'application et la documentation, et met à jour la documentation pour refléter les noms actuels des scripts Docker et les versions des paquets.

## Sécurité {/* #security */}

### Corrections des vulnérabilités des dépendances {/* #dependency-vulnerability-fixes */}

- **Mises à jour des dépendances Dependabot (documentation)**: Deux PRs Dependabot ont été fusionnées pour corriger des vulnérabilités dans l'espace de travail de la documentation:
  - **ajv** dans `/documentation`: mis à jour de 8.17.1 à 8.18.0 et de 6.12.6 à 6.14.0.
  - **fast-xml-parser** dans `/documentation`: mis à jour de 5.3.5 à 5.3.8.
  Les deux ont été fusionnés via la mise à jour multi-dependabot pour /documentation.

- **Surcharges pnpm pour les vulnérabilités de haute sévérité**: Des surcharges pnpm ont été ajoutées pour corriger quatre problèmes de haute sévérité:
  - **minimatch** (>=3.1.4): Corrige GHSA-3ppc-4f35-3m26 (ReDoS via des jokers répétés), GHSA-7r86-cg39-jmmj (retour arrière combinatoire) et GHSA-23c5-xmqv-rm74 (retour arrière des extglobs imbriqués) dans documentation > @docusaurus/core > serve-handler > minimatch.
  - **serialize-javascript** (>=7.0.3): Corrige GHSA-5c6j-r48x-rmvq (RCE via RegExp.flags et Date.prototype.toISOString()) dans webpack > terser-webpack-plugin > serialize-javascript.

## Corrections de bugs {/* #bug-fixes */}

- **Avertissements d'installation pnpm**: Résolution de trois avertissements d'installation: (1) Peer non satisfait `webpack@5.104.1` de `next-intlayer` > `@intlayer/webpack` (le projet a webpack 5.105.3) en ajoutant `pnpm.peerDependencyRules.allowedVersions.webpack: "5"` dans le `package.json` racine. (2) Sous-dépendances obsolètes `prebuild-install@7.1.3` (de better-sqlite3) et `whatwg-encoding@3.1.1` (de documentation > docusaurus-search-local > cheerio) en ajoutant `pnpm.allowedDeprecatedVersions` pour les deux afin que l'installation se fasse sans avertissements.
- **Visionneuse de journaux d'application (exhaustive-deps)**: Résolution de l'avertissement react-hooks/exhaustive-deps pour l'effet de défilement automatique. `logData` est intentionnellement omis du tableau de dépendances afin que le défilement ne se produise que lorsque le défilement automatique ou le fichier sélectionné change, et non à chaque sondage; le défilement de nouvelle ligne est géré dans `loadLogs`. Ajout d'un eslint-disable-next-line avec un commentaire court.
- **Avertissement de build vscode-languageserver-types (documentation)**: Suppression de l'avertissement Webpack "Dépendance critique: la fonction require est utilisée d'une manière où les dépendances ne peuvent pas être extraites statiquement" pour la dépendance transitive `vscode-languageserver-types` (de intlayer-editor) dans le build de la documentation (Docusaurus) via un plugin en ligne dans `documentation/docusaurus.config.ts` qui ajoute `ignoreWarnings`. L'avertissement se produit uniquement lors du build des docs, et non de l'application principale.

## Notes de migration {/* #migration-notes */}

### De la version 1.3.1 {/* #from-version-131 */}

Lors de la mise à niveau vers la version 1.3.2:

1. **Pas de migration de base de données requise**: Cette version ne nécessite aucun changement de schéma de base de données.
2. **Commandes Docker**: Si vous utilisez les scripts pnpm documentés, utilisez `pnpm docker:up`, `pnpm docker:down`, `pnpm docker:clean`, et `pnpm docker:devel` au lieu des précédents `docker-up`, `docker-down`, etc.
3. **Dépendances**: Exécutez `pnpm install` pour appliquer le fichier de verrouillage et les surcharges mis à jour; aucune modification manuelle des dépendances n'est requise pour les installations typiques.
