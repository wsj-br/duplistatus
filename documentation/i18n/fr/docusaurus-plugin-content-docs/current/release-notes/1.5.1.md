# Version 1.5.1 {/* #version-151 */}

## Aperçu {/* #overview */}

La version 1.5.1 est une version de maintenance et de sécurité. Elle met à jour Next.js pour corriger les problèmes de SSRF liés à l'optimisation des images, d'empoisonnement de cache et autres problèmes associés, renforce le chiffrement des secrets stockés et ouvre les liens du serveur NTFY Personnalisé sur le serveur que vous avez configuré. Les images de conteneur Publié pour amd64 et arm64 partagent à nouveau un seul condensé (digest).

---

## Améliorations {/* #improvements */}

### Documentation {/* #documentation */}

- **Page d'accueil de la documentation** : La racine du site de documentation est désormais une page produit couvrant le statut de la Sauvegarde, les captures d'écran, la sécurité et l'installation, au lieu d'une redirection vers l'introduction. **Docs** et `/intro` ouvrent toujours le guide.

---

## Corrections de bogues {/* #bug-fixes */}

- **Liens du serveur NTFY Personnalisé (problème N°85)** : Le lien de la rubrique Paramètres et l'icône NTFY de la barre d'outils ouvrent le serveur que vous avez configuré. Ils ne renvoient plus systématiquement vers `https://ntfy.sh`.
- **Images multi-architectures** : Les builds de version n'attachent plus d'attestations de provenance, ainsi le GitHub Container Registry et Docker Hub partagent un seul condensé et `linux/amd64` et `linux/arm64` sont étiquetés ensemble.

---

## Sécurité {/* #security */}

### Framework et secrets stockés {/* #framework-and-stored-secrets */}

- **Next.js 16.4.3** : `package.json` déclare 16.3.8 (Dependabot N°84). Le remplacement de dépendance installe 16.4.3, qui inclut les correctifs de cette version pour le SSRF d'optimisation d'image, les problèmes de route de métadonnées et d'empoisonnement de cache, la fuite du mode brouillon via `use cache`, et une divulgation d'informations dans le Serveur de développement.
- **Chiffrement des secrets renforcé** : Les secrets nouveaux et ré-Enregistré utilisent PBKDF2-SHA256 avec 600 000 itérations, contre 100 000 auparavant. Les secrets déjà stockés avec le nombre précédent sont toujours déchiffrables. Enregistrer à nouveau un secret le réécrit avec le nombre plus élevé.

## Notes de migration {/* #migration-notes */}

### Depuis la Version 1.5.0 {/* #from-version-150 */}

Quand vous effectuez la mise à niveau vers la version 1.5.1 :

1. **Aucune migration de base de données requise** : Cette version ne modifie pas le schéma de la base de données. Les secrets chiffrés existants continuent de fonctionner.
2. **Dépendances** : Exécutez `pnpm install` pour appliquer le fichier de verrouillage mis à jour et les remplacements.
3. **Aucun changement de configuration nécessaire** : Les Clés API, les listes d'autorisation, les Paramètres de notification et les URL du serveur NTFY restent inchangés.
