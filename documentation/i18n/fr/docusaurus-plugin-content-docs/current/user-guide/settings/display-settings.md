# Affichage {/* #display */}

Configurer les préférences de l'interface utilisateur et d'affichage.

![Paramètres d'affichage](../../assets/screen-settings-display.png)

<br/>

| Paramètre                | Description                                         | Valeur par défaut      |
|:--------------------------|:----------------------------------------------------|:-------------------|
| **Taille du tableau**            | Nombre de lignes par page sur la page des détails du serveur. | 5 lignes             |
| **Afficher la version sur le tableau de bord** | Afficher ou masquer la version de Duplicati sur les cartes du tableau de bord. Le tableau du tableau de bord affiche toujours la colonne Version. Disponible également dans [Versions de Duplicati](duplicati-versions.md). | Sur |
| **Thème**                 | Choisir entre clair, sombre ou suivre l'apparence de votre système d'exploitation (préfère le mode clair/sombre). | Suivre le système si non défini |
| **Plage de temps du graphique**      | Intervalle de temps affiché dans les graphiques. Options disponibles : **1S** (7 derniers jours), **2S** (14 derniers jours), **1M** (30 derniers jours), **3M** (90 derniers jours). Vous pouvez également basculer la plage de temps directement depuis les en-têtes des graphiques. | 1 mois            |
| **Style de graphique**           | Choisir entre des graphiques à lignes lissées ou des graphiques à barres. Les deux modes utilisent l'agrégation par intervalles de temps pour un affichage optimal. Vous pouvez également basculer directement depuis les en-têtes des graphiques. | Lignes lissées       |
| **Paramètres régionaux**         | Sélectionner un paramètre régional de formatage indépendant de votre langue d'interface utilisateur (416 paramètres régionaux pris en charge). Cela affecte la manière dont les dates, heures et nombres sont affichés. Les phrases de temps relatif (par exemple "dans 2 heures") suivent les paramètres régionaux de formatage à moins que **Conserver le temps relatif dans la langue de l'interface utilisateur** ne soit activé. Un aperçu en direct inclut une date, une heure, un nombre et un exemple de temps relatif. Exemple : langue de l'interface utilisateur = Allemand, paramètres régionaux de formatage = Anglais (Royaume-Uni) → interface utilisateur en allemand avec formats de date du Royaume-Uni. | Basé sur la langue de l'interface utilisateur |
| **Conserver le temps relatif dans la langue de l'interface utilisateur** | Lorsque cette option est activée, les phrases telles que "dans 2 heures" suivent **Utilisateur → Langue** au lieu des paramètres régionaux de formatage. Les dates, heures et nombres utilisent toujours les paramètres régionaux de formatage. Désactivé par défaut. | Désactivé |
| **Intervalle d'actualisation automatique** | Fréquence à laquelle les pages se rafraîchissent automatiquement.              | 1 minute           |
| **Ordre de tri des cartes**      | Comment les cartes sont triées sur le tableau de bord.              | Nom du serveur (a-z)  |
| **Début de la semaine**         | Configurer le début de la semaine.                     | Basé sur les paramètres régionaux    |

<br/>

:::tip
**Accès rapide** : Vous pouvez accéder rapidement à cette page en faisant un clic droit sur le bouton d'actualisation automatique dans la barre d'outils de l'application.
:::
