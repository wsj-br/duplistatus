# Affichage {/* #display */}

Configurer l'interface utilisateur et les préférences d'affichage.

![Paramètres d'affichage](../../assets/screen-settings-display.png)

<br/>

| Paramètre                 | Description                                         | Valeur par défaut  |
|:--------------------------|:----------------------------------------------------|:-------------------|
| **Taille du tableau**     | Nombre de lignes par page sur la page des détails du serveur. | 5 lignes           |
| **Afficher la version sur le tableau de bord** | Afficher ou masquer la version de Duplicati sur les cartes du tableau de bord. Le tableau du tableau de bord affiche toujours la colonne Version. Également disponible dans [Versions de Duplicati](duplicati-versions.md). | Sur |
| **Thème**                 | Choisir entre clair, sombre ou correspondre à l'apparence de votre système d'exploitation (mode clair/sombre préféré). | Suit le système d'exploitation lorsqu'il n'est pas défini |
| **Plage de temps du graphique** | Intervalle de temps affiché dans les graphiques. Options disponibles : **1S** (7 derniers jours), **2S** (14 derniers jours), **1M** (30 derniers jours), **3M** (90 derniers jours). Vous pouvez également basculer la plage de temps directement depuis les en-têtes des graphiques. | 1 mois             |
| **Style de graphique**    | Choisir entre des graphiques en ligne lissée ou une visualisation en graphique à barres. Les deux modes utilisent l'agrégation par intervalles de temps pour un affichage optimal. Vous pouvez également basculer directement depuis les en-têtes des graphiques. | Lignes lissées     |
| **Paramètres régionaux**  | Sélectionner des paramètres régionaux de formatage indépendants de votre langue d'interface (416 paramètres régionaux pris en charge). Cela affecte la manière dont les dates, heures et nombres sont affichés. Les expressions temporelles relatives (par exemple "dans 2 heures") suivent les paramètres régionaux de formatage sauf si **Conserver le temps relatif dans la langue de l'interface utilisateur** est activé. Un aperçu en direct inclut la date, l'heure, le nombre et un exemple de temps relatif. Exemple : Langue de l'interface = Allemand, Paramètres régionaux de formatage = Anglais (Royaume-Uni) → Interface en allemand avec formats de date britanniques. | Basé sur la langue de l'interface |
| **Conserver le temps relatif dans la langue de l'interface utilisateur** | Lorsque cette option est activée, les expressions telles que "dans 2 heures" suivent **Utilisateur → Langue** au lieu des paramètres régionaux de formatage. Les dates, heures et nombres continuent d'utiliser les paramètres régionaux de formatage. Désactivé par défaut. | Désactivé |
| **Intervalle d'actualisation automatique** | Fréquence de rafraîchissement automatique des pages. | 1 minute           |
| **Ordre de tri des cartes** | Mode de tri des cartes sur le tableau de bord.       | Nom du serveur (a-z) |
| **Début de la semaine**   | Configurer quand commence la semaine.               | Basé sur les paramètres régionaux |

<br/>

:::tip
**Accès rapide** : Vous pouvez accéder rapidement à cette page en cliquant avec le bouton droit sur le bouton d'actualisation automatique dans la barre d'outils de l'application.
:::
