# duplistatus -  监控多个 [Duplicati的](https://github.com/duplicati/duplicati) 服务器 {/* #duplistatus----monitor-multiple-duplicatishttpsgithubcomduplicatiduplicati-servers */}

![版本](https://img.shields.io/badge/version-{VERSION}-blue) 
[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?logo=github)](https://github.com/wsj-br/duplistatus)

<br/>

该网络应用程序监控并可视化来自 [Duplicati](https://github.com/duplicati/duplicati) 的备份操作。 **duplistatus** 提供了一个全面的仪表板，以跟踪备份状态，通知过期备份，作业历史，
指标和多个服务器的性能。

使用 Docker、Podman 或 Portainer 部署简单，并提供 7 种语言（英语、德语、法语、西班牙语、葡萄牙语、印地语和简体中文），每种语言都有完整的文档。
