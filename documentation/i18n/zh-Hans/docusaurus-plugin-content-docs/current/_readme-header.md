# duplistatus - 监控多个[Duplicati](https://github.com/duplicati/duplicati)服务器{/* #duplistatus----monitor-multiple-duplicatishttpsgithubcomduplicatiduplicati-servers */}

![version](https://img.shields.io/badge/version-{VERSION}-blue) 
[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?logo=github)](https://github.com/wsj-br/duplistatus)

<br/>

此网络应用程序监控和可视化来自[Duplicati](https://github.com/duplicati/duplicati)的备份操作。**duplistatus**提供一个全面的仪表板来跟踪备份状态、通知过期备份、作业历史、指标和跨多个服务器的性能。

易于使用Docker、Podman或Portainer部署，并提供7种语言（英语、德语、法语、西班牙语、葡萄牙语、印地语和简体中文）的支持，每种语言均有完整的文档。
