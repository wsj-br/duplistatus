# 备份指标 {/* #backup-metrics */}

备份指标随时间变化的图表在仪表板（表格视图）和服务器详细信息页面上都有显示。

- **仪表板**，图表显示在 **duplistatus** 数据库中记录的备份总数。如果使用卡片布局，您可以选择一个服务器来查看其汇总指标（当侧边面板显示指标时）。
- **服务器详细信息** 页面，图表显示所选服务器的指标（针对其所有备份）或单个特定备份的指标。

![备份指标](../assets/screen-metrics.png)

## 内联图表控制 {/* #inline-chart-controls */}

快速访问控件直接位于图表面板标题上，无需导航到显示设置即可轻松配置：

### 时间范围选择器 {/* #time-range-selector */}

图表标题中会出现药丸按钮，用于快速选择时间范围：**1W | 2W | 1M | 3M**

- **1W**：最近 7 天（滚动窗口）
- **2W**：最近 14 天（滚动窗口）
- **1M**：最近 30 天（滚动窗口，默认）
- **3M**：最近 90 天（滚动窗口）

此处所做的更改会与您的显示设置同步，因此您的偏好会在页面刷新后保持不变。

### 图表样式切换 {/* #chart-style-toggle */}

图表标题中的切换按钮允许您在以下选项之间切换：

- **平滑线**：显示用平滑曲线连接的数据点
- **条形图**：将数据以每个时间段的离散条形显示

两种模式都使用时间桶聚合以实现最佳显示效果。条形模式中的空时间段不显示条形。您的偏好会在页面刷新后保持不变，并与显示设置同步。

## 图表数据合并 {/* #chart-data-consolidation */}

当同一天发生多个备份时，**duplistatus** 会在将其显示在图表上前合并数据：

- **SUM**：用于累积指标（持续时间、文件数量、文件大小、上传大小）
- **LAST**：用于存储大小（当天最新值）
- **MAX**：用于可用版本（当天最高计数）

此合并发生在应用时间分桶之前，确保准确的聚合指标。例如，26年5月12日的两个备份将在图表上产生一个合并的数据点。

## 指标定义 {/* #metric-definitions */}

- **上传大小**：每天从 Duplicati 服务器到目标位置（本地存储、FTP、云提供商等）上传/传输的数据总量。
- **持续时间**：每天接收的所有备份的总持续时间，以 HH:MM 表示。
- **文件数量**：每天接收的所有备份的文件计数器总和。
- **文件大小**：Duplicati 服务器报告的每天接收的所有备份的文件大小总和。
- **存储大小**：每天由 duplicati 服务器报告的备份目标上使用的存储大小总和。
- **可用版本**：每天所有备份的所有可用版本的总和。

:::note
您可以使用[显示设置](settings/display-settings.md)控件来配置图表的时间范围。
:::
