# 备份指标 {/* #backup-metrics */}

备份指标随时间的变化图表显示在仪表板（表格视图）和服务器详情页面上。

- **仪表板**，图表显示**duplistatus**数据库中记录的备份总数。如果使用卡片布局，可以选择一个服务器以查看其汇总指标（当侧边栏显示指标时）。
- **服务器详情**页面，图表显示所选服务器的指标（对于其所有备份）或单个特定备份的指标。

![备份指标](../assets/screen-metrics.png)

## 内联图表控件 {/* #inline-chart-controls */}

快速访问控件可直接在图表面板标题上使用，以便轻松配置而无需导航到显示设置：

### 时间范围选择器 {/* #time-range-selector */}

图表标题中出现胶囊按钮，用于快速选择时间范围：**1W | 2W | 1M | 3M**

- **1W**：过去7天（滚动窗口）
- **2W**：过去14天（滚动窗口）
- **1M**：过去30天（滚动窗口，默认）
- **3M**：过去90天（滚动窗口）

此处的更改与您的显示设置同步，因此您的偏好会在页面刷新后保持不变。

### 图表样式切换 {/* #chart-style-toggle */}

图表标题中的切换按钮允许您在以下模式之间切换：

- **平滑线**：使用平滑曲线连接数据点
- **条形图**：以每个时间段的离散条显示数据

两种模式均使用时间分桶聚合以获得最佳显示效果。条形模式中的空时间段不显示条形。您的偏好会在页面刷新后保持不变，并与显示设置同步。

## 图表数据合并 {/* #chart-data-consolidation */}

当同一天发生多次备份时，**duplistatus**会在将数据显示在图表上之前合并数据：

- **SUM**：用于累积指标（持续时间、文件数量、文件大小、上传大小）
- **LAST**：用于存储大小（当天的最新值）
- **MAX**：用于可用版本（当天的最高计数）

此合并发生在应用时间分桶之前，确保准确的聚合指标。例如，5/12/26的两次备份将在图表上产生一个合并的数据点。

## 指标定义 {/* #metric-definitions */}

- **上传大小**：Duplicati服务器将数据上传/传输到目标（本地存储、FTP、云提供商等）的总数据量每天。
- **持续时间**：每天收到的所有备份的总持续时间以HH:MM表示。
- **文件数量**：每天收到的所有备份的文件计数器的总和。
- **文件大小**：每天收到的所有备份的Duplicati服务器报告的文件大小总和。
- **存储大小**：每天 Duplicati 服务器报告的备份目标上使用的存储大小总和。
- **可用版本**：每天所有备份的所有可用版本总和。

:::note
您可以使用[显示设置](settings/display-settings.md)控件来配置图表的时间范围。
:::
