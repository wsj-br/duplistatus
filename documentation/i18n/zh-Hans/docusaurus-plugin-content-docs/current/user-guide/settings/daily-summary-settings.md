# 每日摘要 {/* #daily-summary */}

每日摘要是一种可选的通知模式，它会在指定的本地时间发送**一份**已知备份作业的本地化快照。启用时，默认邮箱接收者（设置 → 邮箱 → 接收者邮箱）的备份和过期邮件将暂停。在[备份通知](backup-notifications-settings.md)中配置的其他邮件目的地仍将继续接收匹配的事件。每个作业的NTFY通知将继续发送。这些设置将保持存储，并在每日摘要关闭后立即恢复活动状态。

快照是发送时的**当前**状态（每个作业的最新结果）。它不是前一天运行的历史记录。

![每日摘要设置](../../assets/screen-settings-daily-summary.png)

## 要求 {/* #requirements */}

- 必须配置SMTP。电子邮件将发送一次，如果已保存**覆盖SMTP收件人**，则发送至该收件人，否则发送至[电子邮件设置](/user-guide/settings/email-settings)中的SMTP收件人。
- 在依赖每日摘要之前，请检查您的SMTP配置并确保其正常工作。
- 计划发送需要cron服务。调度程序每天在存储的UTC发送时间触发一次。

## 包含内容 {/* #what-is-included */}

已知作业是每个服务器和备份名称的**最新观察到的备份** — 与仪表板和设置 → 备份监控中的相同集合。

状态桶（成功、警告、错误、致命、未知）是互斥的，并且总和等于作业计数。**过期**是单独计算的：过期的成功作业仍然是成功，并且也是过期的。

## 时间表 {/* #schedule */}

在 **浏览器时区** 中选择一个精确的 `HH:mm` 时间。duplistatus 将计划存储为 UTC 并显示页面上的两个值（与 **Duplicati 版本** 相同的模式）。此页面上的更改会自动保存。新安装的默认发送时间为 **01:00 UTC**。

- 启用或更改计划将从**下一次未来**发生开始，永远不会立即发送。
- 计划的时钟时间总是在cron作业触发时发送。**立即发送摘要**、重试或同一天的更早发送不会跳过它。

## 公共仪表板 URL {/* #public-dashboard-url */}

此页面上的可选 **公共仪表板 URL** 用于填充每日摘要电子邮件中的 `{duplistatus_link}` 占位符。使用没有尾部斜杠的 `http://` 或 `https://` URL。留空以省略链接。

当环境中设置了 `DUPLISTATUS_PUBLIC_URL` 时，它会覆盖已保存的设置（请参见 [环境变量](/installation/environment-variables)）。

## 覆盖SMTP收件人 {/* #override-smtp-recipient */}

可选的**覆盖SMTP收件人**将每日摘要发送至与电子邮件设置中的收件人不同的地址。留空以继续使用默认收件人。该值存储在`daily_summary`配置键（`smtpRecipient`）中，并用于计划发送、**立即发送摘要**和重试。发送API仍然不接受请求中的收件人。

## 替换行为 {/* #replacement-behaviour */}

当每日摘要开启时：

- 不会发送上传和过期邮件至默认电子邮件接收者
- 备份通知中的其他电子邮件目标仍然会收到匹配的事件（过期计数作为该过滤器的警告）
- 每个作业的NTFY通知仍然继续
- 当没有发送时，过期时间戳不会推进，因此当模式关闭时，过期警报可以立即恢复
- 模板预览、传输测试和**立即发送摘要**仍然有效

**立即发送摘要**是一个额外的传递。它不会消耗下一个计划发生的时间。

计划、**立即发送摘要** 和重试发送记录在 [审计日志](audit-logs-viewer.md) 中为 `daily_summary_sent`（系统操作）。保存设置为 `daily_summary_updated`（配置）。

## 模板 {/* #templates */}

编辑 [设置 → 模板](/user-guide/settings/notification-templates) 下的每日摘要电子邮件模板（Markdown）。默认主题包括 `{summary_date}` 加上成功、警告、过期、错误和致命的计数，以便收件箱行总结快照。过期可能与状态计数重叠。成功、警告/错误、过期和每日摘要的电子邮件正文都使用 Markdown。默认模板在公共仪表板 URL 配置在此页面或通过 `DUPLISTATUS_PUBLIC_URL` 时，在末尾包含 `{duplistatus_link}`。

**生成预览** 此页面上的预览对话框与 [设置 → 模板](/user-guide/settings/notification-templates) 中的预览对话框相同：电子邮件主题加上电子邮件HTML和纯文本。电子邮件HTML遵循当前的浅色或深色主题。
