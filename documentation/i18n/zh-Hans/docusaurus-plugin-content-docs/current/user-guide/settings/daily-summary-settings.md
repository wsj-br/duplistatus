# 每日摘要 {#daily-summary}

每日摘要是一种可选的通知模式，它会在指定的本地时间发送**一份**已知备份作业的本地化快照。启用此模式时，单独的备份和过期**电子邮件**消息将被暂停，包括额外的每个作业的电子邮件目标。每个作业的NTFY通知将继续。这些设置将被存储，并在每日摘要关闭后重新激活。

快照是发送时的**当前**状态（每个作业的最新结果）。它不是前一天运行的历史记录。

![每日摘要设置](../../assets/screen-settings-left-panel-admin.png)

## 要求 {#requirements}

- 必须配置 SMTP。电子邮件始终发送一次到 SMTP 收件人。
- 定时发送需要 cron 服务。调度程序在运行时每分钟检查一次 UTC。

## 包含什么 {#what-is-included}

已知作业是以下内容的并集：

- 每个服务器和备份名称的最新观察到的备份
- 服务器仍然存在的显式每个作业设置

配置的作业从未发送过报告，标记为**未收到报告**。状态桶（成功、警告、错误、致命、未知、未收到报告）是互斥的，并且总和为作业计数。**过期**单独计算：过期的成功作业仍然是成功，并且也是过期的。

## 时间表 {#schedule}

在您的 **浏览器时区**中选择一个确切的 `HH:mm` 时间。duplistatus 将计划存储为 UTC，并在页面上显示两个值（与 **Duplicati 版本** 相同的模式）。此页面上的更改会自动保存。

- 启用或更改时间表将从**下一个未来**发生开始，永远不会立即发送意外的内容。
- 在同一天的稍后重新启动仍然会在配置时间之后赶上。
- 完全错过的早期天数不会重播。
- 春季向前错过的时间在间隙后的第一个有效分钟运行。重复的秋季小时数发送一次。

## 公共仪表板 URL {#public-dashboard-url}

此页面上的可选 **公共仪表板 URL** 用于填充每日摘要电子邮件中的 `{duplistatus_link}` 占位符。使用没有尾部斜杠的 `http://` 或 `https://` URL。留空以省略链接。

当环境中设置了 `DUPLISTATUS_PUBLIC_URL` 时，它会覆盖已保存的设置（请参见 [环境变量](/installation/environment-variables)）。

## 替换行为 {#replacement-behaviour}

当每日摘要开启时：

- 不发送上传和过期电子邮件
- 每个作业的NTFY通知继续
- 过期时间戳不会前进，因此过期警报在模式关闭后可以立即恢复
- 模板预览、传输测试和**立即发送摘要**仍然有效

**立即发送摘要**是一个额外的传递。它不会消耗下一个计划发生的时间。

## 模板 {#templates}

在 [设置 → 模板](/user-guide/settings/notification-templates) 下编辑每日摘要电子邮件模板（Markdown）。成功、警告/错误、过期和每日摘要的电子邮件正文均使用 Markdown。默认模板在配置了公共仪表板 URL 时，在末尾包含 `{duplistatus_link}`，无论是在此页面上还是通过 `DUPLISTATUS_PUBLIC_URL`。

**生成预览** 此页打开一个对话框，其中包含当前快照。电子邮件HTML遵循当前的浅色或深色主题。
