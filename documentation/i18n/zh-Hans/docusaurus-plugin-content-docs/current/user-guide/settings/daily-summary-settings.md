# 每日摘要 {#daily-summary}

每日摘要是一种可选的通知模式，它会在精确的本地时间发送**一份**已知的每个备份作业的本地化快照。当它被启用时，单独的备份和过期电子邮件和NTFY消息将被暂停，包括额外的每个作业的目标。这些设置将被存储，并在每日摘要被关闭时重新激活。

快照是发送时的**当前**状态（每个作业的最新结果）。它不是前一天运行的历史记录。

![每日摘要设置](../../assets/screen-settings-left-panel-admin.png)

## 要求 {#requirements}

- 必须配置SMTP。电子邮件总是发送一次到SMTP收件人。
- cron服务必须正在运行。调度程序每分钟在UTC时间检查一次。
- 可选的NTFY传递还需要有效的存储NTFY设置。

## 包含什么 {#what-is-included}

已知作业是以下内容的并集：

- 每个服务器和备份名称的最新观察到的备份
- 服务器仍然存在的显式每个作业设置

配置的作业从未发送过报告，标记为**未收到报告**。状态桶（成功、警告、错误、致命、未知、未收到报告）是互斥的，并且总和为作业计数。**过期**单独计算：过期的成功作业仍然是成功，并且也是过期的。

## 时间表 {#schedule}

选择一个精确的`HH:mm`时间并保存浏览器的IANA时区。保存的时区始终可见，当另一个浏览器打开设置时，不会被替换。

- 启用或更改时间表将从**下一个未来**发生开始，永远不会立即发送意外的内容。
- 在同一天的稍后重新启动仍然会在配置时间之后赶上。
- 完全错过的早期天数不会重播。
- 春季向前错过的时间在间隙后的第一个有效分钟运行。重复的秋季小时数发送一次。

## 替换行为 {#replacement-behaviour}

当每日摘要开启时：

- 上传和过期电子邮件/NTFY不会发送
- 过期时间戳不会前进，因此过期警报可以在模式关闭时立即恢复
- 模板预览、传输测试和**立即发送摘要**仍然有效

**立即发送摘要**是一个额外的传递。它不会消耗下一个计划发生的时间。

## 模板 {#templates}

在[设置→模板](/user-guide/settings/notification-templates)下编辑每日摘要电子邮件（Markdown）和紧凑的NTFY模板。成功、警告/错误、过期和每日摘要的电子邮件正文都使用Markdown。

**生成预览** 此页打开一个对话框，其中包含当前快照。电子邮件HTML遵循当前的浅色或深色主题。
