# 每日摘要 {/* #daily-summary */}

每日摘要是一种可选的通知模式，它会在指定的本地时间发送**一份**已知的所有备份作业的本地化快照。启用后，备份和逾期邮件将暂停发送到默认电子邮件收件人（设置 → 电子邮件 → 接收者邮箱）。在[备份通知](backup-notifications-settings.md)中配置的其他电子邮件目标仍然会收到匹配的事件。每个作业的 NTFY 通知将继续发送。这些设置将被存储，并在每日摘要关闭时重新激活。

快照是发送时的**当前**状态（每个作业的最新结果）。它不是前一天运行的历史记录。

![每日摘要设置](../../assets/screen-settings-daily-summary.png)

## 要求 {/* #requirements */}

- 必须配置 SMTP。电子邮件将发送一次，如果已保存**覆盖 SMTP 收件人**，则发送到该收件人，否则发送到[电子邮件设置](/user-guide/settings/email-settings)中的 SMTP 收件人。
- 在依赖每日摘要之前，请检查您的 SMTP 配置并确保其正常工作。
- 计划发送需要 cron 服务。调度程序每天在存储的 UTC 发送时间触发一次。

## 包含的内容 {/* #what-is-included */}

已知作业是每个服务器和备份名称的**最新观察到的备份** — 与仪表板和设置 → 备份监控中的集合相同。

状态桶（成功、警告、错误、致命、未知）是互斥的，并加起来等于作业数。**逾期**单独计算：逾期的成功作业仍然是成功，并且也是逾期的。

## 计划 {/* #schedule */}

在您的**浏览器时区**中选择一个精确的`HH:mm`时间。duplistatus 将计划存储为 UTC，并在页面上显示两个值（与**Duplicati 版本**相同的模式）。此页面上的更改将自动保存。新安装的默认发送时间是**01:00 UTC**。

- 启用或更改计划将从**下一个未来**发生开始，永远不会立即发送。
- 计划的时钟时间总是在 cron 作业触发时发送。**立即发送摘要**、重试或同一天的早期发送不会跳过它。

## 公共仪表板 URL {/* #public-dashboard-url */}

此页面上的可选**公共仪表板 URL**为每日摘要电子邮件中的`{duplistatus_link}`占位符提供数据。使用没有尾部斜杠的`http://`或`https://` URL。留空以省略链接。

当环境中设置了`DUPLISTATUS_PUBLIC_URL`时，它将覆盖保存的设置（请参阅[环境变量](/installation/environment-variables)）。

## 覆盖 SMTP 收件人 {/* #override-smtp-recipient */}

可选的**覆盖 SMTP 收件人**将每日摘要发送到与电子邮件设置中的收件人不同的地址。留空以继续使用该默认值。该值存储在`daily_summary`配置键（`smtpRecipient`）中，并用于计划发送、**立即发送摘要**和重试。发送 API 仍然不接受请求中的收件人。

## 替换行为 {/* #replacement-behaviour */}

当每日摘要开启时：

- 上传和逾期邮件不会发送到默认电子邮件收件人
- 备份通知中的其他电子邮件目标仍然会收到匹配的事件（逾期计为该过滤器的警告）
- 每个作业的 NTFY 通知将继续发送
- 当没有发送时，逾期时间戳不会推进，因此逾期警报可以在模式关闭时立即恢复
- 模板预览、传输测试和 **立即发送摘要** 仍然有效

**立即发送摘要** 是额外的投递。它不会消耗下一次计划的发生。

计划、**立即发送摘要** 和重试投递都会记录在 [审计日志](audit-logs-viewer.md) 中为 `daily_summary_sent`（系统操作）。保存设置为 `daily_summary_updated`（配置）。

## 模板 {/* #templates */}

在 [设置 → 模板](/user-guide/settings/notification-templates) 下编辑每日摘要电子邮件模板（Markdown）。默认主题包括 `{summary_date}` 加上成功、警告、过期、错误和致命的计数，以便收件箱行总结快照。过期可能与状态计数重叠。成功、警告/错误、过期和每日摘要的电子邮件正文都使用 Markdown。当此页面或通过 `DUPLISTATUS_PUBLIC_URL` 配置公共仪表板 URL 时，默认模板在末尾包含 `{duplistatus_link}`。

此页面上的 **生成预览** 打开与 [设置 → 模板](/user-guide/settings/notification-templates) 相同的预览对话框：电子邮件主题加上电子邮件 HTML 和纯文本。电子邮件 HTML 遵循当前的浅色或深色主题。
