# 每日摘要 {/* #daily-summary */}

每日摘要是可选的通知模式，会在确切的本地时间发送每项已知备份任务的**一个**本地化快照。启用期间，默认电子邮件收件人（设置 → 电子邮件 → 接收者邮箱）的备份和逾期邮件将暂停。在[备份通知](backup-notifications-settings.md)中配置的其他电子邮件目标将继续接收匹配事件。按任务的 NTFY 通知将继续。这些设置会保持存储，并在关闭每日摘要时再次激活。

快照是发送时间的**当前**状态（每个任务的最新结果）。这不是前一天运行的历史记录。

![每日摘要设置](../../assets/screen-settings-daily-summary.png)

## 要求 {/* #requirements */}

- 必须配置 SMTP。邮件仅发送一次，如果有保存的**覆盖 SMTP 收件人**则发送给该收件人，否则发送给[电子邮件设置](/user-guide/settings/email-settings)中的 SMTP 收件人。
- 在依赖每日摘要之前，请检查您的 SMTP 配置并确保其正常工作。
- 计划发送需要 cron 服务。调度程序会在存储的 UTC 发送时间每天触发一次。

## 包含内容 {/* #what-is-included */}

已知任务是每个服务器和备份名称的**最新观察到的备份**——与仪表板和设置 → 备份监控相同的集合。

状态桶（成功、警告、错误、致命、未知）是互斥的，加起来等于任务数。**逾期**单独计算：逾期的成功任务仍然是成功但也逾期。

## 计划 {/* #schedule */}

选择您**浏览器时区**内的确切`HH:mm`时间。duplistatus 将计划存储为 UTC 并在页面上显示两个值（与**Duplicati 版本**相同的模式）。此页面上的更改会自动保存。新安装的默认发送时间是**01:00 UTC**。

- 启用或更改计划将在**下一个未来**发生时间开始，永远不会立即意外发送。
- 计划的时钟时间总是在 cron 作业触发时发送。**立即发送摘要**、重试或当天早些时候的发送不会跳过它。

## 公共仪表板 URL {/* #public-dashboard-url */}

此页面上的可选**公共仪表板 URL**为每日摘要邮件中的`{duplistatus_link}`占位符提供内容。使用没有尾随斜杠的`http://`或`https://` URL。留空以省略链接。

当在环境中设置了`DUPLISTATUS_PUBLIC_URL`时，它会覆盖已保存的设置（参见[环境变量](/installation/environment-variables)）。

## 覆盖 SMTP 收件人 {/* #override-smtp-recipient */}

可选的**覆盖 SMTP 收件人**将每日摘要发送到与电子邮件设置中收件人不同的地址。留空以继续使用该默认值。该值存储在`daily_summary`配置键（`smtpRecipient`）中，用于计划发送、**立即发送摘要**和重试。发送 API 仍然不接受请求中的收件人。

## 替换行为 {/* #replacement-behaviour */}

当每日摘要开启时：

- 不会向默认电子邮件收件人发送上传和逾期邮件
- 备份通知中的其他电子邮件目标仍会接收匹配事件（逾期在此过滤器中计为警告）
- 按任务的 NTFY 通知将继续
- 当未发送任何内容时，逾期时间戳不会提前，因此当模式关闭时逾期警报可以立即恢复
- 模板预览、传输测试和**立即发送摘要**仍然有效

**立即发送摘要**是一次额外的投递。它不会消耗下一次计划出现的时间。

计划投递、**立即发送摘要**和重试投递都会记录在[审计日志](audit-logs-viewer.md)中，类型为`daily_summary_sent`（系统操作）。保存设置为`daily_summary_updated`（配置）。

## 模板 {/* #templates */}

在[设置 → 模板](/user-guide/settings/notification-templates)下编辑每日摘要电子邮件模板（Markdown）。默认主题包含`{summary_date}`以及成功、警告、逾期、错误和致命错误计数，以便收件箱行汇总快照。逾期可能与状态计数重叠。成功、警告/错误、逾期和每日摘要的邮件正文都使用 Markdown。当在此页面或通过`DUPLISTATUS_PUBLIC_URL`配置了公共仪表板 URL 时，默认模板末尾会包含`{duplistatus_link}`。

此页面上的**生成预览**会打开与[设置 → 模板](/user-guide/settings/notification-templates)相同的预览对话框：邮件主题加上电子邮件 HTML 和纯文本。电子邮件 HTML 遵循当前的浅色或深色主题。
