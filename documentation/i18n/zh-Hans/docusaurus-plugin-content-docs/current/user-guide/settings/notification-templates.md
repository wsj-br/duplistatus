# 模板 {/* #templates */}

**duplistatus** 使用四个模板来生成通知消息。电子邮件正文使用 Markdown（标题、列表、链接和表格）。NTFY 用于成功、警告/错误和过期备份，使用相同的 Markdown 正文，通过 `Markdown: yes` 发送，以便 ntfy 客户端可以渲染它。任何 GFM 表格省略其标题行，并将正文作为纯文本发送，因为 ntfy 不能渲染表格。每日摘要仅适用于电子邮件。

该页面包含一个 **模板语言** 选择器，用于设置默认模板的区域设置。更改语言会更新新默认值的区域设置，但它并 **不** 更改现有模板的文本。要将新语言应用于您的模板，可以手动编辑它们或使用 **将此模板重置为默认值**（针对当前选项卡）或 **全部重置为默认值**（针对所有模板）。

![通知模板](../../assets/screen-settings-templates.png)

| 模板               | 描述                                         |
| :----------------- | :-------------------------------------------------- |
| **成功**        | 当备份成功完成时使用。            |
| **警告/错误**  | 当备份完成时出现警告或错误时使用。 |
| **过期备份** | 当备份过期时使用。                      |
| **每日摘要**  | 用于可选每日快照的 Markdown 电子邮件模板。 |

<br/>

## 模板语言 {/* #template-language */}

页面顶部的 **模板语言** 选择器可让您选择默认模板的语言（英语、德语、法语、西班牙语、葡萄牙语、印地语和简体中文）。更改语言会更新默认值的区域设置，但现有的自定义模板会保留其当前文本，直到您更新它们或使用其中一个重置按钮。

<br/>

## 可用操作 {/* #available-actions */}

| 按钮                                                              | 描述                                                                                         |
|:--------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------|
| <IconButton label="保存模板设置" />                      | 更改模板时保存设置。该按钮保存正在显示的模板（成功、警告/错误、过期备份或每日摘要）。 |
| <IconButton icon="lucide:send" label="发送测试通知"/>     | 更新模板后检查模板。变量将被替换为测试的名称。对于电子邮件通知，模板标题将成为电子邮件主题行。在每日摘要选项卡上不可用。 |
| <IconButton icon="lucide:rotate-ccw" label="将此模板重置为默认值"/> | 将 **选定模板**（当前选项卡）恢复为默认模板。记得在重置后保存。 |
| <IconButton icon="lucide:rotate-ccw" label="全部重置为默认值"/> | 将所有模板（成功、警告/错误、过期备份和每日摘要）恢复为所选模板语言的默认值。记得在重置后保存。 |

## 变量 {/* #variables */}

电子邮件正文使用 Markdown。支持标题、列表、链接和表格。占位符值作为转义文本插入，不能引入 Markdown 或 HTML。先前在自定义模板中嵌入的原始 HTML 现在被转义。NTFY 接收相同的 Markdown，除了 GFM 表格：省略标题行，并将正文行作为纯文本发送，适用于任何列布局。

默认的成功、警告/错误和过期正文使用与每日摘要相同的 Markdown 样式：标题、粗体值和概述表格。未修改的存储默认值在加载时升级；自定义模板保持不变。

所有成功、警告/错误和过期模板都支持变量，这些变量将被实际值替换。以下表格显示了可用的变量：

| 变量               | 描述                                     | 可用于     |
|:-----------------------|:------------------------------------------------|:-----------------|
| `{server_name}`        | 服务器名称。                             | 成功、警告、过期 |
| `{server_alias}`       | 服务器别名。                            | 成功, 警告, 过期 |
| `{server_note}`        | 服务器备注。                            | 成功, 警告, 过期 |
| `{server_url}`         | Duplicati 服务器 URL。   | 成功, 警告, 过期 |
| `{backup_name}`        | 备份名称。                             | 成功, 警告, 过期 |
| `{status}`             | 备份状态（成功, 警告, 错误, 严重）。 | 成功, 警告 |
| `{backup_date}`        | 备份日期和时间。                    | 成功, 警告 |
| `{duration}`           | 备份持续时间。                         | 成功, 警告 |
| `{uploaded_size}`      | 上传的数据量。                        | 成功, 警告 |
| `{storage_size}`       | 存储使用情况。                      | 成功, 警告 |
| `{available_versions}` | 可用备份版本数量。            | 成功, 警告 |
| `{file_count}`         | 处理的文件数量。                      | 成功, 警告 |
| `{file_size}`          | 备份文件的总大小。                  | 成功, 警告 |
| `{messages_count}`     | 消息数量。                             | 成功, 警告 |
| `{warnings_count}`     | 警告数量。                             | 成功, 警告 |
| `{errors_count}`       | 错误数量。                               | 成功, 警告 |
| `{log_text}`           | 仅警告和错误日志行（不包括完整信息日志）。 NTFY 使用简短摘要并可能截断。 | 成功, 警告 |
| `{last_backup_date}`   | 最后备份日期。                        | 过期          |
| `{last_elapsed}`       | 自最后备份以来的时间。             | 过期          |
| `{expected_date}`      | 预期备份日期。                           | 过期          |
| `{expected_elapsed}`   | 自预期日期以来的时间。           | 过期          |
| `{backup_interval}`    | 间隔字符串（例如 "1D"、"2W"、"1M"）。       | 逾期          |
| `{overdue_tolerance}`  | 逾期容忍度设置。                      | 逾期          |

每日摘要模板使用一组不同的变量来表示当前状态的快照：

| 变量 | 描述 |
|:---------|:------------|
| `{summary_date}` | 快照的本地日历日期 |
| `{generated_at}` | 生成快照的日期和时间 |
| `{time_zone}` | 已保存的IANA时区 |
| `{server_count}` / `{job_count}` | 服务器和已知作业 |
| `{success_count}` / `{warning_count}` / `{error_count}` / `{fatal_count}` / `{unknown_count}` / `{no_report_count}` | 互斥的状态桶 |
| `{overdue_count}` | 逾期作业（与状态正交；可以与上述桶重叠） |
| `{problem_table}` / `{all_jobs_table}` | 生成注意所需和所有作业的表。列：服务器、备份、逾期、上次状态、最后结果、持续时间、警告、错误、已上传。 |
| `{duplistatus_link}` | 链接到duplistatus仪表板（未配置公共URL时省略）。优先使用此链接而不是手动构建的Markdown链接。 |
| `{duplistatus_url}` | 与纯文本相同的URL（未配置公共URL时为空）。 |
| `{latest_uploaded_size}` / `{latest_source_size}` / `{latest_storage_size}` / `{latest_file_count}` / `{total_warnings}` / `{total_errors}` | 最新结果总计 |

默认每日摘要电子邮件主题为：

```text
Daily Backup Summary — {summary_date} — ✅ {success_count} Success, ⚠️ {warning_count} Warning, 🕑 {overdue_count} Overdue, 🛑 {error_count} Error, ❌ {fatal_count} Fatal
```

未修改的存储默认主题将升级为此格式。自定义主题保持不变。`{unknown_count}`和`{no_report_count}`保留在电子邮件正文中，而不是默认主题中。

使用**预览**渲染电子邮件主题、HTML和纯文本，而不发送。成功、警告/错误和逾期预览还包括NTFY Markdown有效负载。预览在对话框中打开。电子邮件HTML/纯文本/NTFY按钮位于主题上方。电子邮件HTML遵循当前的浅色或深色主题。
