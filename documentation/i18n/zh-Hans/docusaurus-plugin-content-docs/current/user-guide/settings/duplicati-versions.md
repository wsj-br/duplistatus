# Duplicati 版本 {/* #duplicati-versions */}

此页面显示存储在 **duplistatus** 缓存中的最新 Duplicati 发布版本，并允许管理员配置从 GitHub 刷新这些版本的频率。

![Duplicati 版本](../../assets/screen-settings-duplicati-versions.png)

缓存被 [仪表板](../dashboard.md#duplicati-server-version) 和 [服务器](server-settings.md) 页面用于为每个服务器版本着色，并显示它是否是最新的或过时的。

## 最新频道版本 {/* #latest-channel-versions */}

该表列出了每个 Duplicati 频道的最新缓存版本：

| 频道           | 描述                                           |
|:---------------|:-------------------------------------------------|
| **稳定**     | 最新稳定版本                                   |
| **测试**       | 最新测试版本                                   |
| **实验** | 最新实验版本                                   |
| **金丝雀**     | 最新金丝雀版本                                   |

表格上方显示了最后一次成功的 GitHub 更新时间。如果某个频道尚未找到，或者缓存从未被更新过，页面会显示该版本不可用。

管理员可以点击 **立即更新** 以立即获取最新的发布版本。这不需要 cron 服务运行。如果无法访问 GitHub，**duplistatus** 会保留之前的缓存。

## 版本检查计划 {/* #version-check-schedule */}

**在仪表板上显示版本** 在 [仪表板](../dashboard.md#duplicati-server-version) 卡片视图中开启或关闭版本徽章。仪表板表格始终显示 **版本** 列。默认情况下它是开启的，也可以在 [显示设置](display-settings.md) 中使用。这是一个每个用户的显示偏好。

管理员可以选择 **duplistatus** 检查 GitHub 上的新 Duplicati 发布的频率：

| 间隔               | 运行                                                         |
|:-------------------|:-------------------------------------------------------------|
| **每天一次**     | 在配置的开始时间运行一次                            |
| **每 12 小时** | 在开始时间和 12 小时后运行                         |
| **每 6 小时**  | 在开始时间和之后每 6 小时运行               |

开始时间是在您的浏览器时区中使用与每日摘要相同的紧凑时间控件选择的。选择任何 `HH:mm` 时间。**duplistatus** 将该值存储为 UTC，cron 服务在 UTC 中运行检查。

示例：

- 每天在 06:00 开始运行于 06:00。
- 每天在 06:30 开始运行于 06:30。
- 每 12 小时在 08:15 开始运行于 08:15 和 20:15。
- 每 6 小时在 02:45 开始运行于 02:45、08:45、14:45 和 20:45。

在启动时，**duplistatus** 还会刷新缓存，如果缓存的时间超过所选的间隔（24 小时、12 小时或 6 小时），包括在新的空数据库上。短暂的 GitHub 故障，如 HTTP 504，会被重试。刷新失败会保留最后缓存的版本。

普通用户可以查看缓存的版本和计划，并可以开启或关闭 **在仪表板上显示版本**。只有管理员可以更改间隔、开始时间或强制更新。

:::note
更改计划会写入一条 `duplicati_version_check_updated` 条目到 [审计日志](audit-logs-viewer.md)。成功和失败的 GitHub 更新会被记录为 `duplicati_version_refresh`，触发器为 `startup`、`cron` 或 `manual`。
:::
