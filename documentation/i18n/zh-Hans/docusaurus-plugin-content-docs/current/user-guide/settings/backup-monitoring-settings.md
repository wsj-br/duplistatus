## 服务器过滤 {/* #server-filtering */}

此页面上的服务器列表可以使用筛选字段进行筛选。

当启用**每日摘要**时，过期检测将继续进行，但不会向默认电子邮件收件人发送过期电子邮件。匹配事件的其他电子邮件目标将继续。请参阅[每日摘要](daily-summary-settings.md)。

**过滤匹配项：**
- 服务器 ID
- 服务器 URL
- 备份作业名称

这使得在管理许多系统时，可以快速定位监控设置中的特定服务器或备份。

## 配置每备份监控设置 {/* #configure-per-backup-monitoring-settings */}

- **服务器名称**：要监控过期备份的服务器名称。
   - 点击<SvgIcon svgFilename="duplicati_logo.svg" height="18"/>打开Duplicati服务器的Web界面
   - 点击<IIcon2 icon="lucide:download" height="18"/>从该服务器收集备份日志。
- **备份名称**：要监控过期备份的备份名称。
- **下次运行**：显示在未来计划的绿色或过期的红色下次计划备份时间。将鼠标悬停在“下次运行”值上会显示一个工具提示，其中包含来自数据库的最后备份时间戳，格式为完整的日期/时间和相对时间。
- **备份监控**：启用或禁用此备份的备份监控。
- **预期备份间隔**：预期的备份间隔。
- **单位**：预期间隔的单位。
- **允许的天数**：备份允许的工作日。

如果服务器名称旁边的图标变灰，则该服务器未在[设置→服务器设置](/user-guide/settings/server-settings)中配置。

:::note
从Duplicati服务器收集备份日志时，**duplistatus**会自动更新备份监控间隔和配置。
:::

:::tip
为获得最佳结果，请在更改Duplicati服务器中的备份作业间隔配置后收集备份日志。这将确保**duplistatus**与您的当前配置保持同步。
:::

## 全局配置 {/* #global-configurations */}

这些设置适用于所有备份：

| 设置                         | 描述                                                                                                                                                                                                                                                                                                                             |
|:--------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **备份容忍度**            | 在将备份标记为过期之前，预期备份时间的宽限期（允许的额外时间）。默认值为**1小时**。                                                                                                                                                                                                             |
| **备份监控间隔** | 系统检查过期备份的频率。默认值为**5分钟**。                                                                                                                                                                                                                                                            |
| **通知频率**      | 发送过期通知的频率：<br/> **一次性`: Send **just one** notification when the backup becomes overdue. <br/> `每天`: Send **daily** notifications while overdue (default). <br/> `每周`: Send **weekly** notifications while overdue. <br/> `每月**：在过期时发送**每月**通知。 |

## 可用操作 {/* #available-actions */}

| 按钮                                                              | 描述                                                                                                                           |
|:--------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------|
| <IconButton label="保存备份监控设置" />              | 保存设置，清除任何禁用备份的计时器，并运行过期检查。                                                |
| <IconButton icon="lucide:import" label="收集所有 (#)"/>          | 从所有配置的服务器收集备份日志，括号内为要收集的服务器数量。                                   |
| <IconButton icon="lucide:download" label="下载CSV"/>           | 下载一个包含所有备份监控设置和数据库中的“最后备份时间戳（DB）”的CSV文件。               |
| <IconButton icon="lucide:refresh-cw" label="立即检查"/>            | 立即运行过期备份检查。在更改配置后很有用。它还会触发“下次运行”重新计算。 |
| <IconButton icon="lucide:timer-reset" label="重置通知"/> | 重置所有备份的最后过期通知。                                                                            |
