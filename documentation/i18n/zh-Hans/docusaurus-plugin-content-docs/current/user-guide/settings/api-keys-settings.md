# API 密钥 {/* #api-keys */}

管理员可以为 Duplicati 和 Homepage 使用的外部 HTTP API 创建范围有限的 API 密钥。默认情况下，密钥是可选的，因此现有的 Duplicati 作业仍然可以正常工作。

![API 密钥](../../assets/screen-settings-api-keys.png)

## 范围 {/* #scopes */}

| 范围 | 端点 |
|-------|-----------|
| 上传 | `POST /api/upload` |
| 读取 | `GET /api/summary`, `GET /api/lastbackup/:id`, `GET /api/lastbackups/:id` |

上传密钥无法调用读取 API，读取密钥无法上传报告。

## 创建密钥 {/* #creating-a-key */}

1. 打开 **设置 → API 密钥**。
2. 点击 API 密钥卡片底部的 **创建 API 密钥**。
3. 输入名称，选择范围，并可选地设置过期日期（`YYYY-MM-DD`）。
4. 生成密钥并立即复制密钥。它只在对话框中显示一次。
5. 之后的列表显示指纹，例如 `Qk7v…3xTa`（前四位和后四位字符），过期日期和状态。相同的指纹也会出现在审计日志中。

### 禁用或删除 {/* #disable-or-delete */}

使用 **操作** 列中的复选框禁用密钥而不删除它。禁用的密钥无法进行身份验证。再次勾选复选框以重新启用密钥。已过期的密钥无法启用；请改为创建新密钥。删除会永久删除密钥。

### 过期 {/* #expiry */}

可选的过期日期是密钥保持有效的最后一个日历日。它在浏览器的本地时区于当天的 **23:59:59** 过期，而不是在当天开始时的午夜过期。

选择 `2026-12-01` 在本地构建 `2026-12-01T23:59:59`，然后将该时刻存储为 UTC。对于 UTC+1 的浏览器，这是 `2026-12-01T22:59:59.000Z`。密钥在 12 月 1 日保持有效，并且从当地时间 23:59:59 开始被视为已过期（`expires_at <= now`）。API 密钥表显示过期日期（如果未设置，则显示 **永不**）。之后，状态徽章会变为 **已过期**（灰色）；即使密钥保持启用状态，已过期的密钥也无法进行身份验证。

## 使用密钥 {/* #using-a-key */}

Duplicati 无法设置自定义标头。将密钥放在报告 URL 中：

```bash
--send-http-json-urls=https://your-host/api/upload?api_key=YOUR_KEY
```

Homepage 小部件可以使用相同的查询参数：

```yaml
url: http://your-host/api/summary?api_key=YOUR_READ_KEY
```

可以发送标头的客户端可以使用 `X-Api-Key` 或 `Authorization: Bearer` 代替。查询字符串密钥会出现在反向代理访问日志中。

## 需要密钥 {/* #require-keys */}

**要求外部 API 使用 API 密钥** 开关默认处于关闭状态。当开关关闭时，没有密钥的请求是允许的。如果客户端仍然发送密钥，则接受有效的匹配范围密钥并记录；无效、禁用、过期或范围错误的密钥会被忽略，请求仍然允许。当您打开开关时，四个外部数据 API 会在没有有效密钥的情况下返回 `401`（并拒绝坏密钥）。首先启用至少一个上传密钥和一个读取密钥，否则 Duplicati 上传和 Homepage 小部件将停止。更改会自动保存。

## 外部 API 保护 {/* #external-api-protection */}

同一页面可以为公共上传和读取API设置API密钥，并配置最大主体大小（默认5 MB）和每个IP地址的速率限制，用于`/api/upload`。即使密钥是可选的，大小和速率限制仍然适用，并且是防止洪水攻击的主要防御措施。开关和限制字段会自动保存；没有单独的保存按钮。

另请参阅[IP白名单](ip-allowlist-settings.md)。IP白名单和API密钥是独立的功能；您可以单独使用其中一个，也可以同时使用两者。启用两者可以通过IP地址限制访问并要求API密钥来提高安全性。
