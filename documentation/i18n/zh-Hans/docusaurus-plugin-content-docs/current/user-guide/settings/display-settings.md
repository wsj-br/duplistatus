# 显示 {/* #display */}

配置用户界面和显示偏好。

![显示设置](../../assets/screen-settings-display.png)

<br/>

| 设置                      | 描述                                                | 默认值             |
|:--------------------------|:----------------------------------------------------|:-------------------|
| **表格大小**            | 服务器详情页面每页的行数。                            | 5 行               |
| **在仪表板上显示版本** | 在仪表板卡片上显示或隐藏 Duplicati 版本。仪表板表格始终显示版本列。也可在 [Duplicati 版本](duplicati-versions.md) 中查看。 | 开启 |
| **主题**                 | 选择浅色、深色或匹配您的操作系统外观（优先使用浅色/深色模式）。 | 未设置时跟随操作系统 |
| **图表时间范围**      | 图表中显示的时间间隔。可用选项：**1W**（最近 7 天）、**2W**（最近 14 天）、**1M**（最近 30 天）、**3M**（最近 90 天）。您也可以直接从图表标题切换时间范围。 | 1 个月             |
| **图表样式**           | 在平滑线图表或条形图可视化之间选择。两种模式都使用时间桶聚合以获得最佳显示效果。您也可以直接从图表标题切换。 | 平滑线             |
| **格式区域**         | 选择独立于 UI 语言的格式化区域（支持 416 个区域）。这会影响日期、时间和数字的显示方式。相对时间短语（例如"2 小时内"）遵循格式区域，除非启用了 **保持 UI 语言中的相对时间**。实时预览包括日期、时间、数字和相对时间示例。例如：UI 语言 = 德语，格式区域 = 英语（英国）→ 德语 UI 配合英国日期格式。 | 基于 UI 语言 |
| **保持 UI 语言中的相对时间** | 启用后，"2 小时内"等短语遵循 **用户 → 语言** 而非格式区域。日期、时间和数字仍使用格式区域。默认关闭。 | 关闭 |
| **自动刷新间隔** | 页面自动刷新的频率。                                | 1 分钟             |
| **卡片排序顺序**      | 仪表板上卡片的排序方式。                            | 服务器名称 (a-z)   |
| **一周开始**         | 配置一周何时开始。                                  | 基于区域           |

<br/>

:::tip
**快速访问**：您可以通过右键单击应用程序工具栏中的自动刷新按钮来快速访问此页面。
:::
