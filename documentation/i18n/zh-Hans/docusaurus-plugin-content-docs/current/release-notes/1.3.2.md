# 版本 1.3.2 {/* #version-132 */}

## 概述 {/* #overview */}

版本 1.3.2 是一个维护版本，解决了依赖项中的安全漏洞，修复了 pnpm 安装警告（对等 webpack 和已弃用的子依赖项），解决了应用程序和文档中的 lint 和构建警告，并更新了文档以反映当前的 Docker 脚本名称和包版本。

## 安全性 {/* #security */}

### 依赖项漏洞修复 {/* #dependency-vulnerability-fixes */}

- **Dependabot 依赖项更新（文档）**：合并了两个 Dependabot PR 以解决文档工作区中的漏洞：
  - **ajv** 在 `/documentation` 中：从 8.17.1 更新到 8.18.0，从 6.12.6 更新到 6.14.0。
  - **fast-xml-parser** 在 `/documentation` 中：从 5.3.5 更新到 5.3.8。
  这些都是通过 /documentation 的 dependabot 多更新合并的

- **高严重性漏洞的 pnpm 覆盖**：添加了 pnpm 覆盖以修复四个高严重性问题：
  - **minimatch** (>=3.1.4)：修复 GHSA-3ppc-4f35-3m26（通过重复通配符的 ReDoS）、GHSA-7r86-cg39-jmmj（组合回溯）和 GHSA-23c5-xmqv-rm74（嵌套 extglobs 回溯）在 documentation > @docusaurus/core > serve-handler > minimatch 中的问题。
  - **serialize-javascript** (>=7.0.3)：修复 GHSA-5c6j-r48x-rmvq（通过 RegExp.flags 和 Date.prototype.toISOString() 的 RCE）在 webpack > terser-webpack-plugin > serialize-javascript 中的问题。

## 错误修复 {/* #bug-fixes */}

- **pnpm 安装警告**：解决了三个安装时警告：(1) 未满足的对等 `webpack@5.104.1` 来自 `next-intlayer` > `@intlayer/webpack`（项目有 webpack 5.105.3）通过在根 `package.json` 中添加 `pnpm.peerDependencyRules.allowedVersions.webpack: "5"`。(2) 已弃用的子依赖项 `prebuild-install@7.1.3`（来自 better-sqlite3）和 `whatwg-encoding@3.1.1`（来自 documentation > docusaurus-search-local > cheerio）通过为两者添加 `pnpm.allowedDeprecatedVersions` 以便安装运行时不出现警告。
- **应用程序日志查看器（exhaustive-deps）**：解决了 auto-scroll 效果的 react-hooks/exhaustive-deps 警告。`logData` 有意从依赖数组中省略，因此滚动仅在自动滚动或所选文件更改时发生，而不是每次轮询时；换行滚动在 `loadLogs` 中处理。添加了 eslint-disable-next-line 并附带简短注释。
- **构建警告 vscode-languageserver-types（文档）**：通过 `documentation/docusaurus.config.ts` 中的内联插件添加 `ignoreWarnings` 来抑制 Webpack "关键依赖项：require 函数以一种无法静态提取依赖项的方式使用" 对于传递依赖项 `vscode-languageserver-types`（来自 intlayer-editor）在文档（Docusaurus）构建期间的警告。此警告仅在文档构建期间发生，不在主应用程序中。

## 迁移说明 {/* #migration-notes */}

### 从版本 1.3.1 {/* #from-version-131 */}

升级到版本 1.3.2 时：

1. **无需数据库迁移**：此版本不需要任何数据库模式更改。
2. **Docker 命令**：如果您使用文档中记录的 pnpm 脚本，请使用 `pnpm docker:up`、`pnpm docker:down`、`pnpm docker:clean` 和 `pnpm docker:devel` 而不是之前的 `docker-up`、`docker-down` 等。
3. **依赖项**：运行 `pnpm install` 以应用更新的锁定文件和覆盖；典型安装不需要手动依赖项更改。
