# 版本 1.3.2 {/* #version-132 */}

## 概述 {/* #overview */}

版本 1.3.2 是一个维护版本，修复了依赖项中的安全漏洞，解决了 pnpm 安装警告（同伴 webpack 和已弃用的子依赖项），解决了应用程序和文档中的 lint 和构建警告，并更新了文档以反映当前的 Docker 脚本名称和软件包版本。

## 安全 {/* #security */}

### 依赖漏洞修复 {/* #dependency-vulnerability-fixes */}

- **Dependabot 依赖更新（文档）**：合并了两个 Dependabot PR 以解决文档工作区中的漏洞：
  - **ajv** 在 `/documentation` 中：从 8.17.1 更新到 8.18.0，从 6.12.6 更新到 6.14.0。
  - **fast-xml-parser** 在 `/documentation` 中：从 5.3.5 更新到 5.3.8。
  两者均通过 /documentation 的 dependabot multi-update 合并。

- **pnpm 覆盖高严重性漏洞**：添加了 pnpm 覆盖以修复四个高严重性问题：
  - **minimatch**（>=3.1.4）：修复了文档 > @docusaurus/core > serve-handler > minimatch 中的 GHSA-3ppc-4f35-3m26（通过重复通配符的 ReDoS）、GHSA-7r86-cg39-jmmj（组合回溯）和 GHSA-23c5-xmqv-rm74（嵌套 extglobs 回溯）。
  - **serialize-javascript**（>=7.0.3）：修复了 webpack > terser-webpack-plugin > serialize-javascript 中的 GHSA-5c6j-r48x-rmvq（通过 RegExp.flags 和 Date.prototype.toISOString() 的 RCE）。

## 缺陷修复 {/* #bug-fixes */}

- **pnpm 安装警告**：解决了三个安装时警告：(1) 通过在根目录的 `package.json` 中添加 `pnpm.peerDependencyRules.allowedVersions.webpack: "5"`，解决了来自 `next-intlayer` > `@intlayer/webpack` 的未满足同伴 `webpack@5.104.1`（项目中有 webpack 5.105.3）。(2) 通过为两者都添加 `pnpm.allowedDeprecatedVersions`，解决了已弃用的子依赖项 `prebuild-install@7.1.3`（来自 better-sqlite3）和 `whatwg-encoding@3.1.1`（来自 documentation > docusaurus-search-local > cheerio），使安装无警告运行。
- **应用程序日志查看器（exhaustive-deps）**：解决了 react-hooks/exhaustive-deps 警告，用于自动滚动效果。`logData` 有意从依赖项数组中省略，因此只有在自动滚动或选定文件更改时才会发生滚动，而不是在每次轮询时；新行滚动在 `loadLogs` 中处理。添加了一个带有简短注释的 eslint-disable-next-line。
- **构建警告 vscode-languageserver-types（文档）**：通过在 `documentation/docusaurus.config.ts` 中添加 `ignoreWarnings` 的内联插件，在文档（Docusaurus）构建中抑制了来自传递依赖项 `vscode-languageserver-types`（来自 intlayer-editor）的 Webpack "Critical dependency: require function is used in a way in which dependencies cannot be statically extracted" 警告。该警告仅在文档构建期间出现，而不是主应用程序。

## 文档 {/* #documentation */}

- **Docker 脚本名称**：文档现在使用当前的 npm/pnpm 脚本名称：`docker-up` → `docker:up`，`docker-down` → `docker:down`，`docker-clean` → `docker:clean`，`docker-devel` → `docker:devel`。更新内容包括 AGENTS.md 和文档（setup.md、devel.md、release-management.md）。

## 迁移说明 {/* #migration-notes */}

### 从版本 1.3.1 {/* #from-version-131 */}

升级到版本 1.3.2 时：

1. **无需数据库迁移**：此版本不需要任何数据库架构更改。
2. **Docker 命令**：如果使用文档化的 pnpm 脚本，请使用 `pnpm docker:up`、`pnpm docker:down`、`pnpm docker:clean` 和 `pnpm docker:devel`，而不是之前的 `docker-up`、`docker-down` 等。
3. **依赖项**：运行 `pnpm install` 以应用更新的锁文件和覆盖；典型安装无需手动更改依赖项。
