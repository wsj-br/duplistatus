# 版本 0.8.x {/* #version-08x */}

## 概述 {/* #overview */}

版本 0.8.x 是一个重大更新，引入了显著的安全增强功能、改进的服务器管理能力以及全面的通知系统，支持 SMTP 电子邮件。此版本重点强化安全性、增强用户体验并提供更灵活的备份监控选项。

## 新功能 {/* #new-features */}

### 服务器管理增强 {/* #server-management-enhancements */}

- **自动保存服务器 URL 和密码** 当收集备份时
  - 用户可以使用两种方法更新 URL 和密码：
     - 使用更新后的值重新收集备份
     - 在 [设置 → 服务器设置](../user-guide/settings/server-settings.md) 中修改设置

### 增强的备份监控 {/* #enhanced-backup-monitoring */}

- **新 `Backup monitoring` 配置选项卡**，支持与 Duplicati 服务器兼容的间隔设置
    - 支持自定义间隔（例如 "1D12h"）
    - 在备份日志收集期间自动更新 Duplicati 配置中的过期间隔
    - **推荐：** 在 Duplicati 服务器中更改备份作业间隔后运行收集以同步 duplistatus 配置
    - 通知模板现在使用 `{backup_interval}` 而不是 `{backup_interval_value}` 和 `{backup_interval_type}`。

### NTFY 设备配置 {/* #ntfy-device-configuration */}

- **生成二维码** 以自动配置设备以接收来自 **duplistatus** 的通知
   - 在应用程序工具栏中右键单击 `View NTFY Messages` 按钮
   - [设置 → NTFY 设置](../user-guide/settings/ntfy-settings.md) 中的 "配置设备" 按钮

### 改进的备份收集 {/* #improved-backup-collection */}

- **自动检测 HTTP/HTTPS**，连接按以下顺序尝试：HTTPS → 自签名 HTTPS → HTTP 回退
- `Collect Backup Logs` 界面中的 **服务器选择下拉菜单**，用于直接收集特定服务器的备份
- 主机名中现在接受 **多个地址**（逗号分隔），必须共享相同的密码和端口
- 在 `Dashboard (table)`、[设置 → 备份监控](../user-guide/settings/backup-monitoring-settings.md) 和 [设置 → 服务器](../user-guide/settings/server-settings.md) 中添加了 **单服务器备份收集按钮**
- **批量收集功能** 用于所有具有有效配置（URL 和密码）的服务器
   - [设置 → 备份监控](../user-guide/settings/backup-monitoring-settings.md) 和 [设置 → 服务器](../user-guide/settings/server-settings.md) 中的 `Collect All` 按钮
   - 在应用程序工具栏中右键单击 `Collect Backup Logs` 按钮的上下文菜单

### 增强的通知系统 {/* #enhanced-notification-system */}

- **SMTP 电子邮件通知支持：**
    - 在 [设置 → 电子邮件设置](../user-guide/settings/email-settings.md) 中配置 SMTP 服务器
    - 每个备份作业配置 NTFY 和/或电子邮件通知
    - 使用现有 [设置 → 通知模板](../user-guide/settings/notification-templates.md) 的 HTML 格式模板
- **每个备份作业的通知配置：**
    - 在 [设置 → 备份通知](../user-guide/settings/backup-notifications-settings.md) 中的个别通知偏好
    - 当 NTFY 或电子邮件未正确配置时，显示灰色图标

- **区域设置支持：**
    - 创建了一个新的环境变量 `LANG` 以在应用程序中设置区域设置
    - 现在可以预测通知和日志中日期和数字的格式

## 🔒 安全增强 {/* #-security-enhancements */}

### CSRF 保护 {/* #csrf-protection */}

- **基于会话的身份验证** 具有强大的会话管理
- **强制执行 CSRF 令牌验证** 用于所有更改状态的 API 请求
- **会话自动过期** 24 小时后；CSRF 令牌每 30 分钟刷新一次
- 确保防止跨站点请求伪造，同时保持与外部 API 的兼容性

### 密码明文最小化 {/* #plaintext-password-minimization */}

- **密码只能通过用户界面设置**；没有 API 端点会暴露存储的密码
- **系统中最小化了明文密码操作**

### 敏感数据的高级加密 {/* #advanced-cryptography-for-sensitive-data */}

- **敏感数据加密**（例如密码、SMTP凭证）使用AES-256-GCM
- **主密钥自动生成**并安全存储在`.duplistatus.key`
- **使用PBKDF2和100,000次迭代**进行密钥派生以增强安全性
- **验证身份验证标签**并使用后安全清除内存
- **主密钥文件权限**严格设置为0400以获得最大保护

## 🚀 迁移说明 {/* #-migration-notes */}

### 从版本0.7.x {/* #from-version-07x */}

此版本包含重大的安全增强和新功能。从版本0.7.x升级时：

1. **自动数据库迁移：** 应用程序将自动迁移数据库架构以支持新功能
2. **主密钥生成：** 将为敏感数据加密生成新的主密钥
3. **会话管理：** 现有会话将被使无效，并建立新的CSRF保护会话
4. **配置更新：** 某些配置键已更新以支持新功能
5. **模板更改：** 变量`{backup_interval_value}`和`{backup_interval_type}`被替换为`{backup_interval}`。默认模板将自动调整，但自定义模板不会被迁移。请检查您的模板。

### 安全注意事项 {/* #security-considerations */}

- **主密钥文件：** 确保`.duplistatus.key`文件被正确备份和保护
- **文件权限：** 主密钥文件将具有受限权限（0400）以确保安全
- **密码加密：** 现有密码将使用新的加密系统进行加密
