# 版本 1.3.0 {/* #version-130 */}

## 概述 {/* #overview */}

版本 1.3.0 引入了可配置的密码策略、用于管理员的新应用程序日志查看器、基于区域的星期显示以及多项用户体验改进。此版本重点关注增强的管理工具和改进的国际化支持。

## 新功能 {/* #new-features */}

### 可配置的密码策略 {/* #configurable-password-policy */}

- **密码策略环境变量**：通过环境变量配置密码验证要求：
  - `PWD_ENFORCE`：设置为 `false` 以禁用密码复杂性要求（大写、小写、数字）。默认情况下强制执行所有规则。禁用时，仅强制执行最小长度。
  - `PWD_MIN_LEN`：设置以字符为单位的最小密码长度。默认为 8 个字符。
  - 默认密码检查（防止使用默认管理员密码）始终强制执行，无论 `PWD_ENFORCE` 设置如何。

### 应用程序日志查看器 {/* #application-logs-viewer */}

- **新的仅限管理员的日志查看器**：从设置页面直接查看和下载应用程序日志：
  - 访问合并的 `application.log` 文件和轮换的日志版本
  - 可配置的行数选择器（100、500、1000、5000、10000 行）
  - 实时搜索过滤器，支持不区分大小写的文本匹配
  - 实时日志监控的自动滚动切换，带有自动轮询
  - 将过滤后的日志复制到剪贴板并导出为文本文件
  - 显示文件元数据，包括行数、文件大小和最后修改时间戳
  - 容器启动时的日志轮换（可通过 `LOG_ROTATION_VERSIONS` 配置，默认值：5）

### 上下文感知的用户指南 {/* #context-aware-user-guide */}

- **动态帮助按钮**：应用程序标题中的用户指南按钮现在会打开与当前页面相关的文档。工具提示会更新以显示“`Page Name` 的帮助”，以指示将打开哪些文档。

### 服务器配置增强 {/* #server-configuration-enhancement */}

- **快速访问 Duplicati UI**：右键单击服务器配置按钮或服务器选择弹出窗口中的任何服务器项会在新标签页中打开 Duplicati 遗留 UI（`/ngax`）。

## 🔧 改进 {/* #-improvements */}

### 基于区域的星期显示 {/* #locale-aware-weekday-display */}

- **国际化星期顺序**：备份监控表单中的星期显示现在遵循您的浏览器区域设置。星期显示顺序基于区域（英国/欧洲为星期一至星期日，美国/巴西为星期日至星期六）。

### 增强的 SMTP 错误处理 {/* #enhanced-smtp-error-handling */}

- **改进的错误消息**：SMTP 错误消息现在提供更准确的指导：
  - 认证错误清楚地指示用户名/密码问题
  - SSL/TLS 版本错误被正确识别
  - 仅在真正相关时才显示连接类型建议

### 通知行为 {/* #toast-notification-behaviour */}

- **持久化错误通知**：错误通知现在会持续显示，直到手动关闭，确保您不会错过重要的错误消息。成功和信息通知在 3 秒后自动消失。

### 通知设置表 {/* #notification-settings-table */}

- **简化的布局**：通知设置表已简化，合并了“服务器 / 备份”列，并使用上下文图标指示其他目标配置状态。

## 🚀 迁移说明 {/* #-migration-notes */}

### 从版本 1.2.x {/* #from-version-12x */}

升级到版本 1.3.0 时：

1. **密码策略**：新的密码策略默认强制执行所有复杂性要求。如果您需要更简单的密码策略，请配置 `PWD_ENFORCE` 和 `PWD_MIN_LEN` 环境变量。

2. **应用程序日志**：所有容器输出（服务器和 cron 服务）现在合并到单个 `data/logs/application.log` 文件中。

3. **日志轮换**：日志轮换可通过 `LOG_ROTATION_VERSIONS` 环境变量配置（默认：5 个版本）。

4. **无需数据库迁移**：此版本不需要任何数据库架构更改。

## API 端点 {/* #api-endpoints */}

此版本中引入了以下 API 端点：

### 密码策略端点 {/* #password-policy-endpoint */}

- `GET /api/auth/password-policy` - 返回当前密码策略配置

### 应用程序日志端点 {/* #application-logs-endpoints */}

- `GET /api/application-logs` - 使用文件选择和尾部功能查看日志
- `GET /api/application-logs/export` - 将过滤后的日志导出为文本文件

### 已移除的端点 {/* #removed-endpoints */}

此版本中已移除以下未使用的 API 端点：

- `DELETE /api/backups/[backupId]` - 仅用于开发的端点，从未被使用
- `GET /api/audit-log/stats` - 审计日志查看器未调用的端点
