# 版本 1.5.1 {/* #version-151 */}

## 概述 {/* #overview */}

版本 1.5.1 是一个维护和安全更新版本。它更新了 Next.js 以解决图像优化 SSRF、缓存中毒及相关问题，加强了存储密钥的加密，并会在您配置的服务器上打开自定义 NTFY 服务器链接。发布的 amd64 和 arm64 容器镜像再次共享同一个摘要。

---

## 改进 {/* #improvements */}

### 文档 {/* #documentation */}

- **文档着陆页**：文档站点根目录现在是一个涵盖备份状态、截图、安全性和安装的产品页面，而不是跳转到介绍页面。**文档**和 `/intro` 仍然会打开指南。

---

## 错误修复 {/* #bug-fixes */}

- **自定义 NTFY 服务器链接 (问题 #85)**：设置主题链接和工具栏 NTFY 图标现在会打开您配置的服务器。它们不再总是跳转到 `https://ntfy.sh`。
- **多架构镜像**：发布版本不再附加来源证明，因此 GitHub Container Registry 和 Docker Hub 共享同一个摘要，且 `linux/amd64` 和 `linux/arm64` 被标记在一起。

---

## 安全性 {/* #security */}

### 框架和存储的密钥 {/* #framework-and-stored-secrets */}

- **Next.js 16.4.3**：`package.json` 声明为 16.3.8 (Dependabot #84)。依赖项覆盖安装了 16.4.3，其中包含了该版本针对图像优化 SSRF、元数据路由和缓存中毒问题的修复，以及通过 `use cache` 导致的草稿模式泄漏和开发服务器中的信息泄露修复。
- **更强的密钥加密**：新建和重新保存的密钥使用 PBKDF2-SHA256 和 600,000 次迭代，高于之前的 100,000 次。已使用之前次数存储的密钥仍然可以解密。再次保存密钥会以更高的次数重写它。

---

## 迁移说明 {/* #migration-notes */}

### 从版本 1.5.0 升级 {/* #from-version-150 */}

升级到 1.5.1 版本时：

1. **无需数据库迁移**：此版本不会更改数据库架构。现有的加密密钥可继续使用。
2. **依赖项**：运行 `pnpm install` 以应用更新后的锁文件和覆盖项。
3. **无需更改配置**：API 密钥、允许列表、通知设置和 NTFY 服务器 URL 保持不变。
