# 版本 1.4.2 {/* #version-142 */}

## 概述 {/* #overview */}

版本 1.4.2 是一个维护版本，专注于更广泛的语言支持、可靠性和依赖项清理。它引入了完全本地化的简体中文和印地语界面，将文档扩展到七种语言，并解决了一个重要的 Docker 启动崩溃问题，以及几个仪表板和服务器合并问题。依赖项也已更新，包括对 `nodemailer` 的重大升级。

---

## 新功能 {/* #new-features */}

### 语言支持 {/* #language-support */}

- **简体中文和印地语界面**：应用程序界面现在完全提供简体中文和印地语版本，与英语、法语、德语、西班牙语和巴西葡萄牙语一起。从设置中的语言菜单中选择它们。
- **扩展的文档语言**：在线文档现在以七种语言发布，新增印地语和简体中文，与现有翻译并列。

---

## 改进 {/* #improvements */}

### 备份收集 {/* #backup-collection */}

- **收集日志时稳定的服务器标识**：在收集备份日志时，duplistatus 现在将 Duplicati 机器名称与您现有的服务器匹配并重用该服务器的记录，而不是依赖 Duplicati 的机器 ID。这使得即使 Duplicati 的机器 ID 发生变化（例如重新安装后），备份历史也会附加到同一台服务器上，减少重复服务器条目。

### 文档 {/* #documentation */}

- **最新的语言列表**：README 和文档现在描述所有七种支持的语言并链接到每个翻译版本。
- **文档语言菜单标志**：为新的印地语和简体中文文档添加了国旗图标，并将葡萄牙语切换为葡萄牙国旗以保持一致性。国旗现在在 Windows、Linux 和 Chromium 上可靠渲染，无需外部字体下载。
- **扩展的重复服务器指导**：用户指南现在解释重复服务器的两种原因（更改的 Duplicati 机器 ID，以及混合身份 ID 和机器 ID 的 Duplicati API 错误）并记录 Duplicati 方面的变通方法以及 duplistatus 合并步骤。

### 仪表板性能 {/* #dashboard-performance */}

- **加载时更少的登录检查**：仪表板现在只获取一次当前用户并在页面间共享（页眉、设置保护、主题和小部件），而不是每个组件单独请求，减少了页面加载时的冗余请求。

---

## 错误修复 {/* #bug-fixes */}

- **Docker 启动崩溃**：修复了容器启动时报告 `Cannot find module '.../@swc/helpers/...'` 的崩溃，这可能会阻止应用程序启动。容器现在可以可靠启动。
- **重复仪表板条目**：当多个记录共享相同的最新备份日期时，仪表板不再为同一备份显示多行。
- **合并重复服务器**：合并服务器现在还会合并共享相同备份名称的重复 Duplicati 备份 ID，保留来自最新备份的 ID。合并操作现在记录在审计日志中。

---

## 安全性 {/* #security */}

### 依赖项更新 {/* #dependency-updates */}

- **`nodemailer` 升级到 9.x**：将电子邮件库更新到最新主要版本。v9 中唯一的破坏性更改（获取远程附件、OAuth2 或代理内容时更严格的 TLS 验证）不影响仅发送内联文本和 HTML 电子邮件的 duplistatus。
- **其他依赖项更新**：将多个构建和类型依赖项刷新到其最新的兼容版本。

---

## 迁移说明 {/* #migration-notes */}

### 从版本 1.4.1 {/* #from-version-141 */}

升级到版本 1.4.2 时：

1. **无需数据库迁移**：此版本不需要任何数据库架构更改。
2. **依赖项**：运行 `pnpm install` 以应用更新的锁定文件和覆盖配置。
3. **无需配置更改**：保留现有设置，包括您选择的语言。

## 更新日志 {/* #changelog */}

### 版本 1.4.2 更改 {/* #version-142-changes */}

- **新增**：完整的简体中文和印地语用户界面。
- **新增**：文档现在提供七种语言，包括印地语和简体中文。
- **已更改**：备份日志收集现在通过 Duplicati 机器名称识别服务器（重用现有记录），即使机器 ID 更改也能保持历史记录关联。

- **已更改**：文档和 README 已更新以描述支持的完整语言集，并扩展了重复服务器故障排除指南。
- **已更改**：将 `nodemailer` 升级到 9.x 并刷新了其他构建/类型依赖项。
- **已修复**：由缺少 `@swc/helpers` 模块导致的 Docker 启动崩溃。
- **已修复**：当多个备份共享相同最新日期时的仪表板重复条目。
- **已修复**：合并重复服务器现在会合并重复的备份 ID 并记录在审计日志中。
- **已修复**：减少了加载仪表板时的冗余登录检查。
