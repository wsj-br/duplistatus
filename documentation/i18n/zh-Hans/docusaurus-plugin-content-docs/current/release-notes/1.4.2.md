# 版本 1.4.2 {/* #version-142 */}

## 概述 {/* #overview */}

版本 1.4.2 是一个维护版本，专注于更广泛的语言支持、可靠性和依赖关系管理。它引入了完全本地化的简体中文和印地语界面，将文档扩展到七种语言，并解决了一个重要的 Docker 启动崩溃问题，以及几个仪表板和服务器合并问题。依赖关系也已更新，包括对 `nodemailer` 的重大升级。

---

## 新功能 {/* #new-features */}

### 语言支持 {/* #language-support */}

- **简体中文和印地语界面**：应用程序界面现在完全支持简体中文和印地语，加入了英语、法语、德语、西班牙语和巴西葡萄牙语。从设置中的语言菜单中选择它们。
- **扩展的文档语言**：在线文档现在以七种语言发布，新增印地语和简体中文，配合现有翻译。

---

## 改进 {/* #improvements */}

### 备份收集 {/* #backup-collection */}

- **收集日志时稳定的服务器身份**：在收集备份日志时，duplistatus 现在将 Duplicati 机器名称与您现有的服务器匹配，并重用该服务器的记录，而不是依赖 Duplicati 的机器 ID。这使得备份历史记录保持与同一服务器关联，即使 Duplicati 的机器 ID 发生变化（例如，重新安装后），从而减少重复服务器条目。

### 文档 {/* #documentation */}

- **最新的语言列表**：README 和文档现在描述所有七种支持的语言，并链接到每个翻译版本。
- **文档语言菜单标志**：为新的印地语和简体中文文档添加了国旗图标，并将葡萄牙语切换为葡萄牙国旗以保持一致性。国旗现在在 Windows、Linux 和 Chromium 上可靠呈现，无需外部字体下载。
- **扩展的重复服务器指导**：用户指南现在解释了重复服务器的两个原因（更改的 Duplicati 机器 ID 和混合身份 ID 与机器 ID 的 Duplicati API 错误），并记录了 Duplicati 侧的解决方法以及 duplistatus 合并步骤。

### 仪表板性能 {/* #dashboard-performance */}

- **加载时减少登录检查**：仪表板现在一次获取您的当前用户，并在页面（标题、设置保护、主题和小部件）之间共享，而不是每个组件单独请求，从而减少页面加载时的冗余请求。

---

## 缺陷修复 {/* #bug-fixes */}

- **Docker 启动崩溃**：修复了一个在容器启动时报告 `Cannot find module '.../@swc/helpers/...'` 的崩溃，这可能会阻止应用程序启动。容器现在可靠启动。
- **重复的仪表板条目**：当多个记录共享相同的最新备份日期时，仪表板不再显示相同备份的多行。
- **合并重复服务器**：合并服务器现在还会合并共享相同备份名称的重复 Duplicati 备份 ID，保留最新备份的 ID。合并操作现在记录在审计日志中。

---

## 安全 {/* #security */}

### 依赖关系更新 {/* #dependency-updates */}

- **`nodemailer` 升级到 9.x**：将电子邮件库更新到最新的主要版本。v9 中唯一的重大变化（在获取远程附件、OAuth2 或代理内容时更严格的 TLS 验证）不影响 duplistatus，它仅发送内联文本和 HTML 电子邮件。
- **其他依赖关系更新**：将多个构建和类型依赖关系刷新到其最新兼容版本。

---

## 迁移说明 {/* #migration-notes */}

### 从版本 1.4.1 {/* #from-version-141 */}

升级到版本 1.4.2 时：

1. **无需数据库迁移**：此版本不需要任何数据库架构更改。
2. **依赖关系**：运行 `pnpm install` 以应用更新的锁定文件和覆盖。
3. **无需配置更改**：现有设置，包括您选择的语言，均被保留。

## 变更日志 {/* #changelog */}

### 版本 1.4.2 更改 {/* #version-142-changes */}

- **新增**：完整的简体中文和印地语用户界面。
- **新增**：文档现已提供七种语言，包括印地语和简体中文。
- **更改**：备份日志收集现在通过Duplicati机器名称识别服务器（重用现有记录），即使机器ID发生变化，也能保持历史记录附加。
- **更改**：文档语言菜单添加了新语言的国旗，并为葡萄牙语使用葡萄牙国旗。
- **更改**：文档和README更新以描述完整的支持语言集，并扩展了重复服务器故障排除指南。
- **更改**：升级`nodemailer`到9.x，并刷新其他构建/类型依赖项。
- **修复**：由于缺少`@swc/helpers`模块导致的Docker启动崩溃。
- **修复**：当多个备份共享相同时间时，仪表板出现重复条目。
- **修复**：合并重复服务器现在合并重复的备份ID，并在审计日志中记录。
- **修复**：加载仪表板时减少了冗余的登录检查。
