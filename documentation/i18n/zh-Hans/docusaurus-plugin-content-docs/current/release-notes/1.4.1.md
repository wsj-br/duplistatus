# 版本 1.4.1 {/* #version-141 */}

## 概述 {/* #overview */}

版本 1.4.1 引入了内联图表控件、增强的过滤功能、系统主题支持和区域格式选项等显著改进，以增强仪表板体验。此版本还解决了影响图表渲染、备份详细信息加载和服务器连接检测的多个错误。此外，已解决依赖项中的安全漏洞。

---

## 新功能 {/* #new-features */}

### 内联图表控件 {/* #inline-chart-controls */}

- **图表时间范围选择器**：在图表面板标题中添加类似股票图表的胶囊按钮（`1W | 2W | 1M | 3M`），用于快速切换时间范围，无需导航至显示设置。与显示设置共享状态。
- **图表样式切换（问题 #54）**：在图表面板标题中添加切换按钮，直接在线图和柱状图之间切换。持久化并同步所有面板。
- **简化的时间范围**：从 7 个选项减少为 4 个重点范围（1 周、2 周、1 个月、3 个月），其中 1 个月为新默认值。

### 显示和格式化选项 {/* #display-and-formatting-options */}

- **系统主题支持**：显示设置现在包括“系统（跟随操作系统）”选项，以自动匹配操作系统的浅色/深色偏好。
- **格式区域覆盖（问题 #59）**：用户可以在设置 > 显示设置中独立选择格式区域，不受 UI 语言影响（支持 416 个区域）。日期、时间和数字格式化遵循所选格式区域，并提供实时预览。

### 服务器过滤 {/* #server-filtering */}

- **仪表板服务器过滤器**：搜索字段移至应用程序标题，支持自动刷新和工具栏操作。当为空时，控件仅显示搜索图标；悬停或点击时展开文本字段。
- **改进的过滤匹配（问题 #53）**：过滤器现在匹配服务器 ID、URL 和任何备份作业名称。修复了过滤器更改时概览卡片网格未更新的问题。
- **设置过滤**：在设置 > 备份监控和设置 > 服务器中的服务器列表中添加过滤器输入。

## 改进 {/* #improvements */}

### 图表数据处理 {/* #chart-data-handling */}

- **滚动时间窗口**：时间范围现在使用滚动日窗口：1W = 过去 7 天，2W = 过去 14 天，1M = 过去 30 天，3M = 过去 90 天（之前为日历基础）。
- **数据合并**：在分桶之前，所有图表数据点都按日历日合并。同一天的多个备份将被适当地合并。
- **有限数据点**：图表现在强制执行最多 30 个数据点，以提高性能和可读性。
- **工具提示简化**：工具提示现在仅显示日期（例如“5/12/26”），而不显示日期和时间。

### 备份调度 {/* #backup-scheduling */}

- **基于 UTC 的计算**：下一个预期备份和过期检测现在在 UTC 中推进间隔和工作日检查，而不是本地时间，避免在主机时区跨越夏令时时出现一小时 UTC 漂移。
- **增加过期容忍度**：新安装和默认值现在使用 2 小时而不是 1 小时的过期容忍度。

### 连接和可靠性 {/* #connectivity-and-reliability */}

- **连接丢失检测**：添加了 `/api/ping` 端点和基于标头的 30 秒连接探测。刷新和自动刷新失败现在打开丢失连接模态框，而不显示原始错误文本。
- **UI 偏好持久化**：修复了导致用户 UI 偏好（概览侧边栏、图表时间范围、图表样式）在页面刷新时不持久化的竞态条件。

### 文档 {/* #documentation */}

- **Duplicati 远程访问说明（问题 #40）**：文档现在明确说明 Duplicati 远程访问是可选的，仅在需要直接链接到 Duplicati UI 时才需要。

## 缺陷修复 {/* #bug-fixes */}

- **概述图表面板忽略时间范围过滤器**：修复了面板显示所有数据点而不考虑所选时间范围的问题。面板现在从API获取自己的数据，并带有正确的时间范围参数。
- **备份详情中的OOM崩溃（问题#62）**：通过优化查询和UI渲染来防止`JavaScript heap out of memory`。备份日志现在按需获取，而不是一次性加载所有日志，最多1000行。
- **备份版本解析（问题#65）**：`convertTimestampToISO()`现在可以处理Duplicati在不同系统区域设置下使用的所有常见区域特定时间戳格式。

## 安全 {/* #security */}

### 依赖漏洞修复 {/* #dependency-vulnerability-fixes */}

- **npm审计漏洞**：解决了7个漏洞（1个高危，6个中危）：
  - 将`next`更新至`16.3.0-canary.19`以修复`postcss@8.4.31`（XSS）
  - 添加`.pnpmfile.cjs`以强制`serialize-javascript@^7.0.5`（RCE，DoS）
  - 将`mermaid`覆盖更新至`>=11.14.1`（4个中危漏洞）
  - 添加了显式的`postcss@^8.5.14`和`serialize-javascript@^7.0.5`依赖项

- **pnpm覆盖**：为传递性`uuid >=14.0.0`和`postcss >=8.5.10`添加了根`pnpm.overrides`。

- **高危漏洞**：通过pnpm覆盖修复了4个高危漏洞，涉及`minimatch >=3.1.4`和`serialize-javascript >=7.0.3`。

## 迁移说明 {/* #migration-notes */}

### 从版本1.3.2升级到1.4.1 {/* #from-version-132 */}

升级到版本1.4.1时：

1. **无需数据库迁移**：此版本不需要任何数据库架构更改。
2. **新的默认超时容忍度**：新安装将默认使用2小时超时容忍度，而不是1小时。现有设置保持不变。
3. **图表偏好**：图表时间范围和样式偏好现在存储方式不同，升级后将重置为默认值（1个月，线图）。
4. **依赖项**：运行`pnpm install`以应用更新后的锁定文件和覆盖。
