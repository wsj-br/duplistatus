# 版本 1.1.x {/* #version-11x */}

## 概述 {/* #overview */}

版本 1.1.x 是一个次要版本，解决了过期备份检测的关键问题，改进了 Podman 容器兼容性，并引入了容器架构改进。该版本重点解决过期备份检测的准确性，并解决了 Podman 环境中的网络问题。

## 新功能 {/* #new-features */}

### 用户界面增强 {/* #user-interface-enhancements */}

- **自动刷新按钮的右键单击菜单** - 在应用程序工具栏中右键单击自动刷新按钮会打开显示设置页面，以便快速访问显示首选项
- **改进的收集备份模态框** - 密码字段标签现在清楚地指示“（仅当密码更改时填写）”，当选择服务器时，清楚地表明何时需要该字段

### 文档改进 {/* #documentation-improvements */}

- **文档托管迁移** - 文档已从 Docker 容器镜像迁移到 GitHub Pages，网址为 https://wsj-br.github.io/duplistatus/user-guide/overview，以提高可访问性和简化更新
- 应用程序头部中的用户指南链接现在指向外部文档站点

---

## 🐛 错误修复 {/* #-bug-fixes */}

### 关键：过期备份检测 - 完全重新实现 {/* #critical-overdue-backup-detection---complete-reimplementation */}

- **修复过期备份检测** - 完全重新实现了过期备份检测系统，采用新算法正确跟踪预期的备份日期：
  - 算法确保手动备份不会改变计划备份时间（例如，晚上 10 点的手动备份不会改变下午 2 点的计划）
  - 修复了备份监控设置中“下次运行”列显示不正确的日期
  - 通过 `/api/upload` 或 `/api/backups/collect` 接收备份后，备份设置现在会立即更新
  - 对于没有 Duplicati 同步的新服务器，使用第一次备份的时间作为计划参考
  - 有关详细信息，请参阅 [过期检测算法](https://github.com/wsj-br/duplistatus/blob/main/dev/OVERDUE_DETECTION_ALGORITHM.md) 文档

### Podman 容器修复 {/* #podman-container-fixes */}

- **修复 Podman pod 网络** - 解决了在 Podman pod 中运行时阻止外部访问应用程序的问题。服务器现在在 Podman pod 和独立容器模式下都正确绑定到所有接口（`0.0.0.0:9666`）
- **修复 Tailscale 主机名的 DNS 解析** - 解决了 Podman 容器中阻止连接到 Tailscale 主机名或自定义 DNS 服务器的 DNS 解析问题。已更新安装文档以包含说明。

### 电子邮件配置修复 {/* #email-configuration-fixes */}

- **修复 SMTP 空用户名/密码处理** - 解决了在电子邮件配置中清除用户名或密码字段会导致数据库仍存储加密值的问题。空字段现在会被正确存储为空字符串，并且可以正确清除

### 系统改进 {/* #system-improvements */}

- **减少控制台日志记录** - AuditLogger 现在仅将失败的登录尝试记录到控制台；所有其他审计条目仅写入数据库

## 🚀 迁移说明 {/* #-migration-notes */}

### 从版本 1.0.x {/* #from-version-10x */}

升级到版本 1.1.0 时：

1. **文档位置变更** - 文档现在托管在 GitHub Pages 上，而不是包含在 Docker 容器中。应用程序头部中的用户指南链接现在指向外部文档站点

2. **Podman 容器配置** - 如果使用 Podman pod，请确保在 pod 级别使用 `--dns` 和 `--dns-search` 标志设置 DNS 配置。应用程序现在在 Podman pod 和独立容器中都能正常工作

3. **过期备份检测** - 过期备份检测系统已完全重新实现，采用新算法保留计划时间。现有备份监控配置将继续工作，但您可能会在备份监控设置中看到更准确的“下次运行”日期。新算法确保手动备份不会改变计划备份时间

4. **无需数据库迁移** - 该版本不需要任何数据库架构更改
