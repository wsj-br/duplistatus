# 版本 0.7.x {/* #version-07x */}

## 概述 {/* #overview */}

版本 0.7.x 是一个重大发布，引入了对数据库架构、API 结构和用户界面的显著改进。此版本包括需要更新外部集成的重大更改。

## 重大更改 {/* #breaking-changes */}

### 数据库架构更改 {/* #database-schema-changes */}
- **表重命名**: `machines` 表重命名为 `servers`
- **新字段**: 添加了 `alias`、`notes`、`created_at` 和 `updated_at` 字段
- **API 响应更改**: 更新字段名称以保持一致

### 向后不兼容的 API 更改 {/* #backward-incompatible-api-changes */}
- **字段重命名**: `totalMachines` → `totalServers`
- **对象重命名**: API 响应中的 `machine` → `server`
- **字段重命名**: `backup_types_count` → `backupJobsCount`

:::warning
**使用 API 的外部集成必须更新** 以与版本 0.7.x 兼容。有关详细信息，请参阅 [向后不兼容的 API 更改](../migration/api-changes) 指南。
:::

## Migration Guide {/* #migration-guide */}

### Automatic Migration {/* #automatic-migration */}
从0.6.x到0.7.x的迁移会自动进行：

1. **Backup Creation**: 自动创建数据库备份
2. **Schema Update**: 自动更新数据库架构
3. **Data Migration**: 保留并迁移现有数据
4. **Verification**: 验证并记录迁移

### Manual Steps Required {/* #manual-steps-required */}
- **Update External Integrations**: 更新使用API的任何外部工具
- **Test Functionality**: 验证所有功能是否正常工作
- **Update Documentation**: 更新任何自定义文档

    image: wsjbr/duplistatus:0.7.x

## 升级说明 {/* #upgrade-instructions */}

### 从版本 0.6.x {/* #from-version-06x */}
1. **备份数据**（升级期间自动创建备份）
2. **更新 Docker 镜像**: `docker pull wsjbr/duplistatus:0.7.x`
3. **重启容器**: `docker-compose down && docker-compose up -d`
4. **监控日志**: `docker logs -f duplistatus`
5. **更新集成**: 更新使用 API 的任何外部工具
6. **验证升级**: 检查所有功能是否正常工作

### 从版本 0.5.x 或更早版本 {/* #from-version-05x-or-earlier */}
1. **首先升级到 0.6.x**（如果可用）
2. **然后使用上述步骤升级到 0.7.x**
