# 版本 1.5.2 {/* #version-152 */}

## 概述 {/* #overview */}

版本 1.5.2 是一个维护版本。在 duplicati 2.4.1.0 及更高版本中，备份报告中的保留日期会被 `-redacted-` 替换，除非设置了 `--allow-paths-in-log-messages=true`，否则可用版本列表将为空。推荐的报告选项和故障排除现已包含该设置。

---

## 改进 {/* #improvements */}

### duplicati 报告 {/* #duplicati-reporting */}

- **duplicati 2.4.1.0 及更高版本上的保留日期**：在 **设置 → 默认选项**（或备份的高级选项）中添加 `--allow-paths-in-log-messages=true`。如果不添加，duplicati 会将 `Backups to consider` 中的日期替换为 `-redacted-`，因此可用版本共显示，但时间戳列表保持为空。请勿设置 `--reduced-reporting`，因为该选项会移除消息文本，然后再次运行备份。已存储的报告将保持脱敏状态。该选项还包括 HTTP 报告中来自警告和错误的本地文件路径。备份详情页面上的截断日志提示也指出了相同的选项。

---

## 迁移说明 {/* #migration-notes */}

### 自 1.5.1 版本起 {/* #from-version-151 */}

升级到 1.5.2 版本时：

1. **无需数据库迁移**：此版本不会更改数据库架构。
2. **依赖项**：运行 `pnpm install` 以应用更新后的锁文件和覆盖项。
3. **duplicati 2.4.1.0 及更高版本**：如果可用版本列表为空，请在每个 duplicati 服务器上添加 `--allow-paths-in-log-messages=true` 并再次运行备份。现有的已存储报告保持不变。
