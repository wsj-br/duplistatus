# 版本 1.0.x {/* #version-10x */}

## 概述 {/* #overview */}

版本 1.0.x 是一个功能发布，带来了对电子邮件配置、服务器管理能力和数据库维护工具的重大增强。此版本专注于提高电子邮件通知的可靠性，扩展 SMTP 连接选项，并提供更好的工具来管理服务器和数据库完整性。

## 新功能 {/* #new-features */}

### 服务器管理增强 {/* #server-management-enhancements */}

- **服务器密码更改功能** - 用户现在可以通过点击服务器详细信息页面上的钥匙图标直接更改服务器密码
- **重复服务器检测和合并** - 数据库维护表单中的新功能，用于检测重复服务器并将其合并为单个服务器条目

### 审计日志增强 {/* #audit-logging-enhancements */}

- **备份上传审计日志** - 通过 `/api/upload` 端点上传的所有备份日志现在会自动记录在审计日志中。每个条目包括备份详细信息（服务器 ID、服务器名称、备份名称、状态、日期、持续时间、文件计数、大小、警告和错误），以及客户端 IP 地址和用户代理信息，以便于跟踪和安全目的

### 电子邮件配置增强 {/* #email-configuration-enhancements */}

- **配置不完整通知** - 当电子邮件设置未正确配置时显示视觉警报
- **服务状态指示器** - 当电子邮件服务未配置时，在通知复选框上显示 "(禁用)" 标签
- **可自定义发件人信息**:
  - `Sender Name` 字段用于自定义在电子邮件通知中显示的发件人名称
  - `From Address` 字段用于指定显示为发件人的电子邮件地址
  - 注意：某些电子邮件提供商将用 `From Address` 覆盖 `SMTP Server Username`
- **SMTP 身份验证切换** - 启用或禁用 SMTP 身份验证的选项，支持不需要身份验证的服务器
- **电子邮件格式验证** - 对接收者和发件人地址字段进行验证，以确保电子邮件地址格式正确
- **增强的测试电子邮件** - 测试电子邮件现在显示全面的连接详细信息，包括 SMTP 服务器主机名、端口、连接类型、身份验证状态、用户名（如适用）、接收者邮箱、发件人地址、发件人名称和测试时间戳

### SMTP 连接类型支持 {/* #smtp-connection-type-support */}

- **多种连接类型** - 支持三种连接类型：
  - `Plain SMTP`（无加密）在端口 25
  - `STARTTLS`（升级到 TLS）在端口 587
  - `Direct SSL/TLS`（从开始加密）在端口 465
- **默认连接类型** - 新配置的默认值更改为 `Direct SSL/TLS`
- **特定连接要求** - `From Address` 字段是 `Plain SMTP` 连接所需，以确保正确的电子邮件发件人识别和 RFC 5322 合规性

## 🐛 错误修复 {/* #-bug-fixes */}

### 电子邮件系统修复 {/* #email-system-fixes */}

- **修复缺失的 `From` 头** - 通过确保所有电子邮件消息包含正确的 `From` 头，解决了 RFC 5322 合规性错误
- **修复 STARTTLS 的电子邮件加密** - 修正了 `STARTTLS` 连接（端口 587）的加密处理
- **修复普通 SMTP 连接** - 解决了导致 `Plain SMTP` 连接失败的 TLS 协商错误
- **修复未保存的配置丢失** - 防止在更改密码时未保存的电子邮件配置被清除
- **修复过时的 SMTP 配置** - 解决了测试电子邮件端点使用过时 SMTP 配置的问题

### 用户界面修复 {/* #user-interface-fixes */}

- **修复密码可见性切换** - 更正了密码更改表单中查看密码功能的行为；点击眼睛图标现在同时显示两个密码字段的密码

### 系统修复 {/* #system-fixes */}

- **修复 Docker 入口点日志** - 解决了 Docker 入口点脚本丢失日志消息的问题
- **修复下次运行日期计算** - 在收集备份日志后，自动重新计算 `Next Run` 日期，确保在日志收集后日期正确更新

## 🚀 迁移说明 {/* #-migration-notes */}

### 从版本 0.9.x {/* #from-version-09x */}

此版本包括电子邮件配置和服务器管理的增强功能。从版本 0.9.x 升级时：

1. **无需数据库迁移** - 此版本不需要任何数据库架构更改
2. **电子邮件配置更新** - 现有电子邮件配置将继续工作，但您可能希望查看并更新设置以利用新功能：
   - 考虑设置自定义 `Sender Name` 以获得更好的电子邮件识别
   - 验证您的 `From Address` 是否正确设置，特别是在使用 `Plain SMTP` 连接时
   - 使用增强的测试电子邮件功能测试您的电子邮件配置
3. **连接类型默认值** - 新的电子邮件配置将默认为 `Direct SSL/TLS` 连接类型
4. **服务器密码管理** - 您现在可以直接从服务器详细信息页面更改服务器密码，无需重新收集备份

### 电子邮件配置建议 {/* #email-configuration-recommendations */}

- **生产环境**：使用 `STARTTLS` 或 `Direct SSL/TLS` 连接以确保安全的电子邮件传递
- **本地测试**：`Plain SMTP` 连接可用于受信任的本地网络
- **发件人地址要求**：使用 `Plain SMTP` 或禁用身份验证时，请确保正确配置 `From Address` 字段
- **测试您的配置**：始终使用“发送测试电子邮件”按钮验证您的电子邮件设置是否正常工作

## API 端点 {/* #api-endpoints */}

### 电子邮件配置端点 {/* #email-configuration-endpoints */}

- `GET /api/email/config` - 获取电子邮件配置
- `POST /api/email/config` - 更新电子邮件配置
- `POST /api/email/test` - 发送测试电子邮件
- `DELETE /api/email/config` - 删除电子邮件配置

### 服务器管理端点 {/* #server-management-endpoints */}

- `PATCH /api/servers/{id}/password` - 更新服务器密码
- `POST /api/database/maintenance/merge-duplicate-servers` - 合并重复服务器
