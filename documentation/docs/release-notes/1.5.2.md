# Version 1.5.2 {/* #version-152 */}

## Overview {/* #overview */}

Version 1.5.2 is a maintenance release. On Duplicati 2.4.1.0 and later, retention dates in backup reports are replaced with `-redacted-` unless `--allow-paths-in-log-messages=true` is set, which leaves the available-versions list empty. The recommended reporting options and troubleshooting now include that setting.

---

## Improvements {/* #improvements */}

### Duplicati reporting {/* #duplicati-reporting */}

- **Retention dates on Duplicati 2.4.1.0 and later**: Add `--allow-paths-in-log-messages=true` in **Settings → Default options** (or the backup's advanced options). Without it, Duplicati replaces the dates in `Backups to consider` with `-redacted-`, so the available-versions count can still appear while the timestamp list stays empty. Leave `--reduced-reporting` unset, because that option removes the message text, then run the backup again. Reports already stored stay redacted. The option also includes local file paths from warnings and errors in the HTTP report. The truncated-log hint on a backup's detail page names the same option.

---

## Migration notes {/* #migration-notes */}

### From version 1.5.1 {/* #from-version-151 */}

When upgrading to version 1.5.2:

1. **No database migration required**: This release does not change the database schema.
2. **Dependencies**: Run `pnpm install` to apply the updated lockfile and overrides.
3. **Duplicati 2.4.1.0 and later**: If the available-versions list is empty, add `--allow-paths-in-log-messages=true` on each Duplicati server and run the backup again. Existing stored reports are unchanged.
