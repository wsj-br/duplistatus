# Version 1.5.1 {/* #version-151 */}

## Overview {/* #overview */}

Version 1.5.1 is a maintenance and security release. It updates Next.js to address image-optimisation SSRF, cache poisoning, and related issues, strengthens encryption of stored secrets, and opens custom NTFY server links on the server you configured. Published container images for amd64 and arm64 again share one digest.

---

## Improvements {/* #improvements */}

### Documentation {/* #documentation */}

- **Documentation landing page**: The documentation site root is now a product page covering backup status, screenshots, security, and install, instead of a redirect to the introduction. **Docs** and `/intro` still open the guide.

---

## Bug fixes {/* #bug-fixes */}

- **Custom NTFY server links (issue #85)**: The settings topic link and the toolbar NTFY icon open the server you configured. They no longer always go to `https://ntfy.sh`.
- **Multi-architecture images**: Release builds no longer attach provenance attestations, so GitHub Container Registry and Docker Hub share one digest and `linux/amd64` and `linux/arm64` are tagged together.

---

## Security {/* #security */}

### Framework and stored secrets {/* #framework-and-stored-secrets */}

- **Next.js 16.4.3**: `package.json` declares 16.3.8 (Dependabot #84). The dependency override installs 16.4.3, which includes that release's fixes for image-optimisation SSRF, metadata-route and cache-poisoning issues, Draft Mode leakage through `use cache`, and an information disclosure in the development server.
- **Stronger secret encryption**: New and re-saved secrets use PBKDF2-SHA256 with 600,000 iterations, up from 100,000. Secrets already stored with the previous count still decrypt. Saving a secret again rewrites it with the higher count.

---

## Migration notes {/* #migration-notes */}

### From version 1.5.0 {/* #from-version-150 */}

When upgrading to version 1.5.1:

1. **No database migration required**: This release does not change the database schema. Existing encrypted secrets keep working.
2. **Dependencies**: Run `pnpm install` to apply the updated lockfile and overrides.
3. **No configuration changes needed**: API keys, allowlists, notification settings, and NTFY server URLs are unchanged.
