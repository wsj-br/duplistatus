在一个仪表板中监控每个 Duplicati 服务器和任务。具备清晰的状态指示器、包含 10 次运行状态条的单服务器卡片、可排序的表格视图，并可深入查看包含警告和错误信息的单次备份日志。

  • 包含 10 次运行状态条的单服务器卡片
  • 跨所有服务器的可排序表格视图
  • 深入查看单项备份日志
  • 与 GitHub 最新发布版本进行版本对比

02

防患于未然，避免数据丢失

自动检测过期备份、警告和失败的备份。通过 ntfy 推送或 SMTP 电子邮件及时接收 警报 — 支持针对每个作业设置通知筛选器， 并可在固定的本地时间接收可选的每日摘要电子邮件。

  • 默认每 5 分钟进行一次过期检查
  • 单个作业筛选器：关闭 / 所有 / 警告 / 错误
  • ntfy 推送通知和 SMTP 电子邮件
  • 每日摘要仅暂停向默认收件人发送电子邮件

仅需四步，从零开始实现全面监控

容器化部署让您在数分钟内即可启动并运行 — 无需耗费数小时。

步骤 1

部署容器

从 Docker Hub 或 GitHub 拉取镜像，设置时区并挂载数据卷。Web UI 监听 9666 端口。架构迁移会在启动时自动应用。 

wget https://github.com/wsj-br/duplistatus/raw/refs/heads/master/production.yml -O duplistatus.yml
docker compose -f duplistatus.yml up -d
安装指南
步骤 2

将 Duplicati 指向 duplistatus

配置每个 Duplicati 服务器将 JSON 报告 POST 到 /api/upload。然后收集历史日志，以便自动填充监控间隔。 

--send-http-json-urls=http://host:9666/api/upload
--send-http-log-level=Information
--send-http-max-log-lines=500
Duplicati 配置
步骤 3

配置告警

设置针对每个作业的通知过滤条件（关闭 / 所有 / 警告 / 错误），启用逾期检查，并选择 ntfy 推送或 SMTP 电子邮件。每日摘要为可选项，且仅暂停发送给默认收件人的电子邮件。 

Notifications:
  ntfy:   enabled
  email:  enabled
  filter: warnings + errors
  overdue: every 5 minutes
通知设置
步骤 4

监控和故障排除

在仪表板中查看状态变化，深入探查任意备份日志，并使用交互式趋势图发现异常。cron 服务在后台处理逾期检查、版本刷新和日志清理。 

Dashboard:  all servers · all jobs
Last check: 2 min ago
Overdue:    0
Failures:   0

几分钟内快速上手

拉取镜像、挂载数据卷和开放 9666 端口。架构迁移会在启动时自动运行。 

# download the compose file
wget https://github.com/wsj-br/duplistatus/raw/refs/heads/master/production.yml -O duplistatus.yml
# start the container
docker compose -f duplistatus.yml up -d
# duplistatus production compose.yml
services:
  duplistatus:
    image: ghcr.io/wsj-br/duplistatus:latest
    container_name: duplistatus
    restart: unless-stopped
    environment:
      - TZ=Europe/London
      - PWD_ENFORCE=true
      - PWD_MIN_LEN=8
    ports:
      - "9666:9666"
    volumes:
      - duplistatus_data:/app/data
    networks:
      - duplistatus_network

networks:
  duplistatus_network:
    driver: bridge

volumes:
  duplistatus_data:
    name: duplistatus_data
# Create the volume
docker volume create duplistatus_data

# Start the container
docker run -d \
  --name duplistatus \
  -p 9666:9666 \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -v duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest
mkdir -p ~/duplistatus_data
# Start the container (standalone)
podman run -d \
  --name duplistatus \
  --userns=keep-id \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -p 9666:9666 \
  -v ~/duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest

容器启动后：

  1. 1 在浏览器中打开 http://localhost:9666
  2. 2 使用安装指南中说明的默认管理员账户登录
  3. 3 配置您的 Duplicati 服务器将备份报告发送至 /api/upload
  4. 4 使用收集备份日志导入历史记录，如果需要警报，请配置 ntfy 或 SMTP
  5. 5 可选择为面向公网的安装启用 API 密钥和 IP 白名单
