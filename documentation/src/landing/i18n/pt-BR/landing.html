Todos os seus backups. Um painel.

Pare de fazer login em cada interface web do Duplicati uma a uma. O duplistatus monitora cada servidor e tarefa a partir de uma única tela — para que você saiba que seus backups estão em ordem antes que a perda de dados o pegue desprevenido.

O duplistatus usa os relatórios HTTP integrados do Duplicati, portanto não há nada para instalar em suas máquinas de backup.

A única pergunta que importa

Todos os meus backups estão operando corretamente? Uma única tela responde a isso, em cada servidor, cada trabalho e cada execução.

localhost:9666

Criado para quem executa o Duplicati em mais de uma máquina

Quer você utilize um NAS, um notebook, um VPS ou dois servidores domésticos, o duplistatus reúne todos eles em uma única tela.

01

Veja cada backup num relance

Um card por servidor exibe as últimas 10 execuções de cada trabalho. Alterne para uma tabela com ordenação quando tiver muitos servidores e abra qualquer execução para ler seu log completo, incluindo avisos e erros.

  • Totais de servidores, trabalhos, execuções, tamanho e armazenamento
  • Painel com atualização automática para uma experiência em video wall
  • Verificação da versão do servidor Duplicati em relação à versão mais recente do GitHub

02

Identifique problemas antes que se tornem perda de dados

O duplistatus detecta backups atrasados, com avisos ou com falha automaticamente e alerta você via push do NTFY ou e-mail SMTP.

  • Verificações de itens atrasados são executadas periodicamente por padrão
  • Receba notificações para cada trabalho com filtros por trabalho: desativado, todos, avisos ou erros
  • Reduza o excesso de notificações com o e-mail de Resumo Diário.

Do zero ao monitoramento em quatro etapas

A implantação em contêineres significa que você está pronto e funcionando em minutos — não horas.

Passo 1

Implantar o contêiner

Baixe a imagem do Docker Hub ou GitHub, defina seu fuso horário e monte um volume de dados. A interface web escuta na porta 9666. As migrações de esquema são aplicadas automaticamente na inicialização.

Primeiros passos
Guia de instalação
Passo 2

Apontar o Duplicati para o duplistatus

Configure cada servidor Duplicati para enviar relatórios JSON via POST para /api/upload. Em seguida, colete logs históricos para que os intervalos de monitoramento sejam preenchidos automaticamente. 

--send-http-json-urls=http://host:9666/api/upload
--send-http-log-level=Information
--send-http-max-log-lines=500
Configuração do Duplicati
Passo 3

Configurar alertas

O ntfy já está configurado. Altere o tópico para o seu próprio tópico e, em seguida, escaneie o código QR gerado pelo duplistatus para configurá-lo no seu celular.
Defina as configurações do servidor de e-mail para começar a receber e-mails do duplistatus.

Configurações de notificação
Passo 4

Deixe o duplistatus monitorar seus backups

O duplistatus faz o monitoramento. Se um backup estiver atrasado ou for concluído com avisos ou erros, você receberá uma notificação ou e-mail.
Para maior tranquilidade, ative o Resumo Diário opcional: você o recebe todos os dias, mesmo quando tudo estiver bem.

Guia do usuário

Seguro por padrão. Adicione mais proteção quando precisar.

O login já vem ativado desde a primeira inicialização, de modo que um homelab privado fica protegido imediatamente. Adicione chaves de API e listas de permissões de IP ao expor para a internet.

Login com funções

Faça login como Administrador ou Usuário. Limite quais servidores cada usuário pode ver.

Chaves de API

Chaves separadas para uploads do Duplicati e para painéis ou widgets somente leitura, com limites de taxa e tamanho de upload.

Listas de permissões de IP

Duas listas de permissões independentes: uma para a interface de administração e outra para APIs externas. Elas protegem contra IPs de clientes forjados quando o duplistatus é executado atrás de um proxy reverso.

Proteção contra CSRF

Rotas baseadas em sessão são protegidas contra cross-site request forgery (CSRF).

Registro de auditoria

Cada alteração de configuração e ação do usuário é registrada. Filtre, exporte e defina por quanto tempo os registros são mantidos.

Logs do aplicativo

Um visualizador exclusivo para administradores permite pesquisar, filtrar e exportar logs do aplicativo, com atualizações em tempo real.

Vai expor para a internet? Execute-o atrás de um proxy reverso com HTTPS. Leia o guia

O duplistatus é um projeto independente e não é afiliado à equipe do Duplicati.

Comece em minutos

Faça o pull da imagem, monte um volume de dados e abra a porta 9666. 

# download the compose file
wget https://github.com/wsj-br/duplistatus/raw/refs/heads/master/production.yml -O duplistatus.yml
# start the container
docker compose -f duplistatus.yml up -d
# duplistatus production compose.yml
services:
  duplistatus:
    image: ghcr.io/wsj-br/duplistatus:latest
    container_name: duplistatus
    restart: unless-stopped
    environment:
      - TZ=Europe/London
      - PWD_ENFORCE=true
      - PWD_MIN_LEN=8
    ports:
      - "9666:9666"
    volumes:
      - duplistatus_data:/app/data
    networks:
      - duplistatus_network

networks:
  duplistatus_network:
    driver: bridge

volumes:
  duplistatus_data:
    name: duplistatus_data
# Create the volume
docker volume create duplistatus_data

# Start the container
docker run -d \
  --name duplistatus \
  -p 9666:9666 \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -v duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest
mkdir -p ~/duplistatus_data
# Start the container (standalone)
podman run -d \
  --name duplistatus \
  --userns=keep-id \
  -e TZ=Europe/London \
  -e LANG=en_GB \
  -p 9666:9666 \
  -v ~/duplistatus_data:/app/data \
  ghcr.io/wsj-br/duplistatus:latest

Depois que o contêiner iniciar:

  1. 1 Abra http://localhost:9666 no seu navegador
  2. 2 Entre com a conta de administrador padrão. Será solicitado que você altere a senha de administrador padrão no primeiro login.
  3. 3 Conecte seus servidores Duplicati seguindo estas instruções e, em seguida, use Coletar Logs de Backup para importar o histórico
  4. 4 Vai expor à internet? Adicione mais proteção ativando chaves de API e listas de permissões de IP, e coloque-o atrás de um proxy reverso com HTTPS.
