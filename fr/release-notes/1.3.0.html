Version 1.3.0

Aperçu​

La version 1.3.0 introduit des politiques de mot de passe configurables, une nouvelle visionneuse de journaux d'application pour les administrateurs, un affichage des jours de la semaine basé sur les paramètres régionaux, et plusieurs améliorations de l'expérience utilisateur. Cette version se concentre sur des outils administratifs améliorés et un meilleur support de l'internationalisation.

Nouvelles fonctionnalités​

Politique de Mot de Passe Configurable​

  • Variables d'environnement de politique de mot de passe : Configurez les exigences de validation des mots de passe via des variables d'environnement :
    • PWD_ENFORCE : Défini sur false pour désactiver les exigences de complexité du mot de passe (majuscules, minuscules, chiffres). Par défaut, toutes les règles sont appliquées. Lorsqu'elles sont désactivées, seule la longueur minimale est appliquée.
    • PWD_MIN_LEN : Définit la longueur minimale du mot de passe en caractères. Par défaut, 8 caractères.
    • La vérification de mot de passe par défaut (empêchant l'utilisation du mot de passe admin par défaut) est toujours appliquée, quelle que soit la configuration de PWD_ENFORCE.

Visionneuse de Journaux d'Application​

  • Nouvelle visionneuse de journaux réservée aux administrateurs : Affichez et téléchargez les journaux d'application directement depuis la page Paramètres :
    • Accédez au fichier application.log consolidé et aux versions de journaux tournés
    • Sélecteur de nombre de lignes configurable (100, 500, 1000, 5000, 10000 lignes)
    • Filtre de recherche en temps réel avec correspondance de texte insensible à la casse
    • Basculer le défilement automatique pour la surveillance des journaux en temps réel avec sondage automatique
    • Copier dans le presse-papiers et exporter les journaux filtrés en tant que fichier texte
    • Affichage des métadonnées du fichier montrant le nombre de lignes, la taille du fichier et l'horodatage de la dernière modification
    • Rotation des journaux au démarrage du conteneur (configurable via LOG_ROTATION_VERSIONS, par défaut : 5)

Guide Utilisateur Contextuel​

  • Bouton d'aide dynamique : Le bouton du Guide Utilisateur dans l'en-tête de l'application ouvre désormais la documentation pertinente pour la page actuelle. L'infobulle se met à jour pour afficher "Aide pour Page Name" afin d'indiquer quelle documentation sera ouverte.

Amélioration de la Configuration du Serveur​

  • Accès rapide à l'interface utilisateur de Duplicati : Un clic droit sur le bouton de configuration du serveur ou sur tout élément du serveur dans le popover de sélection de serveur ouvre l'interface utilisateur héritée de Duplicati (/ngax) dans un nouvel onglet.

🔧 Améliorations​

Affichage des Jours de la Semaine Basé sur les Paramètres Régionaux​

  • Ordre des jours de la semaine internationalisé : L'affichage des jours de la semaine dans le formulaire de surveillance des sauvegardes respecte désormais les paramètres régionaux de votre navigateur. Les jours de la semaine sont affichés dans le bon ordre basé sur les paramètres régionaux (Lundi-Dimanche pour le Royaume-Uni/Europe, Dimanche-Samedi pour les États-Unis/Brasil).

Gestion Améliorée des Erreurs SMTP​

  • Messages d'erreur améliorés : Les messages d'erreur SMTP fournissent désormais des conseils plus précis :
    • Les erreurs d'authentification indiquent clairement les problèmes de nom d'utilisateur/mot de passe
    • Les erreurs de version SSL/TLS sont correctement identifiées
    • Les suggestions de type de connexion n'apparaissent que lorsqu'elles sont réellement pertinentes

Comportement des Notifications Toast​

  • Notifications d'erreur persistantes : Les notifications d'erreur persistent désormais jusqu'à ce qu'elles soient fermées manuellement, garantissant que vous ne manquiez pas de messages d'erreur importants. Les notifications de succès et d'information se ferment automatiquement après 3 secondes.

Tableau des Paramètres de Notification​

  • Mise en page simplifiée : Le tableau des paramètres de notification a été rationalisé avec une colonne combinée "Serveur / Sauvegarde" et des icônes contextuelles indiquant l'état de configuration des destinations supplémentaires.

🚀 Notes de migration​

Depuis la Version 1.2.x​

Quand vous mettez à niveau vers la version 1.3.0 :

  1. Politique de mot de passe : La nouvelle politique de mot de passe impose par défaut toutes les exigences de complexité. Si vous avez besoin d'une politique de mot de passe plus simple, configurez les variables d'environnement PWD_ENFORCE et PWD_MIN_LEN.

  2. Journaux de l'application : Toute la sortie du conteneur (serveur et service cron) est désormais consolidée dans un seul fichier data/logs/application.log.

  3. Rotation des journaux : La rotation des journaux est configurable via la variable d'environnement LOG_ROTATION_VERSIONS (par défaut : 5 versions).

  4. Aucune migration de base de données requise : Cette version ne nécessite aucun changement de schéma de base de données.

Points de terminaison API​

Le point de terminaison API suivant a été introduit dans cette version :

Point de terminaison de la politique de mot de passe​

  • GET /api/auth/password-policy - Renvoie la configuration actuelle de la politique de mot de passe

Points de terminaison des journaux de l'application​

  • GET /api/application-logs - Voir les journaux avec sélection de fichiers et fonctionnalité de suivi
  • GET /api/application-logs/export - Exporter les journaux filtrés en tant que fichier texte

Points de terminaison supprimés​

Les points de terminaison API inutilisés suivants ont été supprimés dans cette version :

  • DELETE /api/backups/[backupId] - Point de terminaison réservé au développement qui n'a jamais été utilisé
  • GET /api/audit-log/stats - Le point de terminaison n'a pas été appelé par la visionneuse de journaux d'audit

  • Version : 1.3.0
  • Système d'exploitation et version
  • Version de Docker/podman
  • Type de conteneur (Docker ou podman/Pod)
  • Messages d'erreur et journaux
  • Étapes pour reproduire
